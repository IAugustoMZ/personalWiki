## Machine Learning Model Development

### Evaluating Model Performance

#### Common Metrics - Classification

- confusion matrix is the foundation for everything

**Metric** | **Description**
--- | ---
Accuracy | the proportion of correctly classified instances. Misleading for imbalance datasets
Precision | how many predicted positives are actually correct. Important when false positives are costly
Recall | How many actual positives were correclty identified. Important when false negatives are costly
$F_1$ score | harmonic mean of precision and recall, used when both false positive and false negatives are costly but the dataset is imbalanced
log loss (cross entropy loss) | compares predicted probability to the actual class labels. Penalizes confident but incorrect predictions heavily. Lower values indicate better calibrated models
ROC AUC | model's ability to distinguishes classes across different thresholds. AUC (area under the curve) closer to 1: indicates a better model. Great to compare models without committing to a specific decision boundary.

#### Common Metrics - Clustering

**Metric** | **Description**
--- | ---
Silhouette Score | how well defined clusters are. Higher values indicate better separation. How close the point is to its own cluster versus the next-nearest cluster. $-1\leq s \leq +1$, where a low silhouette score means clusters bleed into each other
Elbow Method | plots variance within clusters vs the number of cluster to find the elbow point, where adding more clusters doesn't improve separation. K-Means leverages it

- there's no perfect objective answer, domain knowledge usually plays a role

### Hyperparameter Tuning Fundamentals

- hyperaparameters are parameters used to control training process
  - set before training starts
  - anything that is learned from data is not a hyperparameter
- tuning is the process of adjusting the hyperparameters of a model to find the best configuration that maximizes its performance in a given dataset.
