### Data Preparation and Feature Engineering

#### What are Embeddings?

- dense vector representations of data, capturing semantic relationships
  - place similar items cloer together in a lower dimensional space
  - used widely in text, categorical data, images and audio processing
- can be learned from data using neural networks or retrieved from pretrained models
  -  word2vec, fasttext

#### Categorical Enconing

- replace sparse categorical encoding methods with lower-dimensional dense vector representations
  - capture relationships between different categories based on learned patterns
- efficient for high cardinality features and large category sets
- opposite to One Hot Encoding, which does not capture relationships between categories

#### Data Standardization

- process of creating standards and transforming data taken from different source into a consistent format
- benefits
  - improved interpretability
  - prevention of model biases
  - entrance convergence
  - effective regularization
  - facilitates comparison of coefficients
- sensitivity to features scaling may vary according to algorithms
  - sensitive models
    - linear models
    - support vector machines
    - k-nearest neighbors (KNNs)
    - neural networks
  - robust methods
    - decision trees and random forests
    - ensemble models
    - tree-based models
    - principal component analysis (PCA)
- always remember to hold out the test set before applying standardization
  - avoid data leakage
  - may push standardizaed data to feature store
- **Drawbacks**
  - loss of original interpretation
  - challenges in interpreting interaction terms
  - challenges in result interpretation
  - assumption of normally distributed features (i.e. z-scores)
- always a good practice to inspect a sample of the source data
  - null (missing) will not always appear as `null`
