## Machine Learning Model Development

### Summary of Machine Learning Full Lifecycle

**Stage** | **Phase** | **Description**
--- | --- | --- |
Business Problem | Development | Business objective + Machine Learning Objective Framing
Define success criteria | Development | Measurable goals as metrics to determine whether the model is successful |
Data Collection & Preprocessing | Development | Gather, clean, and transform relevant data into features suitable for model training |
Model Training | Development | Train candidate models; iterate on algorithms and hyperparams to optimize performance |
Model Evaluation | Development | Performance on held-out data, compare experiments |
Model Deployment | Production | Package and serve in a production environment |
Model Monitoring | Production | Track model performance on live data, detect drift on degradation, feed insights back into retraining

### Quiz - Machine Learning Model Deployment

**1. Which of the following best describes the difference between supervised and unsupervised learning?** - Supervised learning uses labeled training data; unsupervised learning finds structure in unlabeled data.

**2. In MLflow, what is the primary purpose of setting an experiment before starting a training run?** - It groups all related runs under a named experiment for comparison and reproducibility.

**3. Which statement correctly describes mlflow.sklearn.autolog()?** - It automatically logs parameters, metrics, and the model artifact for scikit-learn estimators without requiring manual mlflow.log_param() calls.

**4. The notebook warns that Genie Code's chat history is finite. What is the recommended practice when working through a long multi-phase notebook?** - Start a new chat thread at natural breakpoints (e.g., between data prep and model training), and re-state key context (table names, DataFrame schemas) when switching topics.

**5. In the Phase 3 feature engineering prompt, the `ColumnTransformer` is configured with two branches. What transformations are applied to categorical and numerical columns respectively?** - OneHotEncoder(handle_unknown='ignore') for categoricals; StandardScaler for numericals.

**6. A classification model achieves 92% overall accuracy on a dataset where 90% of records belong to class 0. What does this suggest?** - Accuracy may be misleading; the model may mostly be predicting the majority class.

**7. After registering the model to Unity Catalog with alias `champion`, the notebook states that a serving endpoint can reference `@champion` instead of a hard-coded version number. What is the operational benefit of this pattern?** - When a newer model version is promoted to the `champion` alias, all downstream endpoints and pipelines update automatically without requiring configuration changes.

**8. During EDA in Phase 1, the churn dataset shows approximately 73% retained (class 0) and 27% churned (class 1). What modeling adjustment does the notebook recommend to address this imbalance?** - Use `class_weight='balanced'` in the RandomForestClassifier to compensate for the imbalanced class distribution.

**9. What are the four phases of the ML workflow demonstrated in the 3.1 Demo notebook, and what is the purpose of each?** - Explore → Iterate → Build → Validate

**10. The custom instructions in `.assistant_instructions.md` include the catalog name, schema, target column, and MLflow experiment path. How does this benefit Genie Code's output?** - It provides project-specific context so Genie Code generates grounded, production-relevant code rather than generic templates — using actual table names, catalog paths, and experiment locations.

**11. In Optuna, what does the `study.optimize(objective, n_trials=50)` call do?** - Runs 50 hyperparameter search trials, each evaluating the objective function and returning a value for Optuna to minimize or maximize.

**12. The demo introduces 'meta-prompting' as a technique for working with Genie Code. What does meta-prompting mean in this context?** - Asking Genie Code to help you write a better, more precise prompt before running the actual task — co-developing the instruction with Genie Code itself.

**13. In the Phase 2 'Iterate' prompt, the notebook explicitly instructs Genie Code: 'Do NOT generate code.' What is the purpose of this instruction?** - To demonstrate that Genie Code can reason analytically — synthesizing EDA findings, recommending modeling strategy, and explaining feature priorities — without producing code.

**14. The demo notebook notes that the `preprocessor` object is not yet fitted after the feature engineering cell runs. When does it actually get fitted?** - Inside the scikit-learn Pipeline during pipeline.fit(X_train, y_train) — the Pipeline calls fit_transform on the preprocessor step automatically.

**15. Which metric should be prioritized when the cost of a false negative significantly outweighs the cost of a false positive — for example, in churn prediction or fraud detection?** - Recall

**16. What is the key difference between grid search and Bayesian hyperparameter optimization?** - Grid search tests all combinations exhaustively; Bayesian optimization uses prior results to guide the search toward promising regions.

**17. What is the role of a model alias such as `champion` in Unity Catalog model registry?** - It pins a specific model version as the production reference, allowing serving endpoints and pipelines to target @champion rather than a hard-coded version number.

**18. What distinguishes Genie Code in Agent Mode from a standard AI code assistant in a Databricks notebook?** - In Agent Mode, Genie Code can read notebook state, execute tool calls (e.g., read DataFrame schemas, inspect variables), insert and run cells, and reason across multiple steps — rather than just generating code snippets in isolation.

**19. In the context of the ML model development process, why is feature engineering typically the most labor-intensive step?** - Because it combines domain expertise, iterative experimentation, and data transformation decisions that directly determine model quality — and must be repeated for each new model or dataset iteration.

**20. The demo loads the `customer_churn` dataset using `spark.table()` joined with `customer_churn_features`. Why is the Feature Store join preferred over directly reading the features table?** - Using the Feature Engineering client preserves feature lineage in Unity Catalog, enabling full traceability from training data to deployed model.
