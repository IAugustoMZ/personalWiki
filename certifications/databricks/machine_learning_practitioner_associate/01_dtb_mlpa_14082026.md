## Introduction to Data Preparation for Machine Learning

### Data Preparation and Feature Engineering

- goal: optimize input quality for accurate model predictions
  - **cleaning and formatting data**: ensure data is in the correct format
    - missing data handling
    - outlier analysis
    - removing uneeded columns
  - **feature engineering**: transformations, aggregations, encoding, create new fetures
- **Feature Engineering**: raw data into a format that allows ML models to extract meaningful patterns and make accurate predictions
  - transform new data for enhanced modeling
  - dimesionality reduction for improved performance
  - simplifying feature engineering
- **Feature Selection: Dropping Columns / Rows**
  - improve model efficiency and effectiveness
    - **irrelevant or redundant features**: the ones that do not contribute significantly or are highly correlated with other services
    - **handling missing values**: high percentage of missing data
    - **computational efficiency**: reduction of dataset size for faster training times
