# Databricks Certified Machine Learning Practitioner Associate

## Machine Learning Operations

### Defining MLOps

- operates over the entire machine learning lifecycle
- end-to-end process
  - **identify business problem:** goal for using machine learning
  - **define sucess criteria:** quantifiable targets
  - **data collection \& preparation:** gather, clean, preprocess and validate its performance
  - **model deployment:** deploy optimal models to handle real-workld operations and continuously changing data, on robust infrastructure
  - **model monitoring:** continuously track model performance and adjust on retrain as necessary
- machine learning lifecycle $\to$ continuous iterative process
  - MLOps $\to$ all-inclusive, holistic approach to managing machine learning systems
  - comprehensive set of processes and automation techniques applied across the full lifecycle
  - manage data, code, and models to improve stability of performance, long-term efficiency in ML Systems
  - ensure systems are reliable and sustainable in production
    - data = foundation $\to$ rigorous management to ensure accuracy, relevance, security
    - code = backbone $\to$ algorithms and computational logic that need continuous integration and deployment
    - models = brain $\to$ lifecycle management from development through deployment and monitoring
- **performance stability**: consistent results across changing data and conditions 
- **long-term efficiency:** optimized resources and processes

#### **Components of MLOps** (set of practices, processes and technologies)

- **DataOps:** around data, increasing speed, governance quality, and collaboration
- **DevOps:** integrate and automate software development for the code behind ML, via production grade Lakeflow jobs
- **ModelOps:** organize and govern the lifecycle of machine learning and artifial intelligence models

#### Responsibilities

**DataOps** | **DevOps** | **ModelOps**
--- | --- | ---
Optimized data processing | Machine Learning is code | Move beyond "model as object"
Centralized data discovery, management, and governance | Continuous Integration and continuous deployment (CI/CD) | Treat model code as software
Ensure data quality | Version control via  git | Treat models as data
Traceable data lineage and monitoring | Production grade Lakeflow jobs | Manage the model lifecycle
--- | Orchestration and Automation | ---

- ModelOps treats models as both code and data, applying DataOps and DevOps principles to ensure models are versioned, validated, and governed through their lifecycle
  - supports compliance, traceability, and continuous improvement
  - models reliable and adaptable

#### Comprehensive MLOps

- the integration of the components
  - data $\to$ models are only as good as the data the train on, requiring through data operations
  - code $\to$ all involves complex algorithms and Lakeflow jobs taht must be managed like any software development project
  - models $\to$ encapsulate both code and data, requiring lifecycle management that spans DataOps and DevOps
- delivers:
  - **performance stability:** models remain reliable as data continuously change
  - **long term efficiency:** operations are sustainable and cost-effective
  - **scalability:** ML solutions can grow with business needs
