# Databricks Certified Machine Learning Practitioner Associate

12 notas sobre preparação de dados, feature engineering, seleção de modelos, treinamento, avaliação, deployment e monitoramento de modelos de machine learning na plataforma Databricks.

## Tópicos cobertos

- Preparação de dados (data cleaning, formatação, handling de valores faltantes, imputation)
- Feature Engineering (transformações, agregações, codificação, redução de dimensionalidade, embeddings)
- Seleção de features (dropping columns/rows, tratamento de valores faltantes, eficiência computacional)
- Data splitting e sampling methods (random sampling, stratified sampling, cross-validation)
- Data encoding (one-hot encoding, label encoding, target encoding, embeddings, categorical encoding)
- Data standardization (scaling, normalization, regularization)
- Spark ML Pipelines (transformers, estimators, reproducible workflows, data leakage prevention)
- Feature Store (Unity Catalog integration, feature management, lineage, discovery, consistency)
- MLflow and ModelServing integration for model training and deployment
- Machine Learning Model Development (supervised/unsupervised/hybrid/reinforcement learning, classification/regression/forecasting)
- ML Lifecycle (business problem, data collection, preprocessing, feature engineering, model training, evaluation, deployment, monitoring)
- MLflow Components (tracking, evaluation, models, registry & deployments, autologging, experiment-run hierarchy)
- Model Evaluation Metrics (regression: R², MAE, MSE, RMSE, MAPE; classification: accuracy, precision, recall, F₁, log loss, ROC AUC; clustering: silhouette score, elbow method)
- Hyperparameter Tuning (fundamentals of controlling training process to maximize model performance; grid/random/Bayesian optimization with Optuna)
- Validation and Cross-Validation (3-way split, k-fold cross-validation for reliable generalization estimates)
- Optuna for Hyperparameter Tuning (framework-agnostic, trial/study/parameter terminology, objective function, dynamic search space, MLflow integration, pruning strategy)
- Genie Code for AI-Assisted ML Development (autonomous AI partner for data teams, data discovery/EDA/training/deployment/monitoring, MCP connections, instructions/skills, end-to-end model development phases)
- Model Deployment (batch inference with SparkUDF/ai_query, streaming/pipeline deployment, real-time Model Serving, MLflow Model Registry, Unity Catalog governance, model aliases, edge deployment with ONNX/TensorFlow Lite)
- Streaming Inference and Lakeflow SDP (pipeline/streaming deployment advantages/limitations, Lakeflow declarative pipelines, streaming tables & materialized views, data quality validation, pipeline observability, AutoLoader continuous ingestion)
- Real-Time Model Serving (deployment fundamentals, challenges of ML infrastructure/tool fragmentation/expert resources, Databricks Model Serving features, serverless compute with autoscaling/GPU support/scale-to-zero, MLflow integration, feature store integration, unified governance)
