# Databricks Certified Machine Learning Practitioner Associate

7 notas sobre preparação de dados, feature engineering, seleção de modelos, treinamento, avaliação e deployment de modelos de machine learning na plataforma Databricks.

## Tópicos cobertos

- Preparação de dados (data cleaning, formatação, handling de valores faltantes, imputation)
- Feature Engineering (transformações, agregações, codificação, redução de dimensionalidade, embeddings)
- Seleção de features (dropping columns/rows, tratamento de valores faltantes, eficiência computacional)
- Data splitting e sampling methods (random sampling, stratified sampling, cross-validation)
- Data encoding (one-hot encoding, label encoding, target encoding, embeddings, categorical encoding)
- Data standardization (scaling, normalization, regularization)
- Spark ML Pipelines (transformers, estimators, reproducible workflows, data leakage prevention)
- Feature Store (Unity Catalog integration, feature management, lineage, discovery, consistency)
- MLflow and ModelServing integration for model training and deployment
- Machine Learning Model Development (supervised/unsupervised/hybrid/reinforcement learning, classification/regression/forecasting)
- ML Lifecycle (business problem, data collection, preprocessing, feature engineering, model training, evaluation, deployment, monitoring)
- MLflow Components (tracking, evaluation, models, registry & deployments, autologging, experiment-run hierarchy)
- Model Evaluation Metrics (regression: R², MAE, MSE, RMSE, MAPE; classification: accuracy, precision, recall, F₁, log loss, ROC AUC; clustering: silhouette score, elbow method)
- Hyperparameter Tuning (fundamentals of controlling training process to maximize model performance)
