##### What is a DAB?

- declarative automation bundle is Databrick's approach to Infrastructure-as-Code (IaC)
  - collection of Databricks artifacts (jobs, ML models, SDP pipelines, clusters) and assets (Python files, notebooks, SQL queries, dashaboards)
  - configured through YAML files and can be co-versioned in the same reposoitory as the assets they reference
  - use the Databricks CLI, bundles can be materialized across multiple workspaces (dev / staging / prod) enabling teams to integrate them into their automation and CI/CD processes
- essential for reliable, scalable Databricks deployments
  - use YAML to standardize and version both code and infrastructure, supporting compliance and auditability
  - team can quickly iterate, update, and rollback deployments across dev, staging, and production environments
  - custom bundle templates enforce organizational standards and enable seamless CI/CD integration
