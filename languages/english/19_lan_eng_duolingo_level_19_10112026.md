# Inglês · Duolingo — Nível 19

> **Tema oficial:** Peça ajuda para fazer compras · **Seção 2, Unidade 9** · Curso: Inglês para falantes de português

## Visão geral

Neste nível você **pede ajuda numa loja**: procura um produto, pergunta o preço, pede outro tamanho ou cor, quer provar uma peça e paga no caixa. Entram **`Do you have…?`**, **`How much is / are…?`**, **`I'm looking for…`**, **`I'd like…`**, os demonstrativos **`this / that / these / those`**, o pronome **`one / ones`** e os números de preço.

```text
Excuse me, do you have this shirt in a larger size?     →  Com licença, vocês têm esta camisa em um tamanho maior?
How much are these shoes?                               →  Quanto custam estes sapatos?
Can I try it on? Where is the fitting room?             →  Posso experimentar? Onde fica o provador?
```

Ideias centrais:

1. Procurar: `I'm looking for…`, `Do you have…?`, `Where can I find…?`.
2. Preço: `How much is it?` (singular) e `How much are they?` (plural).
3. Provar: `try on` (separável): `try it on`.
4. Pedir educadamente: `Could you…?`, `I'd like…`.

## Gramática em exemplos

### 1. `This`, `that`, `these`, `those`

| Distância | Singular | Plural |
|---|---|---|
| perto | this | these |
| longe | that | those |

| Exemplo | Tradução |
|---|---|
| This jacket is nice. | Esta jaqueta é bonita. |
| How much is that dress? | Quanto custa aquele vestido? |
| These jeans are too long. | Esta calça jeans é comprida demais. |
| Those shoes are cheap. | Aqueles sapatos são baratos. |

### 2. `How much is…?` e `How much are…?`

| Quando | Estrutura | Exemplo |
|---|---|---|
| singular | How much is + substantivo? | How much is this hat? |
| plural | How much are + substantivo? | How much are these socks? |
| resposta | It's + valor / They're + valor | It's ten dollars. / They're five dollars. |

- `Jeans`, `shoes`, `pants`, `shorts`, `glasses` são plurais: `How much are these jeans?`

### 3. `Do you have…?`

| Pergunta | Resposta |
|---|---|
| Do you have this in red? | Yes, we do. / No, we don't. |
| Do you have any other colors? | Yes, we have blue and green. |
| Do you have a smaller size? | Sorry, we don't. |

- Com `do`, a resposta curta repete `do`: `Yes, we do.`
- `Any` é usado em perguntas e negativas: `Do you have any belts?` / `We don't have any belts.`

### 4. `I'm looking for…` e `I'd like…`

| Estrutura | Exemplo | Uso |
|---|---|---|
| I'm looking for + substantivo | I'm looking for a gift. | procurar |
| I'm just looking. | Estou só olhando. | recusar ajuda |
| I'd like + substantivo | I'd like this scarf. | pedir educadamente |
| I'd like to + verbo | I'd like to try this on. | pedir educadamente |
| I want… | I want a new bag. | mais direto |

- `I'd` = `I would`. `I'd like` é mais polido que `I want`.

### 5. Verbos frasais: `try on`, `look for`, `pick up`

| Verbo | Exemplo |
|---|---|
| try on | Can I try on this shirt? / Can I try it on? |
| look for | I'm looking for black shoes. |
| pick up | I'd like to pick up my order. |
| take (levar) | I'll take the blue one. |

- Com pronome, `try on` se separa: `try it on` (nunca *try on it*).

### 6. `One` e `ones` para não repetir

| Frase | Exemplo |
|---|---|
| Qual? — o azul | Which one? The blue one. |
| Singular | I like this one. |
| Plural | I prefer the black ones. |
| Com adjetivo | Do you have a cheaper one? |

- `One` substitui um substantivo contável singular; `ones`, o plural.

### 7. Comparativos para preços e tamanhos

| Adjetivo | Comparativo | Exemplo |
|---|---|---|
| cheap | cheaper | This bag is cheaper. |
| big | bigger | I need a bigger size. |
| small | smaller | Do you have a smaller one? |
| long | longer | These pants are longer. |
| expensive | more expensive | That coat is more expensive. |
| good | better | These shoes are better. |

- Adjetivos curtos recebem `-er`; os longos usam `more`. `Big` duplica o `g`: `bigger`.
- Para comparar: `than`. Exemplo: `This jacket is cheaper than that one.`

### 8. `Too` e `enough`

| Estrutura | Exemplo |
|---|---|
| too + adjetivo | It's too small. |
| adjetivo + enough | It isn't big enough. |
| too much / too many | It costs too much. |

- `Too` = demais (excesso, problema). Para "muito" positivo use `very`: `very nice`.

### 9. Números e preços

| Valor | Inglês |
|---|---|
| $5 | five dollars |
| $12.50 | twelve dollars and fifty cents / twelve fifty |
| $19.99 | nineteen ninety-nine |
| $100 | one hundred dollars |
| £30 | thirty pounds |
| 50% off | fifty percent off |

- O ponto decimal é usado em inglês: `$12.50`; em português usamos vírgula.
- `Cent` / `cents`: centavos.

### 10. Contáveis e incontáveis com `some` e `any`

| Estrutura | Exemplo |
|---|---|
| some (afirmativa) | I want some socks. |
| any (pergunta / negativa) | Do you have any socks? / We don't have any. |
| How many (contável) | How many shirts do you want? |
| How much (incontável) | How much money do you have? |

- `Money` é incontável (*a money* está errado); `clothes` só existe no plural (*a clothes* está errado): `These clothes are new.`

## Diálogos

### Diálogo 1 — Procurando uma jaqueta

- Clerk: Hello! Can I help you?
- Customer: Yes, I'm looking for a black jacket.
- Clerk: What size are you?
- Customer: I'm a medium.

### Diálogo 2 — No provador

- Customer: Can I try this on?
- Clerk: Of course. The fitting room is over there.
- Customer: It's too tight. Do you have a larger size?
- Clerk: Yes, here you are.

### Diálogo 3 — No caixa

- Cashier: That's forty-five dollars.
- Customer: Can I pay by card?
- Cashier: Sure. Do you want a bag?
- Customer: Yes, please. And the receipt, too.

## Pontos de atenção e erros comuns

- **`How much is it?`**, não *How much costs it?*: o verbo `be` faz a pergunta de preço.
- **Plurais de roupas**: `jeans`, `pants`, `shorts`, `shoes` são plurais — `these jeans`, `they are`.
- **`Try it on`**: com pronome, o `it` fica no meio do verbo frasal.
- **Falso amigo**: `costume` = fantasia (para festas); "roupa" é `clothes` ou `outfit`; "terno" é `suit`.
- **Falso amigo**: `magazine` = revista; "loja" é `store` ou `shop`.
- **`Pants` (EUA) x `pants` (UK)**: nos EUA `pants` = calça; no Reino Unido `pants` costuma ser cueca/calcinha, e calça é `trousers`.
- **`Cheap` x barato**: `cheap` pode soar "de má qualidade"; para algo bom e em conta, `affordable` ou `reasonable`.
- **`Change`**: em lojas = troco; também significa "mudar" e "trocar de roupa".
- **`Sneakers`** nos EUA e `trainers` no Reino Unido são tênis.
- **`Much` x `many`**: `much` com incontáveis (`money`), `many` com contáveis (`shirts`).

## Complete as lacunas

1. How much ____ these jeans? (são) → `are`
2. Do you ____ this in blue? (ter) → `have`
3. I'd ____ this dress, please. (gostaria) → `like`
4. Can I try it ____ ? (experimentar) → `on`
5. This bag is ____ than that one. (mais barato) → `cheaper`
6. I'm ____ a gift. (procurando) → `looking for`
