# Inglês · Duolingo — Nível 9

> **Tema oficial:** Fale sobre o tempo · **Seção 1, Unidade 9** · Curso: Inglês para falantes de português

## Visão geral

Neste nível você aprende a **falar sobre o tempo (clima)** em inglês. O verbo-chave é **`to be`** com o sujeito vazio **`it`**: `It is sunny`, `It is cold`. Também entram o **`It's raining` / `It's snowing`** (presente contínuo), as **estações**, os **meses**, os **dias da semana** e a **roupa** e as **atividades** adequadas a cada clima.

```text
It is sunny and hot today.                          →  Está ensolarado e quente hoje.
It rains a lot in spring.                           →  Chove muito na primavera.
What's the weather like in London?                  →  Como está o tempo em Londres?
```

Ideias centrais:

1. Em inglês a frase precisa de sujeito: use **`it`** (`It is cold`, não `Is cold`).
2. Para o clima agora: `It's raining.` Para o hábito: `It rains a lot in autumn.`
3. Pergunte com **`What's the weather like?`** ou **`How's the weather?`**.

## Gramática em exemplos

### 1. `It` como sujeito do clima

| Português | Inglês |
|---|---|
| Está frio. | It is cold. |
| Está quente. | It is hot. |
| Está ensolarado. | It is sunny. |
| Está nublado. | It is cloudy. |
| São 10 horas. | It is ten o'clock. |

- `It` não tem tradução: o português omite o sujeito, o inglês não pode.
- Errado: *Is cold today.* Certo: **It is cold today.**

### 2. Verbo `to be` com clima (afirmativa, negativa, pergunta)

| Tipo | Exemplo |
|---|---|
| Afirmativa | It is warm. |
| Negativa | It is not warm. / It isn't warm. |
| Pergunta | Is it warm? |
| Resposta curta (sim) | Yes, it is. |
| Resposta curta (não) | No, it isn't. |

### 3. Clima como adjetivo ou como verbo

| Com `to be` + adjetivo | Com verbo |
|---|---|
| It is rainy. | It rains. |
| It is snowy. | It snows. |
| It is windy. | The wind blows. |
| It is sunny. | The sun shines. |

- Para chuva e neve, os dois jeitos existem: `It is rainy today` e `It rains a lot here`.

### 4. Presente simples × presente contínuo

| Uso | Exemplo | Tradução |
|---|---|---|
| Hábito, fato geral | It rains a lot in spring. | Chove muito na primavera. |
| Agora | It is raining now. | Está chovendo agora. |
| Fato geral | It snows in Canada. | Neva no Canadá. |
| Agora | It's snowing outside. | Está nevando lá fora. |

- Contínuo = `to be` + verbo com **-ing**: `raining`, `snowing`.

### 5. Perguntas sobre o tempo

| Pergunta | Resposta possível |
|---|---|
| What's the weather like? | It's sunny and warm. |
| How's the weather? | It's cloudy. |
| What's the temperature? | It's twenty degrees. |
| Is it cold today? | Yes, it is. |
| Is it going to rain? | I think so. |
| What's the weather like in winter? | It's cold and snowy. |

- `What's ... like?` pede uma descrição. Não use *What is the weather doing?*.

### 6. Estações e meses com preposições

| Estrutura | Exemplo |
|---|---|
| in + estação | in summer; in the winter |
| in + mês | in July; in December |
| on + dia da semana | on Monday; on Friday |
| in the morning / afternoon / evening | in the morning |
| at night | at night |

- **Meses e dias** levam letra maiúscula (`July`, `Monday`); **estações** não (`summer`).

### 7. Adjetivos de intensidade

| Intensidade | Exemplo |
|---|---|
| a little | It's a little cold. |
| quite | It's quite warm. |
| very | It's very hot. |
| really | It's really windy. |
| too | It's too cold to swim. |
| not very | It's not very sunny. |

### 8. Comparativos de clima

| Estrutura | Exemplo |
|---|---|
| adjetivo curto + -er than | Today is colder than yesterday. |
| adjetivo curto + -er than | Summer is hotter than spring. |
| more + adjetivo longo | July is more humid than May. |
| as ... as | It's as warm as yesterday. |
| irregular: better | The weather is better today. |

- Adjetivo curto: `cold → colder`, `hot → hotter` (dobra o t), `warm → warmer`.

### 9. Futuro com `going to`

| Estrutura | Exemplo |
|---|---|
| am/is/are going to + verbo | It is going to rain. |
| Negativa | It isn't going to snow. |
| Pergunta | Is it going to be sunny? |
| Com tempo | It's going to be cold tomorrow. |

- Depois de `going to`, use o verbo **sem** -s: `It is going to rain`, não *It is going to rains*.

### 10. Roupa e decisões conforme o clima

| Situação | Frase |
|---|---|
| Chuva | It's raining, so I need an umbrella. |
| Frio | It's freezing, so I wear a coat and gloves. |
| Sol | It's sunny, so I wear sunglasses. |
| Calor | It's hot, so I wear shorts. |
| Neve | It's snowing, so I put on my boots. |

- `so` = então, por isso. `because` = porque: `I wear a coat because it's cold.`

## Diálogos

### Diálogo 1 — Hoje

- Ana: What's the weather like today?
- Tom: It's cloudy and a little cold.
- Ana: Is it going to rain?
- Tom: Yes, I think it is. Take an umbrella.

### Diálogo 2 — Estações

- Lia: What's your favorite season?
- Ben: I love summer. It's hot and sunny.
- Lia: I prefer autumn. It's cool and the trees are beautiful.
- Ben: Does it rain a lot in autumn?
- Lia: Yes, it does. It rains a lot in October.

### Diálogo 3 — Planos para o fim de semana

- Sam: What's the forecast for Saturday?
- Eva: It's going to be sunny and warm.
- Sam: Great! Let's go to the beach.
- Eva: Good idea. I need sunscreen and sunglasses.
- Sam: And what about Sunday?
- Eva: It's going to rain, so we stay home.

## Pontos de atenção e erros comuns

- **Sujeito obrigatório**: `It is cold`, nunca *Is cold*. O português omite o sujeito; o inglês não.
- **`Hot` não é `quente` em tudo**: `hot` = muito quente; para temperatura agradável use `warm`. Para objetos e comida, `hot` = quente.
- **Não use *do/does* com `to be`**: *Does it is cold?* é errado; diga `Is it cold?`.
- **Presente simples × contínuo**: `It rains in April` (hábito) × `It's raining now` (agora).
- **Maiúsculas**: `Monday`, `July`, `January` levam letra maiúscula em inglês; no português são minúsculas.
- **Preposição**: `in July`, `in summer`, mas `on Monday`. Não diga *in Monday*.
- **Terceira pessoa**: `It rains`, `It snows`, `It snows a lot` — o verbo leva **-s** com `it`.
- **`Weather` × `whether`**: `weather` = tempo (clima); `whether` = se (conjunção). Pronúncia parecida, significado diferente.
- **`Cold` com pessoas**: `It is cold` (o tempo está frio) e `I am cold` (eu estou com frio). Para "estou resfriado" diga `I have a cold` (com o artigo `a`).
