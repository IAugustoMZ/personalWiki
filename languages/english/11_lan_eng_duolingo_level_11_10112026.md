# Inglês · Duolingo — Nível 11

> **Tema oficial:** Saia para comprar roupas · **Seção 2, Unidade 1** · Curso: Inglês para falantes de português

## Visão geral

Neste nível você **vai às compras de roupas**: aprende peças de vestuário, cores, tamanhos, preços e como pedir ajuda numa loja. Entram **`this / that / these / those`**, **`How much is / are...?`**, **`I'd like...`**, **`try on`**, **`too big / too small`**, **`wear`** × **`put on`** e **comparativos** simples.

```text
How much are these jeans?                            →  Quanto custam estas calças jeans?
Can I try on this jacket? It's too small.            →  Posso experimentar esta jaqueta? Está pequena demais.
I'd like a bigger size, please.                      →  Eu gostaria de um tamanho maior, por favor.
```

Ideias centrais:

1. Singular `this / that`; plural `these / those`.
2. Preço: `How much is it?` (singular) e `How much are they?` (plural).
3. Roupas de duas pernas ou dois lados (`jeans`, `pants`, `shorts`, `glasses`) são **plurais**.

## Gramática em exemplos

### 1. `This / that / these / those`

| | Perto | Longe |
|---|---|---|
| Singular | this shirt | that shirt |
| Plural | these shoes | those shoes |

| Exemplo | Tradução |
|---|---|
| I like this jacket. | Gosto desta jaqueta. |
| I don't like that color. | Não gosto daquela cor. |
| These socks are warm. | Estas meias são quentes. |
| Those boots are expensive. | Aquelas botas são caras. |

- Em inglês só há dois graus (perto/longe), não três como no português (este/esse/aquele).

### 2. Preço: `How much is / are...?`

| Singular | Plural |
|---|---|
| How much is this shirt? | How much are these jeans? |
| It is twenty dollars. | They are sixty dollars. |

- Respostas: `It's twenty dollars.` (singular) e `They're sixty dollars.` (plural).
- Plurais: `jeans`, `shoes`, `socks`, `pants` → `are` e `they`.

### 3. Roupas sempre no plural

| Sempre plural | Para falar de uma peça |
|---|---|
| jeans | a pair of jeans |
| pants / trousers | a pair of pants |
| shorts | a pair of shorts |
| glasses | a pair of glasses |
| pajamas | a pair of pajamas |

| Exemplo | Tradução |
|---|---|
| These jeans are new. | Esta calça jeans é nova. |
| I need a new pair of shoes. | Preciso de um par de sapatos novo. |

- `Pair` = par. `Two pairs of jeans` = duas calças jeans.

### 4. `I'd like` e `I want`

| Forma | Tom | Exemplo |
|---|---|---|
| I'd like (= I would like) | educado | I'd like a larger size. |
| I want | direto, menos formal | I want a red dress. |
| Can I have...? | informal educado | Can I have a bag? |
| I'm looking for... | procurando | I'm looking for sneakers. |

- Com `I'd like`, o verbo seguinte leva `to`: `I'd like to try it on`.

### 5. `Wear` × `put on` × `try on`

| Verbo | Sentido | Exemplo |
|---|---|---|
| wear | estar usando; usar habitualmente | She wears a red hat. |
| put on | vestir (ação de colocar) | Put on your coat. |
| take off | tirar | Take off your shoes. |
| try on | experimentar | I want to try on these jeans. |
| be wearing | estar usando agora | He is wearing a blue shirt. |

### 6. Presente contínuo para descrever o que se usa

| Frase | Tradução |
|---|---|
| She is wearing a green dress. | Ela está usando um vestido verde. |
| They are wearing black shoes. | Eles estão calçando sapatos pretos. |
| I am not wearing a hat. | Não estou usando chapéu. |
| What are you wearing? | O que você está vestindo? |

- Presente simples = hábito: `I wear sneakers every day`. Contínuo = agora: `I am wearing sneakers`.

### 7. `Too` + adjetivo

| Frase | Tradução |
|---|---|
| It's too big. | É grande demais. |
| They are too tight. | Estão apertadas demais. |
| This skirt is too short. | Esta saia é curta demais. |
| That coat is too expensive. | Aquele casaco é caro demais. |

- `Too` vem **antes** do adjetivo. `Too` ≠ `very`: `very big` = muito grande (neutro); `too big` = grande demais (problema).

### 8. Comparativos

| Tipo | Estrutura | Exemplo |
|---|---|---|
| curto | adj + -er than | This shirt is cheaper than that one. |
| curto | adj + -er than | These boots are bigger than my size. |
| longo | more + adj + than | This dress is more expensive than that skirt. |
| irregular | better / worse | This color is better. |
| igualdade | as + adj + as | It's as nice as the red one. |

- Dobra a consoante: `big → bigger`. Termina em -y: `y → ier` (`heavy → heavier`). Termina em -e: só `-r` (`large → larger`).

### 9. Pronomes `one` / `ones`

| Frase | Tradução |
|---|---|
| I like the blue one. | Gosto do azul. |
| Do you have a bigger one? | Tem um maior? |
| I prefer the black ones. | Prefiro os pretos. |
| Which ones do you like? | De quais você gosta? |

- `One` substitui um substantivo singular; `ones`, um plural.

### 10. Números e preços em dólares

| Preço | Como se diz |
|---|---|
| $5 | five dollars |
| $12.50 | twelve dollars and fifty cents / twelve fifty |
| $20 | twenty dollars |
| $49.99 | forty-nine ninety-nine |
| $100 | one hundred dollars |
| 50% off | fifty percent off |

- `Dollar` e `cent` ganham `-s` no plural: `ten dollars`, `fifty cents`.

## Diálogos

### Diálogo 1 — Procurando uma jaqueta

- Clerk: Can I help you?
- Customer: Yes, I'm looking for a black jacket.
- Clerk: What size do you wear?
- Customer: I wear a medium.
- Clerk: Here you are. The fitting room is over there.

### Diálogo 2 — No provador

- Customer: This jacket is too small. Do you have a large?
- Clerk: Yes, we have it in a large.
- Customer: Great. How much is it?
- Clerk: It's sixty dollars. It's on sale.
- Customer: Perfect. I'll take it.

### Diálogo 3 — Pagando

- Clerk: Will that be all?
- Customer: Yes. How much are these socks?
- Clerk: They are five dollars.
- Customer: Can I pay by card?
- Clerk: Of course. Here is your receipt. Do you need a bag?

## Pontos de atenção e erros comuns

- **`Jeans`, `pants`, `shorts`, `glasses` são plurais**: `These jeans are blue`; `a jeans` está errado, diga `a pair of jeans`.
- **`Wear` não é "usar" em todos os sentidos**: para ferramentas diga `use`; para roupa, `wear`.
- **`Try on` é verbo frasal**: `I want to try on this dress`, ou `try it on`; com pronome fica no meio.
- **`Too` × `very`**: `too big` indica problema; `very big` só descreve.
- **Falso amigo**: `costume` = fantasia; `suit` = terno.
- **`Cloth` × `clothes`**: `cloth` = tecido/pano; `clothes` = roupas (sempre plural, sem singular `a clothes`).
- **Adjetivos não têm plural**: `blue shoes`, não *blues shoes*.
- **Tamanho de sapato**: `What shoe size do you wear?`; diga `size 9`, não *number 9*.
- **Preço com `much`**: `How much is it?`; `How many` é só para contáveis (`How many shirts?`).

## Complete as lacunas

1. How much ____ these shoes? (are / is) → `are`
2. I like ____ jacket here. (this / these) → `this`
3. It's ____ big for me. (too / very) → `too`
4. She ____ a red dress now. (is wearing) → `is wearing`
5. I ____ like a larger size. (would) → `'d` / `would`
6. A pair ____ jeans. (of) → `of`
