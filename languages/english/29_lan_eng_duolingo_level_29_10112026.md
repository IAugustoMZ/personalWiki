# Inglês · Duolingo — Nível 29

> **Tema oficial:** Saia para comprar roupas · **Seção 2, Unidade 19** · Curso: Inglês para falantes de português

## Visão geral

Este nível volta ao tema das **compras de roupas**, agora com um novo enfoque: **tamanhos e caimento**, **provador**, **promoções**, **comparar peças**, **trocas e devoluções** e **pagamento**. Entram `too` / `enough`, **comparativos** (`cheaper than`), **`try on`**, **`fit`** e o **modal `can` / `could`** para pedir ajuda ao vendedor.

```text
Can I try this on? What size is it?                           →  Posso experimentar isto? Que tamanho é?
It's too big. Do you have a smaller size?                     →  Está grande demais. Você tem um tamanho menor?
This jacket is cheaper than that one. I'll take it.           →  Esta jaqueta é mais barata que aquela. Vou levar.
```

Ideias centrais:

1. `Try on` = experimentar roupa; `fit` = caber/servir.
2. `Too` + adjetivo = demais (problema); `enough` = suficiente.
3. Comparar: adjetivo curto + `-er than`; adjetivo longo: `more … than`.

## Gramática em exemplos

### 1. `Try on` e o pronome

| Frase | Tradução |
|---|---|
| Can I try this on? | Posso experimentar isto? |
| Can I try on this shirt? | Posso experimentar esta camisa? |
| I want to try them on. | Quero experimentá-los. |

- Com pronome, ele fica **no meio**: `try it on`, `try them on` (não `try on it`).

### 2. `Fit`, `suit` e `look good on`

| Verbo | Sentido | Exemplo |
|---|---|---|
| fit | servir no tamanho | This shirt fits me. |
| suit | combinar com a pessoa | Blue suits you. |
| look good on | ficar bem em | That dress looks good on you. |

- `The shirt doesn't fit` = não serve; `The colour doesn't suit me` = a cor não combina comigo.

### 3. `Too` + adjetivo

| Frase | Tradução |
|---|---|
| It's too small. | É pequeno demais. |
| These shoes are too tight. | Estes sapatos estão apertados demais. |
| The coat is too expensive. | O casaco é caro demais. |
| It's too long for me. | É comprido demais para mim. |

- `Too` tem sentido de "demais", negativo. Para "muito" (neutro), use `very`: `very nice`.

### 4. `Enough` e `not … enough`

| Frase | Tradução |
|---|---|
| The jacket is big enough. | A jaqueta é grande o bastante. |
| It's not long enough. | Não é comprida o suficiente. |
| I don't have enough money. | Não tenho dinheiro suficiente. |

- `Enough` vem **depois do adjetivo** (`big enough`) e **antes do substantivo** (`enough money`).

### 5. Comparativos

| Tipo | Regra | Exemplo |
|---|---|---|
| Adjetivo curto | + -er than | cheaper than, smaller than |
| Termina em -e | + -r | nice → nicer |
| Consoante + y | y → -ier | pretty → prettier |
| Adjetivo longo | more … than | more expensive than |
| Irregulares | | good → better, bad → worse |
| Igualdade | as … as | as cheap as |

| Frase | Tradução |
|---|---|
| This dress is cheaper than that one. | Este vestido é mais barato que aquele. |
| Those boots are more comfortable than these. | Aquelas botas são mais confortáveis que estas. |
| These shoes are as nice as those. | Estes sapatos são tão bonitos quanto aqueles. |

### 6. Superlativos

| Frase | Tradução |
|---|---|
| This is the cheapest jacket. | Esta é a jaqueta mais barata. |
| That is the most expensive coat in the shop. | Aquele é o casaco mais caro da loja. |
| She has the best style. | Ela tem o melhor estilo. |

### 7. `Which one?` e `one / ones`

| Frase | Tradução |
|---|---|
| Which one do you like? | De qual você gosta? |
| I like the red one. | Gosto do vermelho. |
| I prefer the black ones. | Prefiro os pretos. |
| This one or that one? | Este ou aquele? |

- `One` substitui um substantivo singular; `ones` o plural.

### 8. Pedidos educados: `can`, `could`, `would like`

| Estrutura | Exemplo |
|---|---|
| Can I + base? | Can I try this on? |
| Could I + base? | Could I have a bigger size? |
| I'd like + substantivo | I'd like a medium. |
| I'd like to + base | I'd like to return this. |
| Do you have…? | Do you have it in black? |

### 9. Preços e descontos

| Expressão | Exemplo |
|---|---|
| It costs / It's … | It costs forty dollars. |
| How much is it? / How much are they? | How much are these shoes? |
| X percent off | It's twenty percent off. |
| on sale | These jeans are on sale. |
| half price | The scarf is half price. |
| buy one, get one free | These T-shirts are buy one, get one free. |

- Singular: `How much **is** this?`; plural: `How much **are** these?`

### 10. Troca e devolução: tempo e condição

| Frase | Tradução |
|---|---|
| You can return it within thirty days. | Você pode devolver em até trinta dias. |
| Keep the receipt. | Guarde o recibo. |
| I'd like a refund. | Gostaria de um reembolso. |
| It's the wrong size. | É o tamanho errado. |
| It's faulty. | Está com defeito. |

## Diálogos

### Diálogo 1 — No provador

- Customer: Excuse me, can I try this on?
- Assistant: Of course. The fitting room is over there.
- Customer: Thanks. ... It's too small. Do you have a large?
- Assistant: Let me check. Yes, here you are.

### Diálogo 2 — Comparando

- Mia: Which jacket do you like?
- Leo: I like the black one. It's cheaper than the blue one.
- Mia: It's also warmer. Is it on sale?
- Leo: Yes, it's thirty percent off. I'll take it.

### Diálogo 3 — Devolução

- Customer: I'd like to return this shirt. It doesn't fit.
- Cashier: Do you have the receipt?
- Customer: Yes, here it is.
- Cashier: You can exchange it for a different size or get store credit.

## Pontos de atenção e erros comuns

- **`Try on` com pronome**: `Try it on`, nunca `Try on it`.
- **`Too` x `very`**: `too small` = pequeno demais (problema); `very small` = muito pequeno (neutro).
- **`Enough` depois do adjetivo**: `big enough`, não `enough big`.
- **`How much is` / `How much are`**: concorde com o objeto: `How much are the shoes?`.
- **Falso amigo**: `costume` em inglês é fantasia, não "costume"; roupa é `clothes` / `clothing`.
- **`Clothes` é sempre plural**: `These clothes are new`; para uma peça, `a piece of clothing` ou `an item`.
- **`Pants` (AmE) = calça**, com verbo no plural: `These pants are long`; em inglês britânico, `trousers`.
- **`Wear` para roupa e tamanho**: `I wear a medium`, `What size do you wear?`; não use `use` nem `put` para o tamanho.
- **`Cheap` pode soar negativo** (de baixa qualidade); para neutro, `inexpensive` ou `affordable`.

## Complete as lacunas

1. Can I try this ____? (on / in) → `on`
2. It's ____ small for me. (too / very, sentido de demais) → `too`
3. This coat is ____ than that one. (cheaper / more cheap) → `cheaper`
4. These shoes don't ____ me. (fit / suit, tamanho) → `fit`
5. How much ____ these jeans? (is / are) → `are`
6. I don't have ____ money. (enough / enough of) → `enough`
