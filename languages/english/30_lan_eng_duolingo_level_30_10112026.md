# Inglês · Duolingo — Nível 30

> **Tema oficial:** Forme o plural irregular de substantivos · **Seção 2, Unidade 20** · Curso: Inglês para falantes de português

## Visão geral

Neste nível você estuda o **plural irregular** dos substantivos em inglês. A regra comum é acrescentar **`-s`** (`book → books`), `-es` (`box → boxes`) ou trocar `-y` por `-ies` (`city → cities`). Mas muitas palavras comuns **mudam a vogal** (`man → men`), **trocam `-f / -fe` por `-ves`** (`knife → knives`), **não mudam** (`sheep → sheep`) ou vêm do latim/grego (`criterion → criteria`). O foco aqui são as formas que você precisa **memorizar**.

```text
One man, two men. One child, three children.                      →  Um homem, dois homens. Uma criança, três crianças.
My feet hurt and my teeth hurt too.                               →  Meus pés doem e meus dentes também.
There are many people, but only one sheep.                        →  Há muitas pessoas, mas só uma ovelha.
```

Ideias centrais:

1. Plural regular: `-s`, `-es`, `-ies`. Irregular: forma própria que muda a palavra.
2. Alguns substantivos têm **a mesma forma** no singular e no plural (`fish`, `sheep`, `deer`).
3. O verbo concorda com o plural: `The men are here`, `The children play`.

## Gramática em exemplos

### 1. Plurais regulares (para comparar)

| Regra | Exemplo |
|---|---|
| maioria: + s | book → books |
| termina em s, x, z, ch, sh: + es | box → boxes, watch → watches |
| consoante + y: y → ies | city → cities, baby → babies |
| vogal + y: + s | day → days, boy → boys |

- O plural irregular é tudo o que **foge** destas regras.

### 2. Mudança de vogal

| Singular | Plural |
|---|---|
| man | men |
| woman | women |
| foot | feet |
| tooth | teeth |
| goose | geese |
| mouse | mice |

- `woman` → `women`: a pronúncia muda (/ˈwʊmən/ → /ˈwɪmɪn/).
- Compostos seguem o mesmo padrão: `policeman → policemen`, `businesswoman → businesswomen`.

### 3. `Child → children`, `ox → oxen`

| Singular | Plural | Exemplo |
|---|---|---|
| child | children | The children are happy. |
| ox | oxen | Two oxen pull the cart. |

- Estas formas terminam em `-en`, um resquício do inglês antigo.

### 4. `Person → people`

| Frase | Tradução |
|---|---|
| One person is waiting. | Uma pessoa está esperando. |
| Two people are waiting. | Duas pessoas estão esperando. |
| Many people like music. | Muitas pessoas gostam de música. |

- `People` é plural e leva verbo no plural: `People are`, nunca `People is`.
- `Persons` existe, mas é formal/jurídico e raro no dia a dia.

### 5. `-f` / `-fe` → `-ves`

| Singular | Plural |
|---|---|
| wife | wives |
| knife | knives |
| life | lives |
| leaf | leaves |
| shelf | shelves |
| wolf | wolves |
| thief | thieves |
| half | halves |
| loaf | loaves |
| calf | calves |

- O som final muda de /f/ para /v/: `knife` /naɪf/ → `knives` /naɪvz/.

### 6. Exceções: `-f` com plural em `-s`

| Singular | Plural |
|---|---|
| roof | roofs |
| chief | chiefs |
| belief | beliefs |
| cliff | cliffs |
| chef | chefs |
| safe | safes |

- Nem toda palavra em `-f` segue o padrão `-ves`; vale decorar.

### 7. Substantivos que não mudam

| Singular e plural | Exemplo |
|---|---|
| fish | I have one fish. / I have two fish. |
| sheep | One sheep is white; three sheep are black. |
| deer | A deer is in the garden. / Five deer are in the garden. |
| series | This series is good. / These series are good. |
| species | One species / many species |
| aircraft | The aircraft is old. / Two aircraft landed. |

- `Fish` é usado como plural de peixes em geral; `fishes` aparece só em contextos técnicos para espécies diferentes.

### 8. Substantivos em `-o`

| Termina em -o | Plural com -es | Plural com -s |
|---|---|---|
| potato | potatoes | |
| tomato | tomatoes | |
| hero | heroes | |
| photo | | photos |
| piano | | pianos |
| radio | | radios |

- Se a palavra é abreviação (`photo`, `piano`) ou termina em vogal + `o` (`radio`, `zoo`), em geral só `-s`.

### 9. Plurais de origem latina ou grega

| Singular | Plural |
|---|---|
| criterion | criteria |
| phenomenon | phenomena |
| analysis | analyses |
| crisis | crises |
| basis | bases |
| cactus | cacti (ou cactuses) |

- `Analyses` e `crises` terminam em `-es`, mas na pronúncia o final é /iːz/.

### 10. Sempre plural e concordância verbal

| Palavra | Exemplo |
|---|---|
| people | People are friendly. |
| police | The police are here. |
| scissors | The scissors are on the desk. |
| jeans / trousers | My jeans are blue. |
| glasses | Her glasses are new. |
| news (singular) | The news is good. |

- `Scissors`, `jeans`, `trousers` e `glasses` pedem verbo no plural; para contar, use `a pair of`: `two pairs of jeans`.
- `News` termina em -s, mas é **incontável singular**: `The news is bad`.

## Pontos de atenção e erros comuns

- **Não diga `childs`, `mans`, `foots`, `tooths`, `mouses` (animal), `persons` (cotidiano)**: use `children`, `men`, `feet`, `teeth`, `mice`, `people`.
- **`People` é plural**: `People are`, não `People is`.
- **`Fish`, `sheep`, `deer` não mudam**: `three sheep`, não `three sheeps`.
- **`Woman` x `women`** têm pronúncia diferente: /ˈwʊmən/ x /ˈwɪmɪn/.
- **`Knife` → `knives`**: o `f` vira `v`; `roof` → `roofs` é exceção.
- **`News` parece plural mas é singular**: `The news is good` (em português, `as notícias são boas`).
- **`Police` leva verbo no plural**: `The police are here`, ao contrário de `a polícia está aqui`.
- **Verbo e pronome concordam**: `The children are happy. They like it.`, não `The children is happy`.
- **Artigo `a` / `an` só com singular**: `a man`, `men` (sem artigo); não `a men`.
