# Francês · Duolingo — Nível 2

> **Tema oficial:** Cumprimente e apresente-se · **Seção 1, Unidade 2** · Curso: Francês para falantes de português

## Visão geral

Neste nível você aprende a **cumprimentar**, **se despedir** e **se apresentar**: nome, origem, profissão básica e como vai. A base gramatical é o verbo **être** (ser/estar) e os **pronomes sujeito**.

```text
Bonjour, je m'appelle Marie.        →  Olá, meu nome é Marie.
Je suis brésilien / brésilienne.    →  Sou brasileiro / brasileira.
Comment allez-vous ? — Très bien.   →  Como vai? — Muito bem.
```

Ideias centrais:

1. O francês distingue **tu** (informal) e **vous** (formal ou plural).
2. `Je m'appelle…` é o jeito natural de dizer o nome (literalmente “eu me chamo”).
3. Nacionalidades e profissões **concordam em gênero** (`brésilien` / `brésilienne`).

## Gramática em exemplos

### 1. Verbo `être` (ser / estar) no presente

| Pessoa | Forma | Exemplo |
|---|---|---|
| je | suis | Je suis brésilien. |
| tu | es | Tu es étudiant. |
| il / elle | est | Il est médecin. |
| nous | sommes | Nous sommes amis. |
| vous | êtes | Vous êtes français ? |
| ils / elles | sont | Ils sont canadiens. |

- `Je suis` = “eu sou” **e** “eu estou”: o francês tem um único verbo.
- Esse verbo é **irregular**: decore a tabela.

### 2. Pronomes sujeito

| Francês | Português | Observação |
|---|---|---|
| je | eu | vira `j'` diante de vogal (`j'ai`) |
| tu | tu/você | informal |
| il | ele | |
| elle | ela | |
| on | a gente; nós (informal) | usa verbo na 3ª pessoa singular |
| nous | nós | |
| vous | vocês; o senhor/a senhora | formal ou plural |
| ils | eles | masculino ou misto |
| elles | elas | só feminino |

### 3. `Tu` ou `vous`?

| Contexto | Pronome |
|---|---|
| amigos, família, colegas jovens | tu |
| desconhecidos, clientes, chefes | vous |
| mais de uma pessoa | vous |

- Na dúvida, use **vous**: ninguém se ofende.

### 4. Nacionalidade: concordância de gênero

| Regra | Masculino | Feminino |
|---|---|---|
| acrescenta `-e` | français | française |
| `-ien` → `-ienne` | brésilien | brésilienne |
| `-ain` → `-aine` | américain | américaine |
| `-and` → `-ande` | allemand | allemande |
| já termina em `-e` | belge | belge |

- No plural, acrescente `-s`: `brésiliens`, `françaises`.
- Não se escreve a nacionalidade com maiúscula quando é adjetivo: `un homme français`.

### 5. Profissões: sem artigo

| Frase | Observação |
|---|---|
| Il est médecin. | sem `un` depois de `être` + profissão |
| Elle est professeure. | |
| C'est un médecin. | com `un` quando usa `c'est` |

- Regra: `il/elle est + profissão` (sem artigo) × `c'est un + profissão`.

### 6. Verbo reflexivo `s'appeler`

| Pessoa | Forma |
|---|---|
| je | m'appelle |
| tu | t'appelles |
| il / elle | s'appelle |
| nous | nous appelons |
| vous | vous appelez |
| ils / elles | s'appellent |

- Exemplo: `Je m'appelle Ana. Comment tu t'appelles ?`

### 7. Pergunta de bem-estar

| Registro | Pergunta | Resposta |
|---|---|---|
| formal | Comment allez-vous ? | Je vais bien, merci. |
| informal | Comment vas-tu ? / Ça va ? | Ça va bien. |
| neutro | Comment ça va ? | Très bien, et toi ? |

### 8. Negação básica com `ne … pas`

| Afirmativo | Negativo |
|---|---|
| Je suis français. | Je ne suis pas français. |
| Elle est médecin. | Elle n'est pas médecin. |
| Nous sommes brésiliens. | Nous ne sommes pas brésiliens. |

- `ne` vira `n'` diante de vogal ou `h` mudo.
- O `ne` costuma cair na fala informal: `Je suis pas français.`

### 9. Perguntas com entonação ou `est-ce que`

| Forma | Exemplo |
|---|---|
| entonação | Tu es brésilien ? |
| est-ce que | Est-ce que tu es brésilien ? |
| inversão | Es-tu brésilien ? |

### 10. `Voici` e `voilà`

- `Voici ma sœur.` — “Esta é minha irmã.”
- `Voilà mon ami.` — “Aqui está meu amigo.”

### Diálogo 1 — Primeiro encontro

- Marie : Bonjour, je m'appelle Marie. Et vous ?

- Mme Silva : Enchantée, Marc.

## Pontos de atenção e erros comuns

- **`être` serve para “ser” e “estar”**: `Je suis fatigué` = “Estou cansado”.
- **Nacionalidades concordam**: `Elle est brésilien` está errado; use `brésilienne`.
- **Profissão sem artigo** depois de `il/elle est`: `Il est un médecin` está errado.
- **`Tu` × `vous`**: errar o tratamento pode soar rude ou distante.
- **`Je m'appelle` ≠ `Je suis appelé`**: a forma natural é reflexiva.
- **Letras finais mudas**: `est`, `sont`, `ils` terminam em som mudo (`est` = /é/).
- **Liaison**: `vous êtes` se pronuncia /vu-zét/; `ils sont` é /il sõ/.
