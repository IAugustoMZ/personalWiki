# Francês · Duolingo — Nível 5

> **Tema oficial:** Compre roupas · **Seção 1, Unidade 5** · Curso: Francês para falantes de português

## Visão geral

Neste nível você aprende a **comprar roupas**: nomear peças, cores, tamanhos e preços, pedir para provar e comentar se algo cabe ou não. A gramática gira em torno de **adjetivos de cor**, **demonstrativos**, **números maiores** e o verbo **aller** com `essayer` e `prendre`.

```text
Je voudrais essayer cette robe rouge.     →  Eu queria experimentar este vestido vermelho.
Elle coûte combien ?                     →  Quanto ela custa?
Vous avez une taille plus grande ?       →  Vocês têm um tamanho maior?
```

Ideias centrais:

1. **Demonstrativos**: `ce / cet / cette / ces` (este/esse/aquele).
2. **Cores** são adjetivos: concordam (`une robe rouge`, `des chaussures noires`), com algumas exceções invariáveis.
3. **Preços e números** até 100 aparecem constantemente.

## Gramática em exemplos

### 1. Demonstrativos: `ce / cet / cette / ces`

| Gênero/número | Forma | Exemplo |
|---|---|---|
| masculino sing. | ce | ce pantalon |
| masculino sing. diante de vogal | cet | cet ensemble, cet homme |
| feminino sing. | cette | cette robe |
| plural | ces | ces chaussures |

- Para distinguir perto/longe, acrescente `-ci` e `-là`: `ce pull-ci` (este) / `ce pull-là` (aquele).

### 2. Cores: concordância

| Regra | Exemplo |
|---|---|
| a maioria concorda | une robe verte / des robes vertes |
| terminadas em `-e` não mudam no feminino | une jupe rouge |
| plural +`s` | des pantalons noirs |
| cores-substantivo **invariáveis** | des chaussures orange / marron |

- Cores vêm **depois** do substantivo.
- Cor composta: `bleu clair` (azul claro), `vert foncé` (verde escuro): invariável.

### 3. Verbo `aller bien` / `faire` para tamanho

| Estrutura | Exemplo |
|---|---|
| Ça me va | Ça me va bien. |
| Ça ne me va pas | Ça ne me va pas du tout. |
| Je fais du + número | Je fais du 40. |
| Quelle est ta taille ? | Je suis en M. |

### 4. Verbo `essayer` (-ayer) e `acheter`

| Pessoa | essayer | acheter |
|---|---|---|
| je | essaie | achète |
| tu | essaies | achètes |
| il / elle | essaie | achète |
| nous | essayons | achetons |
| vous | essayez | achetez |
| ils / elles | essaient | achètent |

- Verbos em `-ayer` admitem `y` ou `i`; `acheter` troca `e` por `è` nas formas de `je/tu/il/ils`.

### 5. Verbo `prendre` (pegar, levar)

| Pessoa | Forma |
|---|---|
| je | prends |
| tu | prends |
| il / elle | prend |
| nous | prenons |
| vous | prenez |
| ils / elles | prennent |

- Muito usado em compras: `Je prends ce manteau.`

### 6. Números de 20 a 100

| Número | Francês |
|---|---|
| 20 | vingt |
| 21 | vingt et un |
| 22 | vingt-deux |
| 30 | trente |
| 40 | quarante |
| 50 | cinquante |
| 60 | soixante |
| 70 | soixante-dix |
| 80 | quatre-vingts |
| 90 | quatre-vingt-dix |
| 100 | cent |

- Atenção: 70 = “sessenta-dez”, 80 = “quatro-vintes”, 90 = “quatro-vintes-dez”.
- Na Suíça e Bélgica: `septante`, `huitante`/`octante`, `nonante`.

### 7. Preço: `ça coûte` e `ça fait`

| Pergunta | Resposta |
|---|---|
| Combien ça coûte ? | Ça coûte trente euros. |
| C'est combien ? | C'est quarante euros. |
| Ça fait combien ? | Ça fait cinquante euros. |

### 8. Comparativo básico: `plus … que`, `moins … que`

| Estrutura | Exemplo |
|---|---|
| plus + adj + que | Cette robe est plus chère que cette jupe. |
| moins + adj + que | Ce pull est moins cher que ce manteau. |
| aussi + adj + que | Ce sac est aussi joli que ce chapeau. |

### 9. Perguntas com `quel / quelle / quels / quelles`

| Forma | Exemplo |
|---|---|
| quel (m. sing.) | Quel pantalon ? |
| quelle (f. sing.) | Quelle taille ? |
| quels (m. pl.) | Quels gants ? |
| quelles (f. pl.) | Quelles chaussures ? |

### 10. Expressões úteis de cortesia

| Francês | Uso |
|---|---|
| Je peux vous aider ? | atendente |
| Je regarde, merci. | “só estou olhando” |
| Vous avez ça en… ? | “vocês têm isso em…?” |
| Je vais réfléchir. | “vou pensar.” |

## Diálogos

### Diálogo 1 — Na loja

- Vendeuse : Bonjour, je peux vous aider ?
- Client : Oui, je cherche un pantalon noir.
- Vendeuse : Quelle est votre taille ?
- Client : Je fais du 42.
- Vendeuse : Voilà. Les cabines sont à droite.

### Diálogo 2 — No provador

- Client : Ça ne me va pas. C'est trop petit.
- Vendeuse : Vous voulez une taille plus grande ?
- Client : Oui, s'il vous plaît.
- Vendeuse : Voilà le 44.
- Client : Parfait, je le prends.

### Diálogo 3 — No caixa

- Vendeuse : Ça fait soixante-quinze euros.
- Client : Je peux payer par carte ?
- Vendeuse : Bien sûr. Voilà votre reçu.
- Client : Merci, bonne journée !

## Pontos de atenção e erros comuns

- **Demonstrativo**: `ce` diante de consoante, `cet` diante de vogal/h mudo (`cet hôtel`).
- **Cores invariáveis**: `orange` e `marron` nunca ganham `s` ou `e`.
- **Falso cognato**: `un costume` = terno, **não** “fantasia”.
- **Falso cognato**: `rester` é “ficar”, não “restar”; `rester` aparece em lojas como “ficar com”.
- **`Porter`** é usar/vestir roupa; **`mettre`** é pôr; não se usa *utiliser*.
- **Tamanho**: `la taille` para roupas, `la pointure` para sapatos.
- **`Cher`** pode ser “caro” (preço) ou “querido” (afeto); em lojas, quase sempre “caro”.
