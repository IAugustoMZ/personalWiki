# Francês · Duolingo — Nível 18

> **Tema oficial:** Prepare-se para os convidados · **Seção 2, Unidade 8** · Curso: Francês para falantes de português

## Visão geral

Neste nível você aprende a **receber visitas**: preparar a casa, organizar a mesa, cozinhar, oferecer bebidas e comida, e conversar com os convidados. A gramática se concentra em **imperativo**, **pronomes objeto** (`le/la/les`, `lui/leur`), **futuro próximo** e **verbos de preparação** (`préparer`, `mettre`, `ranger`, `nettoyer`).

```text
Mets la table, s'il te plaît !                  →  Põe a mesa, por favor!
Mes invités arrivent à huit heures.             →  Meus convidados chegam às 8h.
Je vais leur servir du vin et du fromage.       →  Vou servir vinho e queijo a eles.
```

Ideias centrais:

1. O **imperativo** funciona para tarefas: `Range`, `Mets`, `Prépare`.
2. Pronomes objeto indireto (`lui`, `leur`) aparecem com `servir`, `offrir`, `donner`.
3. A hospitalidade tem expressões fixas: `Faites comme chez vous`, `Servez-vous`.

## Gramática em exemplos

### 1. Imperativo para tarefas domésticas

| Infinitivo | tu | vous |
|---|---|---|
| ranger | range | rangez |
| nettoyer | nettoie | nettoyez |
| mettre | mets | mettez |
| ouvrir | ouvre | ouvrez |
| apporter | apporte | apportez |
| préparer | prépare | préparez |
| faire | fais | faites |

- Verbos em `-er` e `ouvrir` perdem o `-s` no imperativo `tu`: `Range`, `Ouvre`.

### 2. Imperativo negativo

| Afirmativo | Negativo |
|---|---|
| Range ta chambre. | Ne range pas ta chambre. |
| Ouvrez la porte. | N'ouvrez pas la porte. |
| Mets la table. | Ne mets pas la table. |

### 3. Pronomes objeto direto `le / la / les`

| Frase | Com pronome |
|---|---|
| Je range le salon. | Je le range. |
| Il prépare la table. | Il la prépare. |
| Nous nettoyons les verres. | Nous les nettoyons. |

- Imperativo afirmativo: pronome **depois** (`Range-le !`); negativo: **antes** (`Ne le range pas !`).

### 4. Pronomes objeto indireto `lui / leur`

| Pronome | Exemplo |
|---|---|
| lui | Je lui sers du vin. (a ele/ela) |
| leur | Je leur offre un apéritif. (a eles/elas) |
| me / m' | Il m'offre un café. |
| te / t' | Je t'apporte un verre. |
| nous | Ils nous servent le dîner. |
| vous | Je vous sers du fromage. |

### 5. Verbo `mettre` (pôr)

| Pessoa | Forma |
|---|---|
| je | mets |
| tu | mets |
| il / elle | met |
| nous | mettons |
| vous | mettez |
| ils / elles | mettent |

- Expressões: `mettre la table`, `mettre de la musique`, `mettre un manteau`.

### 6. Verbo `servir` e `se servir`

| Pessoa | servir | se servir |
|---|---|---|
| je | sers | me sers |
| tu | sers | te sers |
| il / elle | sert | se sert |
| nous | servons | nous servons |
| vous | servez | vous servez |
| ils / elles | servent | se servent |

### 7. Futuro próximo para planos de festa

| Frase | Tradução |
|---|---|
| Je vais préparer le dîner. | Vou preparar o jantar. |
| Nous allons mettre la table. | Vamos pôr a mesa. |
| Elle va ranger la maison. | Ela vai arrumar a casa. |
| Ils vont arriver à huit heures. | Eles vão chegar às 8h. |

## Diálogos

### Diálogo 1 — Preparando

- A : Mes invités arrivent à huit heures. Tu m'aides ?
- B : Bien sûr. Qu'est-ce que je fais ?
- A : Mets la table, s'il te plaît. Moi, je prépare le plat.
- B : Combien de personnes ?
- A : Six.

### Diálogo 2 — Chegada

- Hôte : Bienvenue ! Entrez, je vous en prie.
- Invité : Merci. Voici une bouteille de vin pour vous.
- Hôte : C'est très gentil. Asseyez-vous, faites comme chez vous.
- Invité : Merci beaucoup.

### Diálogo 3 — À mesa

- Hôte : Je vous sers du vin ?
- Invité : Oui, avec plaisir.
- Hôte : Servez-vous de fromage.
- Invité : C'est délicieux !

## Pontos de atenção e erros comuns

- **`Mettre la table`** = pôr a mesa; **`débarrasser`** = tirar a mesa.
- **Pronome após imperativo afirmativo**: `Range-le !`; no negativo antes: `Ne le range pas !`.
- **`Servir` × `se servir`**: servir os outros × servir-se.
- **Falso cognato**: `assister à` = estar presente, não “assistir” (que é `regarder`).
- **Falso cognato**: `une soirée` = festa/noite; **`un dîner`** = jantar.
- **Faites comme chez vous** é fórmula fixa — não traduza palavra por palavra.
- **`Il manque`** é impessoal e concorda com o objeto no sentido: `Il manque deux verres`.
