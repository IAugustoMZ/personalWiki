# Francês · Duolingo — Nível 4

> **Tema oficial:** Descreva personalidades · **Seção 1, Unidade 4** · Curso: Francês para falantes de português

## Visão geral

Neste nível você descreve **como alguém é**: caráter, humor, qualidades e defeitos. O foco gramatical é a **concordância dos adjetivos** (gênero e número) e o uso de **être** com adjetivos, além de intensificadores como `très`, `assez` e `trop`.

```text
Elle est sympathique et drôle.          →  Ela é simpática e engraçada.
Il n'est pas timide, il est très sociable.  →  Ele não é tímido, é muito sociável.
```

Ideias centrais:

1. Adjetivo **concorda** com o substantivo: masculino/feminino e singular/plural.
2. Os intensificadores (`très`, `assez`, `trop`, `un peu`) vêm **antes** do adjetivo.
3. Atenção a adjetivos que **terminam em `-e`** e não mudam no feminino (`sympathique`, `drôle`, `jeune`).

## Gramática em exemplos

### 1. Concordância em gênero

| Regra | Masculino → Feminino | Exemplo |
|---|---|---|
| + `-e` | petit → petite | Elle est petite. |
| `-eux` → `-euse` | courageux → courageuse | Elle est courageuse. |
| `-if` → `-ive` | actif → active | Elle est active. |
| `-eur` → `-euse` | menteur → menteuse | Elle est menteuse. |
| `-ent` → `-ente` | patient → patiente | Elle est patiente. |
| já termina em `-e` | drôle → drôle | Elle est drôle. |

### 2. Concordância em número

| Singular | Plural |
|---|---|
| gentil | gentils |
| gentille | gentilles |
| sympathique | sympathiques |
| courageux | courageux (já termina em `-x`) |
| sérieux | sérieux |

- Regra geral: acrescente `-s` (mudo).
- Adjetivos em `-s` ou `-x` mantêm a forma no masculino plural.

### 3. Plural misto

| Grupo | Concordância |
|---|---|
| só mulheres | feminino plural: `Elles sont gentilles.` |
| só homens | masculino plural: `Ils sont gentils.` |
| homens + mulheres | masculino plural: `Ils sont gentils.` |

- O masculino “vence” no plural misto.

### 4. Intensificadores antes do adjetivo

| Estrutura | Exemplo |
|---|---|
| très + adjetivo | Il est très timide. |
| assez + adjetivo | Elle est assez drôle. |
| un peu + adjetivo | Je suis un peu fatigué. |
| trop + adjetivo | Il est trop bavard. |
| vraiment + adjetivo | Elle est vraiment sympa. |

### 5. Negação com adjetivos

| Afirmativo | Negativo |
|---|---|
| Il est timide. | Il n'est pas timide. |
| Elle est jalouse. | Elle n'est pas jalouse. |
| Elle est patiente. | Elle n'est pas du tout patiente. |
| Il est toujours en retard. | Il n'est jamais en retard. |

- Fórmulas: `ne … pas`, `ne … jamais` (nunca), `ne … pas du tout` (nada).
- O `ne` precede o verbo conjugado; o segundo elemento vem depois.

### 6. Posição dos advérbios de frequência

| Advérbio | Posição | Exemplo |
|---|---|---|
| toujours | depois de `être` | Il est toujours poli. |
| souvent | depois de `être` | Elle est souvent fatiguée. |
| parfois | início ou depois | Parfois, il est nerveux. |
| jamais | com `ne` | Elle n'est jamais jalouse. |

### 7. Perguntar como alguém é

| Pergunta | Resposta |
|---|---|
| Comment est-il ? | Il est sympa. |
| Comment est ta mère ? | Elle est patiente. |
| Tu es comment ? | Je suis plutôt calme. |
| Quel genre de personne est-ce ? | C'est une personne ouverte. |

### 8. `Mais` e `et` para ligar descrições

| Conector | Exemplo |
|---|---|
| et | Il est gentil et drôle. |
| mais | Elle est timide mais très gentille. |
| aussi | Moi aussi, je suis optimiste. |
| par contre | Il est sérieux ; par contre, elle est drôle. |

### 9. Adjetivos que mudam de significado

| Adjetivo | Sentido (depois do nome) | Sentido (antes do nome) |
|---|---|---|
| grand | alto/a | grande (importante) |
| ancien | antigo | ex- |
| propre | limpo | próprio |

### 10. `C'est` + adjetivo × `il est` + adjetivo

| Estrutura | Exemplo |
|---|---|
| Il/Elle est + adjetivo | Elle est sympathique. |
| C'est + adjetivo (geral) | C'est drôle ! |
| C'est un/une + substantivo + adjetivo | C'est une femme drôle. |

## Diálogos

### Diálogo 1 — Falando de uma amiga

- A : Tu connais Julie ?
- B : Oui. Elle est très sympathique, non ?
- A : Oui, et elle est aussi très drôle !
- B : Par contre, elle est un peu bavarde.

### Diálogo 2 — Falando do chefe

- A : Comment est ton nouveau chef ?
- B : Il est sérieux et travailleur.
- A : Il est strict ?
- B : Un peu, mais il est toujours juste.

### Diálogo 3 — Descrevendo a si mesmo

- A : Tu es comment, toi ?
- B : Je suis plutôt calme et patient.
- A : Moi, je suis impatient ! Mais je suis honnête.

## Pontos de atenção e erros comuns

- **Concordância**: `Elle est gentil` está errado; use `gentille`.
- **`Drôle`, `calme`, `sympathique`** não mudam no feminino.
- **Plural em `-x`**: `courageux` não ganha `s`.
- **Falso cognato**: `sympathique` é “simpático” (não “solidário”); `sympa` é a forma curta e informal.
- **Falso cognato**: `fatigant` = cansativo (quem cansa os outros); `fatigué` = cansado.
- **Falso cognato**: `éduqué` = bem-educado; `malpoli` = mal-educado.
- **Nunca** use `très` com `bon` ou `mauvais` (use `très bon`? sim; mas evite *très excellent*).
- **`Trop`** significa “demais”, geralmente negativo.
