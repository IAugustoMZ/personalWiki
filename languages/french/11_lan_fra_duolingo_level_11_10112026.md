# Francês · Duolingo — Nível 11

> **Tema oficial:** Apresente-se e pergunte sobre os outros · **Seção 2, Unidade 1** · Curso: Francês para falantes de português

## Visão geral

Começa a Seção 2: você amplia a **apresentação** (profissão, idade, origem, gostos) e aprende a **fazer perguntas pessoais** a outras pessoas, sem ser invasivo. Aparecem os **verbos pronominais**, o uso do **possessivo** com perguntas e as **perguntas indiretas simples**.

```text
Je m'appelle Léa, j'ai vingt-cinq ans et je suis architecte.   →  Meu nome é Léa, tenho 25 anos e sou arquiteta.
Et vous, d'où venez-vous ? Qu'est-ce que vous faites ?        →  E o senhor, de onde vem? O que faz?
```

Ideias centrais:

1. Apresentar-se em francês segue a ordem: **nome → origem → profissão → gostos**.
2. `venir de` (vir de), `être de` (ser de) e `habiter à` (morar em) respondem “de onde você é?”.
3. Verbos pronominais (`s'appeler`, `se présenter`) pedem o pronome reflexivo.

## Gramática em exemplos

### 1. Verbos pronominais (`s'appeler`, `se présenter`)

| Pessoa | Pronome | s'appeler |
|---|---|---|
| je | me / m' | m'appelle |
| tu | te / t' | t'appelles |
| il / elle | se / s' | s'appelle |
| nous | nous | nous appelons |
| vous | vous | vous appelez |
| ils / elles | se / s' | s'appellent |

- Exemplo: `Je me présente : je m'appelle Léa.`

### 2. `Venir` (vir) e `être de`

| Pessoa | venir |
|---|---|
| je | viens |
| tu | viens |
| il / elle | vient |
| nous | venons |
| vous | venez |
| ils / elles | viennent |

| Estrutura | Exemplo |
|---|---|
| venir de + cidade | Je viens de Paris. |
| venir du + país masc. | Je viens du Brésil. |
| venir de + país feminino | Je viens de France. |
| venir d' + vogal | Je viens d'Italie. |
| être de + cidade | Je suis de Lyon. |

- País feminino: `de France`, `d'Italie`; masculino: `du Brésil`; plural: `des États-Unis`.

### 3. Profissão: com ou sem artigo

| Estrutura | Exemplo |
|---|---|
| sujeito + être + profissão | Je suis architecte. |
| C'est + artigo + profissão | C'est un architecte. |
| adjetivo na profissão | Elle est une bonne architecte. |

### 4. Feminino das profissões

| Regra | Masculino → Feminino |
|---|---|
| já termina em `-e` | un journaliste → une journaliste |
| +`e` | un avocat → une avocate |
| `-ier` → `-ière` | un infirmier → une infirmière |
| `-eur` → `-euse` | un chanteur → une chanteuse |
| `-teur` → `-trice` | un acteur → une actrice |
| `-ien` → `-ienne` | un informaticien → une informaticienne |

### 5. Verbos de gosto + infinitivo ou substantivo

| Estrutura | Exemplo |
|---|---|
| aimer + infinitivo | J'aime voyager. |
| aimer + artigo + substantivo | J'aime la musique. |
| détester + infinitivo | Je déteste attendre. |
| préférer + A à B | Je préfère le thé au café. |

- Com gostos em geral, use **artigo definido**: `J'aime les films`.

### 6. Responder “eu também / eu também não”

| Afirmação | Concordância | Discordância |
|---|---|---|
| J'aime la musique. | Moi aussi. | Pas moi. |
| Je n'aime pas le café. | Moi non plus. | Moi si ! |

### 7. Pronomes tônicos

| Sujeito | Tônico |
|---|---|
| je | moi |
| tu | toi |
| il | lui |
| elle | elle |
| nous | nous |
| vous | vous |
| ils | eux |
| elles | elles |

- Uso: `Moi, je suis brésilien. Et toi ?`

### 8. Perguntas pessoais educadas

| Direto | Mais educado |
|---|---|
| Tu as quel âge ? | Quel âge avez-vous ? |
| Tu es marié ? | Êtes-vous marié ? |
| Tu gagnes combien ? | (evitar) |
| Tu fais quoi ? | Que faites-vous dans la vie ? |

### 9. Perguntas indiretas simples

| Direta | Indireta |
|---|---|
| Où habites-tu ? | Je voudrais savoir où tu habites. |
| Que fais-tu ? | Dis-moi ce que tu fais. |
| Comment t'appelles-tu ? | Je ne sais pas comment il s'appelle. |

### 10. Conectores para o relato pessoal

| Conector | Exemplo |
|---|---|
| et | Je suis brésilien et j'habite à Paris. |
| mais | Je suis de Lyon, mais j'habite à Paris. |
| donc | J'aime voyager, donc je parle trois langues. |
| parce que | J'apprends le français parce que j'aime Paris. |
| aussi | Elle parle aussi espagnol. |

## Pontos de atenção e erros comuns

- **Profissão sem artigo**: `Je suis médecin`, não *Je suis un médecin*.
- **`Venir de`** × **`aller à`**: origem × destino.
- **`Être de`** (origem) × **`habiter à`** (moradia).
- **`Aimer` + artigo definido**: `J'aime la musique`, não *J'aime musique*.
- **Falso cognato**: `un étudiant` = estudante universitário; para escola use `élève`.
- **Falso cognato**: `un professeur` = professor (escola ou universidade), não “profissional”; para “profissional” use `un professionnel`.
- **Pronomes tônicos** aparecem após preposição: `avec moi`, `chez lui`.
- **Feminino de profissões**: `une médecin` (invariável) é comum, `une docteure` também aparece.
