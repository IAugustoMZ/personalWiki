# Francês · Duolingo — Nível 1

> **Tema oficial:** Peça em uma cafeteria · **Seção 1, Unidade 1** · Curso: Francês para falantes de português

## Visão geral

Primeiro contato com o francês: **pedir algo em um café**. Você já sai da unidade capaz de dizer o que quer, pedir educadamente, agradecer e entender o básico do atendente.

```text
Je voudrais un café, s'il vous plaît.     →  Eu queria um café, por favor.
Un thé et un croissant, s'il vous plaît.  →  Um chá e um croissant, por favor.
```

Ideias centrais:

1. **Substantivos têm gênero**: masculino (`un café`) e feminino (`une eau`).
2. O **artigo indefinido** (`un`, `une`, `des`) acompanha o gênero e o número.
3. **`Je voudrais`** é a forma educada de pedir (condicional de *vouloir*).
4. A **pronúncia** é muito diferente da escrita: letras finais costumam ser mudas (`petit` → /pəti/).

## Gramática em exemplos

### 1. Gênero dos substantivos

| Masculino | Feminino |
|---|---|
| un café | une eau |
| un thé | une tarte |
| un croissant | une salade |
| un gâteau | une glace |

- Todo substantivo é masculino ou feminino; **aprenda sempre com o artigo**.
- Dica: muitos substantivos em `-tion`, `-té`, `-ette` e `-e` são femininos (mas não todos).

### 2. Artigo indefinido

| | Masculino | Feminino |
|---|---|---|
| singular | un | une |
| plural | des | des |

- `un café` / `une eau`.
- `des croissants` = “alguns croissants / croissants”.

### 3. Artigo partitivo (quantidade não contável)

| Forma | Uso | Exemplo |
|---|---|---|
| du | masculino | du pain, du fromage |
| de la | feminino | de la confiture |
| de l' | vogal ou h mudo | de l'eau |
| des | plural | des biscuits |

- O partitivo indica **uma porção** de algo: “um pouco de pão”.

### 4. `Je voudrais` (eu queria)

| Pessoa | Voudrais |
|---|---|
| je | voudrais |
| tu | voudrais |
| il / elle | voudrait |
| nous | voudrions |
| vous | voudriez |
| ils / elles | voudraient |

- Para pedidos, use `Je voudrais` (educado). `Je veux` (eu quero) soa **seco** em café.

### 5. `S'il vous plaît` vs `s'il te plaît`

| Forma | Quando |
|---|---|
| s'il vous plaît | desconhecidos, atendimento, respeito |
| s'il te plaît | amigos, família, crianças |

### 6. Ligando itens com `et`

- `Un café et un croissant`.
- Em listas, repita o artigo: `un thé et un gâteau`.

### 7. Quantidades

| Número | Francês |
|---|---|
| 1 | un / une |
| 2 | deux |
| 3 | trois |
| 4 | quatre |
| 5 | cinq |
| 6 | six |
| 7 | sept |
| 8 | huit |
| 9 | neuf |
| 10 | dix |

- Exemplo: `Deux cafés, s'il vous plaît.`
- O plural geralmente acrescenta `-s`, que **não se pronuncia**.

### 8. Perguntas simples

| Pergunta | Tradução |
|---|---|
| Qu'est-ce que vous désirez ? | O que deseja? |
| Vous désirez autre chose ? | Deseja mais alguma coisa? |
| C'est pour emporter ? | É para levar? |
| Ça fait combien ? | Quanto fica? |

### 9. `C'est` (é)

| Frase | Tradução |
|---|---|
| C'est un café. | É um café. |
| C'est délicieux ! | É delicioso! |
| C'est tout. | É só isso. |
| C'est combien ? | Quanto é? |

### 10. Pronúncia: letras finais mudas

| Palavra | Pronuncia-se | Observação |
|---|---|---|
| petit | pe-ti | o `t` final é mudo |
| thé | té | `th` = `t` |
| croissant | cruá-sã | `ant` = nasal |
| beaucoup | bô-cu | `p` final mudo |
| merci | mér-si | `c` antes de `i` = `s` |

## Diálogos

### Diálogo 1 — Pedido simples

- Serveur : Bonjour ! Qu'est-ce que vous désirez ?
- Client : Bonjour. Je voudrais un café, s'il vous plaît.
- Serveur : Voilà. Autre chose ?
- Client : Non, c'est tout. Merci.

### Diálogo 2 — Café da manhã

- Client : Un thé et un croissant, s'il vous plaît.
- Serveur : Sur place ou à emporter ?
- Client : Sur place, merci.
- Serveur : Ça fait cinq euros.
- Client : Voilà. Merci beaucoup !
- Serveur : De rien. Bonne journée !

### Diálogo 3 — Pedindo a conta

- Client : L'addition, s'il vous plaît.
- Serveur : Tout de suite. Voilà.
- Client : Merci. C'était délicieux.

## Pontos de atenção e erros comuns

- **Não diga `Je veux`** ao pedir; prefira `Je voudrais`.
- **`un`/`une`** devem concordar com o gênero: `une café` está errado.
- **O artigo é obrigatório**: `Je voudrais café` está errado; use `un café` ou `du café`.
- **Letras finais mudas**: `thé`, `petit`, `deux`, `trois` têm final silencioso.
- **`eau` é feminino**, mas se escreve `de l'eau` (elisão).
- **Falsos cognatos**: `le menu` pode ser menu fixo; para o cardápio completo, use `la carte`.
- **Cumprimento**: sempre diga `Bonjour` ao entrar; é mais importante que em português.

## Complete as lacunas

1. Je ____ un café. (eu queria) → `voudrais`
2. ____ eau gazeuse, s'il vous plaît. → `Une`
3. Un thé ____ un croissant. → `et`
4. ____ café, s'il vous plaît. (um) → `Un`
5. Ça ____ cinq euros. (fica) → `fait`
