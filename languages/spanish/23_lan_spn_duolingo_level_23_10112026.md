# Espanhol · Duolingo — Nível 23

> **Tema oficial:** Discuta um projeto escolar · **Seção 2, Unidade 13** · Curso: Espanhol para falantes de português

## Visão geral

Neste nível você **discute um projeto escolar** com colegas: escolhe o tema, divide as tarefas, combina prazos e fala da apresentação. Entram o vocabulário de **escola e trabalho em grupo**, verbos de **planejamento** (`pensar`, `poder`, `querer`, `encargarse de`), o **futuro próximo** (`ir a` + infinitivo) e as **sugestões** (`¿Por qué no…?`, `podemos…`).

```text
¿Qué tema elegimos para el proyecto?                     →  Que tema escolhemos para o projeto?
Yo me encargo de la investigación y tú haces el cartel.  →  Eu cuido da pesquisa e você faz o cartaz.
Tenemos que entregarlo el viernes.                       →  Temos que entregá-lo na sexta.
```

Ideias centrais:

1. Sugerir: `¿Por qué no…?`, `Podemos…`, `¿Qué te parece si…?`.
2. Distribuir tarefas: `Yo me encargo de…`, `Tú te ocupas de…`, `A ti te toca…`.
3. Planejar: `vamos a` + infinitivo, `tenemos que` + infinitivo, `para el lunes`.

## Gramática em exemplos

### 1. `Ir a` + infinitivo (futuro próximo)

| Pessoa | Forma | Exemplo |
|---|---|---|
| yo | voy a | Voy a escribir el informe. |
| tú | vas a | ¿Vas a buscar libros? |
| él / ella / usted | va a | Va a preparar el cartel. |
| nosotros | vamos a | Vamos a presentar el lunes. |
| vosotros | vais a | ¿Vais a trabajar juntos? |
| ellos / ustedes | van a | Van a entregar el trabajo. |

- `Vamos a` + infinitivo também funciona como sugestão: `Vamos a empezar` = "Vamos começar".

### 2. Verbos com mudança vocálica no planejamento

| Verbo | Mudança | yo | tú | nosotros |
|---|---|---|---|---|
| pensar | e → ie | pienso | piensas | pensamos |
| querer | e → ie | quiero | quieres | queremos |
| entender | e → ie | entiendo | entiendes | entendemos |
| empezar | e → ie | empiezo | empiezas | empezamos |
| poder | o → ue | puedo | puedes | podemos |
| volver | o → ue | vuelvo | vuelves | volvemos |
| elegir | e → i | elijo | eliges | elegimos |
| corregir | e → i | corrijo | corriges | corregimos |

- `Elegir` e `corregir` têm mudança e → i e também g → j na 1ª pessoa: `elijo`, `corrijo`.

### 3. Fazer sugestões

| Estrutura | Exemplo |
|---|---|
| ¿Por qué no + presente? | ¿Por qué no hacemos un cartel? |
| Podemos + infinitivo | Podemos dividir el trabajo. |
| ¿Qué te parece si + presente? | ¿Qué te parece si empezamos hoy? |
| Vamos a + infinitivo | Vamos a elegir el tema. |
| ¿Y si + presente? | ¿Y si hablamos del agua? |
| Propongo + infinitivo | Propongo trabajar en grupo. |

### 4. Concordar e discordar

| Concordar | Discordar |
|---|---|
| Estoy de acuerdo. | No estoy de acuerdo. |
| Tienes razón. | No tienes razón. |
| Me parece bien. | No me parece bien. |
| ¡Claro! | Yo prefiero otra cosa. |
| Buena idea. | Creo que es mejor… |
| Sí, por supuesto. | No lo veo claro. |

- `Estar de acuerdo con + pessoa`: `Estoy de acuerdo contigo`, `con ella`, `con mis compañeros`.

### 5. `Encargarse de` e distribuição de tarefas

| Estrutura | Exemplo |
|---|---|
| yo me encargo de + substantivo | Yo me encargo de la presentación. |
| tú te encargas de + infinitivo | Tú te encargas de buscar fotos. |
| él se encarga de | Él se encarga del informe. |
| nos encargamos de | Nos encargamos del cartel. |
| a mí me toca | A mí me toca hablar al final. |
| yo me ocupo de | Yo me ocupo de los gráficos. |

- `De + el` se contrae em `del`: `se encarga del informe`.

### 6. `Para` (prazo, finalidade) e `por`

| Uso | Exemplo |
|---|---|
| para + prazo | El trabajo es para el lunes. |
| para + finalidade | Usamos el ordenador para buscar información. |
| para + destinatário | Este cartel es para la clase. |
| por + motivo | Estudio mucho por mi nota. |
| por + meio | Mando el informe por correo. |
| por la mañana / la tarde | Nos reunimos por la tarde. |

- `Para` olha para frente (objetivo, prazo); `por` olha para trás (causa) ou meio.

### 7. Pronomes de objeto indireto e `ayudar`

| Frase | Tradução |
|---|---|
| Te ayudo con el resumen. | Eu te ajudo com o resumo. |
| Le pregunto al profesor. | Pergunto ao professor. |
| Nos da una semana más. | Ele nos dá mais uma semana. |
| Les explicamos el tema. | Explicamos o tema a eles. |
| ¿Me pasas el cuaderno? | Você me passa o caderno? |
| Le entrego el trabajo. | Entrego o trabalho a ele/ela. |

### 8. Pronomes objeto direto + infinitivo

| Frase | Substituição |
|---|---|
| Tenemos que entregar el trabajo. | Tenemos que entregarlo. / Lo tenemos que entregar. |
| Voy a escribir el informe. | Voy a escribirlo. / Lo voy a escribir. |
| Podemos hacer los carteles. | Podemos hacerlos. / Los podemos hacer. |
| Quiero leer la página. | Quiero leerla. / La quiero leer. |

### 9. Conectores de ordem

| Conector | Exemplo |
|---|---|
| primero | Primero elegimos el tema. |
| luego / después | Luego buscamos información. |
| más tarde | Más tarde escribimos el informe. |
| antes de + infinitivo | Antes de entregar, revisamos. |
| después de + infinitivo | Después de leer, hacemos un resumen. |
| por último / finalmente | Por último, practicamos la presentación. |

### 10. Expressar opinião e expectativa

| Estrutura | Exemplo |
|---|---|
| creo que + indicativo | Creo que el tema es interesante. |
| me parece que | Me parece que es difícil. |
| pienso que | Pienso que vamos a aprobar. |
| espero + infinitivo | Espero sacar un diez. |
| tengo ganas de | Tengo ganas de presentar. |
| me preocupa | Me preocupa el tiempo. |

## Diálogos

### Diálogo 1 — Escolhendo o tema

- Ana: ¿Qué tema elegimos para el proyecto de ciencias?
- Luis: ¿Por qué no hablamos del agua?
- Marta: Me parece buena idea. Hay mucha información en la biblioteca.
- Ana: Entonces, el tema es el agua. ¿Cómo dividimos el trabajo?

### Diálogo 2 — Dividindo as tarefas

- Luis: Yo me encargo de la investigación.
- Marta: Yo escribo el informe, y Ana prepara el cartel.
- Ana: De acuerdo. ¿Cuándo nos reunimos?
- Luis: Mañana a las cuatro en mi casa.

### Diálogo 3 — Perto da entrega

- Marta: ¿Cuántos minutos dura la exposición?
- Ana: Diez minutos. Cada uno habla dos o tres.
- Luis: Vamos a practicar esta tarde.
- Marta: Perfecto. Yo traigo el ordenador para ver las fotos.

## Pontos de atenção e erros comuns

- **`Tarea`** significa "dever" ou "tarefa"; em muitos países é o dever de casa. Na Espanha também se usa `deberes`.
- **`Asignatura`** (Espanha) e **`materia`** (América Latina) = disciplina.
- **`Aprobar`** é o → ue (`apruebo`) e significa "ser aprovado"; **`suspender`** (Espanha) e **`reprobar`** (América Latina) = reprovar.
- **`Nota`** = nota (de prova); **`apuntes`** = anotações feitas em aula (`tomar apuntes`).
- **`Quedar`** com `a las` significa **combinar** de se encontrar: `Quedamos a las cuatro`.
- **`Encargarse de`** pede `de`: `Me encargo del informe`.
- **`Elegir`** e **`corregir`** têm e → i e g → j: `elijo`, `corrijo`.
- **`Ordenador`** (Espanha) e **`computadora`** (América Latina).
- **`Presentar a`** com pessoa: `Te presento a mi amigo` (o `a` pessoal é obrigatório).
- **`Deberes`** (Espanha) e **`tarea`** (América Latina) para o dever de casa.

## Complete as lacunas

1. ¿Por qué no ____ un cartel? (fazemos) → `hacemos`
2. Yo me ____ del informe. (encarrego) → `encargo`
3. Voy ____ buscar información. (a) → `a`

5. Estoy de acuerdo ____ ti. (com) → `contigo`
6. El trabajo es ____ el lunes. (para) → `para`
