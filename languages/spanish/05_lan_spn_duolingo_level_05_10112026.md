# Espanhol · Duolingo — Nível 5

> **Tema oficial:** Descreva personalidades · **Seção 1, Unidade 5** · Curso: Espanhol para falantes de português

## Visão geral

Neste nível você **descreve a personalidade** de pessoas: qualidades, defeitos, humor e jeito de ser. A estrutura central é **`ser` + adjetivo**, com **concordância de gênero e número**, e uso de **intensificadores** (`muy`, `bastante`, `un poco`, `demasiado`).

```text
Mi hermana es muy simpática y bastante tímida.             →  Minha irmã é muito simpática e bastante tímida.
Mis amigos son divertidos pero un poco desordenados.       →  Meus amigos são divertidos, mas um pouco bagunceiros.
Él no es perezoso, es muy trabajador.                      →  Ele não é preguiçoso, é muito trabalhador.
```

Ideias centrais:

1. Para descrever o **caráter permanente**, usa-se `ser`; para estados passageiros, `estar`.
2. Adjetivos concordam com o substantivo: `simpático / simpática / simpáticos / simpáticas`.
3. Adjetivos que terminam em `-e` ou consoante não mudam de gênero (`amable`, `inteligente`, `fiel`).

## Gramática em exemplos

### 1. `Ser` + adjetivo (característica permanente)

| Pessoa | ser | Exemplo |
|---|---|---|
| yo | soy | Soy tímido. |
| tú | eres | Eres muy amable. |
| él / ella / usted | es | Ella es inteligente. |
| nosotros | somos | Somos sociables. |
| vosotros | sois | Sois divertidos. |
| ellos / ustedes | son | Son honestos. |

### 2. Concordância dos adjetivos

| Tipo | Masc. sing. | Fem. sing. | Masc. pl. | Fem. pl. |
|---|---|---|---|---|
| `-o` / `-a` | simpático | simpática | simpáticos | simpáticas |
| `-e` | amable | amable | amables | amables |
| consoante | leal | leal | leales | leales |
| `-dor` | trabajador | trabajadora | trabajadores | trabajadoras |
| `-ista` | optimista | optimista | optimistas | optimistas |

### 3. Posição do adjetivo

| Posição | Exemplo | Observação |
|---|---|---|
| depois do nome | una amiga simpática | padrão |
| antes do nome | una buena amiga | `bueno`, `malo`, `gran` |
| muda de sentido | un hombre grande / un gran hombre | físico / admirável |

### 4. `Bueno` e `malo` antes do nome

| Forma | Exemplo |
|---|---|
| un buen amigo | um bom amigo |
| una buena amiga | uma boa amiga |
| un mal día | um mau dia |
| una mala persona | uma pessoa má |
| un gran hombre | um grande homem |
| una gran mujer | uma grande mulher |

### 5. Intensificadores

| Espanhol | Exemplo |
|---|---|
| muy | Es muy amable. |
| bastante | Es bastante tímido. |

| demasiado | Es demasiado serio. |

### 6. `Ser` × `estar` com adjetivos

| Frase | Sentido |
|---|---|
| Es aburrido. | é chato (caráter) |
| Está aburrido. | está entediado (estado) |
| Es nervioso. | é nervoso (tem esse jeito) |
| Está nervioso. | está nervoso agora |
| Es listo. | é esperto |
| Está listo. | está pronto |

### 7. Comparativos

| Estrutura | Exemplo |
|---|---|
| más … que | Ana es más alta que Luis. |
| menos … que | Luis es menos tímido que yo. |
| tan … como | Soy tan paciente como mi madre. |
| mejor / peor | Es mejor que yo. |

### 8. Superlativo

| Estrutura | Exemplo |
|---|---|
| el / la más + adjetivo | Es la más simpática. |
| -ísimo | Es simpatiquísima. |
| muy | Es muy simpática. |
| el / la menos | Es el menos tímido. |

### 9. Negação

| Afirmativo | Negativo |
|---|---|
| Es simpático. | No es simpático. |
| Soy tímido. | No soy tímido. |
| Son honestos. | No son honestos. |
| Es amable. | No es nada amable. |

### 10. Perguntas de descrição

| Pergunta | Resposta |
|---|---|
| ¿Cómo es? | Es amable y divertido. |
| ¿Cómo eres? | Soy tranquilo. |

## Diálogos

### Diálogo 1 — Falando de uma amiga

- Pablo: ¿Cómo es tu amiga Laura?
- Ana: Es muy simpática y bastante divertida.
- Pablo: ¿Es tímida?
- Ana: No, es muy sociable.

### Diálogo 2 — Falando do chefe

- A: ¿Cómo es tu nuevo jefe?
- B: Es serio, pero muy justo.
- A: ¿Es exigente?
- B: Un poco, pero es amable.

### Diálogo 3 — Auto-descrição

- Luis: Yo soy bastante tranquilo y un poco tímido.
- Ana: Yo soy más sociable. Me encanta conocer gente.
- Luis: Somos muy diferentes.
- Ana: Sí, pero nos llevamos bien.

## Pontos de atenção e erros comuns

- **Concordância**: *Ella es simpático* está errado; use `simpática`.
- **`Ser`** para caráter e **`estar`** para estado: `es aburrido` × `está aburrido`.
- **`Bueno` → `buen`** antes de masculino singular: `un buen amigo`.
- **Falso amigo**: `simpático` = agradável no trato; **`amable`** = gentil.
- **Falso amigo**: `terco` / `cabezota` = teimoso; `pesado` = chato/cansativo.
- **Falso amigo**: `listo` = esperto; `preparado` = preparado; `ocupado` = ocupado.
- **`Aburrido`** pode ser “chato” (com `ser`) ou “entediado” (com `estar`).
