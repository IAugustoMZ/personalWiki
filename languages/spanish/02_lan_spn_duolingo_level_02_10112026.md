# Espanhol · Duolingo — Nível 2

> **Tema oficial:** Cumprimente e despeça-se · **Seção 1, Unidade 2** · Curso: Espanhol para falantes de português

## Visão geral

Neste nível você aprende os **cumprimentos** e **despedidas**, a diferença entre **`tú`** e **`usted`**, e as primeiras perguntas de bem-estar. Entram o verbo **`estar`** para estados temporários, os pronomes pessoais e as fórmulas de cortesia.

```text
Hola, ¿cómo estás? — Bien, gracias, ¿y tú?             →  Oi, como vai? — Bem, obrigado, e você?
Buenos días, ¿cómo está usted?                          →  Bom dia, como vai o senhor?
Mucho gusto. Hasta luego.                               →  Muito prazer. Até logo.
```

Ideias centrais:

1. Para perguntar **como alguém está**, usa-se `estar`: `¿Cómo estás?`.
2. Cumprimentos variam com a hora (`buenos días`, `buenas tardes`, `buenas noches`).
3. `Tú` (informal) e `usted` (formal) mudam o verbo: `estás` × `está`.

## Gramática em exemplos

### 1. Pronomes pessoais

| Pessoa | Espanhol | Observação |
|---|---|---|
| eu | yo | geralmente omitido |
| tu | tú | informal (acento!) |
| você (formal) | usted | verbo na 3ª pessoa |
| ele | él | |
| ela | ella | |
| nós | nosotros / nosotras | |
| vocês (informal, Espanha) | vosotros / vosotras | |
| vocês (formal / América) | ustedes | verbo na 3ª pessoa do plural |
| eles | ellos / ellas | |

- `Tú` com acento = “você”; `tu` sem acento = “teu/sua” (possessivo).

### 2. Verbo `estar` (estar)

| Pessoa | Forma | Exemplo |
|---|---|---|
| yo | estoy | Estoy bien. |
| tú | estás | ¿Cómo estás? |
| él / ella / usted | está | ¿Cómo está usted? |
| nosotros | estamos | Estamos cansados. |
| vosotros | estáis | ¿Cómo estáis? |
| ellos / ustedes | están | ¿Cómo están ustedes? |

- `Estar` indica estados temporários e lugar.

### 3. Verbo `ser` (ser) — introdução

| Pessoa | Forma | Exemplo |
|---|---|---|
| yo | soy | Soy Ana. |
| tú | eres | Eres mi amigo. |
| él / ella / usted | es | Ella es profesora. |
| nosotros | somos | Somos brasileños. |
| vosotros | sois | Sois amigos. |
| ellos / ustedes | son | Son españoles. |

- `Ser` indica identidade, origem, profissão (próximo nível).

### 4. `Llamarse` (chamar-se)

| Pessoa | Forma |
|---|---|
| yo | me llamo |
| tú | te llamas |
| él / ella / usted | se llama |
| nosotros | nos llamamos |
| vosotros | os llamáis |

## Diálogos

### Diálogo 1 — Entre amigos

- Ana: ¡Hola, Pablo! ¿Qué tal?
- Pablo: ¡Hola, Ana! Bien, ¿y tú?
- Ana: Muy bien, gracias. ¿Cómo está tu familia?
- Pablo: Todos bien. Hasta luego.

### Diálogo 2 — Formal

- Sr. García: Buenos días, señora López. ¿Cómo está usted?
- Sra. López: Muy bien, gracias. ¿Y usted?
- Sr. García: Bien, gracias. Hasta mañana.
- Sra. López: Hasta mañana.

### Diálogo 3 — Primeiro encontro

- Ana: Hola, me llamo Ana. ¿Y tú?
- Luis: Mucho gusto, Ana. Soy Luis.
- Ana: Encantada. ¿De dónde eres?
- Luis: Soy de México. ¿Y tú?

## Pontos de atenção e erros comuns

- **`Estar` × `ser`**: `Estoy bien` (estado) × `Soy Ana` (identidade).
- **`Tú` com acento** (pronome) × **`tu`** sem acento (possessivo).
- **`Usted`** pede o verbo na 3ª pessoa: `¿Cómo está?`, não *¿cómo estás?*.
- **`Buenos días`** é a forma padrão; `buen día` aparece em partes da América Latina (Argentina, Uruguai).
- **`Chau`** / **`chao`** são despedidas informais; em contexto formal use `adiós` ou `hasta luego`.
- **`Encantado/a`** significa “encantado em conhecer”, equivalente a “muito prazer”; concorda com o gênero de quem fala.
- **Sinal de abertura** em perguntas: `¿Qué tal?`.

## Complete as lacunas

1. ¿Cómo ____ ? (você está) → `estás`
2. ____ bien, gracias. (estou) → `Estoy`
3. ____ llamo Ana. (me) → `Me`
4. Ella ____ de México. (é) → `es`
5. ____ días. (bom) → `Buenos`
6. ¿Y ____ ? (você) → `tú`
