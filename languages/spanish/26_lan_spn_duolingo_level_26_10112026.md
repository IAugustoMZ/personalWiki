# Espanhol · Duolingo — Nível 26

> **Tema oficial:** Pergunte sobre ingredientes · **Seção 2, Unidade 16** · Curso: Espanhol para falantes de português

## Visão geral

Neste nível você **pergunta sobre ingredientes**: o que leva um prato, se tem algum alimento a que você é alérgico, quanto usar em uma receita. Entram `llevar` no sentido de **conter**, as **quantidades** (`una cucharada de`, `una pizca de`), os **verbos de cozinha** e os **pedidos educados** a um garçom ou cozinheiro.

```text
¿Lleva ajo este plato?                                   →  Este prato leva alho?
Soy alérgico a los frutos secos. ¿Tiene nueces?          →  Sou alérgico a frutas secas. Tem nozes?
Se añade una pizca de sal y un poco de aceite.           →  Acrescenta-se uma pitada de sal e um pouco de azeite.
```

Ideias centrais:

1. `Llevar` + ingrediente = conter: `Lleva leche y huevos`.
2. `Con` e `sin` + substantivo, sem artigo: `con queso`, `sin gluten`.
3. Quantidade + `de` + ingrediente: `una cucharada de azúcar`.

## Gramática em exemplos

### 1. `Llevar` = conter

| Estrutura | Exemplo |
|---|---|
| ¿Lleva + ingrediente? | ¿Lleva ajo la salsa? |
| Lleva + ingrediente | La tortilla lleva huevo y patata. |
| No lleva + ingrediente | El pan no lleva azúcar. |
| ¿Qué lleva? | ¿Qué lleva el pastel? |
| Llevan + plural | Las empanadas llevan carne y cebolla. |

- `Llevar` concorda com o **prato**, não com o ingrediente: `La salsa lleva tomates`, `Los macarrones llevan queso`.
- Sinônimos: `tener`, `contener`, `incluir`.

### 2. `Con` e `sin`

| Estrutura | Exemplo |
|---|---|
| con + substantivo | un café con leche |
| sin + substantivo | un café sin azúcar |
| con + artigo (específico) | pan con el queso de la casa |
| sin + gluten/lactosa | pasta sin gluten |
| con o sin | ¿Con o sin hielo? |

- Sem artigo quando o ingrediente é genérico: `sin sal`, `con aceite`, `con ajo`.

### 3. Ser alérgico, intolerante e vegetariano

| Estrutura | Exemplo |
|---|---|
| ser alérgico/a a + substantivo | Soy alérgica a las nueces. |
| ser alérgico/a al + masc. | Es alérgico al marisco. |
| ser intolerante a | Soy intolerante a la lactosa. |
| ser vegetariano/a | Mi hermana es vegetariana. |
| no poder comer + substantivo | No puedo comer gluten. |
| evitar + substantivo | Evito el azúcar. |

- `A + el` contrai em `al`: `alérgico al huevo`, `alérgico al marisco`.

### 4. Quantidades e medidas

| Medida | Exemplo |
|---|---|
| una cucharada de | una cucharada de aceite |
| una cucharadita de | una cucharadita de sal |
| una taza de | una taza de leche |
| un vaso de | un vaso de agua |
| cien gramos de | cien gramos de mantequilla |
| un litro de | un litro de leche |
| una pizca de | una pizca de pimienta |
| un diente de | un diente de ajo |
| un trozo de | un trozo de queso |
| un poco de | un poco de aceite |

- Depois de `de`, o ingrediente vem sem artigo: `una taza de harina`.

### 5. `Cuánto`, `cuánta`, `cuántos`, `cuántas`

| Forma | Exemplo |
|---|---|
| cuánto + masc. sing. | ¿Cuánto azúcar necesitas? |
| cuánta + fem. sing. | ¿Cuánta harina lleva? |
| cuántos + masc. pl. | ¿Cuántos huevos usas? |
| cuántas + fem. pl. | ¿Cuántas cebollas necesitas? |

- Concordam com o ingrediente. O mesmo vale para `mucho/a/os/as`, `poco/a/os/as`, `bastante` e `demasiado`.

### 6. Verbos de cozinha no presente

| Verbo | Mudança | yo | tú | nosotros |
|---|---|---|---|---|
| freír | e → i | frío | fríes | freímos |
| hervir | e → ie | hiervo | hierves | hervimos |
| calentar | e → ie | caliento | calientas | calentamos |
| cocer | o → ue | cuezo | cueces | cocemos |
| añadir | regular | añado | añades | añadimos |
| mezclar | regular | mezclo | mezclas | mezclamos |
| cortar | regular | corto | cortas | cortamos |
| hornear | regular | horneo | horneas | horneamos |

- `Freír` tem gerúndio `friendo` e particípio `frito` (irregular).
- `Cocer` tem o → ue e c → z na 1ª pessoa: `cuezo`.

### 7. Imperativo de `tú` em receitas

| Infinitivo | Imperativo | Exemplo |
|---|---|---|
| añadir | añade | Añade la sal. |
| mezclar | mezcla | Mezcla la harina. |
| cortar | corta | Corta el tomate. |
| pelar | pela | Pela las patatas. |
| hervir | hierve | Hierve el agua. |
| calentar | calienta | Calienta el aceite. |
| freír | fríe | Fríe las cebollas. |
| poner | pon | Pon el pollo en la sartén. |
| hacer | haz | Haz una salsa con tomate. |

- Em livros de receitas é comum o infinitivo: `Cortar la cebolla`, `Añadir sal`.

### 8. `Se` impessoal e passiva reflexa

| Estrutura | Exemplo |
|---|---|
| se + verbo singular | Se añade sal. |
| se + verbo plural | Se añaden dos huevos. |
| se necesita / se necesitan | Se necesitan tres tomates. |
| se hace con | Esta salsa se hace con tomate. |
| se come | Este plato se come caliente. |
| se corta en | Se corta en trozos. |

- O verbo concorda com o ingrediente: `se añade la sal`, `se añaden las cebollas`.

### 9. `Saber a`, `oler a` e `tener sabor`

| Estrutura | Exemplo |
|---|---|
| saber a + substantivo | Esto sabe a limón. |
| saber + adjetivo | Sabe muy dulce. |
| oler a + substantivo | La cocina huele a ajo. |
| tener sabor a | Tiene sabor a canela. |
| estar + adjetivo | Está salado / dulce / picante. |
| ser + adjetivo | Es picante. |

- Contraste: `saber a` (sabor) × `saber` (conhecer informação): `Sé la receta`.

### 10. Perguntas a um garçom ou cozinheiro

| Pergunta | Resposta |
|---|---|
| ¿Qué lleva el plato del día? | Lleva pescado y verduras. |
| ¿Tiene frutos secos? | No, no tiene. |
| ¿Es picante? | Un poco. |
| ¿Se puede pedir sin cebolla? | Sí, claro. |
| ¿Tiene opción vegetariana? | Sí, tenemos pasta con verduras. |
| ¿Está hecho con leche? | Sí, lleva un poco de leche. |
| ¿Hay gluten? | No, es sin gluten. |

## Diálogos

### Diálogo 1 — No restaurante

- Cliente: Perdone, ¿qué lleva la sopa del día?
- Camarero: Lleva verduras, patatas y un poco de jamón.
- Cliente: Soy vegetariano. ¿Puede hacerla sin jamón?
- Camarero: Sí, claro. La preparamos sin jamón.

### Diálogo 2 — Alergia

- Cliente: Soy alérgica a los frutos secos. ¿Este pastel tiene nueces?
- Camarero: Déjeme preguntar en la cocina.
- Camarero: Sí, lleva nueces. Pero el de limón no lleva.
- Cliente: Entonces tomo el de limón, gracias.

### Diálogo 3 — Cocinando

- Ana: ¿Qué ingredientes necesito para la tortilla?
- Luis: Cuatro huevos, dos patatas y una cebolla. Lleva un poco de sal.
- Ana: ¿Cuánto aceite necesito?
- Luis: Unas tres cucharadas. Fríe primero las patatas y la cebolla.

## Pontos de atenção e erros comuns

- **`Llevar`** = conter ("leva") ou vestir; o contexto decide: `Lleva ajo` (contém), `Lleva falda` (veste).
- **`Pimiento`** (pimentão, o legume) × **`pimienta`** (pimenta-do-reino, o condimento): palavras diferentes.
- **`Conservantes`** = conservantes (aditivos); **`preservativo`** em espanhol é camisinha, **não** conservante.
- **`Mantequilla`** (manteiga) × **`manteca`**: em muitos países `manteca` é banha de porco; no Cone Sul (Argentina, Uruguai) `manteca` é a manteiga.
- **`Nata`** (Espanha) × **`crema`** (América Latina) para creme de leite; **`cacahuete`** (Espanha) × **`maní`** (América Latina) para amendoim.
- **`Tortilla`**: na Espanha é um omelete de batata; no México é uma massa fina de milho ou trigo.
- **`El azúcar`** é masculino (`el azúcar blanco`); **`la sal`** é feminina (`la sal fina`).
- **`Cuánto`/`cuánta`** concordam com o ingrediente: `¿cuánta harina?`, `¿cuántos huevos?`.
- **`Alérgico a`** pede preposição `a` (`alérgico al marisco`), nunca *alérgico de*.
- **`Freír`** é irregular: `frío`, `fríes` (com acento no í), mas `freímos`.

## Complete as lacunas

1. ¿Qué ____ este plato? (leva) → `lleva`
2. Soy alérgico ____ marisco. (ao) → `al`
3. Una taza ____ harina. (de) → `de`
4. ¿____ huevos lleva? (quantos) → `Cuántos`
5. Esto ____ a limón. (tem gosto) → `sabe`
6. Yo ____ las patatas. (frito) → `frío`
