# Espanhol · Duolingo — Nível 16

> **Tema oficial:** Fale sobre comida · **Seção 2, Unidade 6** · Curso: Espanhol para falantes de português

## Visão geral

Neste nível você **fala sobre comida**: refeições do dia, pratos, bebidas, sabores, preferências e dieta. Entram `comer` e `beber`, as expressões com `tener` (**`tengo hambre`, `tengo sed`**), os **quantificadores** (`mucho`, `poco`, `bastante`, `un poco de`), **`ser` × `estar`** com comida, os adjetivos de sabor e verbos de cozinha como **`freír`, `hervir`, `probar`**.

```text
Desayuno café con leche y tostadas, y como arroz con pollo.      →  Tomo café com leite e torradas, e como arroz com frango.
Tengo mucha hambre y un poco de sed.                              →  Estou com muita fome e um pouco de sede.
La sopa está caliente, pero está muy rica.                        →  A sopa está quente, mas está muito gostosa.
```

Ideias centrais:

1. `Tener hambre` / `tener sed` (verbo `tener`, não `estar`): `tengo mucha hambre`.
2. Quantidade: `mucho`, `poco`, `bastante`, `demasiado` concordam com o substantivo (`mucha agua`).
3. `Ser` para natureza do alimento (`el limón es ácido`); `estar` para estado ou gosto agora (`la sopa está fría`).

## Gramática em exemplos

### 1. As refeições e os verbos

| Refeição | Verbo | Exemplo |
|---|---|---|
| el desayuno | desayunar | Desayuno a las ocho. |
| el almuerzo | almorzar (o → ue) | Almuerzo a las dos. |
| la merienda | merendar (e → ie) | Meriendo fruta. |
| la cena | cenar | Cenamos a las nueve. |
| la comida | comer | Como en casa. |

- `Comer` pode significar "comer" ou "almoçar", conforme o contexto.

### 2. `Comer` e `beber`

| Pessoa | comer | beber |
|---|---|---|
| yo | como | bebo |
| tú | comes | bebes |
| él / ella / usted | come | bebe |
| nosotros | comemos | bebemos |
| vosotros | coméis | bebéis |
| ellos / ustedes | comen | beben |

- `Tomar` também vale para bebidas e comida: `tomo un café`, `tomo una sopa`.

### 3. `Tener` + hambre, sed, sueño...

| Expressão | Exemplo | Tradução |
|---|---|---|
| tener hambre | Tengo mucha hambre. | Estou com muita fome. |
| tener sed | Tienen sed. | Eles estão com sede. |
| tener frío / calor | Tengo frío. | Estou com frio. |
| tener sueño | Tenemos sueño. | Estamos com sono. |
| tener ganas de | Tengo ganas de comer pizza. | Estou com vontade de comer pizza. |

- Com essas expressões use `mucho/mucha`, não `muy`: `mucha hambre`, `mucha sed`.
- `Hambre` é feminino, mas usa `el`: `el hambre`; os adjetivos ficam no feminino: `mucha hambre`.

### 4. `Querer`, `preferir` e `pedir`

| Pessoa | querer | preferir |
|---|---|---|
| yo | quiero | prefiero |
| tú | quieres | prefieres |
| él / ella / usted | quiere | prefiere |
| nosotros | queremos | preferimos |
| vosotros | queréis | preferís |
| ellos / ustedes | quieren | prefieren |

| Exemplo | Tradução |
|---|---|
| Quiero pasta. | Quero massa. |
| Prefiero arroz a pasta. | Prefiro arroz a massa. |
| ¿Qué prefieres, té o café? | O que prefere, chá ou café? |

- `Preferir A a B` = preferir A a B: `Prefiero el té al café`.

### 5. Quantidades

| Palavra | Uso | Exemplo |
|---|---|---|
| mucho / mucha | muito (+ subst.) | Hay mucha comida. |
| poco / poca | pouco | Come poca carne. |
| bastante | bastante | Hay bastante pan. |
| demasiado / demasiada | demais | Pones demasiada sal. |
| un poco de | um pouco de | Un poco de azúcar. |
| algo de | algum, um pouco de | ¿Quieres algo de postre? |
| nada de | nada de | No hay nada de leche. |

- Antes de substantivo, estes quantificadores concordam: `mucho pan`, `mucha sal`, `muchos huevos`, `muchas verduras`.

### 6. `Ser` e `estar` com comida

| Verbo | Exemplo | Sentido |
|---|---|---|
| ser | El limón es ácido. | característica permanente |
| ser | La sopa es de verduras. | de que é feito |
| estar | La sopa está caliente. | estado agora |
| estar | El pescado está fresco. | estado |
| estar | Esto está muy rico. | gosto na experiência |
| ser | La paella es española. | origem |

- Para dizer que algo está gostoso, o mais natural é `estar rico` / `estar buenísimo`; `ser rico` costuma significar "ter dinheiro".

### 7. Adjetivos de sabor e temperatura

| Adjetivo | Exemplo |
|---|---|
| dulce | El flan es dulce. |
| salado | Las patatas están muy saladas. |
| amargo | El café sin azúcar es amargo. |
| picante | La salsa es muy picante. |
| soso | La sopa está sosa. |
| crujiente | El pan está crujiente. |
| tierno | La carne está tierna. |

- Concordam em gênero e número: `la sopa sosa`, `los huevos fritos`.

### 8. Verbos de cozinha

| Verbo | Mudança | Exemplo |
|---|---|---|
| freír | e → i: frío, fríes, fríe, freímos, freís, fríen | Frío el huevo. |
| hervir | e → ie: hiervo, hierves, hierve, hervimos, hervís, hierven | Hiervo el arroz. |
| probar | o → ue: pruebo, pruebas, prueba… | Pruebo la salsa. |
| cortar | regular | Corto la cebolla. |
| mezclar | regular | Mezclo la harina. |
| añadir | regular | Añado sal. |

### 9. Negação e alimentos que evitamos

| Estrutura | Exemplo |
|---|---|
| no … nada | No como nada de carne. |
| no … ningún / ninguna | No hay ningún plato vegetariano. |
| no … nunca | Nunca como picante. |
| ni … ni | No bebo ni café ni té. |
| sin + substantivo | Un café sin azúcar. |
| ser alérgico a | Soy alérgico al marisco. |

- `Ninguno` vira `ningún` antes de substantivo masculino singular.
- `Sin` é "sem": `sin leche`, `sin gluten`.

### 10. Convites e preferências

| Frase | Uso |
|---|---|
| ¿Quieres comer algo? | oferecer comida |
| ¿Te apetece un café? | convite (Espanha) |
| ¿Qué te apetece cenar? | perguntar o que dá vontade |
| Me apetece una pizza. | desejo (Espanha) |
| Tengo ganas de comer… | vontade |
| ¡Buen provecho! | bom apetite |
| Está riquísimo. | elogio |

- `Apetecer` funciona como `gustar`: `me apetece`, `te apetece`, `nos apetecen unas tapas`.

## Diálogos

### Diálogo 1 — Hambre

- Ana: Tengo mucha hambre. ¿Qué hay para comer?
- Pablo: Hay arroz con pollo y ensalada.
- Ana: ¡Qué rico! ¿Hay postre?
- Pablo: Sí, fruta o un poco de flan.

### Diálogo 2 — Preferencias

- Luis: ¿Comes carne?
- Marta: No, soy vegetariana. Prefiero verduras y legumbres.
- Luis: Entonces cocino una sopa de verduras.
- Marta: Perfecto, y sin picante, por favor.

### Diálogo 3 — En la cocina

- A: ¿Puedo probar la salsa?
- B: Claro, pero está un poco picante.
- A: Está rica. Le falta sal.
- B: Añade un poco y mezcla bien.

## Pontos de atenção e erros comuns

- **`Tener hambre`**, não *estar com fome*: `tengo hambre`, `tienes sed`.
- **`Mucha hambre`** (não *muy hambre*): essas expressões levam `mucho/a`.
- **Gênero**: `la sal`, `la leche`, `la miel`, `el azúcar`, `el aceite`, `el pan`, `el agua` (feminino: `agua fría`).
- **Falso amigo**: `tortilla` na Espanha é omelete de batata; no México é o disco de milho/trigo.
- **Falso amigo**: `pastel` em espanhol é bolo/torta doce; o "pastel" frito brasileiro não é o mesmo.
- **`Aceite`** cobre óleo e azeite; para azeite diga `aceite de oliva`.
- **`Rico`** pode ser "gostoso" (`está rico`) ou "rico em dinheiro" (`es rico`); o contexto e o verbo ajudam a distinguir.
- **Regional**: `zumo` (Espanha) e `jugo` (América Latina) = suco; `cacahuete` (Espanha) e `maní` (América Latina) = amendoim; `judías` / `alubias` / `frijoles` / `porotos` = feijão.
- **`Comida`** é comida em geral e também a refeição principal em alguns países.
- **`Beber` × `tomar`**: `tomar un café` é muito comum; `beber` enfatiza o ato de beber.
- **Dupla negação**: `No como nada` é correto.
