# Espanhol · Duolingo — Nível 28

> **Tema oficial:** Descreva a aparência · **Seção 2, Unidade 18** · Curso: Espanhol para falantes de português

## Visão geral

Neste nível você aprende a **descrever a aparência de pessoas**: altura, corpo, cabelo, olhos, roupas e acessórios. Os verbos-chave são **`ser`** (características), **`tener`** (cabelo, olhos) e **`llevar`** (roupa, óculos, barba). O foco gramatical é a **concordância dos adjetivos** em gênero e número, a **posição do adjetivo** e as **comparações**.

```text
Mi hermano es alto y delgado. Tiene el pelo corto y los ojos verdes.     →  Meu irmão é alto e magro. Tem o cabelo curto e os olhos verdes.
Mi madre lleva gafas y tiene el pelo rizado.                             →  Minha mãe usa óculos e tem o cabelo cacheado.
¿Cómo es tu amiga? — Es morena, baja y muy simpática.                    →  Como é sua amiga? — É morena, baixa e muito simpática.
```

Ideias centrais:

1. `Ser` + adjetivo: `es alto`, `es joven`. `Tener` + artigo + parte do corpo + adjetivo: `tiene los ojos azules`.
2. `Llevar` + roupa/acessório: `lleva gafas`, `lleva barba`, `lleva una camisa roja`.
3. O adjetivo normalmente vem **depois** do substantivo e **concorda** com ele: `ojos verdes`, `pelo largo`, `camisas blancas`.

## Gramática em exemplos

### 1. `Ser` + adjetivo para características físicas

| Pessoa | Forma | Exemplo |
|---|---|---|
| yo | soy | Soy bajo. |
| tú | eres | Eres muy alta. |
| él / ella / usted | es | Es delgado. |
| nosotros | somos | Somos jóvenes. |
| vosotros | sois | Sois rubios. |
| ellos / ustedes | son | Son morenos. |

- `Ser` expressa características estáveis (altura, cabelo, idade).

### 2. `Tener` + artigo + parte do corpo + adjetivo

| Estrutura | Exemplo | Tradução |
|---|---|---|
| tener + el pelo + adj. | Tiene el pelo largo. | Tem o cabelo comprido. |
| tener + los ojos + adj. | Tienen los ojos azules. | Eles têm os olhos azuis. |
| tener + la nariz + adj. | Tengo la nariz pequeña. | Tenho o nariz pequeno. |
| tener + barba / bigote | Mi tío tiene barba. | Meu tio tem barba. |

| Pessoa | tener |
|---|---|
| yo | tengo |
| tú | tienes |
| él / ella | tiene |
| nosotros | tenemos |
| vosotros | tenéis |
| ellos / ellas | tienen |

- Diga `tiene **el** pelo largo` (artigo definido). Não use possessivo (`tiene su pelo largo`).

### 3. `Llevar` para roupa, óculos e barba

| Pessoa | Forma | Exemplo |
|---|---|---|
| yo | llevo | Llevo gafas. |
| tú | llevas | Llevas una camisa nueva. |
| él / ella / usted | lleva | Lleva barba. |
| nosotros | llevamos | Llevamos botas. |
| vosotros | lleváis | Lleváis gorra. |
| ellos / ustedes | llevan | Llevan uniforme. |

| Variante | Exemplo |
|---|---|
| llevar + substantivo | Lleva un sombrero. |
| llevar puesto/a | Lleva puesta una chaqueta azul. |
| ¿Qué lleva puesto? | O que está vestindo? |

- `Llevar` também é "levar" (`llevo el libro`) e "usar" (`llevo gafas`); o contexto resolve.

### 4. Concordância dos adjetivos em gênero e número

| Terminação do masc. sing. | Fem. sing. | Masc. plural | Fem. plural |
|---|---|---|---|
| -o: alto | alta | altos | altas |
| -e: fuerte | fuerte | fuertes | fuertes |
| consoante: joven | joven | jóvenes | jóvenes |
| -or: trabajador | trabajadora | trabajadores | trabajadoras |
| -ista: optimista | optimista | optimistas | optimistas |
| -és: francés | francesa | franceses | francesas |

| Exemplo | Tradução |
|---|---|
| un chico alto / una chica alta | um garoto alto / uma garota alta |
| dos hermanos rubios | dois irmãos loiros |
| unas amigas muy simpáticas | umas amigas muito simpáticas |

- Se o substantivo plural mistura masculino e feminino, o adjetivo vai ao masculino: `mis padres son altos`.
- `Joven` → `jóvenes` (o acento aparece para manter a sílaba tônica).

### 5. Concordância das cores

| Cor | Masc. / fem. singular | Plural |
|---|---|---|
| rojo | rojo / roja | rojos / rojas |
| blanco | blanco / blanca | blancos / blancas |
| azul | azul / azul | azules |
| verde | verde / verde | verdes |
| gris | gris / gris | grises |
| marrón | marrón / marrón | marrones |
| naranja | naranja / naranja | naranjas |
| rosa | rosa / rosa | rosas (também se vê `rosa`) |

| Exemplo | Tradução |
|---|---|
| una camisa roja | uma camisa vermelha |
| unos pantalones grises | umas calças cinza |
| ojos marrones | olhos castanhos |
| una camiseta azul claro | uma camiseta azul-claro |
| zapatos verde oscuro | sapatos verde-escuro |

- Cor composta com `claro` ou `oscuro` fica **invariável**: `azul claro`, `verde oscuro`, também no plural.

### 6. Posição do adjetivo

| Posição | Uso | Exemplo |
|---|---|---|
| depois do substantivo | descreve, distingue (padrão) | un hombre alto; ojos verdes; pelo largo |
| antes do substantivo | valor subjetivo ou de qualidade | una gran persona; un buen amigo; mi querida tía |

| Forma curta antes do substantivo masc. singular | Exemplo |
|---|---|
| bueno → buen | un buen chico |
| malo → mal | un mal día |
| grande → gran (singular) | un gran hombre |
| primero → primer | el primer día |

- `Un hombre grande` = homem de grande porte (físico); `un gran hombre` = grande homem (importância).

### 7. Perguntar como alguém é

| Pergunta | Resposta |
|---|---|
| ¿Cómo es tu hermano? | Es alto y moreno. |
| ¿Cómo es físicamente? | Es delgado y tiene el pelo corto. |
| ¿De qué color tiene el pelo? | Lo tiene castaño. |
| ¿De qué color son sus ojos? | Son verdes. |
| ¿Qué lleva puesto hoy? | Lleva una camisa blanca. |
| ¿Cuánto mide? | Mide un metro setenta. |
| ¿A quién te pareces? | Me parezco a mi padre. |

### 8. `Ser` x `estar` para a aparência

| Frase | Ideia |
|---|---|
| Es guapa. | Característica geral; ela é bonita. |
| Está guapa hoy. | Hoje, neste momento, ela está bonita. |
| Es delgado. | É magro por natureza. |
| Está delgado. | Ficou magro; está magro agora. |
| Es joven. | É jovem (idade). |
| Está muy elegante. | Hoje está muito elegante (impressão do momento). |

- Para o aspecto passageiro, de um evento ou de uma impressão, use `estar`.

### 9. Graduar e comparar

| Estrutura | Exemplo |
|---|---|
| muy + adjetivo | Es muy alto. |
| bastante + adjetivo | Es bastante delgada. |
| un poco + adjetivo | Es un poco baja. |
| demasiado + adjetivo | Es demasiado serio. |
| más … que | Mi padre es más alto que mi madre. |
| menos … que | Soy menos alto que mi hermano. |
| tan … como | Es tan rubia como su hermana. |
| mayor / menor que (idade) | Mi prima es mayor que yo. |
| mejor / peor que | Esta foto es mejor que la otra. |

- Para comparar idades use `mayor que` / `menor que`; para tamanho, `más grande que` / `más pequeño que`.

### 10. `Parecerse a` e `parecer`

| Pessoa | parecerse a (verbo reflexivo, c→zc na 1ª pessoa) |
|---|---|
| yo | me parezco a |
| tú | te pareces a |
| él / ella | se parece a |
| nosotros | nos parecemos a |
| vosotros | os parecéis a |
| ellos / ellas | se parecen a |

| Exemplo | Tradução |
|---|---|
| Me parezco a mi madre. | Pareço-me com minha mãe. |
| Se parece a su abuelo. | Ele se parece com o avô. |
| Parece mayor de lo que es. | Parece mais velho do que é. |
| Parece cansada. | Ela parece cansada. |


## Diálogos

### Diálogo 1 — Procurando alguém na festa

- Marta: ¿Conoces a mi primo Daniel?
- Luis: No. ¿Cómo es?
- Marta: Es alto, delgado y tiene el pelo castaño.
- Luis: ¿Lleva gafas?
- Marta: Sí, y hoy lleva una camisa azul.

### Diálogo 2 — Descrevendo a família

- Ana: ¿Te pareces a tu madre o a tu padre?
- Pablo: Me parezco a mi madre. Tengo sus ojos verdes.
- Ana: ¿Y tu hermano?
- Pablo: Él es moreno y más alto que yo. Se parece a mi padre.

### Diálogo 3 — Ponto de encontro

- Sara: No te veo. ¿Qué llevas puesto?
- Iván: Llevo una chaqueta negra y una gorra roja.
- Sara: Vale, estoy cerca de la puerta. Soy la chica rubia con el pelo largo.
- Iván: ¡Ya te veo! Estás muy guapa.

## Pontos de atenção e erros comuns

- **`Tener` + artigo**: `tiene el pelo largo`, `tiene los ojos azules`; o artigo definido substitui o possessivo.
- **`Largo` = comprido**, não "largo": o oposto de `corto` é `largo`; "largo" no sentido de largura é `ancho`.
- **`Pelo`** é cabelo (também pelo de animal ou do corpo); `cabello` é um pouco mais formal para cabelo da cabeça.
- **`Calvo`** é careca; `careca` não existe em espanhol.
- **`Gordo`** existe, mas pode soar ofensivo; para descrever alguém com delicadeza use `de complexión robusta` ou `corpulento`.
- **`Moreno/a`** pode se referir ao cabelo escuro ou à pele morena; `negro` para cabelo é mais direto (`pelo negro`).
- **`Ojos marrones`** é a forma mais comum na Espanha; no México usa-se muito `café` (invariável); `castaños` e `pardos` também existem.
- **`Gafas`** é sempre plural: `lleva gafas`. Também `pantalones` (ou `pantalón`) é usado no plural.
- **Cor + `claro/oscuro`** não varia: `camisas azul claro`.
- **`Joven` → `jóvenes`**; `mayor` não é "maior" no sentido de tamanho, e sim "mais velho/idoso".
- **`Ser` x `estar`**: `es guapo` (característica) x `está guapo` (hoje, com essa roupa).
