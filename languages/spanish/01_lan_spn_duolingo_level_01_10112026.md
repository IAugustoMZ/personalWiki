# Espanhol · Duolingo — Nível 1

> **Tema oficial:** Faça pedidos no café · **Seção 1, Unidade 1** · Curso: Espanhol para falantes de português

## Visão geral

Primeiro contato com o espanhol: **pedir algo em um café**. Para quem fala português, o espanhol é muito próximo, mas há armadilhas de pronúncia e de vocabulário. Aqui você aprende a pedir com educação, usar **artigos** (`un`, `una`, `el`, `la`) e perceber os primeiros **falsos amigos**.

```text
Quisiera un café con leche, por favor.                 →  Eu gostaria de um café com leite, por favor.
¿Qué desea tomar?                                      →  O que deseja tomar?
La cuenta, por favor.                                  →  A conta, por favor.
```

Ideias centrais:

1. Perguntas e exclamações levam **sinal de abertura** (`¿…?` e `¡…!`).
2. `Quisiera` e `Me gustaría` são as formas educadas de pedir.
3. Substantivos têm gênero: `el café`, `la leche`, `el agua` (feminino com artigo `el`).

## Gramática em exemplos

### 1. Artigos definidos

| Gênero | Singular | Plural |
|---|---|---|
| masculino | el | los |
| feminino | la | las |

| Exemplo | Tradução |
|---|---|
| el café | o café |
| la leche | o leite |
| los churros | os churros |
| las galletas | as bolachas |

### 2. Artigos indefinidos

| Gênero | Singular | Plural |
|---|---|---|
| masculino | un | unos |
| feminino | una | unas |

| Exemplo | Tradução |
|---|---|
| un café | um café |
| una tostada | uma torrada |
| unos churros | uns churros |
| unas galletas | umas bolachas |

### 3. Substantivos femininos com `el`

| Palavra | Gênero | Exemplo |
|---|---|---|
| el agua | feminino | el agua fría (adjetivo feminino) |
| el águila | feminino | el águila blanca |
| el hacha | feminino | el hacha afilada |
| plural | las aguas | las aguas frías |

- Substantivo feminino que começa com `a` tônica usa **`el`** no singular, mas é **feminino**.

### 4. `Quisiera` e `me gustaría`

| Estrutura | Exemplo |
|---|---|
| Quisiera + substantivo | Quisiera un café. |
| Quisiera + infinitivo | Quisiera pedir la cuenta. |
| Me gustaría + substantivo | Me gustaría un té. |
| ¿Podría traerme…? | ¿Podría traerme la carta? |

- Mais educado que `Quiero un café`.

### 5. Plural dos substantivos

| Terminação | Plural | Exemplo |
|---|---|---|
| vogal | + `s` | café → cafés |
| consoante | + `es` | limón → limones |
| `z` | `ces` | lápiz → lápices |
| terminada em `s` (não tônica) | igual | el lunes → los lunes |

### 6. Números 1–10

| Número | Espanhol |
|---|---|
| 1 | uno / una |
| 2 | dos |
| 3 | tres |
| 4 | cuatro |
| 5 | cinco |
| 6 | seis |
| 7 | siete |
| 8 | ocho |
| 9 | nueve |
| 10 | diez |

### 7. `Con` e `sin`

| Estrutura | Exemplo |
|---|---|
| con + substantivo | un café con leche |
| sin + substantivo | un café sin azúcar |
| con + pronome | conmigo, contigo |
| sin + infinitivo | sin pagar |

### 8. Perguntas com `¿Qué?` e `¿Cuánto?`

| Pergunta | Resposta |
|---|---|
| ¿Qué desea? | Un café, por favor. |
| ¿Cuánto cuesta? | Cuesta dos euros. |
| ¿Cuánto es? | Son cuatro euros. |
| ¿Cuántos cafés? | Dos. |

### 9. Cortesia: `usted` × `tú`

| Contexto | Pronome | Exemplo |
|---|---|---|
| desconhecidos, atendimento | usted | ¿Qué desea usted? |
| amigos, jovens | tú | ¿Qué quieres? |
| Espanha e Latino-América | varia | cheque o costume local |

### 10. Pronúncia: diferenças em relação ao português

| Letra | Som | Exemplo |
|---|---|---|
| j | /x/ (rr forte) | jamón |
| ll | /ʝ/ ou /ʎ/ | llevar |
| ñ | nh | español |
| ce, ci | /θ/ (Espanha) ou /s/ | cerveza |
| z | /θ/ ou /s/ | zumo |
| v | /b/ | vino |
| h | mudo | huevo |
| rr | r forte | churros |

## Diálogos

### Diálogo 1 — Pedido simples

- Camarero: Buenos días. ¿Qué desea tomar?
- Cliente: Buenos días. Quisiera un café con leche y una tostada, por favor.
- Camarero: ¿Algo más?
- Cliente: No, nada más. ¿Cuánto es?
- Camarero: Son tres euros con cincuenta.

### Diálogo 2 — Para levar

- Cliente: Un cortado, por favor.
- Camarero: ¿Para tomar aquí o para llevar?
- Cliente: Para llevar, gracias.
- Camarero: Aquí tiene. Que tenga un buen día.

### Diálogo 3 — Pedindo a conta

- Cliente: La cuenta, por favor.
- Camarero: Enseguida. Aquí tiene.
- Cliente: ¿Puedo pagar con tarjeta?
- Camarero: Por supuesto.

## Pontos de atenção e erros comuns

- **Sinais de abertura**: `¿Cuánto es?` e `¡Qué rico!`.
- **`Quiero`** é direto demais em atendimento; prefira `Quisiera` ou `Me gustaría`.
- **Falso amigo**: `exquisito` = delicioso (não “esquisito”, que é `raro`).
- **Falso amigo**: `rico` = gostoso (comida) ou rico (dinheiro); `salsa` = molho.
- **Falso amigo**: `taza` = xícara; `vaso` = copo; `cuchara` = colher.
- **Falso amigo**: `jugo` / `zumo` = suco (`zumo` na Espanha); `pastel` pode ser bolo ou torta doce.
- **`El agua`** é feminino: `el agua fría`, não *el agua frío*.

## Complete as lacunas

1. ____ un café, por favor. (gostaria) → `Quisiera`
2. ____ cuenta, por favor. (a) → `La`
3. Un café ____ leche. (com) → `con`
4. Un té ____ azúcar. (sem) → `sin`
5. ____ cuesta? (quanto) → `¿Cuánto`
6. ____ gracias. (muito) → `Muchas`
