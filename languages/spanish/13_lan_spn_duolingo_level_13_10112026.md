# Espanhol · Duolingo — Nível 13

> **Tema oficial:** Fale sobre esportes · **Seção 2, Unidade 3** · Curso: Espanhol para falantes de português

## Visão geral

Neste nível você **fala sobre esportes**: quais pratica, com que frequência treina, o que acompanha na TV e como foi um jogo. Entram os **nomes de esportes**, o verbo **`jugar`** (u → ue) com `a`, a diferença entre **`jugar`, `practicar` e `hacer`**, o gerúndio com **`estar`**, os **comparativos e superlativos** e o vocabulário de **resultado** (`ganar`, `perder`, `empatar`).

```text
Juego al fútbol los sábados y hago natación los martes.     →  Jogo futebol aos sábados e faço natação às terças.
Mi equipo gana por dos a uno.                                →  Meu time ganha por dois a um.
Es el mejor jugador del equipo.                              →  É o melhor jogador do time.
```

Ideias centrais:

1. `Jugar a` + esporte de bola/jogo: `jugar al tenis`; `hacer` + esporte individual: `hacer natación`.
2. `Jugar` muda a raiz: `juego`, `juegas`, `juega`, `jugamos`, `jugáis`, `juegan`.
3. `Estar` + gerúndio mostra o que acontece agora: `Está jugando muy bien`.

## Gramática em exemplos

### 1. `Jugar` (u → ue)

| Pessoa | Forma |
|---|---|
| yo | juego |
| tú | juegas |
| él / ella / usted | juega |
| nosotros | jugamos |
| vosotros | jugáis |
| ellos / ustedes | juegan |

| Exemplo | Tradução |
|---|---|
| Juego al baloncesto. | Jogo basquete. |
| ¿Juegas al pádel? | Você joga padel? |
| Jugamos al fútbol en el parque. | Jogamos futebol no parque. |

- `Jugar` é o único verbo comum com mudança `u → ue`. Nós e vós mantêm o `u`.

### 2. `Jugar a`, `hacer` e `practicar`

| Verbo | Quando usar | Exemplo |
|---|---|---|
| jugar a + el/la | esportes de bola, equipe, jogo | Juego al tenis. / Juego a las cartas. |
| hacer + esporte | atividades individuais | Hago natación. / Hago yoga. |
| practicar + esporte | qualquer esporte | Practico ciclismo. / Practico tenis. |
| ir a | ir para a atividade | Voy a nadar. / Voy al gimnasio. |

- `A + el = al`: `jugar al fútbol`, `jugar al tenis`. Em parte da América Latina também se ouve `jugar fútbol` sem preposição.
- Esportes como `atletismo`, `natación`, `ciclismo`, `senderismo` combinam com `hacer` ou `practicar`.

### 3. `Gustar`, `encantar` e `preferir` com esportes

| Estrutura | Exemplo |
|---|---|
| me gusta + infinitivo | Me gusta correr. |
| me gusta + substantivo singular | Me gusta el tenis. |
| me gustan + substantivo plural | Me gustan los deportes de equipo. |
| me encanta | Me encanta nadar. |
| prefiero + infinitivo | Prefiero entrenar por la mañana. |
| no me gusta | No me gusta perder. |

- `Preferir` muda e → ie: `prefiero`, `prefieres`, `prefiere`, `preferimos`, `preferís`, `prefieren`.

### 4. Frequência e duração

| Pergunta | Resposta |
|---|---|
| ¿Con qué frecuencia entrenas? | Tres veces a la semana. |
| ¿Cuántas veces juegas al mes? | Dos veces al mes. |
| ¿Cuánto tiempo entrenas? | Una hora cada día. |
| ¿Cuándo juegas? | Los sábados por la tarde. |
| ¿A qué hora es el partido? | A las nueve. |

- `Una vez`, `dos veces`: `veces` é o plural de `vez` (z → c).

### 5. `Estar` + gerúndio

| Verbo | Gerúndio | Exemplo |
|---|---|---|
| jugar | jugando | Estoy jugando al fútbol. |
| correr | corriendo | Estamos corriendo en el parque. |
| nadar | nadando | Está nadando en la piscina. |
| entrenar | entrenando | Estoy entrenando para el torneo. |
| ganar | ganando | Mi equipo está ganando. |

- Gerúndio: -ar → `-ando`; -er/-ir → `-iendo`.
- Para hábitos use o presente simples (`Juego los sábados`); para o que acontece agora, `estoy jugando`.

### 6. Comparar jogadores e esportes

| Estrutura | Exemplo |
|---|---|
| más … que | El tenis es más lento que el baloncesto. |
| menos … que | El golf es menos intenso que el rugby. |
| tan … como | Ella corre tan rápido como yo. |
| tanto … como | Juego tanto como mi hermano. |
| mejor / peor | Este equipo es mejor que el otro. |
| mayor / menor | Mi hermano mayor juega al balonmano. |

### 7. Superlativos

| Estrutura | Exemplo |
|---|---|
| el más + adjetivo + de | Es el jugador más rápido del equipo. |
| la más + adjetivo + de | Es la deportista más famosa del país. |
| el mejor / la mejor | Es el mejor portero de la liga. |
| -ísimo | Es rapidísimo. |
| el que más | Es el que más entrena. |

- O superlativo usa `de`, não *em*: `del equipo`, `de la liga`.

### 8. Resultados

| Resultado | Espanhol |
|---|---|
| 1 – 0 | uno a cero |
| 2 – 1 | dos a uno |
| 3 – 3 | tres a tres |
| empate | un empate |
| vitória | una victoria |
| derrota | una derrota |

| Exemplo | Tradução |
|---|---|
| Ganamos dos a uno. | Ganhamos de dois a um. |
| Perdemos por tres goles. | Perdemos por três gols. |
| Empatan a cero. | Empatam em zero a zero. |

- `Perder` muda e → ie: `pierdo`, `pierdes`, `pierde`, `perdemos`, `perdéis`, `pierden`.

### 9. Obrigação e capacidade

| Estrutura | Exemplo |
|---|---|
| tener que + infinitivo | Tengo que entrenar hoy. |
| hay que + infinitivo | Hay que beber agua. |
| poder (o → ue) + infinitivo | Puedo correr diez kilómetros. |
| saber + infinitivo | Sé nadar muy bien. |
| deber + infinitivo | Debes calentar antes de jugar. |

- `Saber` + infinitivo = saber fazer (habilidade); `poder` = ter possibilidade.

### 10. Planos e convites

| Estrutura | Exemplo |
|---|---|
| ir a + infinitivo | Voy a jugar al tenis mañana. |
| ¿Quieres + infinitivo? | ¿Quieres jugar conmigo? |
| ¿Vamos a + infinitivo? | ¿Vamos a nadar? |
| Sí, vamos | Sí, vamos a las cinco. |
| No puedo | No puedo, tengo que estudiar. |

- `Querer` muda e → ie: `quiero`, `quieres`, `quiere`.

## Pontos de atenção e erros comuns

- **`Jugar` muda a raiz**: `juego` (não *jugo*), `juegan` (não *jugan*); `jugamos` e `jugáis` não mudam.
- **`Jugar al` + esporte**: `juego al tenis`, não *juego el tenis*; `a + el = al`.
- **`Hacer natación` / `practicar natación`**, não *jugar natación*.
- **Falso amigo**: `partido` em espanhol é o **jogo** (partida); em português, partido é "party/partido político". `Juego` é o jogo em geral (`el juego`).
- **`Equipo`** é time/equipe e também equipamento.
- **`Balón` × `pelota`**: `balón` é usado para futebol, basquete e vôlei; `pelota` para tênis, beisebol e pequenas bolas (na América Latina `pelota` é usado de modo geral).
- **`Campo` × `cancha`**: `campo` (Espanha) e `cancha` (América Latina) para futebol; a quadra de tênis é `pista` (Espanha) ou `cancha`.
- **`Hincha`** (América Latina) × `aficionado` (Espanha) para torcedor.
- **`Ganar`** também significa ganhar dinheiro: `gana mucho dinero`.
- **Placar**: usa-se `a` entre os números (`dos a uno`); `por` indica a margem de diferença (`ganamos por dos goles`).
