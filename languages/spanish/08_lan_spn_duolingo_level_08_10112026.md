# Espanhol · Duolingo — Nível 8

> **Tema oficial:** Fale sobre idiomas · **Seção 1, Unidade 8** · Curso: Espanhol para falantes de português

## Visão geral

Neste nível você **fala sobre idiomas**: quais fala, entende, aprende e estuda; o nível de cada um; e como praticar. Entram os verbos **`hablar`**, **`entender`**, **`aprender`**, **`estudiar`**, o uso de **`saber`** + infinitivo, os **advérbios de grau** e a conjugação dos verbos regulares em `-ar`, `-er`, `-ir`.

```text
Hablo portugués, entiendo inglés y estudio español.            →  Falo português, entendo inglês e estudo espanhol.
Mi hermano sabe hablar francés muy bien.                       →  Meu irmão sabe falar francês muito bem.
Aprendo español porque quiero viajar a México.                 →  Aprendo espanhol porque quero viajar ao México.
```

Ideias centrais:

1. Línguas são **masculinas** e escritas sem maiúscula: `el español`, `el inglés`.
2. `Hablar` + língua não leva artigo: `hablo español`; com `estudiar`, `aprender`, `entender`, o artigo é opcional.
3. `Saber` + infinitivo = “saber fazer”: `Sé nadar`.

## Gramática em exemplos

### 1. Verbos regulares em `-ar` (hablar, estudiar)

| Pessoa | hablar | estudiar |
|---|---|---|
| yo | hablo | estudio |
| tú | hablas | estudias |
| él / ella / usted | habla | estudia |
| nosotros | hablamos | estudiamos |
| vosotros | habláis | estudiáis |
| ellos / ustedes | hablan | estudian |

### 2. Verbos regulares em `-er` e `-ir`

| Pessoa | entender¹ | aprender | escribir |
|---|---|---|---|
| yo | entiendo | aprendo | escribo |
| tú | entiendes | aprendes | escribes |
| él / ella / usted | entiende | aprende | escribe |
| nosotros | entendemos | aprendemos | escribimos |
| vosotros | entendéis | aprendéis | escribís |
| ellos / ustedes | entienden | aprenden | escriben |

- ¹ `entender` é irregular (`e → ie`), exceto em `nosotros/vosotros`.

### 3. `Saber` + infinitivo

| Pessoa | saber |
|---|---|
| yo | sé |
| tú | sabes |
| él / ella / usted | sabe |
| nosotros | sabemos |
| vosotros | sabéis |
| ellos / ustedes | saben |

| Exemplo | Tradução |
|---|---|
| Sé nadar. | Sei nadar. |
| Sé hablar tres idiomas. | Sei falar três idiomas. |
| No sé cocinar. | Não sei cozinhar. |

### 4. Artigo com idiomas

| Verbo | Artigo? | Exemplo |
|---|---|---|
| hablar | não | Hablo español. |
| entender | opcional | Entiendo (el) italiano. |
| estudiar | sim, comum | Estudio el español. |
| aprender | opcional | Aprendo (el) inglés. |
| en + idioma | não | Escribo en español. |
| ser (sujeito) | sim | El español es fácil. |

### 5. Advérbios de grau

| Espanhol | Exemplo |
|---|---|
| muy bien | Hablo muy bien inglés. |
| bastante bien | Entiendo bastante bien. |
| un poco | Hablo un poco de francés. |
| mal | Hablo mal alemán. |
| con fluidez | Habla con fluidez. |
| con dificultad | Lee con dificultad. |

- `Un poco de` + substantivo: `un poco de español`.

### 6. Pronomes objeto `lo`, `la`

| Frase | Substituição |
|---|---|
| Hablo español. | Lo hablo. |
| Entiendo el francés. | Lo entiendo. |
| Escribo cartas. | Las escribo. |
| Aprendo palabras nuevas. | Las aprendo. |

### 7. Perguntas sobre idiomas

| Pergunta | Resposta |
|---|---|
| ¿Qué idiomas hablas? | Hablo portugués y español. |
| ¿Hablas inglés? | Sí, un poco. |
| ¿Desde cuándo estudias español? | Desde hace dos años. |
| ¿Por qué aprendes español? | Porque quiero viajar. |
| ¿Cómo practicas? | Veo series y leo libros. |

### 8. `Desde hace` e `hace`

| Estrutura | Exemplo |
|---|---|
| desde hace + duração | Estudio español desde hace dos años. |
| hace + duração (passado) | Empecé hace dos años. |
| desde + data | Estudio desde enero. |
| llevar + gerúndio | Llevo dos años estudiando. |

## Pontos de atenção e erros comuns

- **Línguas sem maiúscula**: `español`, `portugués`.
- **`Hablar` + língua** sem artigo; **`en`** + língua para meio: `escribo en español`.
- **`Saber`** + infinitivo = habilidade; **`conocer`** = conhecer pessoa/lugar.
- **Falso amigo**: `apuntar` = anotar; `asistir` = estar presente (não “assistir”).
- **Falso amigo**: `lengua` = língua (idioma e órgão); `idioma` = idioma.
- **Falso amigo**: `traducir` = traduzir; `traer` = trazer.
- **`Hace`** + tempo no passado: `hace dos años`.

## Complete as lacunas

1. Yo ____ español. (falo) → `hablo`
2. Tú ____ inglés. (entendes) → `entiendes`
3. ¿Cómo se ____ ? (escreve) → `escribe`
4. ____ nadar. (sei) → `Sé`
5. Estudio español ____ hace dos años. (há, desde) → `desde`
6. Lo ____ mal. (falo) → `hablo`
