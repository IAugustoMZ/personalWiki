# Espanhol · Duolingo — Nível 24

> **Tema oficial:** Pergunte como alguém se sente · **Seção 2, Unidade 14** · Curso: Espanhol para falantes de português

## Visão geral

Neste nível você **pergunta e descreve como alguém se sente**: emoções, estados físicos e pequenos problemas de saúde. Entram `estar` + adjetivo (`estoy cansado`), `tener` + substantivo (`tengo hambre`), `sentirse` (e → ie), `doler` (o → ue) e as fórmulas de **consolo e empatia**.

```text
¿Cómo estás? — Estoy un poco cansada, pero bien.          →  Como você está? — Estou um pouco cansada, mas bem.
¿Qué te pasa? — Me duele la cabeza y tengo fiebre.        →  O que você tem? — Me dói a cabeça e estou com febre.
Me siento muy contento hoy.                               →  Estou me sentindo muito contente hoje.
```

Ideias centrais:

1. Estados temporários: `estar` + adjetivo (`estoy triste`, `está nervioso`).
2. Sensações: `tener` + substantivo (`tengo frío`, `tiene sueño`), sem `muy`, com `mucho`.
3. Dores: `me duele(n)` + parte do corpo, com artigo (`me duele **la** cabeza`).

## Gramática em exemplos

### 1. `Estar` + adjetivo (estados temporários)

| Pessoa | Forma | Exemplo |
|---|---|---|
| yo | estoy | Estoy cansado. |
| tú | estás | Estás muy serio. |
| él / ella / usted | está | Ella está preocupada. |
| nosotros | estamos | Estamos contentos. |
| vosotros | estáis | ¿Estáis nerviosos? |
| ellos / ustedes | están | Están tristes. |

- O adjetivo concorda em gênero e número com quem sente: `ella está cansada`, `ellos están cansados`.

### 2. `Tener` + substantivo (sensações)

| Expressão | Exemplo |
|---|---|
| tener hambre | Tengo hambre. |
| tener sed | Tiene sed. |
| tener sueño | Tenemos sueño. |
| tener frío | Tengo frío. |
| tener calor | Tiene calor. |
| tener miedo | Tengo miedo. |
| tener prisa | Tienen prisa. |
| tener razón | Tienes razón. |
| tener suerte | Tengo suerte. |

- Intensificador: `mucho/mucha`, **nunca** `muy`: `tengo mucha hambre`, `tengo mucho frío`.
- Não se usa `estar` com essas expressões: *estoy hambre* está errado.

### 3. `Sentirse` (e → ie, reflexivo)

| Pessoa | Forma |
|---|---|
| yo | me siento |
| tú | te sientes |
| él / ella / usted | se siente |
| nosotros | nos sentimos |
| vosotros | os sentís |
| ellos / ustedes | se sienten |

| Estrutura | Exemplo |
|---|---|
| sentirse + advérbio | Me siento mal. / Me siento mejor. |
| sentirse + adjetivo | Me siento cansada. |
| sentirse + muy + adjetivo | Se sienten muy felices. |
| ¿Cómo te sientes? | Me siento bien. |

- Atenção: `Me siento bien/mal` (advérbio, não varia) × `me siento cansado/a` (adjetivo, varia).

### 4. `Doler` (o → ue) como `gustar`

| Estrutura | Exemplo |
|---|---|
| me duele + singular | Me duele la cabeza. |
| me duelen + plural | Me duelen los pies. |
| te duele | ¿Te duele el estómago? |
| le duele | A mi madre le duele la espalda. |
| nos duele | Nos duelen las piernas. |
| les duele | A ellos les duele la garganta. |

- O verbo concorda com a parte do corpo, não com a pessoa.
- Usa-se artigo definido: `me duele **la** cabeza`, não *me duele mi cabeza*.

### 5. `Ser` × `estar` com adjetivos de sentimento

| Adjetivo | Com `ser` | Com `estar` |
|---|---|---|
| aburrido | Es aburrido (é chato) | Está aburrido (está entediado) |
| listo | Es listo (é esperto) | Está listo (está pronto) |
| cansado | Es cansado (é cansativo) | Está cansado (está cansado) |
| malo | Es malo (é mau) | Está malo (está doente, em vários países) |
| nervioso | Es nervioso (temperamento) | Está nervioso (agora) |

- `Ser` = característica permanente; `estar` = estado do momento.

### 6. Perguntar como alguém está

| Registro | Pergunta | Resposta |
|---|---|---|
| informal | ¿Cómo estás? | Bien, ¿y tú? |
| informal | ¿Qué tal? | Muy bien. / Así así. |
| formal | ¿Cómo está usted? | Muy bien, gracias. |
| preocupação | ¿Qué te pasa? | Nada, estoy cansado. |
| saúde | ¿Te encuentras bien? | Me duele la cabeza. |
| plural | ¿Cómo estáis? / ¿Cómo están? | Estamos bien. |

### 7. Gradação de intensidade

| Intensidade | Exemplo |
|---|---|
| un poco | Estoy un poco triste. |
| bastante | Estoy bastante cansado. |
| muy | Estoy muy contento. |
| demasiado | Estoy demasiado nervioso. |
| nada | No estoy nada preocupado. |
| tan… que | Estoy tan cansado que no puedo estudiar. |

- `Muy` vai antes do adjetivo; `mucho` modifica o verbo ou substantivo.

### 8. `Estar` + gerúndio e `acabar de` para estados

| Estrutura | Exemplo |
|---|---|
| estar + gerúndio | Estoy durmiendo mal estos días. |
| estar sintiéndose | Se está sintiendo mejor. |
| acabar de + infinitivo | Acabo de recibir una mala noticia. |
| seguir + gerúndio | Sigue sintiéndose mal. |
| ponerse + adjetivo | Me pongo nervioso en los exámenes. |
| quedarse + adjetivo | Me quedo tranquilo. |

- `Ponerse` + adjetivo indica uma mudança de estado: `se pone triste`, `se pone rojo`.

### 9. Consolar e animar

| Situação | Fórmula |
|---|---|
| tristeza | Lo siento mucho. / ¡Qué pena! |
| doença | Que te mejores. / ¡Mejórate pronto! |
| preocupação | No te preocupes. / Tranquilo. |
| cansaço | Descansa un poco. |
| alegria | ¡Me alegro mucho! / ¡Qué bien! |
| apoio | Estoy aquí para ayudarte. |
| sugestão | Deberías hablar con alguien. |

### 10. Verbos de emoção com pronome (tipo `gustar`)

| Verbo | Exemplo | Tradução |
|---|---|---|
| preocupar | Me preocupa el examen. | A prova me preocupa. |
| alegrar | Me alegra verte. | Me alegra te ver. |
| molestar | Me molesta el ruido. | O barulho me incomoda. |
| dar miedo | Me dan miedo las arañas. | Aranhas me dão medo. |
| dar vergüenza | Me da vergüenza hablar. | Tenho vergonha de falar. |
| poner nervioso | Me pone nervioso esperar. | Esperar me deixa nervoso. |

## Diálogos

### Diálogo 1 — Encontro entre amigos

- Ana: Hola, Luis, ¿cómo estás?
- Luis: Estoy un poco cansado. Duermo mal estos días.
- Ana: Vaya. ¿Y por qué?
- Luis: Estoy nervioso por el examen de mañana.

### Diálogo 2 — Mal-estar físico

- Marta: ¿Qué te pasa? Tienes mala cara.
- Pedro: Me duele la cabeza y tengo mucho frío.
- Marta: Creo que tienes fiebre. Tienes que descansar.
- Pedro: Sí, voy a quedarme en casa.
- Marta: Que te mejores pronto. Cuídate.

### Diálogo 3 — Formal

- Doctora: Buenos días. ¿Cómo se siente?
- Paciente: Me siento mal. Me duele el estómago.
- Doctora: ¿Tiene fiebre?
- Paciente: No, pero estoy mareado.
- Doctora: No se preocupe. Vamos a ver qué tiene.

## Pontos de atenção e erros comuns

- **`Tener` + sensação**: `tengo hambre`, `tengo frío` — não se usa `estar`.
- **`Mucho`/`mucha`** com essas expressões: `tengo mucho sueño`, nunca *muy sueño*.
- **`Me siento bien`** (advérbio) × **`me siento cansada`** (adjetivo concorda).
- **`Doler`** concorda com o substantivo: `me duele la mano`, `me duelen las manos`.
- **`Embarazada`** = grávida, **não** "embaraçada"; para "envergonhado" use `avergonzado`.
- **`Estar`** × **`ser`**: `está aburrido` (entediado) × `es aburrido` (chato).
- **`Enfadado`** (Espanha) e **`enojado`** (América Latina) = bravo, irritado.
- **`Mareado`** cobre "tonto" e "enjoado" (tontura ou náusea).
- **Artigo com partes do corpo**: `Me lavo las manos`, `Me duele la cabeza` — o possessivo não é usado.
- **`Cuidar` × `cuidarse`**: `Cuídate` = "se cuide"; `cuidar a alguien` = cuidar de alguém.
