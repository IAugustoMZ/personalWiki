# Espanhol · Duolingo — Nível 15

> **Tema oficial:** Participe da aula · **Seção 2, Unidade 5** · Curso: Espanhol para falantes de português

## Visão geral

Neste nível você **participa de uma aula** em espanhol: entende o que o professor pede, faz perguntas, pede ajuda e responde. Entram o **vocabulário de sala de aula**, o **imperativo** (`abre`, `escuche`, `repitan`), as **palavras interrogativas** (`qué`, `cómo`, `por qué`), os pedidos educados (`¿Puede repetir?`) e a diferença entre **`pedir`, `preguntar` e `responder`**.

```text
Abran el libro en la página diez.                          →  Abram o livro na página dez.
¿Puede repetir, por favor? No entiendo.                    →  Pode repetir, por favor? Não entendo.
¿Cómo se dice "obrigado" en español?                       →  Como se diz "obrigado" em espanhol?
```

Ideias centrais:

1. O professor usa o **imperativo**: `escuchen`, `lean`, `escriban`; entre amigos, `escucha`, `lee`.
2. Pedidos educados: `¿Puede…?`, `¿Podría…?`, `por favor`, `perdone`.
3. Interrogativos levam acento gráfico: `qué`, `quién`, `cuándo`, `dónde`, `cómo`, `por qué`.

## Gramática em exemplos

### 1. Imperativo afirmativo com `tú`

| Verbo | Imperativo `tú` | Exemplo |
|---|---|---|
| abrir | abre | Abre el libro. |
| escuchar | escucha | Escucha el audio. |
| leer | lee | Lee la frase. |
| repetir | repite | Repite la palabra. |
| escribir | escribe | Escribe tu nombre. |
| mirar | mira | Mira la pizarra. |
| esperar | espera | Espera un momento. |

- O imperativo afirmativo de `tú` é igual à forma de `él/ella` do presente: `abre`, `escucha`, `repite`.

### 2. Imperativo `tú` irregular

| Verbo | Forma | Exemplo |
|---|---|---|
| venir | ven | Ven aquí. |
| decir | di | Di la respuesta. |
| hacer | haz | Haz el ejercicio. |
| ir | ve | Ve a la pizarra. |
| poner | pon | Pon el libro en la mesa. |
| salir | sal | Sal de la clase. |
| ser | sé | Sé puntual. |
| tener | ten | Ten paciencia. |

- São oito formas curtas que não seguem a regra de `él/ella`; vale decorá-las.

### 3. Imperativo com `usted` e `ustedes`

| Verbo | usted | ustedes |
|---|---|---|
| abrir | abra | abran |
| escuchar | escuche | escuchen |
| leer | lea | lean |
| repetir | repita | repitan |
| escribir | escriba | escriban |
| hablar | hable | hablen |
| venir | venga | vengan |

- O imperativo de `usted(es)` usa a forma do subjuntivo: -ar → `-e/-en`; -er/-ir → `-a/-an`.
- `Vosotros` (Espanha): `abrid`, `escuchad`, `leed`, `repetid`.

### 4. Imperativo negativo

| Afirmativo | Negativo `tú` | Negativo `usted` |
|---|---|---|
| Habla. | No hables. | No hable. |
| Abre. | No abras. | No abra. |
| Escribe. | No escribas. | No escriba. |
| Haz. | No hagas. | No haga. |
| Ve. | No vayas. | No vaya. |
| Di. | No digas. | No diga. |

- No negativo, `tú` usa as terminações `-es` (verbos em -ar) e `-as` (-er/-ir). Não use a forma afirmativa: *no habla* não funciona como ordem.

### 5. Interrogativos

| Palavra | Uso | Exemplo |
|---|---|---|
| qué | o que | ¿Qué significa esto? |
| quién / quiénes | quem | ¿Quién sabe la respuesta? |
| cuál / cuáles | qual | ¿Cuál es tu asignatura favorita? |
| cuándo | quando | ¿Cuándo es el examen? |
| dónde | onde | ¿Dónde está la tarea? |
| cómo | como | ¿Cómo se escribe? |
| cuánto / cuánta | quanto | ¿Cuánto dura la clase? |
| por qué | por que | ¿Por qué estudias español? |

- Todos levam **acento** e **¿ ?** nas perguntas.
- `Cuál` se usa antes de `ser` e verbo: `¿Cuál es tu libro?`; `qué` antes de substantivo: `¿Qué libro es?`.

### 6. `Por qué`, `porque`, `porqué`, `por que`

| Forma | Sentido | Exemplo |
|---|---|---|
| por qué | pergunta "por que" | ¿Por qué llegas tarde? |
| porque | resposta "porque" | Porque pierdo el autobús. |
| porqué | o motivo (substantivo) | No sé el porqué. |
| por que (ou por la que) | preposição + relativo | La razón por la que estudio es viajar. |

- Para perguntar use sempre `por qué` (duas palavras e acento); para responder, `porque`.

### 7. Pedidos educados

| Estrutura | Exemplo |
|---|---|
| ¿Puede + infinitivo? | ¿Puede repetir, por favor? |
| ¿Podría + infinitivo? | ¿Podría explicarlo otra vez? |
| ¿Me puede + infinitivo? | ¿Me puede ayudar? |
| ¿Puedo + infinitivo? | ¿Puedo salir un momento? |
| Perdone / Disculpe | Perdone, profesora, no entiendo. |
| Por favor | Más despacio, por favor. |

- `Poder` muda o → ue: `puedo`, `puedes`, `puede`, `podemos`, `podéis`, `pueden`.

### 8. Verbos úteis com mudança de raiz

| Verbo | yo | él / ella | nosotros |
|---|---|---|---|
| entender (e → ie) | entiendo | entiende | entendemos |
| pensar (e → ie) | pienso | piensa | pensamos |
| repetir (e → i) | repito | repite | repetimos |
| recordar (o → ue) | recuerdo | recuerda | recordamos |
| poder (o → ue) | puedo | puede | podemos |
| contar (o → ue) | cuento | cuenta | contamos |

| Exemplo | Tradução |
|---|---|
| No entiendo la pregunta. | Não entendo a pergunta. |
| Recuerdo las palabras. | Lembro as palavras. |

### 9. `Preguntar`, `pedir` e `responder`

| Verbo | Sentido | Exemplo |
|---|---|---|
| preguntar | fazer uma pergunta | Pregunto al profesor. |
| pedir | solicitar algo | Pido un bolígrafo. |
| responder / contestar | dar resposta | Respondo a la pregunta. |
| preguntar por | perguntar sobre alguém | Pregunto por mi amigo. |
| pedir ayuda | pedir ajuda | Pido ayuda a mi compañero. |

- `Pedir` muda e → i: `pido`, `pides`, `pide`. `Pedir` = solicitar; `preguntar` = fazer pergunta.

### 10. Horário, dias e matérias

| Estrutura | Exemplo |
|---|---|
| los + dia | Los lunes tengo matemáticas. |
| a las + hora | La clase empieza a las ocho. |
| de … a … | De ocho a diez tenemos historia. |
| hay + clase / examen | Hoy hay examen. |
| tener + clase de | Tengo clase de inglés. |
| ser + día / hora | La tarea es para el viernes. |

## Diálogos

### Diálogo 1 — En clase

- Profesora: Buenos días. Abran el libro en la página doce.
- Alumno: Profesora, ¿puede repetir la página?
- Profesora: Claro, la página doce. Lean el texto.
- Alumno: Gracias.

### Diálogo 2 — Una duda

- Marta: Profesor, ¿qué significa "tarea"?
- Profesor: Significa trabajo que haces en casa.
- Marta: ¿Cómo se escribe?
- Profesor: T-A-R-E-A. Escríbela en tu cuaderno.

### Diálogo 3 — Entre compañeros

- Luis: ¿Me prestas un bolígrafo?
- Ana: Sí, toma. ¿Cuándo es el examen?
- Luis: El miércoles. ¿Estudiamos juntos?
- Ana: Vale, ven a mi casa mañana.

## Pontos de atenção e erros comuns

- **`Pedir` × `preguntar`**: `pedir` = solicitar (`pido ayuda`); `preguntar` = fazer pergunta (`pregunto la hora`). *Pedir una pregunta* é incorreto.
- **Imperativo `tú`**: use `abre`, `lee`, `escribe`; a forma negativa muda: `no abras`, `no leas`.
- **Imperativo irregular**: `ven`, `di`, `haz`, `ve`, `pon`, `sal`, `sé`, `ten`.
- **`Por qué` × `porque`**: pergunta com `por qué`, resposta com `porque`.
- **`Aula`** é feminino, mas leva `el`: `el aula`, `las aulas`.
- **`Examen`** → plural `exámenes` (o acento aparece).
- **`Lápiz`** → plural `lápices` (z → c).
- **Atenção a `colegio`**: em espanhol é a **escola** (ensino fundamental/médio), pública ou privada; não implica escola particular como o "colégio" brasileiro. `Escuela` também é escola.
- **`Apuntes`** são as anotações de aula; `apuntar` é anotar.
- **`Los deberes`** (Espanha) e **`la tarea`** (América Latina) = lição de casa.
- **Regional**: lousa = `pizarra` (Espanha) ou `pizarrón` (México); caneta = `bolígrafo`, `lapicera` (Argentina) ou `pluma` (México).
- **Aprovação**: `aprobar` = passar; `suspender` (Espanha) ou `reprobar` (América Latina) = ser reprovado.
- **`Asistir a clase`** = frequentar a aula.
