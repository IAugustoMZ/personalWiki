# Espanhol · Duolingo — Nível 9

> **Tema oficial:** Use "faz" para descrever o tempo · **Seção 1, Unidade 9** · Curso: Espanhol para falantes de português

## Visão geral

Neste nível você aprende a **descrever o tempo (clima)** em espanhol: `hace frío`, `hace calor`, `llueve`, `nieva`. O verbo-chave é **`hacer`** em expressões impessoais, além das **estações**, dos **meses**, dos **verbos meteorológicos** e das **atividades** conforme o clima.

```text
Hoy hace calor y hace sol.                          →  Hoje faz calor e faz sol.
En invierno llueve mucho y hace frío.               →  No inverno chove muito e faz frio.
¿Qué tiempo hace en Madrid en verano?               →  Que tempo faz em Madri no verão?
```

Ideias centrais:

1. `Hace` + substantivo (`frío`, `calor`, `sol`, `viento`) descreve o clima.
2. Verbos impessoais: `llover` (`llueve`), `nevar` (`nieva`), `granizar`.
3. `Estar` + adjetivo (`nublado`, `despejado`) e `hay` + substantivo (`hay niebla`).

## Gramática em exemplos

### 1. `Hacer` (presente)

| Pessoa | Forma |
|---|---|
| yo | hago |
| tú | haces |
| él / ella / usted | hace |
| nosotros | hacemos |
| vosotros | hacéis |
| ellos / ustedes | hacen |

- Em expressões de clima só se usa a **3ª pessoa do singular**: `hace`.

### 2. Expressões de clima com `hacer`

| Expressão | Exemplo |
|---|---|
| hace + frío / calor | Hace mucho frío. |
| hace + sol / viento | Hace sol y viento. |
| hace + buen/mal tiempo | Hace buen tiempo. |
| hace + número + grados | Hace 25 grados. |
| qué tiempo hace | ¿Qué tiempo hace hoy? |

- `Mucho` / `poco` com `frío` e `calor`: `hace mucho frío`.

### 3. Verbos impessoais de clima

| Verbo | 3ª pessoa | Exemplo |
|---|---|---|
| llover (o → ue) | llueve | Llueve mucho. |
| nevar (e → ie) | nieva | Nieva en invierno. |
| granizar | graniza | Graniza hoy. |
| tronar | truena | Truena esta noche. |
| amanecer | amanece | Amanece temprano. |
| anochecer | anochece | Anochece pronto. |

- Verbos com mudança vocálica: **llueve**, **nieva**.

### Diálogo 3 — Previsão

- A: ¿Qué tiempo va a hacer mañana?
- B: Va a llover por la mañana y a hacer frío.
- A: Entonces llevo paraguas y abrigo.
- B: Buena idea.

## Pontos de atenção e erros comuns

- **`Hace calor` ≠ `está caliente`**: `hace calor` para clima; `está caliente` para objeto/comida.
- **`Hacer`** em clima só na **3ª pessoa do singular**.
- **Verbos de chuva**: `llover` → `llueve`; *llove* está errado.
- **Falso amigo**: `tiempo` = tempo (clima ou tempo cronológico); `clima` = clima (região).
- **Falso amigo**: `frío` / `fresco` / `fresquito` indicam graus.
- **Falso amigo**: `lluvia` = chuva; `llover` = chover.
- **`Hace` + tempo no passado**: `hace dos días` = há dois dias.
