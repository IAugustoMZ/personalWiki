# Espanhol · Duolingo — Nível 17

> **Tema oficial:** Avalie comida e serviço · **Seção 2, Unidade 7** · Curso: Espanhol para falantes de português

## Visão geral

Neste nível você **vai a um restaurante**, faz o pedido e **avalia comida e serviço**. Entram as fórmulas de pedido (**`quisiera`, `me gustaría`, `voy a tomar`**), os verbos **`pedir`, `servir`, `recomendar`, `traer`**, os adjetivos de opinião, o **superlativo em `-ísimo`**, as exclamações **`¡Qué rico!`**, as reclamações educadas (**`me falta…`**) e a **conta**.

```text
Quisiera la sopa de primero y el pollo de segundo.        →  Gostaria da sopa de entrada e do frango de prato principal.
La comida estaba riquísima y el servicio fue muy rápido.   →  A comida estava deliciosa e o serviço foi muito rápido.
¿Nos trae la cuenta, por favor?                            →  Pode nos trazer a conta, por favor?
```

Ideias centrais:

1. Pedir com cortesia: `Quisiera…`, `Me gustaría…`, `Para mí…`, `¿Me trae…?`.
2. Opinar: `ser` para qualidade geral (`el servicio es rápido`); `estar` para estado/sabor (`la sopa está fría`).
3. Elogiar com intensidade: `muy rico`, `riquísimo`, `¡qué rico!`.

## Gramática em exemplos

### 1. Fórmulas de pedido

| Fórmula | Exemplo | Tom |
|---|---|---|
| Quisiera + substantivo | Quisiera una mesa para dos. | muito cortês |
| Me gustaría + infinitivo/subst. | Me gustaría probar la paella. | cortês |
| Voy a tomar + substantivo | Voy a tomar una cerveza. | natural |
| Para mí + substantivo | Para mí, la sopa. | informal |
| Quiero + substantivo | Quiero un café. | direto |
| ¿Me trae…? | ¿Me trae la cuenta? | pedido ao garçom |

- `Quisiera` e `me gustaría` são mais corteses que `quiero`.

### 2. `Pedir`, `servir`, `recomendar`, `traer`

| Verbo | yo | él / ella | nosotros |
|---|---|---|---|
| pedir (e → i) | pido | pide | pedimos |
| servir (e → i) | sirvo | sirve | servimos |
| recomendar (e → ie) | recomiendo | recomienda | recomendamos |
| traer | traigo | trae | traemos |
| probar (o → ue) | pruebo | prueba | probamos |
| poder (o → ue) | puedo | puede | podemos |

| Exemplo | Tradução |
|---|---|
| Pido una ensalada. | Peço uma salada. |
| ¿Qué recomienda usted? | O que o senhor recomenda? |
| Nos sirven rápido. | Nos servem rápido. |

### 3. `Ser` × `estar` para avaliar

| Verbo | Exemplo | Sentido |
|---|---|---|
| ser | El restaurante es caro. | característica geral |
| ser | El camarero es amable. | personalidade |
| estar | La sopa está fría. | estado agora |
| estar | El postre está riquísimo. | sabor naquele prato |
| ser | Los platos son abundantes. | característica |
| estar | La mesa está sucia. | estado |

- Pessoa: `ser amable` (é gentil), `estar amable hoy` (está gentil hoje).

### 4. `Estar` e `ser` no passado (3.ª pessoa)

| Verbo | Imperfeito | Pretérito |
|---|---|---|
| ser | era | fue |
| estar | estaba | estuvo |

| Exemplo | Tradução |
|---|---|
| La comida estaba muy buena. | A comida estava muito boa. |
| El servicio fue excelente. | O serviço foi excelente. |
| El restaurante era muy bonito. | O restaurante era muito bonito. |
| La cena estuvo perfecta. | O jantar foi perfeito. |

- `Estaba` / `era` descrevem como as coisas eram; `fue` / `estuvo` resumem a experiência como um todo.

### 5. Superlativo em `-ísimo`

| Adjetivo | Superlativo | Exemplo |
|---|---|---|
| rico | riquísimo | La tarta está riquísima. |
| bueno | buenísimo | El café está buenísimo. |
| rápido | rapidísimo | El servicio es rapidísimo. |
| caro | carísimo | El vino es carísimo. |
| grande | grandísimo | La ración es grandísima. |
| fácil | facilísimo | Es facilísimo reservar. |
| poco | poquísimo | Hay poquísima gente. |

- Troca-se a vogal final pelo sufixo: `rico` → `riquísimo` (c → qu), `largo` → `larguísimo` (g → gu).

### 6. Intensificadores e exclamações

| Estrutura | Exemplo |
|---|---|
| muy + adjetivo | El plato es muy bueno. |
| bastante + adjetivo | El servicio es bastante lento. |
| demasiado + adjetivo | La sopa está demasiado salada. |
| un poco + adjetivo | Está un poco fría. |
| ¡Qué + adjetivo! | ¡Qué rico! |
| ¡Qué + subst. + tan + adj.! | ¡Qué postre tan bueno! |
| ¡Qué + subst. + más + adj.! | ¡Qué camarero más simpático! |

### 7. `Faltar`, `sobrar` e `quedar` (como `gustar`)

| Verbo | Exemplo | Tradução |
|---|---|---|
| faltar | Me falta una cuchara. | Falta-me uma colher. |
| faltar | Nos faltan dos vasos. | Faltam-nos dois copos. |
| sobrar | Nos sobra comida. | Sobra-nos comida. |
| quedar | Ya no queda pan. | Já não resta pão. |
| gustar | Me gusta el plato. | Gosto do prato. |

- O verbo concorda com o que falta: `me falta un tenedor` / `me faltan dos tenedores`.

### 8. O menú: primero, segundo, postre

| Seção | Exemplo |
|---|---|
| de primero | De primero tomo sopa. |
| de segundo | De segundo, pescado. |
| de postre | De postre, flan. |
| de beber | Para beber, agua. |
| de entrante | Pido tapas de entrante. |

- Na Espanha o `menú del día` é uma refeição de preço fixo; a lista completa é `la carta`.

### 9. Pagar e dar gorjeta

| Frase | Uso |
|---|---|
| La cuenta, por favor. | pedir a conta |
| ¿Cuánto es? | perguntar o valor |
| ¿Se puede pagar con tarjeta? | perguntar a forma de pagamento |
| Pago en efectivo. | informar |
| ¿Me cobra, por favor? | pedir que cobre |
| Quédese con el cambio. | deixar o troco |

| Valor | Espanhol |
|---|---|

### 10. Reclamar com educação

| Frase | Exemplo |
|---|---|
| Disculpe, … | Disculpe, la sopa está fría. |
| ¿Podría + infinitivo? | ¿Podría cambiar este plato? |
| Esto no es lo que pedí | Pedí pescado, no carne. |
| Hay un error | Creo que hay un error en la cuenta. |
| Gracias de todos modos | Gracias de todos modos. |
| Lo siento, pero… | Lo siento, pero está muy salado. |

- Comece com `disculpe` ou `perdone`, descreva o problema e proponha uma solução.

## Diálogos

### Diálogo 1 — Pedir

- Camarero: Buenas noches. ¿Qué van a tomar?
- Ana: De primero, la sopa. De segundo, el pescado.
- Pablo: Para mí, una ensalada y el pollo.
- Camarero: ¿Y para beber?

### Diálogo 2 — Un problema

- Luis: Disculpe, la sopa está fría.
- Camarero: Lo siento mucho. Se la caliento ahora mismo.
- Luis: Gracias. Y me falta un tenedor.
- Camarero: Enseguida se lo traigo.

### Diálogo 3 — La cuenta

- Marta: ¿Nos trae la cuenta, por favor?
- Camarero: Son treinta y ocho euros con cincuenta.
- Marta: ¿Está incluido el servicio?
- Camarero: No, la propina es voluntaria. La comida estaba muy rica, ¿verdad?

## Pontos de atenção e erros comuns

- **`La carta` × `el menú`**: na Espanha, `la carta` é o cardápio e `el menú del día` é a refeição de preço fixo; em vários países da América Latina, `el menú` é o cardápio.
- **`Sobremesa`** em espanhol **não** é a sobremesa: é o tempo de conversa depois de comer. A sobremesa é `el postre`.
- **`Entrada`** é também o ingresso (`entradas para el cine`); para o prato de entrada, na Espanha se diz `entrante` ou `primer plato`, e na América Latina `entrada` é comum.
- **`Pedir`** muda e → i (`pido`, `pide`); `servir` também (`sirvo`).
- **`Faltar`** funciona como `gustar`: `me falta un tenedor`, `me faltan dos`.
- **Estar cheio**: use `estoy lleno/a`; `embarazada` quer dizer **grávida**, não constrangida.
- **`Mozo` / `mesero` / `camarero`**: variam por região (Argentina e Peru, `mozo`; México e outros países, `mesero`).
- **`Ser` × `estar`**: `la sopa es fría` descreve uma sopa que por natureza se serve fria (como o gazpacho); `la sopa está fría` aponta um problema agora.
- **`Soso`** = sem sal; também descreve alguém sem graça.
- **`Propina`** = gorjeta (não obrigatória na Espanha; costuma ser esperada na América Latina).
- **`Cuchara`** é colher; **`cuchillo`** é faca.
