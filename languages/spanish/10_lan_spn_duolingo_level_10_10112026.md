# Espanhol · Duolingo — Nível 10

> **Tema oficial:** Compre frutas · **Seção 1, Unidade 10** · Curso: Espanhol para falantes de português

## Visão geral

Último nível da Seção 1: você **compra frutas** no mercado e na fruteria. Aprende nomes de frutas e verduras, quantidades, preços, e pedidos educados. Entram **`quisiera` / `póngame`**, **quantidades** (`un kilo de`, `medio kilo`), **números e preços**, e **`cuánto cuesta`**.

```text
Póngame un kilo de manzanas y medio kilo de uvas, por favor.     →  Me coloca um quilo de maçãs e meio quilo de uvas, por favor.
¿Cuánto cuestan las fresas?                                      →  Quanto custam os morangos?
Está bien, me llevo estas.                                       →  Está bem, levo estas.
```

Ideias centrais:

1. Pedido: `Quisiera…`, `Póngame…`, `Me da…`.
2. Quantidade: `un kilo **de** manzanas` (sem artigo após `de`).
3. Preço: `¿Cuánto cuesta?` (singular) e `¿Cuánto cuestan?` (plural).

## Gramática em exemplos

### 1. Quantidades com `de`

| Estrutura | Exemplo |
|---|---|
| un kilo de + substantivo | un kilo de manzanas |
| medio kilo de + substantivo | medio kilo de uvas |
| cien gramos de + substantivo | cien gramos de queso |
| una docena de + substantivo | una docena de huevos |
| una bolsa de + substantivo | una bolsa de naranjas |

- Após `de`, **sem artigo**: *un kilo de las manzanas* está errado.

### 2. Pedir com cortesia

| Fórmula | Exemplo |
|---|---|
| Quisiera… | Quisiera un kilo de manzanas. |
| Póngame… | Póngame medio kilo de fresas. |
| Me da… | ¿Me da dos plátanos? |
| ¿Tiene…? | ¿Tiene mangos? |
| Quiero… | Quiero un melón. (mais direto) |

### 3. Números e preços

| Valor | Espanhol |
|---|---|
| 1,50 € | un euro con cincuenta |
| 2,20 € | dos euros con veinte |
| 3,75 € | tres euros con setenta y cinco |
| 8,50 € | ocho euros con cincuenta |
| 12 € | doce euros |
| 0,80 € | ochenta céntimos |

- `Con` = vírgula nos preços: `ocho con cincuenta`.

### 4. `Costar` (o → ue)

| Pessoa | Forma |
|---|---|
| él / ella / usted | cuesta |
| ellos / ustedes | cuestan |

| Exemplo | Tradução |
|---|---|
| ¿Cuánto cuesta el kilo? | Quanto custa o quilo? |
| ¿Cuánto cuestan las fresas? | Quanto custam os morangos? |

### 5. `Estar` com adjetivo de estado

| Adjetivo | Exemplo |
|---|---|
| maduro | Las peras están maduras. |
| verde | El plátano está verde. |
| fresco | El pescado está fresco. |
| rico | La fruta está muy rica. |
| caro | Está muy caro hoy. |

### 6. Demonstrativos

| Distância | Masc. | Fem. |
|---|---|---|
| perto | este | esta |
| médio | ese | esa |
| longe | aquel | aquella |

| Exemplo | Tradução |
|---|---|
| Me llevo este melón. | Levo este melão. |
| Quiero esas peras. | Quero essas peras. |
| Aquellas uvas parecen buenas. | Aquelas uvas parecem boas. |

### 7. Pronomes objeto

| Frase | Substituição |
|---|---|
| Compro las manzanas. | Las compro. |
| Quiero el melón. | Lo quiero. |
| Me llevo estos plátanos. | Me los llevo. |
| Me llevo esta sandía. | Me la llevo. |

### 8. Comparativos

| Estrutura | Exemplo |
|---|---|
| más … que | Las fresas son más caras que las manzanas. |
| menos … que | Las patatas son menos caras que las fresas. |
| tan … como | Son tan dulces como las cerezas. |
| mejor que | Son mejores que las del supermercado. |

### 9. Frutas e verduras de estação

| Estação | Exemplos |
|---|---|
| primavera | fresas, cerezas |
| verano | sandía, melón, melocotón |
| otoño | uvas, granadas, manzanas |
| invierno | naranjas, mandarinas, kiwi |

### 10. Perguntas no mercado

| Pergunta | Resposta |
|---|---|
| ¿Qué desea? | Un kilo de naranjas. |
| ¿Cuánto cuesta? | Dos euros el kilo. |
| ¿Algo más? | No, nada más. |
| ¿Cuánto es? | Son cinco euros. |
| ¿Qué fruta es de temporada? | Las fresas. |

## Diálogos

### Diálogo 1 — Na feira

- Frutero: Buenos días. ¿Qué desea?
- Cliente: Quisiera un kilo de manzanas y medio kilo de uvas.
- Frutero: Aquí tiene. ¿Algo más?
- Cliente: ¿Cuánto cuestan las fresas?
- Frutero: Cuatro euros el kilo.

### Diálogo 2 — Escolhendo

- Cliente: ¿Están maduros los melocotones?
- Frutero: Sí, están muy dulces. Pruebe uno.
- Cliente: ¡Qué ricos! Me llevo un kilo.
- Frutero: Son cuatro euros con cincuenta.

### Diálogo 3 — Pagando

- Cliente: ¿Cuánto es todo?
- Frutero: Son once euros con veinte.
- Cliente: Aquí tiene.
- Frutero: Gracias. ¿Necesita una bolsa?

## Pontos de atenção e erros comuns

- **Quantidade + `de`** sem artigo: `un kilo de manzanas`.
- **`Costar`** muda o → ue: `cuesta`, `cuestan`.
- **Falso amigo**: `aguacate` / `palta` = abacate; `plátano` = banana na Espanha, plátano (fruta frita) na América Latina.
- **Falso amigo**: `melocotón` / `durazno` = pêssego; `papa` / `patata` = batata.
- **Falso amigo**: `fresa` = morango; `frutilla` no Cone Sul.
- **Falso amigo**: `maíz` = milho; `elote` no México.
- **`Rica`** = gostosa; **`rico`** como adjetivo de dinheiro = rico.
