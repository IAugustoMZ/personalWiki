# Alemão · Duolingo — Nível 9

> **Tema oficial:** Fale sobre preços de alimentos · **Seção 1, Unidade 9** · Curso: Alemão para falantes de português

## Visão geral

Neste nível você aprende a **perguntar e dizer preços** de alimentos no mercado e no supermercado: euros e centavos, quantidades (`ein Kilo`, `500 Gramm`), comparações de preço e pagamento. Gramática: **números grandes**, **`kosten`**, **quantidades sem plural**, **comparativos** (`billiger`, `teurer`) e **adjetivos no acusativo**.

```text
Was kostet ein Kilo Äpfel? — Zwei Euro fünfzig.            →  Quanto custa um quilo de maçãs? — 2,50 euros.
Die Bananen sind billiger als die Orangen.                 →  As bananas são mais baratas que as laranjas.
Ich nehme ein Pfund Tomaten und 200 Gramm Käse.            →  Levo meio quilo de tomates e 200 g de queijo.
```

Ideias centrais:

1. `Was kostet…?` (singular) e `Was kosten…?` (plural).
2. Quantidades: **sem plural** e **sem artigo**: `zwei Kilo Äpfel`, `eine Flasche Wasser`.
3. Comparativo: adjetivo + `-er` + `als`: `billiger als`.

1. Was kostet das? — Quanto custa isso?

## Gramática em exemplos

### 1. Números de 20 a 100 (e centenas)

| Número | Alemão |
|---|---|
| 21 | einundzwanzig |
| 22 | zweiundzwanzig |
| 30 | dreißig |
| 45 | fünfundvierzig |
| 67 | siebenundsechzig |
| 99 | neunundneunzig |
| 100 | hundert |
| 250 | zweihundertfünfzig |
| 1000 | tausend |

- Unidade + `und` + dezena: `fünfundvierzig` = “cinco e quarenta”.

### 2. Preços

| Valor | Alemão |
|---|---|
| 1,00 € | ein Euro |
| 1,50 € | ein Euro fünfzig |
| 2,99 € | zwei Euro neunundneunzig |
| 0,80 € | achtzig Cent |
| 10,00 € | zehn Euro |
| 12,35 € | zwölf Euro fünfunddreißig |

### 3. `Kosten` e `machen`

| Estrutura | Exemplo |
|---|---|
| Was kostet + singular | Was kostet das Brot? |
| Was kosten + plural | Was kosten die Eier? |
| Das macht + total | Das macht zehn Euro. |
| Das kostet + valor | Das kostet drei Euro. |

### 4. Quantidades sem plural

| Estrutura | Exemplo |
|---|---|
| numeral + medida + substantivo (sem plural) | zwei Kilo Äpfel |
| numeral + medida + substantivo | drei Liter Milch |
| eine Flasche + substantivo | eine Flasche Wasser |
| ein Stück + substantivo | ein Stück Käse |
| 500 Gramm + substantivo | 500 Gramm Reis |

- Medidas masculinas/neutras ficam no **singular** depois de número (`zwei Kilo`, `drei Liter`).
- Femininas pluralizam: `zwei Flaschen`, `drei Packungen`.

### 5. Comparativos

| Adjetivo | Comparativo | Exemplo |
|---|---|---|
| billig | billiger | billiger als |
| teuer | teurer | teurer als |
| günstig | günstiger | günstiger als |
| frisch | frischer | frischer als |
| groß | größer | größer als |
| gut | besser | besser als |
| viel | mehr | mehr als |

| Exemplo | Tradução |
|---|---|
| Äpfel sind billiger als Orangen. | Maçãs são mais baratas que laranjas. |
| Das Fleisch ist teurer als der Fisch. | A carne é mais cara que o peixe. |
| Das ist besser als das. | Isso é melhor que aquilo. |

- Algumas vogais ganham trema no comparativo: `groß → größer`, `alt → älter`.

### 6. Superlativos

| Adjetivo | Superlativo | Exemplo |
|---|---|---|
| billig | am billigsten | Das ist am billigsten. |
| teuer | am teuersten | Das ist am teuersten. |
| gut | am besten | Das ist am besten. |
| gern | am liebsten | Ich esse am liebsten Pizza. |

### 7. Adjetivos no acusativo (começo)

| Gênero | Artigo indefinido + adj + subst. | Exemplo |
|---|---|---|
| masculino | einen + -en | einen frischen Salat |
| feminino | eine + -e | eine frische Tomate |
| neutro | ein + -es | ein frisches Brot |
| plural | — + -e | frische Äpfel |

### 8. `Ein bisschen`, `viel`, `wenig`

| Expressão | Exemplo |
|---|---|
| ein bisschen | Ich brauche ein bisschen Zucker. |
| viel | Ich trinke viel Wasser. |
| wenig | Er isst wenig Fleisch. |
| zu viel | Das ist zu viel. |
| genug | Das reicht, danke. |

### 9. Perguntas no mercado

| Pergunta | Resposta |
|---|---|
| Haben Sie Tomaten? | Ja, frische aus der Region. |
| Wie viel möchten Sie? | Ein Pfund. |
| Was kostet das Kilo? | Drei Euro. |
| Darf es sonst noch etwas sein? | Nein, das ist alles. |
| Zahlen Sie bar? | Nein, mit Karte. |

### 10. Cortesia na loja

| Frase | Tradução |
|---|---|
| Bitte schön. | Aqui está. |
| Danke schön. | Muito obrigado. |
| Gern geschehen. | De nada. |
| Schönen Tag noch! | Tenha um bom dia! |
| Auf Wiedersehen! | Até logo! |

## Diálogos

### Diálogo 1 — No mercado

- Verkäufer: Guten Tag! Was darf es sein?
- Kunde: Ein Kilo Äpfel, bitte. Was kosten sie?
- Verkäufer: Zwei Euro fünfzig das Kilo.
- Kunde: Gut. Und ein Pfund Tomaten.
- Verkäufer: Das macht vier Euro fünfzig.

### Diálogo 2 — No supermercado

- A: Sind die Orangen im Angebot?
- B: Ja, 1,99 € das Kilo. Das ist billiger als gestern.
- A: Dann nehme ich zwei Kilo.
- B: Gute Idee!

### Diálogo 3 — Na caixa

- Kassierer: Das macht zwölf Euro dreißig.
- Kunde: Mit Karte, bitte.
- Kassierer: Bitte schön. Hier ist Ihr Kassenbon.
- Kunde: Danke, schönen Tag noch!

## Pontos de atenção e erros comuns

- **`Was kostet`/`Was kosten`**: concorda com o número do que se pergunta.
- **Medidas masculinas/neutras** não pluralizam: `zwei Kilo`, não *zwei Kilos*.
- **`Das Pfund`** = 500 g, não “libra”.
- **Comparativos com trema**: `größer`, `älter`, `jünger`.
- **`Billiger als`**, não *billiger wie*: `als` para comparação de desigualdade, `so … wie` para igualdade.
- **`Günstig`** = em conta; **`billig`** pode soar “de baixa qualidade”.
- **Vocabulário que engana**: `die Kartoffel` = batata; `die Gurke` = pepino.
