# Alemão · Duolingo — Nível 1

> **Tema oficial:** Faça pedidos no café · **Seção 1, Unidade 1** · Curso: Alemão para falantes de português

## Visão geral

Primeiro contato com o alemão: **pedir algo em um café**. Mesmo sendo o primeiro nível, já aparecem três pilares da língua: **substantivos com gênero e artigo** (`der`, `die`, `das`), **substantivos escritos com maiúscula** e o verbo **`möchten`** (gostaria) para pedir com educação.

```text
Ich möchte einen Kaffee, bitte.                      →  Eu gostaria de um café, por favor.
Einen Tee und ein Stück Kuchen, bitte.               →  Um chá e um pedaço de bolo, por favor.
Was kostet das?                                      →  Quanto custa?
```

Ideias centrais:

1. **Todo substantivo** é escrito com letra maiúscula: `der Kaffee`, `die Milch`.
2. Os três gêneros — masculino (`der`), feminino (`die`), neutro (`das`) — precisam ser aprendidos com cada palavra.
3. No pedido, o objeto fica no **acusativo**: masculino `ein` → `einen` (`einen Kaffee`).

## Gramática em exemplos

### 1. Artigos definidos e gêneros

| Gênero | Artigo | Exemplo |
|---|---|---|
| masculino | der | der Kaffee, der Tee, der Saft |
| feminino | die | die Milch, die Cola, die Torte |
| neutro | das | das Wasser, das Brot, das Bier |
| plural (todos) | die | die Kaffees, die Brötchen |

- O gênero é **gramatical**: não segue o sexo ou a lógica. Aprenda sempre `der Tee`, `die Milch`, `das Wasser`.

### 2. Artigos indefinidos

| Gênero | Nominativo | Acusativo |
|---|---|---|
| masculino | ein | **einen** |
| feminino | eine | eine |
| neutro | ein | ein |
| plural | — | — |

| Exemplo | Caso |
|---|---|
| Das ist ein Kaffee. | nominativo |
| Ich möchte einen Kaffee. | acusativo (objeto) |
| Ich möchte eine Milch. | acusativo feminino (igual) |
| Ich möchte ein Wasser. | acusativo neutro (igual) |

- **Só o masculino muda** do nominativo para o acusativo: `ein` → `einen`.

### 3. Verbo `möchten` (gostaria de)

| Pessoa | Forma | Exemplo |
|---|---|---|
| ich | möchte | Ich möchte einen Tee. |
| du | möchtest | Möchtest du Kaffee? |
| er / sie / es | möchte | Er möchte einen Saft. |
| wir | möchten | Wir möchten zwei Kaffee. |
| ihr | möchtet | Möchtet ihr Kuchen? |
| sie / Sie | möchten | Was möchten Sie? |

- `möchten` + objeto no acusativo; se houver verbo, ele vai ao **fim**: `Ich möchte einen Kaffee trinken.`

### 4. Ordem das palavras: verbo na 2ª posição

| Posição 1 | Posição 2 (verbo) | Resto |
|---|---|---|
| Ich | möchte | einen Kaffee. |
| Heute | möchte | ich einen Kaffee. |
| Einen Kaffee | möchte | ich. |

- O verbo conjugado fica **sempre na segunda posição** em frases afirmativas.

### 5. Perguntas

| Tipo | Estrutura | Exemplo |
|---|---|---|
| sim/não | verbo + sujeito | Möchten Sie einen Kaffee? |
| com palavra interrogativa | W-palavra + verbo + sujeito | Was möchten Sie? |
| preço | Was kostet…? | Was kostet der Kaffee? |
| plural | Was kosten…? | Was kosten die Brötchen? |

### 6. Números de 1 a 10

| Número | Alemão |
|---|---|
| 1 | eins |
| 2 | zwei |
| 3 | drei |
| 4 | vier |
| 5 | fünf |
| 6 | sechs |
| 7 | sieben |
| 8 | acht |
| 9 | neun |
| 10 | zehn |

- `ein` / `eine` / `ein` quando acompanham substantivo; `eins` quando é número isolado.

### 7. `Bitte`: vários usos

| Uso | Exemplo |
|---|---|
| por favor | Einen Kaffee, bitte. |
| de nada | — Danke! — Bitte! |
| aqui está | Bitte schön. |
| como? (pedir para repetir) | Bitte? |

| Grafia | Som | Exemplo |
|---|---|---|
| ä | é aberto | Käse |
| ö | /œ/ (lábios arredondados) | möchten |
| ü | /y/ (u francês) | Brötchen (ö), Süß |
| ß | s forte | Straße |
| ch | /ç/ ou /x/ | ich, Kuchen |
| sch | x | Schinken |
| sp / st (início) | xp / xt | Spaß, Stück |

### 9. Substantivos compostos

| Composto | Parte 1 + Parte 2 | Significado |
|---|---|---|
| der Orangensaft | Orange + Saft | suco de laranja |
| der Apfelstrudel | Apfel + Strudel | strudel de maçã |
| das Mineralwasser | Mineral + Wasser | água mineral |
| der Milchkaffee | Milch + Kaffee | café com leite |

- O **último** elemento define o gênero: `der Saft` → `der Orangensaft`.

### 10. Cortesia: `Sie` × `du`

| Contexto | Pronome |
|---|---|
| atendimento, desconhecidos | Sie |
| amigos, crianças | du |

## Diálogos

### Diálogo 1 — Pedindo

- Kellner: Guten Tag! Was möchten Sie?
- Gast: Guten Tag. Ich möchte einen Kaffee, bitte.
- Kellner: Noch etwas?
- Gast: Ja, ein Stück Apfelkuchen.
- Kellner: Gern. Hier oder zum Mitnehmen?
- Gast: Hier, bitte.

### Diálogo 2 — Pagando

- Gast: Die Rechnung, bitte.
- Kellner: Zusammen oder getrennt?
- Gast: Zusammen. Was macht das?
- Kellner: Das macht sieben Euro zwanzig.
- Gast: Acht Euro. Stimmt so.

### Diálogo 3 — Entre amigos

- Anna: Möchtest du einen Tee?
- Paul: Nein, danke. Ich nehme einen Kaffee.
- Anna: Mit Milch?
- Paul: Ohne Milch, bitte.

## Pontos de atenção e erros comuns

- **Letra maiúscula** em todos os substantivos: `der Kaffee`, não *der kaffee*.
- **`einen`** só para masculino no acusativo: *Ich möchte ein Kaffee* está errado.
- **`Ich möchte`** (educado) em vez de *Ich will* (seco).
- **Verbo na 2ª posição**: *Ich einen Kaffee möchte* está errado.
- **`Kaffee`** é a bebida; **`das Café`** é a cafeteria.
- **`Gift`** = veneno (nunca “presente”, que é `Geschenk`); **`bekommen`** = receber.
- **`Kellner/Kellnerin`** = garçom/garçonete; o chamado é `Entschuldigung!` ou `Hallo!`.
