# Alemão · Duolingo — Nível 16

> **Tema oficial:** Use "möchten" para pedidos educados · **Seção 2, Unidade 6** · Curso: Alemão para falantes de português

## Visão geral

Neste nível você domina o **`möchten`** (gostaria) e outras fórmulas de **cortesia**: `Ich hätte gern…`, `Könnte ich…?`, `Würden Sie…?`, `Dürfte ich…?`. Aprende a pedir em restaurantes, lojas, hotéis e a responder a pedidos. A gramática central: **verbos modais no Konjunktiv II**, **ordem das palavras com infinitivo no fim** e **`bitte`/`danke`**.

```text
Ich möchte einen Tisch für zwei Personen reservieren.       →  Gostaria de reservar uma mesa para duas pessoas.
Könnte ich bitte die Speisekarte haben?                     →  Poderia ter o cardápio, por favor?
Würden Sie mir bitte das Wasser bringen?                    →  O senhor poderia me trazer a água?
```

Ideias centrais:

1. `Möchten` é a forma educada de `wollen`.
2. O verbo principal vai ao **fim** como infinitivo: `Ich möchte einen Kaffee trinken.`
3. Em pedidos formais, use `Sie` e `bitte`.

## Gramática em exemplos

### 1. `Möchten` (presente do Konjunktiv II de `mögen`)

| Pessoa | Forma | Exemplo |
|---|---|---|
| ich | möchte | Ich möchte einen Tee. |
| du | möchtest | Möchtest du Kuchen? |
| er / sie / es | möchte | Sie möchte zahlen. |
| wir | möchten | Wir möchten bestellen. |
| ihr | möchtet | Möchtet ihr etwas trinken? |
| sie / Sie | möchten | Was möchten Sie? |

- Com substantivo: `Ich möchte einen Kaffee.`; com verbo: `Ich möchte einen Kaffee trinken.`

### 2. Ordem das palavras com modal

| Estrutura | Exemplo |
|---|---|
| sujeito + modal + objeto + infinitivo | Ich möchte einen Tisch reservieren. |
| pergunta | Möchten Sie die Speisekarte sehen? |
| com tempo | Heute möchte ich Fisch essen. |
| negação | Ich möchte keinen Fisch essen. |

### 3. `Ich hätte gern` (Konjunktiv II de `haben`)

| Pessoa | Forma |
|---|---|
| ich | hätte |
| du | hättest |
| er / sie / es | hätte |
| wir | hätten |
| ihr | hättet |
| sie / Sie | hätten |

- Exemplo: `Ich hätte gern einen Kaffee.` / `Wir hätten gern die Rechnung.`

### 4. Konjunktiv II de `können`, `dürfen`, `werden`

| Pessoa | könnte | dürfte | würde |
|---|---|---|---|
| ich | könnte | dürfte | würde |
| du | könntest | dürftest | würdest |
| er / sie / es | könnte | dürfte | würde |
| wir | könnten | dürften | würden |
| ihr | könntet | dürftet | würdet |
| sie / Sie | könnten | dürften | würden |

| Exemplo | Tradução |
|---|---|
| Könnten Sie mir helfen? | O senhor poderia me ajudar? |
| Dürfte ich fragen …? | Eu poderia perguntar …? |
| Würden Sie bitte warten? | O senhor poderia esperar? |

### 5. Pedidos diretos × educados

| Direto | Mais educado |
|---|---|
| Ich will einen Kaffee. | Ich möchte einen Kaffee. |
| Gib mir die Karte. | Könnte ich die Karte haben? |
| Bring mir Wasser. | Würden Sie mir bitte Wasser bringen? |
| Ich will zahlen. | Ich möchte bitte zahlen. |

### 7. `Bitte` e `Danke` em contexto

| Contexto | Frase |
|---|---|
| pedir | Einen Kaffee, bitte. |
| oferecer | Bitte schön. |
| agradecer | Danke schön. / Vielen Dank. |
| responder | Bitte. / Gern geschehen. / Nichts zu danken. |
| pedir repetição | Wie bitte? |

### 8. Imperativo × cortesia

| Imperativo seco | Alternativa educada |
|---|---|
| Warten Sie! | Würden Sie bitte warten? |
| Kommen Sie! | Könnten Sie bitte kommen? |
| Geben Sie mir! | Könnte ich … haben? |

| Gênero | Nominativo | Acusativo |

| masc. | der Tisch | den Tisch |

| Estrutura | Exemplo |
|---|---|

## Diálogos

### Diálogo 1 — No restaurante

- Kellner: Guten Abend! Haben Sie reserviert?
- Gast: Ja, auf den Namen Silva. Wir möchten einen Tisch für zwei Personen.
- Kellner: Gern, hier entlang. Hier ist die Speisekarte.
- Gast: Danke. Könnten wir bitte etwas zu trinken bestellen?

### Diálogo 2 — Fazendo o pedido

- Kellner: Was möchten Sie essen?
- Gast: Ich hätte gern das Tagesgericht. Was empfehlen Sie als Vorspeise?
- Kellner: Die Kartoffelsuppe ist ausgezeichnet.
- Gast: Dann nehme ich die Suppe.

### Diálogo 3 — No hotel

- Gast: Guten Tag, ich möchte ein Doppelzimmer für zwei Nächte.
- Rezeptionist: Gern. Ist das Frühstück inklusive?
- Gast: Ja, bitte. Dürfte ich mit Karte bezahlen?
- Rezeptionist: Natürlich.

## Pontos de atenção e erros comuns

- **`Möchten` ≠ `mögen`**: `möchten` = gostaria; `mögen` = gostar.
- **Infinitivo no fim**: *Ich möchte trinken einen Kaffee* está errado.
- **`Könnten`/`würden`** + infinitivo no fim: `Könnten Sie mir helfen?`.
- **`Bitte`** no fim ou início do pedido: `Bitte, einen Kaffee.` / `Einen Kaffee, bitte.`
- **`Bitte`** também responde a `Danke`.
- **Vocabulário que engana**: `die Karte` = cartão/cardápio/mapa; `die Rechnung` = conta.
- **Gorjeta**: `das Trinkgeld`; comum arredondar (`Stimmt so`).

## Complete as lacunas

1. Ich ____ einen Tee. (gostaria) → `möchte`
2. ____ ich die Karte haben? (poderia) → `Könnte`
3. Ich ____ gern ein Wasser. (gostaria) → `hätte`
4. ____ Sie mir helfen? (poderia, würden) → `Würden`
5. Einen Kaffee ____ Milch. (com) → `mit`
6. Ich möchte einen Tisch ____ . (reservar) → `reservieren`
