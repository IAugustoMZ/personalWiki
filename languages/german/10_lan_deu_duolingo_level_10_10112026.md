# Alemão · Duolingo — Nível 10

> **Tema oficial:** Comente sobre comida e bebida · **Seção 1, Unidade 10** · Curso: Alemão para falantes de português

## Visão geral

Neste nível você **comenta sobre comida e bebida**: elogia, critica, descreve sabores e texturas, dá sua opinião e recomenda. Gramática: **`schmecken`** (+ dativo), **adjetivos de sabor**, **`finden` + adjetivo**, **`gefallen`**, **intensificadores** e **adjetivos no nominativo**.

```text
Die Suppe schmeckt sehr gut!                              →  A sopa está muito boa!
Ich finde den Kuchen zu süß.                              →  Acho o bolo doce demais.
Das Essen ist lecker, aber ein bisschen scharf.           →  A comida está gostosa, mas um pouco picante.
```

Ideias centrais:

1. `Schmecken` pede **dativo**: `Es schmeckt mir.`
2. `Ich finde + objeto + adjetivo` dá opinião: `Ich finde den Kuchen lecker.`
3. Intensificadores: `sehr`, `ziemlich`, `ein bisschen`, `zu`, `echt`.

## Gramática em exemplos

### 1. `Schmecken` + dativo

| Estrutura | Exemplo |
|---|---|
| etwas schmeckt + (Dativ) | Der Kuchen schmeckt mir. |
| schmeckt gut | Die Suppe schmeckt gut. |
| schmeckt nicht | Das schmeckt nicht. |
| schmeckt nach … | Es schmeckt nach Zitrone. |

| Pessoa | Dativo |
|---|---|
| mir | Es schmeckt mir. |
| dir | Schmeckt es dir? |
| ihm / ihr | Es schmeckt ihm / ihr. |
| uns | Es schmeckt uns. |
| euch | Schmeckt es euch? |
| ihnen | Es schmeckt ihnen. |

### 2. `Finden` + opinião

| Estrutura | Exemplo |
|---|---|
| Ich finde + objeto (acus.) + adjetivo | Ich finde den Kuchen lecker. |
| Ich finde, dass … | Ich finde, dass die Suppe gut ist. |
| Findest du … ? | Findest du das Essen gut? |
| Ich finde es + adj + zu + inf. | Ich finde es schwer, das zu essen. |

### 3. Adjetivos predicativos (sem declinação)

| Estrutura | Exemplo |
|---|---|
| sein + adjetivo | Die Suppe ist heiß. |
| werden + adjetivo | Das Wasser wird kalt. |
| finden + adjetivo | Ich finde das Essen lecker. |

- Quando o adjetivo vem **depois de `sein`**, não há declinação.

### 4. Adjetivos atributivos (antes do substantivo, introdução)

| Gênero | Nominativo | Exemplo |
|---|---|---|
| masc. | der + -e | der heiße Tee |
| fem. | die + -e | die heiße Suppe |
| neutro | das + -e | das heiße Wasser |
| plural | die + -en | die heißen Getränke |
| masc. | ein + -er | ein heißer Tee |
| fem. | eine + -e | eine heiße Suppe |
| neutro | ein + -es | ein heißes Wasser |

### 5. Intensificadores

| Alemão | Significado | Exemplo |
|---|---|---|
| sehr | muito | sehr gut |
| ziemlich | bem | ziemlich scharf |
| ein bisschen | um pouco | ein bisschen süß |
| zu | demais | zu salzig |
| echt | realmente | echt lecker |
| total | totalmente | total fade |
| nicht so | não tão | nicht so süß |
| genug | o suficiente | süß genug |

### 6. Comparativos para sabor

| Estrutura | Exemplo |
|---|---|
| Adjetivo + -er + als | Das Eis ist süßer als der Kuchen. |
| genauso … wie | Die Suppe ist genauso gut wie gestern. |
| nicht so … wie | Der Kaffee ist nicht so heiß wie der Tee. |
| der / die / das … -ste | Das ist der leckerste Kuchen. |
| am besten | Das schmeckt am besten. |

### 7. `Gefallen` e `mögen`

| Verbo | Estrutura | Exemplo |
|---|---|---|
| gefallen | + Dativ | Das Essen gefällt mir. |
| mögen | + Akkusativ | Ich mag den Kuchen. |
| schmecken | + Dativ | Der Kuchen schmeckt mir. |
| lieben | + Akkusativ | Ich liebe Schokolade. |
| hassen | + Akkusativ | Ich hasse Fisch. |

### 8. Recomendar e pedir recomendação

| Pergunta | Resposta |
|---|---|
| Was empfehlen Sie? | Ich empfehle das Schnitzel. |
| Was ist heute besonders gut? | Der Fisch ist heute sehr frisch. |
| Was können Sie empfehlen? | Die Suppe ist ausgezeichnet. |
| Was ist das? | Das ist ein Gericht aus Spätzle und Käse. |

| Frase | Tradução |

## Diálogos

### Diálogo 1 — No restaurante

- Kellner: Wie schmeckt es Ihnen?
- Gast: Ausgezeichnet! Die Suppe ist sehr lecker.
- Kellner: Und das Schnitzel?
- Gast: Ein bisschen zu salzig, aber gut.

### Diálogo 2 — Em casa

- Gastgeber: Schmeckt es dir?
- Gast: Ja, sehr! Das Essen ist wirklich lecker.
- Gastgeber: Möchtest du noch etwas?
- Gast: Gern, ein bisschen Kartoffelsalat.

### Diálogo 3 — Comparando

- A: Ich finde die Currywurst besser als die Bratwurst.
- B: Wirklich? Ich finde die Currywurst zu scharf.
- A: Ich mag scharfes Essen.
- B: Ich nicht so.

## Pontos de atenção e erros comuns

- **`Schmecken` + dativo**: *Ich schmecke den Kuchen* significa “eu experimento”; use `Der Kuchen schmeckt mir`.
- **`Zu`** é negativo: `zu süß` = doce demais.
- **`Finden` + acusativo + adjetivo**: `Ich finde den Kuchen lecker`.
- **`Mahlzeit`** é saudação e desejo de bom apetite no horário do almoço.
- **Adjetivo predicativo** não declina: `Die Suppe ist heiß`, não *heiße*.
- **Vocabulário que engana**: `lecker` = gostoso; `bitter` = amargo; `sauer` = azedo.
- **`Fade`** é insosso (sem sal/tempero).

## Complete as lacunas

1. Das Essen ____ mir. (agrada ao sabor) → `schmeckt`
2. Ich ____ den Kuchen zu süß. (acho) → `finde`
3. Die Suppe ist ____ salzig. (demais) → `zu`
4. Es schmeckt ____ sehr gut. (a mim) → `mir`
5. Das Eis ist ____ als der Kuchen. (mais doce) → `süßer`
6. ____ Appetit! (bom) → `Guten`
