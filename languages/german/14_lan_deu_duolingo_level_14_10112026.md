# Alemão · Duolingo — Nível 14

> **Tema oficial:** Fale sobre problemas de saúde · **Seção 2, Unidade 4** · Curso: Alemão para falantes de português

## Visão geral

Neste nível você aprende a **falar de saúde**: partes do corpo, sintomas, dor, consulta médica, farmácia e conselhos. Gramática: **`wehtun` / `weh tun`** e **`Schmerzen haben`**, **dativo de interesse**, **imperativo** para conselhos, **modais** `sollen`/`müssen`, e **perfeito** com `haben`.

```text
Ich habe Kopfschmerzen und Fieber.                          →  Estou com dor de cabeça e febre.
Mir tut der Rücken weh.                                     →  Minhas costas doem.
Sie sollten viel trinken und im Bett bleiben.               →  O senhor deveria beber muito e ficar de cama.
```

Ideias centrais:

1. Para dor: `Ich habe Kopfschmerzen` ou `Mir tut der Kopf weh`.
2. O **dativo** (`mir`, `dir`, `ihm`) indica quem sente a dor.
3. Conselhos: imperativo (`Bleiben Sie…`) ou `sollen` (`Sie sollten…`).

## Gramática em exemplos

### 1. `Haben` + sintomas

| Estrutura | Exemplo |
|---|---|
| ich habe + substantivo | Ich habe Kopfschmerzen. |
| du hast + substantivo | Du hast Fieber. |
| er hat + substantivo | Er hat Husten. |
| wir haben + substantivo | Wir haben eine Erkältung. |

### 2. `Weh tun` + dativo

| Pessoa | Dativo | Exemplo |
|---|---|---|
| ich | mir | Mir tut der Kopf weh. |
| du | dir | Dir tut der Rücken weh. |
| er | ihm | Ihm tun die Füße weh. |
| sie | ihr | Ihr tut der Bauch weh. |
| wir | uns | Uns tun die Beine weh. |
| ihr | euch | Euch tut der Hals weh. |
| sie / Sie | ihnen / Ihnen | Ihnen tut der Arm weh. |

- O verbo concorda com a **parte do corpo**: `tut` (singular), `tun` (plural).

### 3. `Sich fühlen` e `es geht mir …`

| Estrutura | Exemplo |
|---|---|
| ich fühle mich + adj | Ich fühle mich schlecht. |
| es geht mir + adv | Es geht mir gut / schlecht / besser. |
| mir ist + adj | Mir ist schlecht / kalt / heiß. |
| ich bin + adj | Ich bin müde / krank. |

### 4. Imperativo para conselhos

| Pessoa | Exemplo |
|---|---|
| du | Bleib im Bett! Trink viel Tee! |
| Sie | Bleiben Sie im Bett! Trinken Sie viel Tee! |
| ihr | Bleibt im Bett! Trinkt viel Tee! |

| Verbo | du | Sie |
|---|---|---|
| nehmen | Nimm! | Nehmen Sie! |
| essen | Iss! | Essen Sie! |
| schlafen | Schlaf! | Schlafen Sie! |
| gehen | Geh! | Gehen Sie! |
| sich ausruhen | Ruh dich aus! | Ruhen Sie sich aus! |

### 5. Modais para conselhos e necessidade

| Verbo | Exemplo |
|---|---|
| sollen | Sie sollen viel trinken. |
| sollten | Du solltest zum Arzt gehen. |
| müssen | Ich muss im Bett bleiben. |
| dürfen | Ich darf nicht arbeiten. |
| können | Ich kann nicht schlafen. |

### 6. Perfeito (Perfekt) com `haben`

| Pessoa | Estrutura | Exemplo |
|---|---|---|
| ich | habe + Partizip | Ich habe schlecht geschlafen. |
| du | hast + Partizip | Du hast Medikamente genommen. |
| er / sie / es | hat + Partizip | Er hat Fieber gehabt. |
| wir | haben + Partizip | Wir haben den Arzt gerufen. |
| ihr | habt + Partizip | Ihr habt euch ausgeruht. |
| sie / Sie | haben + Partizip | Sie haben den Termin gehabt. |

| Infinitivo | Particípio |
|---|---|
| schlafen | geschlafen |
| nehmen | genommen |
| trinken | getrunken |
| untersuchen | untersucht |
| verschreiben | verschrieben |
| brechen | gebrochen |

### 7. Perfeito com `sein` (movimento ou mudança)

| Verbo | Particípio | Exemplo |
|---|---|---|
| gehen | gegangen | Ich bin zum Arzt gegangen. |
| kommen | gekommen | Er ist ins Krankenhaus gekommen. |
| werden | geworden | Ich bin krank geworden. |
| aufstehen | aufgestanden | Ich bin um sieben aufgestanden. |

### 8. Reflexivos e dativo reflexivo

| Estrutura | Exemplo |
|---|---|
| sich verletzen | Ich habe mich verletzt. |
| sich ausruhen | Du musst dich ausruhen. |
| sich (Dativ) etwas brechen | Ich habe mir den Fuß gebrochen. |
| sich (Dativ) die Hände waschen | Ich wasche mir die Hände. |

- Com partes do corpo, usa-se **dativo reflexivo** (`mir`, `dir`, `sich`).

### 9. Perguntas do médico

| Pergunta | Resposta |
|---|---|
| Was fehlt Ihnen? | Ich habe Halsschmerzen. |
| Seit wann haben Sie das? | Seit drei Tagen. |
| Haben Sie Fieber? | Ja, 38,5. |
| Wo tut es weh? | Hier am Hals. |
| Nehmen Sie Medikamente? | Nein, keine. |

### 10. Frases úteis na farmácia

| Frase | Tradução |
|---|---|
| Ich brauche etwas gegen Kopfschmerzen. | Preciso de algo para dor de cabeça. |
| Haben Sie Hustensaft? | Tem xarope para tosse? |
| Wie oft muss ich das nehmen? | Quantas vezes devo tomar? |
| Das ist rezeptpflichtig. | Precisa de receita. |
| Gute Besserung! | Melhoras! |

## Diálogos

### Diálogo 1 — No consultório

- Arzt: Was fehlt Ihnen?
- Patient: Ich habe Halsschmerzen und Fieber.
- Arzt: Seit wann?
- Patient: Seit zwei Tagen.
- Arzt: Ich verschreibe Ihnen Tabletten. Bleiben Sie im Bett.

### Diálogo 2 — Na farmácia

- Kunde: Ich brauche etwas gegen Husten.
- Apotheker: Haben Sie auch Fieber?
- Kunde: Nein, nur Husten.
- Apotheker: Dann nehmen Sie diesen Saft dreimal täglich.

### Diálogo 3 — Entre amigos

- A: Du siehst müde aus. Was ist los?
- B: Ich habe schlecht geschlafen. Mir tut der Kopf weh.
- A: Trink viel Wasser und ruh dich aus!
- B: Danke, mach ich!

## Pontos de atenção e erros comuns

- **`Mir tut … weh`**: o verbo concorda com a parte do corpo.
- **`Ich habe Schmerzen`** (dores) × **`Es tut weh`** (dói).
- **`Sich fühlen`** é reflexivo: `Ich fühle mich schlecht`.
- **Perfeito com `sein`**: `Ich bin zum Arzt gegangen`.
- **Dativo reflexivo** com partes do corpo: `Ich wasche mir die Hände`.
- **`Gute Besserung`** é a fórmula de melhoras.
- **Vocabulário que engana**: `die Praxis` = consultório; `das Rezept` = receita (médica ou culinária).
