# Alemão · Duolingo — Nível 6

> **Tema oficial:** Fale sobre empregos · **Seção 1, Unidade 6** · Curso: Alemão para falantes de português

## Visão geral

Neste nível você fala sobre **profissões e trabalho**: o que faz, onde trabalha, horários e colegas. Gramática: **profissões sem artigo**, **feminino com `-in`**, **verbos de trabalho**, **preposições de local** (`bei`, `in`, `für`) e **horas**.

```text
Ich bin Lehrerin. Ich arbeite in einer Schule.                  →  Sou professora. Trabalho em uma escola.
Was bist du von Beruf? — Ich bin Ingenieur.                     →  Qual é a sua profissão? — Sou engenheiro.
Er arbeitet bei Siemens von neun bis siebzehn Uhr.              →  Ele trabalha na Siemens das 9h às 17h.
```

Ideias centrais:

1. Profissão após `sein` **sem artigo**: `Ich bin Arzt.`
2. O feminino das profissões geralmente acrescenta **`-in`**: `Lehrer → Lehrerin`.
3. Preposições de trabalho: `bei` + empresa, `in` + local, `als` + função.

## Gramática em exemplos

### 1. Profissão sem artigo

| Estrutura | Exemplo |
|---|---|
| sein + profissão | Ich bin Lehrer. |
| sein + profissão (fem.) | Sie ist Ärztin. |
| com adjetivo → artigo | Er ist ein guter Arzt. |
| com `als` | Ich arbeite als Koch. |

- Sem adjetivo, **não há artigo**; com adjetivo, usa-se o artigo.

### 2. Feminino com `-in`

| Masculino | Feminino | Observação |
|---|---|---|
| Lehrer | Lehrerin | +in |
| Arzt | Ärztin | +in + trema |
| Anwalt | Anwältin | +in + trema |
| Koch | Köchin | +in + trema |
| Student | Studentin | +in |
| Krankenpfleger | Krankenschwester | forma própria |

- Plural feminino: `-innen` (`Lehrerinnen`, `Ärztinnen`).

### 3. Verbo `arbeiten` e `lernen`

| Pessoa | arbeiten | lernen |
|---|---|---|
| ich | arbeite | lerne |
| du | arbeitest | lernst |
| er / sie / es | arbeitet | lernt |
| wir | arbeiten | lernen |
| ihr | arbeitet | lernt |
| sie / Sie | arbeiten | lernen |

- Verbos cujo radical termina em `-t` ou `-d` inserem `-e-`: **arbeitest**, **arbeitet**.

### 4. Preposições para trabalho

| Estrutura | Exemplo |
|---|---|
| bei + empresa | Ich arbeite bei Bosch. |
| in + local | Er arbeitet in einem Büro. |
| als + função | Ich arbeite als Lehrer. |
| für + empregador | Ich arbeite für die Stadt. |
| zu Hause | Ich arbeite zu Hause. |
| im Home-Office | Ich arbeite im Home-Office. |

### 5. Horas e dias

| Estrutura | Exemplo |
|---|---|
| um + hora | Die Besprechung ist um zehn Uhr. |
| von … bis … | Ich arbeite von neun bis siebzehn Uhr. |
| montags | Ich arbeite montags. |
| am Wochenende | Am Wochenende habe ich frei. |
| jeden Tag | Ich arbeite jeden Tag. |

### 6. Horas em alemão

| Hora | Alemão |
|---|---|
| 9:00 | neun Uhr |
| 9:15 | Viertel nach neun |
| 9:30 | halb zehn |
| 9:45 | Viertel vor zehn |
| 10:00 | zehn Uhr |
| 12:00 | zwölf Uhr / Mittag |

- `halb zehn` = **meia hora para as dez** (9:30), não 10:30.

### 7. Verbos modais no trabalho

| Pessoa | müssen | können | dürfen |
|---|---|---|---|
| ich | muss | kann | darf |
| du | musst | kannst | darfst |
| er / sie / es | muss | kann | darf |
| wir | müssen | können | dürfen |
| ihr | müsst | könnt | dürft |
| sie / Sie | müssen | können | dürfen |

| Exemplo | Tradução |
|---|---|
| Ich muss heute arbeiten. | Preciso trabalhar hoje. |
| Ich kann gut kochen. | Sei cozinhar bem. |
| Man darf hier nicht rauchen. | Não é permitido fumar aqui. |

- Modal + **infinitivo no final**: `Ich muss heute lange arbeiten.`

### 8. Passado simples de `sein` e `haben` (introdução)

| Pessoa | sein | haben |
|---|---|---|
| ich | war | hatte |
| du | warst | hattest |
| er / sie / es | war | hatte |
| wir | waren | hatten |
| ihr | wart | hattet |
| sie / Sie | waren | hatten |

- Exemplo: `Ich war Lehrer.` / `Ich hatte einen guten Chef.`

### 9. Perguntas sobre trabalho

| Pergunta | Resposta |
|---|---|
| Was bist du von Beruf? | Ich bin Arzt. |
| Wo arbeitest du? | Im Krankenhaus. |
| Wie lange arbeitest du dort? | Seit fünf Jahren. |
| Gefällt dir die Arbeit? | Ja, sehr. |
| Verdienst du gut? | Es geht. |

### 10. `Seit` (desde / há)

| Estrutura | Exemplo |
|---|---|
| seit + dativo | Ich arbeite seit drei Jahren hier. |
| seit + data | Ich lebe seit 2015 in Berlin. |
| Präsens + seit | Er ist seit einem Monat arbeitslos. |

- A: Hast du schon eine neue Stelle?
- B: Noch nicht. Ich habe nächste Woche ein Vorstellungsgespräch.

- B: Danke!

## Pontos de atenção e erros comuns

- **Sem artigo**: *Ich bin ein Lehrer* soa estranho; use `Ich bin Lehrer`.
- **`Arbeiten`** insere `-e-` em `du arbeitest`, `er arbeitet`.
- **`Halb`** conta para a próxima hora: `halb neun` = 8:30.
- **Modais** levam infinitivo no **fim**: `Ich muss heute arbeiten.`
- **`Studieren`** = estudar na universidade; **`lernen`** = aprender/estudar em geral.
- **`Seit`** + presente: `Ich arbeite seit drei Jahren hier`.
- **Vocabulário que engana**: `die Stelle` = vaga/emprego; `der Job` = trabalho informal.
- **`Chef`** é qualquer chefe; **`Direktor`** é diretor de escola ou instituição.

## Complete as lacunas

1. Ich ____ Lehrerin. (sou) → `bin`
2. Er ____ bei Bosch. (trabalha) → `arbeitet`
3. Sie ist ____ . (médica) → `Ärztin`
4. Ich arbeite ____ neun ____ siebzehn Uhr. (das … às) → `von … bis`
5. Ich ____ heute arbeiten. (devo) → `muss`
6. Ich arbeite ____ Verkäufer. (como) → `als`
