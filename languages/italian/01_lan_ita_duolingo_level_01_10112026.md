# Italiano · Duolingo — Nível 1

> **Tema oficial:** Faça pedidos no café · **Seção 1, Unidade 1** · Curso: Italiano para falantes de português

## Visão geral

Primeiro contato com o italiano: **pedir algo em um café** (*bar*). O italiano é parecido com o português, mas tem hábitos próprios: o café é tomado em pé no balcão, o `cappuccino` é coisa de manhã, e os pedidos são curtos e educados.

```text
Buongiorno, un caffè, per favore.                 →  Bom dia, um café, por favor.
Vorrei un cappuccino e un cornetto.               →  Gostaria de um cappuccino e um cornetto.
Quanto costa?                                     →  Quanto custa?
```

Ideias centrais:

1. **Artigos** italianos (`un`, `una`, `il`, `la`) concordam em gênero e número.
2. **`Vorrei`** (gostaria) é a forma educada de pedir; `Voglio` soa seco.
3. A pronúncia é quase fonética: cada letra tem som constante, e **consoantes duplas** são pronunciadas mais longas (`caffè`).

## Gramática em exemplos

### 1. Artigos indefinidos

| | Masculino | Feminino |
|---|---|---|
| singular | un (uno diante de z, s+consoante) | una (un' diante de vogal) |
| plural | dei / degli | delle |

| Exemplo | Observação |
|---|---|
| un caffè | masc. |
| una brioche | fem. |
| un'acqua | fem. + vogal |
| uno zucchero | `z` |
| uno spritz | `s + consoante` |

### 2. Artigos definidos

| | Masculino | Feminino |
|---|---|---|
| singular | il (lo diante de z/s+cons.; l' diante de vogal) | la (l' diante de vogal) |
| plural | i (gli diante de vogal/z/s+cons.) | le |

| Exemplo | Tradução |
|---|---|
| il caffè | o café |
| lo zucchero | o açúcar |
| l'acqua | a água |
| gli spritz | os spritz |
| i cornetti | os cornettos |
| le brioche | as brioches |

### 3. Gênero e plural

| Singular | Plural | Regra |
|---|---|---|
| il cornetto | i cornetti | `-o` → `-i` |
| la torta | le torte | `-a` → `-e` |
| il tè | i tè | invariável (acento final) |
| il caffè | i caffè | invariável |
| il latte | i latti | `-e` → `-i` |
| la birra | le birre | `-a` → `-e` |

### 4. `Vorrei` (condicional de `volere`)

| Pessoa | Forma |
|---|---|
| io | vorrei |
| tu | vorresti |
| lui / lei | vorrebbe |
| noi | vorremmo |
| voi | vorreste |
| loro | vorrebbero |

- `Vorrei un caffè.` = “Gostaria de um café.”
- `Voglio un caffè.` = “Quero um café.” (menos educado)

### 5. Verbo `volere` (presente)

| Pessoa | Forma |
|---|---|
| io | voglio |
| tu | vuoi |
| lui / lei | vuole |
| noi | vogliamo |
| voi | volete |
| loro | vogliono |

| Número | Italiano |

| 1 | uno / una |
| 2 | due |
| 3 | tre |
| 4 | quattro |
| 5 | cinque |

## Diálogos

### Diálogo 1 — Pedido simples

- Barista: Buongiorno! Che cosa desidera?
- Cliente: Buongiorno. Un cappuccino e un cornetto, per favore.
- Barista: Subito. Qualcos'altro?
- Cliente: No, basta così. Quanto costa?
- Barista: Tre euro e cinquanta.

### Diálogo 2 — Na caixa

- Cliente: Faccio lo scontrino?
- Cassiere: Sì, prima alla cassa. Che cosa prende?
- Cliente: Un caffè e un succo d'arancia.
- Cassiere: Quattro euro.

### Diálogo 3 — No balcão

- Cliente: Un caffè macchiato, per favore. Ecco lo scontrino.
- Barista: Prego. Ecco il caffè.
- Cliente: Grazie mille!
- Barista: Prego, buona giornata!

## Pontos de atenção e erros comuns

- **`Caffè`** pede um **espresso**; para uma xícara grande, peça `caffè americano` ou `caffè lungo`.
- **`Cappuccino`** é bebida de manhã; pedir depois do almoço soa estranho aos italianos.
- **Pagar primeiro** (`lo scontrino`) é o comum em muitos bares, depois levar ao balcão.
- **Falso cognato**: `il cornetto` = croissant, não “cornetto” de sorvete; `il panino` = sanduíche.
- **Falso cognato**: `caldo` = quente (não “caldo”); `caldo` também é calor.
- **Falso cognato**: `burro` = manteiga (não “burro”); `pasta` = massa/docinho.
- **Pronúncia**: `gn` = *nh*, `gli` = *lh*, `ci/ce` = *tchi/tche*.
