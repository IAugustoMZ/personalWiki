# Italiano · Duolingo — Nível 5

> **Tema oficial:** Descreva personalidades · **Seção 1, Unidade 5** · Curso: Italiano para falantes de português

## Visão geral

Neste nível você descreve **como as pessoas são**: qualidades, defeitos e humor. O foco é a **concordância dos adjetivos** (gênero e número), o uso de **essere** com adjetivos e **advérbios de intensidade** (`molto`, `abbastanza`, `troppo`).

```text
Mia sorella è simpatica e molto socievole.      →  Minha irmã é simpática e muito sociável.
Mio fratello non è timido, è abbastanza aperto.  →  Meu irmão não é tímido, é bem aberto.
I miei amici sono divertenti.                    →  Meus amigos são engraçados.
```

Ideias centrais:

1. Adjetivos em `-o/-a` flexionam (`simpatico/simpatica`); os em `-e` têm uma forma só no singular (`gentile`).
2. O plural varia: `-i` (masc.) e `-e` (fem.), com mudança de `c` para `ch` em `-ca`.
3. O adjetivo costuma vir **depois** do substantivo, mas alguns vêm antes (`bello`, `buono`, `grande`).

## Gramática em exemplos

### 1. Adjetivos em `-o / -a`

| Masculino sing. | Feminino sing. | Masc. pl. | Fem. pl. |
|---|---|---|---|
| simpatico | simpatica | simpatici | simpatiche |
| allegro | allegra | allegri | allegre |
| pigro | pigra | pigri | pigre |
| testardo | testarda | testardi | testarde |
| onesto | onesta | onesti | oneste |

### 2. Adjetivos em `-e`

| Singular (m./f.) | Plural (m./f.) |
|---|---|
| gentile | gentili |
| intelligente | intelligenti |
| paziente | pazienti |
| socievole | socievoli |
| responsabile | responsabili |
| felice | felici |

### 3. Mudanças ortográficas no plural

| Terminação | Plural | Exemplo |
|---|---|---|
| `-co` (som /k/) | `-chi` | pigro → pigri; bianco → bianchi |
| `-co` (paroxítona) | `-ci` | simpatico → simpatici |
| `-ca` | `-che` | simpatica → simpatiche |
| `-go` | `-ghi` | lungo → lunghi |
| `-ga` | `-ghe` | lunga → lunghe |
| `-cia` / `-gia` | `-ce` / `-ge` | provincia → province |

### 4. `Essere` com adjetivos

| Pessoa | essere | Exemplo |
|---|---|---|
| io | sono | Sono timido. |
| tu | sei | Sei molto gentile. |
| lui / lei | è | Lei è simpatica. |
| noi | siamo | Siamo allegri. |
| voi | siete | Siete pigri. |
| loro | sono | Sono onesti. |

### 5. Posição do adjetivo

| Posição | Exemplos |
|---|---|
| depois (padrão) | una ragazza simpatica; un amico fedele |
| antes (comuns) | un bel ragazzo; una brava persona; un buon amico |
| muda de sentido | un grande uomo (importante) × un uomo grande (alto/grande) |

### 6. `Bello` e `buono` antes do nome

| Masculino | Feminino |
|---|---|
| un bel ragazzo | una bella ragazza |
| un bell'uomo | una bell'amica |
| dei bei ragazzi | delle belle ragazze |
| un buon amico | una buona amica |
| un buon padre | una buona madre |

### 7. Advérbios de frequência

| Advérbio | Posição | Exemplo |
|---|---|---|
| sempre | depois do verbo | È sempre gentile. |
| spesso | depois do verbo | È spesso nervoso. |
| a volte | início ou fim | A volte è pigro. |
| non … mai | em torno do verbo | Non è mai in ritardo. |
| raramente | depois do verbo | È raramente arrabbiato. |

### 8. Comparativos

| Estrutura | Exemplo |
|---|---|
| più … di | Marco è più alto di Luca. |
| meno … di | Anna è meno timida di me. |
| (tanto) … quanto | È tanto gentile quanto generosa. |
| (così) … come | È così simpatica come sua madre. |
| migliore / peggiore | È migliore di me. |

### 9. Superlativo

| Tipo | Exemplo |
|---|---|
| relativo | È il più simpatico della classe. |
| absoluto `-issimo` | È simpaticissimo. |
| absoluto com `molto` | È molto simpatico. |
| irregulares | ottimo, pessimo, massimo, minimo |

### 10. Perguntas de descrição

| Pergunta | Resposta |
|---|---|
| Com'è? | È simpatico. |
| Che carattere ha? | Ha un carattere tranquillo. |
| È timido? | No, per niente. |
| A chi assomiglia? | Assomiglia a sua madre. |

## Pontos de atenção e erros comuns

- **Plural em `-chi / -ci / -che`**: `simpatici`, `simpatiche`, `pigri`.
- **Adjetivos em `-e`** não distinguem gênero no singular: `un ragazzo gentile`, `una ragazza gentile`.
- **`Bello` e `buono`** mudam de forma antes do substantivo.
- **`Grande`** antes do nome vira `gran` diante de consoante: `un gran uomo`.
- **Falso cognato**: `sensibile` = sensível/empático; `sensato` = sensato.
- **Falso cognato**: `simpatico` = simpático; **`carino`** = fofo/gentil.
- **Falso cognato**: `educato` = bem-educado, não “educado” só de estudo.
- **Falso cognato**: `noioso` = chato, **não** “nojoso”.
