# Italiano · Duolingo — Nível 14

> **Tema oficial:** Fale sobre os seus estudos · **Seção 2, Unidade 4** · Curso: Italiano para falantes de português

## Visão geral

Neste nível você fala sobre **estudos**: escola, universidade, matérias, aulas, provas e planos acadêmicos. Gramática: **verbos de estudo** (`studiare`, `frequentare`, `laurearsi`), **artigos com matérias**, **passato prossimo** introdutório e **expressões de tempo**.

```text
Studio ingegneria all'università di Bologna.         →  Estudo engenharia na Universidade de Bolonha.
Ho un esame di matematica domani.                   →  Tenho uma prova de matemática amanhã.
Mi sono laureato in economia due anni fa.           →  Formei-me em economia há dois anos.
```

Ideias centrais:

1. `Studiare` + matéria (sem artigo): `studio storia`.
2. `Frequentare` + curso/escola: `frequento il liceo`.
3. O **passato prossimo** (avere/essere + particípio) conta o que já aconteceu.

## Gramática em exemplos

### 1. `Studiare` e `frequentare`

| Verbo | Estrutura | Exemplo |
|---|---|---|
| studiare | + matéria (sem artigo) | Studio storia. |
| studiare | + a/in + lugar | Studio all'università. |
| frequentare | + curso/escola | Frequento il liceo. |
| frequentare | + ano | Frequento il terzo anno. |

| Pessoa | studiare | frequentare |
|---|---|---|
| io | studio | frequento |
| tu | studi | frequenti |
| lui / lei | studia | frequenta |
| noi | studiamo | frequentiamo |
| voi | studiate | frequentate |
| loro | studiano | frequentano |

### 2. Artigo com matérias

| Contexto | Exemplo |
|---|---|
| após `studiare` | sem artigo: Studio storia. |
| sujeito | com artigo: La storia è interessante. |
| com `piacere` | com artigo: Mi piace la storia. |
| com preposição | di storia: un libro di storia |
| com `essere bravo in` | Sono bravo in matematica. |

### 3. Passato prossimo com `avere`

| Pessoa | Forma | Exemplo |
|---|---|---|
| io | ho + particípio | Ho studiato molto. |
| tu | hai + particípio | Hai superato l'esame. |
| lui / lei | ha + particípio | Ha scritto la tesi. |
| noi | abbiamo + particípio | Abbiamo ripassato. |
| voi | avete + particípio | Avete capito? |
| loro | hanno + particípio | Hanno consegnato. |

| Terminação | Particípio | Exemplo |
|---|---|---|
| -are | -ato | studiare → studiato |
| -ere | -uto | ripetere → ripetuto |
| -ire | -ito | capire → capito |

| Irregular | Particípio |
|---|---|
| fare | fatto |
| scrivere | scritto |
| leggere | letto |
| prendere | preso |
| dire | detto |
| vedere | visto / veduto |

### 4. Passato prossimo com `essere`

| Verbo | Particípio | Exemplo |
|---|---|---|
| andare | andato | Sono andato a lezione. |
| venire | venuto | È venuta in biblioteca. |
| laurearsi | laureato | Mi sono laureato. |
| iscriversi | iscritto | Mi sono iscritta a legge. |

- Com `essere`, o particípio **concorda** com o sujeito: `Sono andata`, `Sono andati`.

### 5. Reflexivos no passato prossimo

| Pessoa | Forma |
|---|---|
| io | mi sono laureato/a |
| tu | ti sei laureato/a |
| lui / lei | si è laureato/a |
| noi | ci siamo laureati/e |
| voi | vi siete laureati/e |
| loro | si sono laureati/e |

### 6. Expressões de tempo

| Expressão | Exemplo |
|---|---|
| da + duração | Studio italiano da due anni. |
| fa | Mi sono laureato due anni fa. |
| ieri / ieri sera | Ieri ho studiato. |
| la settimana scorsa | La settimana scorsa ho avuto un esame. |
| l'anno prossimo | Mi laureo l'anno prossimo. |
| fra / tra + duração | Fra due mesi finisco. |

### 7. `Sapere` e `conoscere` nos estudos

| Verbo | Uso | Exemplo |
|---|---|---|
| sapere | saber fatos, saber fazer | So la lezione. / So parlare inglese. |
| conoscere | conhecer pessoas/lugares | Conosco il professore. |
| sapere + infinitivo | habilidade | So scrivere bene. |

## Diálogos

### Diálogo 1 — Conversa entre universitários

- Marco: Che cosa studi?
- Sara: Studio medicina. E tu?
- Marco: Io ingegneria. Frequento il terzo anno.
- Sara: Hai un esame questa settimana?
- Marco: Sì, venerdì. Devo ripassare molto.

### Diálogo 2 — Aula

- Prof.: Chi ha fatto i compiti?
- Studente: Io li ho fatti.
- Prof.: Bene. Consegnateli entro domani.
- Studente: Va bene, grazie.

### Diálogo 3 — Planos

- Anna: Quando ti laurei?
- Luca: L'anno prossimo.
- Anna: E dopo?
- Luca: Vorrei studiare all'estero.

## Pontos de atenção e erros comuns

- **Matéria sem artigo** após `studiare`, mas com artigo como sujeito.
- **`Laurearsi in`** + matéria; **`diplomarsi`** é ensino médio/técnico.
- **`Passato prossimo`** com `essere`: o particípio concorda (`sono andata`).
- **`Fa`** (atrás) vem **depois** do tempo: `due anni fa`.
- **`Da`** + duração indica tempo em curso: `Studio da due anni`.
- **Falso cognato**: `la lezione` = aula; `la lettura` = leitura.
- **Falso cognato**: `l'esame` = prova; `l'esame scritto/orale` = prova escrita/oral.
- **Falso cognato**: `la facoltà` = faculdade (departamento), não necessariamente “faculdade”.
