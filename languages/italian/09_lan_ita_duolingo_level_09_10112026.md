# Italiano · Duolingo — Nível 9

> **Tema oficial:** Use concordância de gênero e número · **Seção 1, Unidade 9** · Curso: Italiano para falantes de português

## Visão geral

Neste nível você consolida a **concordância** em italiano: substantivo, artigo e adjetivo precisam combinar em **gênero** (masculino/feminino) e **número** (singular/plural). É a base de toda frase correta.

```text
il ragazzo alto    →  i ragazzi alti
la ragazza alta    →  le ragazze alte
lo zaino nuovo     →  gli zaini nuovi
```

Ideias centrais:

1. Todo substantivo tem **gênero**; aprenda com o artigo.
2. Artigo, substantivo e adjetivo **concordam** entre si.
3. Há terminações e exceções que mudam o plural (`-co/-go`, `-ca/-ga`, `-cia/-gia`, palavras invariáveis).

## Gramática em exemplos

### 1. Gênero: terminações típicas

| Terminação | Gênero | Exemplo |
|---|---|---|
| `-o` | masculino | il libro, il ragazzo |
| `-a` | feminino | la casa, la ragazza |
| `-e` | ambos | il fiore (m.), la notte (f.) |
| `-tà`, `-tù`, `-ione`, `-zione` | feminino | la città, la gioventù, la stazione |
| `-ma` (gregas) | masculino | il problema, il programma, il tema |
| consoante (estrangeiros) | masculino (em geral) | il computer, il film |

### 2. Plural dos substantivos

| Singular | Plural | Regra |
|---|---|---|
| il libro | i libri | `-o` → `-i` |
| la casa | le case | `-a` → `-e` |
| il fiore | i fiori | `-e` → `-i` (masc.) |
| la notte | le notti | `-e` → `-i` (fem.) |
| la città | le città | invariável (acento) |
| il caffè | i caffè | invariável |
| il film | i film | invariável (estrangeiro) |
| il problema | i problemi | `-ma` → `-mi` |

### 3. Plural com `c` e `g`

| Singular | Plural | Regra |
|---|---|---|
| l'amico | gli amici | `-co` → `-ci` (paroxítona) |
| il bosco | i boschi | `-co` → `-chi` |
| l'amica | le amiche | `-ca` → `-che` |
| il lago | i laghi | `-go` → `-ghi` |
| la riga | le righe | `-ga` → `-ghe` |
| la farmacia | le farmacie | `-cia` (vogal antes) → `-cie` |
| la mancia | le mance | `-cia` (consoante antes) → `-ce` |

### 4. Artigos definidos

| Gênero | Singular | Plural | Quando |
|---|---|---|---|
| masc. | il | i | consoante simples |
| masc. | lo | gli | z, s+consoante, gn, ps, x, y |
| masc. | l' | gli | vogal |
| fem. | la | le | consoante |
| fem. | l' | le | vogal |

| Exemplo |
|---|
| il ragazzo → i ragazzi |
| lo zaino → gli zaini |
| lo studente → gli studenti |
| l'amico → gli amici |
| la casa → le case |
| l'amica → le amiche |

| Gênero | Forma | Quando |
|---|---|---|
| masc. | un | consoante ou vogal |
| masc. | uno | z, s+consoante |
| fem. | una | consoante |
| fem. | un' | vogal |

| Exemplo |
|---|

## Diálogos

### Diálogo 1 — Descrevendo coisas

- A: Hai un nuovo zaino?
- B: Sì, uno zaino blu e nero.
- A: Anche gli amici hanno zaini nuovi?
- B: Sì, ma i loro sono rossi.

### Diálogo 2 — Na escola

- Prof.: La studentessa è italiana?
- Aluno: No, è brasiliana. I suoi amici sono italiani.
- Prof.: E le sue amiche?
- Aluno: Sono francesi.

### Diálogo 3 — Compras

- Cliente: Vorrei dei libri nuovi.
- Commesso: Abbiamo dei bei libri di storia.
- Cliente: Anche delle belle riviste?
- Commesso: Sì, ecco le nuove riviste.

## Pontos de atenção e erros comuns

- **Palavras em `-ma`** (`problema`, `programma`) são masculinas, apesar do `-a`.
- **`La mano`** (a mão) é feminina, apesar do `-o`; plural `le mani`.
- **`Plurale irregolare`**: `uomo` → `uomini`, `dio` → `dei`, `uovo` → `le uova`.
- **Adjetivos de cor invariáveis**: `blu`, `rosa`, `viola`, `beige`.
- **`Il caffè`** → `i caffè`; **`la città`** → `le città`.
- **`Lo studente`** vale para qualquer estudante; `l'allievo` é o aluno de uma escola ou de um mestre.
- **Uma só forma para dois gêneros**: `il/la cantante`, `il/la turista`, `il/la collega` mudam só no artigo.
- **`Gli` antes de vogal**: `gli amici`, mas o artigo feminino `le` não elide em plural.
