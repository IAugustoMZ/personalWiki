# Chinês · Duolingo — Nível 7

## Sessão de estudo · pedir bebidas

### Vocabulário

| Chinês | Pinyin | Português |
|---|---|---|
| 一 / 两 / 三 | yī / liǎng / sān | um / dois / três |
| 杯 | bēi | copo; xícara (classificador) |
| 奶茶 | nǎichá | chá com leite |
| 牛奶 | niúnǎi | leite |
| 绿茶 | lǜchá | chá verde |
| 糖 | táng | açúcar |
| 冰 | bīng | gelo |
| 要 | yào | querer; pedir |
| 谢谢 | xièxie | obrigado/a |
| 不客气 | bú kèqi | de nada |

### Frases da sessão

- Eu quero um chá com leite — 我要一杯奶茶。— *Wǒ yào yì bēi nǎichá.*
- Eu quero dois chás verdes — 我要两杯绿茶。— *Wǒ yào liǎng bēi lǜchá.*
- Sem açúcar e sem gelo — 不要糖，不要冰。— *Bú yào táng, bú yào bīng.*
- Obrigado/a — 谢谢。— *Xièxie.*
- De nada — 不客气。— *Bú kèqi.*

### Ponto de atenção

- Para quantificar bebidas, use número + `杯` + bebida.
- `两` é a forma usual de “dois” antes de classificadores: `两杯`.

### Prática guiada

- Eu quero uma xícara de leite — 我要一杯牛奶。— *Wǒ yào yì bēi niúnǎi.*
- Eu quero três chás com leite — 我要三杯奶茶。— *Wǒ yào sān bēi nǎichá.*
- Esta é uma xícara de chá verde — 这是一杯绿茶。— *Zhè shì yì bēi lǜchá.*
- Sem leite, por favor — 不要牛奶。— *Bú yào niúnǎi.*
