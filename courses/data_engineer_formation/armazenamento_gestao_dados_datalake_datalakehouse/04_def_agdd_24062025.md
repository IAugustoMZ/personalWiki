# Formação Engenheiro de Dados

## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### Plano de Custo para Implementar Data Lakes e Data Lakehouses em Diferentes Cenários

#### Fatores que impactam no custo

- volume dos dados
- diversidade das fontes
- requisitos de desempenho
- necessidades de segurança e conformidade
- escalabilidade para demandas futuras
- custos operacionais contínuos
  - manutenção
  - monitoramento
  - atualizações
- análise de ROI $\to$ custos diretos, indiretos, benefícios indiretos e diretos

#### Regras Gerais e Premissas

1. valores em dólares (US$)
2. valores podem sofrer alterações por conta de país, região, qualidade dos produtos e serviços, além de outros fatores
3. valores apresentados são estimativas de alto nível para ajudar como ponto de partida
4. valores são anuais
5. para cada total previsto, considere 15 \% de impostos

#### Cenários

1. Data Lake On Premises (10 TB dados / mês)
2. Data Lake em Cloud (10 TB dados / mês)
3. Data Lakehouse em Cloud (avançado $\to$ 100 TB / mês)

#### Cenário 1: Datalake On Premises (10 TB/mês)

##### **Hardware**

- exemplo de custo inicial (CAPEX)
- maior diferença com o ambiente em nuvem
- servidores: alto desempenho ($5,000 a $10,000)
  - 3x = $15,000
- armazenamento de alta capacidade
  - 3x = $15,000
- rede: equipamentos, switchs e roteadores
  - $5,000
- o CAPEX é o custo inicial apenas, a empresa pode diluir esse CAPEX ao longo do tempo

##### **Software**

- sistema operacional: Linux para economizar com licenças
  - ($500 a $2,000 / licença) $\to$ mesmo sendo Linux, existe suporte pago
- softwares específicos para Data Lake
  - alguns são open source
  - custos de suporte ou versões pagas
  - $0 (open source) a $5,000
  - escolha: HDFS para armazenamento distribuído
- ETL: soluções 100 % open source
  - Airbyte
  - Apache Spark
- segurança
