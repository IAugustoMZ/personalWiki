# Formação Engenheiro de Dados

## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### Linhagem, Observabilidade, Qualidade, Enriquecimento, e Governança de Dados

- linhagem de addos (data lineage)
  - ratreamento detalhado do ciclo de vida dos dados dentro de um sistema de informação
  - origem, transformações, armazenamento
  - transparência e rastreabilidade
  - precisão e a confiabilidade em ambientes complexos
  - conformidade regulatória e governança de dados
    - GDPR / LGPD
    - resposta rápida a auditorias
  - identificação e resolução de problemas / inconsistências
  - melhoria na colaboração $\to$ visão clara

#### Ferramentas de Rastreamento e Visualização de Linhagem

- softwares para capturar, documentar e exibir visualmente o percurso dos dados através dos processos
  - visão clara e detalhada

- **Apache Atlas**
  - open source usado em ambiente Hadoop
  - definição de metadados, catalogação e ratreamento dos dados
  - interface para visualização da linhagem de dados
    - classificação e segurança para garantir o uso adequado dos dados
- **Collibra**
  - empresarial
  - vasta integração com sistemas de dados
  - visão centralizada e visual de linhagem dos dados
- **Talend** $\to$ ETL + integração + linhagem
- **Informatica**

- **Benefícios**
  - transparência e rastreabilidade
  - auditorias completas e documentadas
  - visão clara e compartilhada $\to$ colaboração
  - gestão de dados mais segura e robusta

#### Princípios da Observabilidae em Data Lake

- capacidade de monitorar, entender e diagnostica o comportamento interno do sistema a partir de sua saída

1. **Coleta Abrangente de Dados**
   1. abrangente e contínua
   2. logs, métricas e rastreamentos que cobrem todas as operações
      1. eventos específicos (acessos e falhas)
      2. desempenho, latência e utilização de recursos
2. **Monitoramento em Tempo Real**
   1. capturar e exibir dados à medida que ocorrem
   2. detecção rápida de anomalias e resposta a incidentes
   3. Apache Kafka, Prometheus e Grafana
3. **Alertas e Notificações**
   1. informar partes interessadas
      1. diferentes níveis de gravidade e tipos de eventos
4. **Visualização e Análise**
   1. dashboard e ferramentas $\to$ entendimento do estado do Data Lake
      1. gráficos, tabelas, mapas de calor
   2. Kibana, Grafana, Tableau
5. **Correlação e Contexto**
   1. correlacionar diferentes tipos de dados e fornecer contexto
      1. logs, métricas, rastreamentos $\to$ visão holística
   2. entender causa raiz, como diferentes eventos e componentes estão interrelacionados
   3. Elastic Stack / Datadog

- **Benefícios**
  - confiabilidade e performance do sistema
  - detecção de anomalias
  - otimização contínua das operações
  - conformidade regulatória $\to$ auditoria detalhada + documentação completa
  - melhoria da tomada de decisão
    - visibilidade sobre estado e o desempenho
    - decisões informadas sobre ajustes operacionais, planejamento de capacidade, estratégias de manutenção
  - gestão mais eficiente e eficaz dos dados

#### Monitoramento e Alertas em Ambientes de Dados

- garantir eficiência e integridade das operações $\to$ manter disponibilidade dos serviços
- coleta contínua de métricas e logs $\to$ desempenho, a utilização dos recursos, saúde geral do sistema
  - identificar degradações de desempenho ou falhas

##### Implementações de sistemas de monitoramento

- capturar e analisar dados em tempo real
- Prometheus, Grafana e Elasticsearch
  - dashboard personalizados
  - visão detalhada dos componentes
- integração com sistemas de logs
  - ELK Stack (Elasticsearch, Logstack, Kibana)
    - correlação entre eventos
    - identificação de causas raízes
- **Configuração de Alertas**
  - notificação das equipes responsáveis sobre eventos e acionamento por condições
    - pico de uso de CPU
    - falhas de rede
    - erros de bancos de dados
  - PagerDuty, Slack, Opsgenie $\to$ entrega de alertas e assegurar que notificações cheguem às ésspas certas em tempo hábil
  - resposta rápida aos incidentes

#### Fundamentos da Qualidade de Dados

- medidas em que os dados são precisos, completos, consistentes, relevantes, e atualizados
  - uso eficaz para suportar decisões negócios
- impactos diretos na eficiência operacional, satisfação do cliente e capacidade de alcançar seus objetivos estratégicos

##### **Dimensões da Qualidade dos Dados**

1. **Precisão:** exatidão dos dados em representar a realidade
2. **Completude:** se todos os dados necessários estão presentes
3. **Consistência:** dados uniformes e sem discrepâncias através de diferentes sistemas e fontes
4. **Relevância:** se os dados são pertinentes e úteis para a finalidade desejada
5. **Atualidade:** se os dados são recentes e atualizados

- qualidade de dados é mais relacionada com práticas robustas e processos contínuos
