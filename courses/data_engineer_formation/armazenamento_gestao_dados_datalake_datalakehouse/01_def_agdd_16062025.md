# Formação Engenheiro de Dados

## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### Data Warehouse - Conceito e Evolução

- não é mutuamente exclusivo com Data Lake
- depende da maturidade e do tipo de problema a ser resolvido
- repositório centralizado de dados que foram coletados de diferentes fontes
  - dados processados, transformados e limpos
  - análise de negócio, relatórios, tomada de decisão
- tecnologia mais estabelecida $\to$ mais simples de se implementar
- fornecer visão consolidada e unificada dos dados
- on-premises $\to$ infraestrutura em nuvem
  - evolução das tecnologias de Big Data e análise em tempo real
  - uso de IA e aprendizado de máquina para melhorar qualidade e precisão das análises

### Datalake - Conceito e Evolução

- repositório para armazenamento de grandes volumes de dados brutos, em seu formato original
  - dados estruturados, semi-estruturados, e não estruturados
- armazenamento flexível e econômico
  - integração de diversos tipos
  - análises complexas
- tendência $\to$ convergência de Datalakes + Data Warehouses
  - aproveitar benefícios de ambos
    - volumes de dados brutos (DL) + visão unificada e consolidada (DW)

### Data Lakehouse - Conceito e Evolução

- combinação dos benefícios de Data Lakes e Data Warehouses
- aramazena grandes volumes de dados brutos, em seu formato original (DL), mas também oferece recursos de gerenciamento de dados e análise (DW)
- armazenamento flexível + visão unificada e consolidada

| Data Warehouse | Data Lake | Data Lakehouse |
| --- | --- | --- |
| <li>dados limpos, transformados e estruturados<li>gerenciamento e análise, consultas SQL e relatórios<li>visão consolidada e unificada para análises e relatórios | <li>armazenar grandes volumes de dados brutos em formatos originais<li>estruturados, semi-estruturados e não estruturados<li>flexibilidade de armazenamento e custo-benefício<li>não oferece muitas funcionalidades de gerenciamento e análise | <li>combina características de Data Lake e Data Warehouse<li>grandes volumes de dados brutos em formatos originais<li>funcionalidades de gerenciamento e análise<li>visão consolidada e unificada para relatórios e tomadas de decisão |
