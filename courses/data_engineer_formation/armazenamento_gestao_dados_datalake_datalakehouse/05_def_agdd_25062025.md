# Formação Engenheiro de Dados

## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### Plano de Custo para Implementar Data Lakes e Data Lakehouses em Diferentes Cenários

#### Cenário 1: Datalake On Premises (10 TB/mês)

##### **Manutenção, Administração e Recursos Humanos**

- custo operacional (OPEX)
- **Manutenção:** dos equipamentos ($ 1,000 a $5,000)
- **Recursos Humanos:** equipe  de TI para gerenciar o Data Lake: $50,000 a $150,000
- não vamos considerar custos de administração
  - energia elétrica
  - refrigeração

##### **Considerações finais**

- escalabilidade pode alterar os custos inciais (volumetria)
- energia de resfriamento
- custos indiretos $\to$ treinamento, consultoria

#### Cenário 2: Datalake na Nuvem (10 TB/mês)

##### **Hardware (Infra em Cloud)**

- tipo Object Storage
  - Amazon S3
  - Azure Blob Storage
  - Google Cloud Storage
- $0.023 por GB/mês (Amazon S3) $\to$ $ 230 (armazenamento)
- computação: instâncias de máquina virtual
  - Amazon EC2
  - Azure VMs
  - Google Compute Engine
  - 2 vCPU + 8 GB RAM $\to$ $0.10/h
- rede e transferência de dados
  - geralmente os custos são para transferências para gora
  - $0.09 / GB para 10 TB
- sempre bom colocar alertas e notificações no ambiente de nuvem para controlar custos

##### **Software**

- plataforma de data lake
  - Azure Data Lake
  - AWS Lake Formation
  - cobrança por consulta ou volume de dados processados ($0.44 / TB)
- ferramentas de ETL
  - AWS Glue
  - Azure Data Factory
  - Google Cloud Dataflow
  - custo baseado no tempo de execução do job ($0.44 / h DPU)
    - DPU = *data processing unit*
- outras ferramentas (opcional)
  - análise e visualização de dados
    - Tableau
    - Power BI
- gerenciamento e monitoramento
  - desempenho
  - segurança e conformidade

##### **Manutenção, Segurança e Recursos Humanos**

- manutenção $\to$ $ 0 por ano
- segurança $\to$ softwares de segurança e firewalls = $ 0 / ano
- recursos humanos $\to$ equipe de TI para gerenciar = $50,000 - $150,000
- custos de manutenção e segurança já estão inclusos nos custos de hardware / software em cloud
  - pode ser necessário conectar à internet (tem que configurar firewall externo)
  - implementar uma VPN
