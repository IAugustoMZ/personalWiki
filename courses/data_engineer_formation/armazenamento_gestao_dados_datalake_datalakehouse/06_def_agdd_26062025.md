# Formação Engenheiro de Dados

## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### Plano de Custo para Implementar Data Lakes e Data Lakehouses em Diferentes Cenários

#### Cenário 3: Datalakehouse em Cloud

- 100 TB / mês (solução mais avançada)

##### Hardware

- infraestrutura robusta para grandes volumes de dados
- serviços
  - Amazon S3: armazenamento de dados
  - Amazon EC2: processamento e operações dos dados
  - Amazon Redshift: acesso aos dados carregados a partir do S3
- custos
  - Amazon S3 $\to$ $ 0.023 no primeiro TB e diminuindo com o volume = $2,300 / mês
  - Amazon EC2: `r5 4x large` ($ 1,008 por instância por mês)
  - Amazon Redshift: `ra3 large` ($ 3.26/h $\times$ 160 h /mês)
- alguns serviços podem ser desligados para economizar custos
  - momentos de redução de demanda
  - automação com IaC (Terraform)
  - considerações de escalabilidade

##### Software

- AWS Glue (ETL)
  - $ 0.044 / DPU.h (a complexidade do ETL afeta o custo)
  - DPU.h / job = 10
  - operações por semana = 5 
    - desligar a infra de madrugada, depois de rodar o ETL e atualizar o Lakehouse
  - 4 semanas por mês = $ 88 / mês
  - não consideramos dados vindo de fora da AWS
- AWS Lake Formation: sem custo direto
- software adicional: $ 500 / mês
  - monitoramento e gestão
