# Formação Engenheiro de Dados

## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### Segurança e Privacidade em Data Lakehouses

- **autenticação e autorização**
  - apenas usuários autorizados podem acessar os dados
    - mesmo entre esses, garantir que cada usuário só possa acessar o que precisa (dados relevantes)
  - políticas de controle de acesso baseada em função (RBAC)
- **criptografia**
  - em trânsito e em repouso
- **monitoramento e auditoria**
  - manutenção da integridade e segurança
  - registros detalhados de atividades
    - consultas e modificações
  - detecção de atividades suspeitas
  - histórico e rastreabilidade
- **privacidade**
  - minização de dados (apenas dados necessários são coletados)
  - anonimização
  - mecanismos de acesso e atendimento dos direitos do titular
    - acesso, retificação e exclusão

### Ferramentas e Tecnologias no Mercado para DataLake

| Tecnolgia | Descrição |
| --- | --- |
| **Apache Hadoop HDFS** | open source para armazenamento distribuído e processamento usando o Hadoop Distributed Filesystem |
| **Amazon S3 (Simple Storage Service)** | durabilidade, escalabilidade e flexibilidade oferecido pela Ama\on AWS |
| **Azure Data Lake Storage** | oferecido pela Microsoft, solução de armazenamento em nuvem para Big Data Analytics: altamente escalável, integra-se bem com ferramentas em análise da Azure |
| **Google Cloud Storage** | armazenamento robusto e escalável da Google; combinada com ferramentas de análise da Google Cloud, como Big Query |
| **Apache Kafka** | ingestão de dados em tempo real |
| **AWS Lake Formation** | ferramenta de criação, configuração e gestão do Data Lake: automatiza muitos passos necessários para coletar, limpar e catalogar dados |
| **Presto** | open source de consultas distribuídas que permite a execução de consulta SQL em Data Lake: análise direta de dados armazenados em sistemas como HDFS, Amazon S3 |

### Ferramentas de Tecnologias no Mercado para Data Lakehouse

| Tecnologia | Descrição |
| --- | --- |
| **Databricks Delta Lake** | armazenamento em camadas, oferece recursos ACID para grandes conjuntos de dados: suporta operações de leitura e gravação em escala |
| **Snowflake** | escalabilidade elástica, separação, e computação e armazenamento, suporte para diveros tipos de dados |
| **Azure Synapse Analytics** | big data + data warehousing simplificando ingestão, limpeza e catalagoção dos dados |
| **Google BigQuery** | capacidade de trabalhar com dados semi-estruturados e realizar análises em escala |
| **Apache Hudi (Hadoop Upsert, Delete and Incrementals)** | open source que permite operações de upsert e delete em grandes datasets: gerenciar e processar dados em um ambiente |
| **Redshift Spectrum** | extensão do Redshift, permitindo consultas em escala de exabytes no S3 |
