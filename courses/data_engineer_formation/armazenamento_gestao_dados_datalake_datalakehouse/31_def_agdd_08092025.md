# Formação Engenheiro de Dados

## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### Gestão de Metadados no Databricks

- organização, catalogação e controle dos metadados associados aos dados armazenados e processados na plataforma
  - informações descritivas, técnicas e operacionais sobre os dados
    - esquema, origem, uso, qualidade e governança

##### Unity Catalog

- **catalogação centralizada**: catálogo único para registrar todos os dados disponíveis em diferentes fontes, facilitando a descoberta
- **RBAC**: gerenciamento de permissões detalhadas para acessar tabelas, colunas ou objetos específicos
- **auditoria e rastreamento**: registro de atividades para garantir conformidade e facilitar investigações
- **integração com ferramentas de governança**: suporte para tags, versionamento e políticas de retenção de dados

##### Solução de Problemas Comuns no Databricks

- erros de configuração de cluster
  - verificar se os recursos alocados são adequados para o workload
  - garantir que as versões do Databricks Runtime e bibliotecas sejam compatíveis
- desempenho ruim
  - otimizar tabelas usando o Delta Lake (z-ordering, compactação de arquivos)
  - usar caches como Delta Cache para reduzir latência
  - ajustar a paralelização de tarefas com base no tamanho do dataset
- erros com workflows e jobs
  - inspecionar logs detalhados fornecidos pelo Databricks para identificar falhas
  - validar dependências de bibliotecas e variáveis de ambiente
- problemas de conectividade com fontes de dados
  - verificar conexões de rede e permissões de autenticação
  - garantir que os drivers necessários estejam instalados no cluster
- gerenciamento de permissões
  - usar o Unity Catalog para auditar acessos e corrigir configurações de permissões inadequadas
- uso ineficiente de recursos
  - monitorar o uso de recursos usando o SparkUI
  - redimensionar cluster ou usar o escalonamento automático

##### Melhores Práticas e Recomendações ao usar o Databricks

1. **Gerenciamento de clusters**
   1. clusters de propósito único para isolar workloads diferentes e evitar interferências
   2. ativar o escalonamento automático (auto-scaling) para ajustar recursos dinamicamente com base na carga de trabalho
   3. desligamento automático de cluster inativos para economizar custos
2. **Otimização de Dados**
   1. utilizar o Delta Lake para garantir ACID, versionamento de dados e melhor desempenho em consultas
   2. técnicas como z-ordering, e compactação de arquivos para otimizar a leitura de grandes volumes de dados
   3. usar caches (Delta cache) para reduzir a latência de consultas repetitivas
3. **Desenvolvimento de notebooks**
   1. mantenha o código organizado, usando células de markdown para documentar e explicar blocos de código
   2. uso de parâmetros em notebooks para facilitar a reutilização em diferentes contextos
   3. divida tarefas complexas em notebooks menores e conectados por workflows
4. **Gerenciamento de metadados e Governança**
   1. centralize a gestão de metadados com o Unity Catalog para controle de acesso detalhado e organização dos dados
   2. classifique e rotule dados críticos para conformidade e segurança
   3. audite regularmente o uso de dados para garantir segurança e conformidade regulatória
5. **Segurança e controle de acesso**
   1. uso de RBAC para limitar permissões de leitura, escrita e execução
   2. armazenar senhas e credenciais no Databricks Secret Scope
   3. configure VPCs e regras de firewall para proteger redes e conexões externas
6. **Otimização do desempenho**
   1. minimize shuffles e ampliações desnecessárias ajustando partições e reparticionando adequadamente
   2. monitore e recupere jobs usando SparkUI para identificar gargalos
   3. use JOINs e filtros antecipadamente para reduzir o volume de dados processados
7. **Colaboração**
   1. promova a colaboração usando notebooks compartilhados e comentários em tempo real
   2. mantenha o versionamento de código integrado com ferramentas como Git
8. **Automação e Workflows**
   1. use o Databricks Workflows para agendar e automatizar jobs
   2. monitore e notifique falhas de jobs para corrigir rapidamente
9. **Gerenciamento de custos**
   1.  analise o uso de recursos regularmente usando relatórios integrados no Databricks
   2.  use tags de recursos para rastrear custos por projeto e por equipe
10. **Aprendizado Contínuo**
    1.  acompanhe atualizações do Databricks Runtime pra aproveitar as últimas melhorias de desempenho e consulte a documentação
    2.  para executar a criação de schemas no Spark $\to$ `CREATE DATABASE`
    3.  podemos configurar nossos próprios ambientes de computação

  - configurados com parâmetros como dependências, triggers de execução (manual ou agendada) e configurações do cluster $\to$ automação de processos de dados
