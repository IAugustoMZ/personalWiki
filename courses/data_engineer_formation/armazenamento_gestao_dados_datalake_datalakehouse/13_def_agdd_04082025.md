# Formação Engenheiro de Dados

## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### Design da Solução

#### Planejamento de Design Arquitetônico

- **definição dos requisitos**: necessidades dos stakeholders, acessibilidae, segurança e compliance
- **escolha da plataforma**: cloud
- **arquitetura:** definir como dados são coletadsos, armazenamentos, organizados ou acessados

#### Infraestrutura como Código com Terraform

- **criação de templates Terraform**
- **modularidade e reutilização:** em diferentes ambientes
- **gerenciamento de estado:** gerenciamento e sincronização

#### Implementação de Segurança

- **controle de acesso:** políticas IAM para acesso e operação
- **criptografia:** trânsito e repouso
- **auditoria e monitoriramento:** logging para responder a incidentes de segurança

#### **Integração e Automação**

- CI/CD para automação
- automação de data pipeline $\to$ processamento de dados

#### **Monitoramento e Otimização**

- desempenho e saúde
- otimização de custos $\to$ instâncias reservadas ou desalocando recursos não utilizados

#### **Documentação e Treinamento**

- detalhamento sobre arquitetura, configuração e operação
- capacitar a equipe sobre uso e manutenção

- definir diferentes regiões implicam em diferentes custos de nuvem
- no momento da criação de recursos, o valor padrão dos atributos serão utilizados, caso nenhum outro seja informar
- **provisionar**: permite a execução de um script externo
  - Terraform não é ferramenta de carregar dados
- configurar políticas de acesso ao bucket para controlar acesso e operações dos dados
