### Criando o Catálogo de Dados

#### Restrições de Qualidade de Dados

- podem ser criadas várias tabelas gold
  - cada uma atendendo a um problema de negócio
- notebooks PySPark podem ser agendados para ser executados ou manter em modo contínuo
- delta live tables são tabelas na prática, mas internamente são gerenciadas de forma que permitem essas funcionalidades
- o pipeline é definido como um arquivo JSON e que pode ser baixado e salvo em disco
- cada execução do pipeline $\to$ execução de uma query
  - conseguimos analisar informações a respeito
  - conseguimos analisar cada passo da consulta para estudos de otimização e planejamento
    - eliminação de gargalos
- podemos visualizar a linha de dados, por meio da visualização do grafo de execução
  - **upstream**: tabelas que estão antes da tabela que estou analisando
  - **downstream**: tabelas que estão depois (tabelas que são originadas da presente tabela)
- podemos criar monitor de qualidade das tabelas
  - a própria tabela no Databricks apresenta essas funcionalidades
