# Formação Engenheiro de Dados

## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### O que é Enriquecimento de Dados

- processo de melhorar a qualidade e utilidade dos dados brutos adicionando informações contextuais
  - fusão de dados externos
  - correção de informações incompletas ou imprecisas
  - adição de novos atributos $\to$ dados mais informativos
- dados enriquecidos permitem compreensão mais profunda e detalhada do contexto
  - identificação de tendências ocultas
- APIS de dados públicos, serviços de dados comerciais
  - limpeza e normalização
  - machine learning e IA $\to$ novos atributos ou categorização mais granular
  - plataformas de endereços ou inteligência de mercado
- situações comumente aplicáveis
  - **segmentação de clientes**: informações demográficas, comportamentais, psicológicas
  - **setor financeiro e seguros**: dados de crédito, histórico de pagamentos, dados econômicos para previsão de risco e condições de crédito mais adequadas
  - **manufatura e logística**: dados de fornecedores, condições de mercado, previsões econômicas para gestão de inventários, previsão de demandas
  - **governos e planejamento urbano**: gestão de infraestrutura, informações demográficas, registros de construção e dados ambientais
  - **pesquisa e desenvolvimento**: dados de mercado, feedback de clientes, patentes e publicações científicas, oportunidades de inovação para melhorar processos de desenvolvimento de produtos
- é possível criar buckets S3 via programação Python
- `boto3` é o Pacote Python quer permite a interação com AWS
- hash é o resultado de uma função matemática que transforma dados de comprimento variável numa sequência fixa de caracteres
  - resultado é determinístico $\to$ a mesma entrada sempre produz o mesmo hash
- SHA-256 $\to$ função de hash criptográfico
- a linhagem pode ser registrada por meio do cálculo das funções hash
  - que são identificadores únicos dos estados pelos quais o conjunto de dados passa ao longo do tempo
- observabilidade $\to$ tirar "fotos" dos dados em diferentes momentos, para acompanhar mudanças
  - verificação dos tipos
  - geração de relatórios estatísticos
    - cuidado com tipos e arredondamentos, pois podem mascarar as estatísticas
- qualidade $\to$ geralmente baseado em regras de negócio
  - entender as diretrizes para cada tipo de tratativa de qualidade
  - a diretriz precisa trazer consistência para os dados da empresa
    - fundamentadas nos objetivos estratégicos e nas necessidades, além de garantir a conformidade com regulamentações
- enriquecimento é opcional (depende do caso de uso dos dados)
- mascaramento dos dados $\to$ técnicas para proteção de informações confidenciais ao substituir ou ocultar partes dos dados com valores fictícios
  - privacidade ou segurança
  - ambientes de desenvolvimento / testes
  - mantém a usabilidade sem expor informações reais
  - tipos
    - substituição
    - embaralhamento
    - truncamento
    - criptografia
  - conformidade e mitigação de riscos de vazamentos
- no S3 não conseguimos ver ou editar os arquivos contidos
- o pipeline pode ser automatizado colocando-se as chamadas dos passos dentro de um script bash
  - integração com Grafana para visualização em tempo real das aplicações
  - notificações por email

### Documentação e Metadados de Projetos de Data Lake

- informações detalhadas sobre a arquitetura, os objetivos de projeto, fontes de dados, formatos utilizados, transformações aplicadas e políticas de governança
  - referência central para equipe técnica e stakeholders
  - alinhamento, continuidade, rastreabilidade
- metadados descrevem as características dos dados armazenados
  - origem, estrutura, esquema, contexto de uso, políticas de acesso
  - catalogar, organizar e buscar dados de maneira eficiente
    - facilita a descoberta e utilização
  - assegurar a qualidade, conformidade, governança
