# Formação Engenheiro de Dados

## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### Implementação

- não esquecer o mapeamento de portas
- `env-file` falar qual o arquivo contém as variáveis de ambiente
- build só se faz para o primeiro container $\to$ apenas no caso de todos os containers usarem a mesma imagem
- no container worker, nós não colocamos nomes, para garantir que dois workers não tenham o mesmo nome
  - nome do worker será automaticamente criado com base na manutenção dos workers
- gerenciamento do processamento distribuído $\to$ YARN
  - precisamos executar no history server
- jobs de processamento devem ser configuradas para usar o YARN, pois em caso contrário, o cluster vai usar o Hadoop Map Reduce
  - muitas operações em disco $\to$ mais lentas
