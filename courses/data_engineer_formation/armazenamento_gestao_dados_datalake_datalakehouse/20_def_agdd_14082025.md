## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### Data Lakehouse - Convergência entre Data Lakes e Datalakehouses

#### Plataforma Databricks no Cenário de Dados

- abordagem de Data Lakehouse
    - armazenamento + machine learning / inteligência artificial
- flexibiliade e processamento em tempo real
    - Apache Spark é a base
    - processamento distribuído de grandes volume
- suporte a dados não estruturados
- integração com ferramentas de machine learning

- quando criamos a conta Databricks, já temos uma workspace criada
    - notebook, jobs, ...
    - podemos criar vários ambientes de trabalho
    - implentação na nuvem $\to$ ambiente unificado para uma equipe acessar e gerenciar ativos
        - organiza objetos em pastas
        - acesso a dados e recursos computacionais necessários
    - vários ou apenas um contidos na mesma workspace
    - interação via UI, API REST ou CLI do Databricks
- na aba de ingestão, existem centenas de conectores de fontes conhecidas
- notebooks $\to$ onde a lógica é implementada
    - suporte múltiplas linguagens ao mesmo tempo
        - Python, Scala, SQL e R
- suporta a criação de consultas ou dashboards
- agendamento de jobs para processamento
    - tarefas e experimentos
- registro de modelos usando MLFlow e oferecimento por meio de endpoints

##### Unity Catalog

- sistema de gerenciamento unificado de dados e metadados
- **gerenciamento de metadados**: informações sobre tabelas, colunas, outras estruturas de dados, permitindo consultas consistentes e rastreáveis
- **governança centralizada**: controle granular de acesso , conformidade regulatória
- **compatibilidade multicloud**: gerenciamento de dados em múltplos provedores
- **rastreabilidade de dados**? auditoria e rastreamento de alterações em dados e metadados
- **integração com ferramentas de análise**: pipelines mais seguros e eficientes
