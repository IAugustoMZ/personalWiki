# Formação Engenheiro de Dados

## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### Quais as Diferenças entre Datalake e Datalakehouse?

| Datalake | Datalakehouse |
| --- | --- |
| <li>armazenar vasta quantidade de dados<li>estruturados, semi-estruturados, ou não estruturados<li>armazenamento de dados no formato bruto<li>grande flexibilidade<li>dados armazenados primeiro e definidos depois, conforme necessário (menor custo por TB)<li>muito escaláveis<li>bom para Big Data / tempo real | <li>características de Data Lake e Data Warehouse<li>flexibilidade, escalabilidade, gerenciamento e análise de desempenho<li>suporta dados transformados, curados e prontos para análise<li>esquema aplicado no momento da leitura (DL) ou na escrita (DW)<li>melhor governança. qualidade de dados e gerenciamento<li>otimizados para consultas de alto desempenho<li>indexado, armazenamento em colunas |

### O que é um Data Stack?

- conjunto de tecnologias, ferramentas e infraestrutura usada para coletar, armazenar, processar, analisar e visualizar dados
  - pilha de soluções tecnológicas para uso dos dados

1. **Fontes de dados:** origem dos dados
2. **Pipelines dos dados e ETL:** extrais das fontes, processar (transformar) e carregar num repositório centralizado
3. **Data Warehouses, Data Lakes, Data Lakehouses:** sistemas de armazenamentos centralizados, manter dados para análise
4. **Plataformas de Análise e Processamento:** processamento e análise em larga escala, *streaming* e Big Data
5. **Ferramentas de Business Intelligence e visualização:** criação de relatórios, dashboards, e visualizações que tornam os insights acessíveis
6. **Plataformas de Machine Learning e Inteligência Artificial:** construção e implementação de modelos
7. **Governança e Segurança dos Dados:** gestão de acesso, qualidade, integridade, conformidade, dados manuseados de forma segura e responsável
