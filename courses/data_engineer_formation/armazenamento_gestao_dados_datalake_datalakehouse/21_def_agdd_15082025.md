# Formação Engenheiro de Dados

## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### Data Lakehouse - Convergência entre Data Lakes e Datalakehouses

#### Plataforma Databricks no Cenário de Dados

##### Clean Rooms

- basicamente são os ambientes de processamento que apontam para os ambientes de armazenamento
    - evita a necessidade de uplodas de dados
- permite a configuração de credenciais e conexões para buscar os dados das fontes externas

- **no catalog**
    - não deletar information.schema e nem o default
        são usados internamente pelo sistema
    - precisa iniciar o sistema de Warehouse
    - podemos acessar remotamente por vários métodos
    - permite busca vetorial
- **workflows**: execução de jobs, monitoramento
- jobs podem ser definidos por várias linguagens e eles também podem ser monitorados
    - jobs = workflows $\to$ sequência de tarefas
        - compostos de tarefas (ex.: notebooks)

##### Criação de Pipelines com Delta Live Tables

- abordagem gerenciada e otimizada para criar e manter pipelines de dados de forma declarativa
    - facilitar o processamento e transformação de grandes volumes de dados
    - contínuos ou lotes
- definir tabelas e transformações em SQL ou Python
    - dependências entre os dados
    - Databricks gerencia automaticamente a execução e otimização dos pipelines

- **SQL Editor** $\to$ interface para execução de consultas SQL
- recurso Genie permite "conversar" com os dados
    - dados precisam estar bem organizados
- bloco de engenharia de dados
    - execuções dos jobs
    - ingestão dos dados
    - Delta Live Tables
- recursos de aprendizado de máquina
    - machine learning
        - experimentos com MLflow
        - montar feature store
    - modelos de IA generativa
    - disponibilização via endpoints
