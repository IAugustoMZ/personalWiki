## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### Data Lake Local $\times$ Data Lake na Nuvem

- usar IaC para automatizar a criação / gerenciamento ou destruição para infraestrutura na nuvem
  - facilitação do processo, definição por meio de arquivos scripts
  - versionamento + code review
  - CI/CD
- precisamos entender como a tarefa funciona antes de automatizarmos
- Amazon S3 $\to$ Data Lake
  - estrutura de pastas (*buckets*) $\to$ nome precisa ser globalmente único
  - qualquer formato de dados
  - permite versionamento dos dados
    - impacto no espaço de armazenamento
  - identificação de recursos AWS por tags
- WORM - *write-once-read-many*
  - ideia do Data Lake $\to$ escrever dados poucas vezes, mas ler com maior frequência
