# Formação Engenheiro de Dados

## Armazenamento e Gestão de Dados com Datalake e Datalakehouse

### Componentes Chave de um Data Lake

- **armazanemento:** às vezes, só faz sentido coletar e armazenar para analizar depois
- **processamento:** usamos ELT ao invés de ETL
- **catalogação e metadados:** evitar virar o pântano de dados
- **governança:** saber quais dados estão, e onde estão
- **segurança:** dados são ativos da organização, controle de acesso
- **integração:** data lake não é backup, precisamos ter condições de usar os dados

### Benefícios dos Data Lakes

- armazenamento de grandes volumes de dados
- repositório central de dados em qualquer formato
- font única dos dados dentro da empresa
- flexibilidade e escalabilidade
- custo benefício, comparado ao data warehouse, ou data lakehouse com as mesmas configurações e parâmetros

### Desafios dos Data Lake

- percepção de valor - o valor não está no armazenamento mas sim na análise
  - isoladamente, o valor é baixo
  - o valor está na integração como um componente da stack de dados
- governança e gestão de metadados $\to$ não é só jogar os dados lá no Lake
  - difícil gerir metadados na escala dos dados do lake
- qualidade dos dados $\to$ armazenamento no formato original pode ser arriscado
- integração $\to$ ferramentas de ingestão e também de consumo
- segurança $\to$ fonte única de dados da empresa, segmentação e controle de acesso

## Casos de Uso e Aplicações de Data Lakehouses

- evolução na gestão e análise de dados
  - processamento de grandes volumes de dados
  - operações analíticas de alto desempenho
- análise avançada de dados
  - modelos de ciência de dados e machine learning
- análise de sentimentos
- dashboards interativos, relatórios detalhados (BI)
  - gerenciamento e curadoria dos dados
  - relatórios detalhados
- análise em tempo real
  - compreender rapidamente mudanças de tendências
- análise de dados históricos
  - consolidação de dados várias fontes
- análise de cliques (atividade do usuário para otimizar a experiência)
- IoT $\to$ coleta e análise de dados dos dispositivos conectados
- soluções robustas $\to$ armazenamento e gerenciamento de dados de acordo com regulamentações específicas
  - auditoria e rastreabilidade
