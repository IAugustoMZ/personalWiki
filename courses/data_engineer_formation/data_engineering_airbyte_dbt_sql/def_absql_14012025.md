# Formação Engenheiro de Dados

## Engenharia de Dados com Airbyte, DBT e SQL

### Definindo Testes de Integridade Referencial

- integridade referencial garante que as relações entre tabelas sejam mantidas corretamente
  - chaves estrangeiras de uma tabela -> chave primária de outra tabela
- assegura que chaves estrangeiras tenham correpondentes válidos

### Testes de Regras de Negócio via Macro

- função reutilizável escrita em Jinja (linguagem de template)
  - automação e simplificação de trechos de códigos SQL
  - padronização de lógica complexa ou repetitiva
    - encapsular lógica comum em funções e chamar em vários pontos do pipeline
    - aceitam argumentos
    - invocados dentro de modelos, snapshots, seeds, ou outras macros
