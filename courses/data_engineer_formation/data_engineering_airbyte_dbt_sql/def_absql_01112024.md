# Formação Engenheiro de Dados

## Engenharia de Dados com Airbyte, DBT e SQL

### Benefícios da Engenharia de Dados nas Organizações

- projetar, construir, e gerenciar a arquitetura de dados
  - habilitar análises avançadas
  - suportar a tomada de decisão
  - otimização de processos
  - integridade, qualidade ou segurança de dados
  - eficiência operacional
- novos modelos de negócios -> produtos baseados em dados
  - vantagem competitiva

#### A importância do ETL na Era dos Dados

- Extração, Transformação e Carregamento
- espinha dorsal na estratégia de gestão e análise de dados
  - ponto entre dados brutos e dados consumíveis
- consolidação de diversas fontes
  - centralização dos dados coletados
- transformação -> qualidade e insights
  - precisão, consistência e usabilidade
- carga -> sistema de destino
  - acesso e análise
