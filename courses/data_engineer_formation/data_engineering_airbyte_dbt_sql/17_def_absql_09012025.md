# Formação Engenheiro de Dados

## Engenharia de Dados com Airbyte, DBT e SQL

### Vantagens do Refatoramento do dbt

- manutenção facilitada
- aumenta a eficiência -> remover redundâncias e otimizar consultas
- reduz erros -> menor duplicação
- melhora a colaboração e o entendimento

### Gestão de Dependências enter Modelos de Dados

- organização modular -> cada modelo descrito e versionado de forma independente
- dependências explicitadas pelo `ref()`
  - relações hierárquicas entre modelos refletindo a ordem necessária de chamada de modelos
- gerenciamento de dependências por meio de DAGs (grafos direcionais acíclicos)
  - rastreio de impactos de mudanças
- documentação e monitoramento de dependências
- bom integrar com versionamento e gestão de dependências

### Uso de Snapshots para Histórico de Dados

- versão histórica dos dados
  - captura e versiona mudanças ao longo do tempo
  - consultas SQL
- acompanhamento de dimensões lentamente mutáveis (SCD)
  - rastreamento
- configuração por meio de regras que definem como mudanças são identificadas
  - timestamps
  - comparações de colunas
- em cada execução, dbt compara dados atuais em comparação com snapshots anteriores
  - histórico atualizado com mudanças detectadas
  - modificações rastreadas sem sobrescrita
- piplein ingestão automatizado e versionado
  - auditories
  - conformidades regulatórias
  - análises temporais

### Estratégias para Lidar com grandes Volumes de Dados

- estratégia = partição de dados
  - critérios de datas ou identificadores específicos
  - cargas e transformações incrementais (performance)
- materialização apropriada
  - incremental / ephemeral models
  - apenas novos dados ou dados alterados sejam processados -> tempo e uso de recursos
- sincronizações incrementais e detecção de mudanças
  - *change data capture*
