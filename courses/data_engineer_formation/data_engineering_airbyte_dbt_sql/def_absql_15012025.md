# Formação Engenheiro de Dados

## Engenharia de Dados com Airbyte, DBT e SQL

### Segurança e Privacidade de Dados no dbt

- forma com que os dados são manipulados e protegidos
- boas práticas
  - autenticação e autorização - controle de acesso
  - gestão de permissões -> permissão granular no banco de dados
  - mascaramento de dados -> anonimização e mascaramento de dados sensíveis
  - segurança dos ambientes -> desenvolvimento, staging, produção
  - monitoramento de los -> auditoria para identifique e reagir a ameaças

### Integração com Ferramentas de Versionamento

- todo o código usando para transformação são arquivos de texto
- controle de versão -> rastreabilidade de mudanças e histórico
- colaboração -> branches
- revisão de código dbt -> pull request, antes de mesclar ao código principal
- automação com CI/CD -> execução automática de testes de modelagem, validação a cada push

### Integração do dbt com Plataformas em Nuvem (BigQuery, Snowflake)

- transformação dos dados diretamente no Data Warehouse usando o poder de processamento dessas plataformas
  - transformações complexas
- evitar movimentações dos dados -> redução de latência e custos
- conexão simplificada -> segura (chaves de API ou OAuth)
- gerenciamento de modelos -> modelos SQL executadas como views e tabelas materializadas
  - reutilização e organização dos dados
- custo otimizado -> consultas otimizadas
  - tabelas materizadadas
  - incremental models
- escabilidade -> nativas de plataforms, sem necessidades de gerenciamento adicional
  - volumes massivos com desempenho consistente

### Monitoramento e Alertas no dbt

- garantir qualidade e confiabilidade das transformações de dados e detectar problemas de maneira proativa
- testes de qualidade -> dados corretos e consistentes
  - geração de alertas
- monitoramento -> histórico de execuções
  - tempo de execução
  - sucesso ou falhas de cada etapa
  - gargalos de desempenho
- integração com ferramentas de monitoramento
  - Slack, PagerDuty, ferramentas de CI/CD
  - notificações automática sobre falhas ou problemas
  - respostas rápidas a incidentes
- scheduling e agendamento de tarefas
  - dbt Cloud, Airflow
  - agendar execuções regulares
  - alertas para execuções anômalas
- logs e auditorias -> logs detalhados, auditoria, e análise de problemas detalhados

### Analytics Engineering com dbt

- transformações de dados brutos em modelos analíticos estruturados e prontos para consumo em análises / relatórios
  - modelagem, transformação, qualidade e documentação
- aspectos
  - **transformações SQL-first** -> SQL é a linguagem central
  - **camadas de modelagem** -> múltiplas, organização dos dados
  - **automação e gerenciamento de pipelines** -> simplicação das camadas que atualizam ou reconstroem tabelas
    - agendamento e orquestração
    - Airflow
  - **testes de qualidade e validação de dados** - definir testes de qualidade de dados diretamente
  - **documentação e controle de versão** - descrição e metadados, facilitar entendimento
    - controle de versão
  - **escalabilidade e modularidade** - blocos reutilizáveis, adaptação
    - adição de novos modelos sem impacar a estrutura existente
  - **orquestração e observabilidade** - visibilidade sobre cada etapa da transformação

### Automação e Orquestração com dbt

- transformação de maneira eficiente, confiável e sincronizada
- execução automatizada em momentos estratégicos
  - integração a ferramentas de agendamento
    - Apache Airflow
    - Prefect
    - dbt Cloud
  - horários específicos ou após a conclusão de etapas anteriores
- dbt Cloud
  - interface web: notificações, e logs
  - acompanhamento de erros e o rastreamento de execuções
- fluxos de trabalhos condicionais
  - evitar execuções desnecessárias
- monitoramento e rastreamento de dependências
  - transformação apenas dados atualizados
- execução incremental -> atualização frequente de grandes volumes de dados
- integração CI/CD -> testes e implantações automáticos após atualizações no código

#### Compreendendo o conceito de linhagem de dados

- rastreamento e visualização de todo o caminho que os dados percorrem desde a origem até o destino final
  - documentação de todos os passos
- prática de governança
  - confiabilidade de informações
- **componentes e benefícios**
  1. transparências e visibilidade
  2. rastreabilidade de informações -> regras de negócio, cálculos ou agregações
  3. impacto das mudanças -> dependências
  4. depuração e resolução de problemas -> dados incorretos ou inconsistentes
     1. identificação da etapa que falhou
  5. conformidade e auditoria -> dados pessoais e sensíveis
  6. documentação e governança
     1. mapa detalhado do pipeline
     2. documentação contínua e automática
  7. ferramentas de linhagem de dados
     1. Airflow
     2. Apache Atlas
     3. dbt
     4. Data catalog
     5. visualização e rastreio automatizados -> produtividade e precisão no gerenciamento.
