# Formação Engenheiro de Dados

## Engenharia de Dados com Airbyte, DBT e SQL

### O que é o dbt (Data Build Tool) ?

- ferramenta de transformação de dados, que facilita a criação, gerenciamento e manutenção de pipelines de dados em SQL
  - transformação de dados de maneira mais eficiente
- workflow de transformação *SQL-first*
  - código analítico de forma rápida
  - práticas recomendadas de engenharia de software, modularidade, portabilidade, CI/CD e documentação
- **principais características**
  - transformações em SQL
  - modularidade: cada transformação é um módulo independente (manutenção e reutilização de código)
  - teste de dados: qualidade, dados corretos e dentro das expectativas
  - documentação automatizada, compreensão e colaboração
  - versionamento e controle de dependências: integra com git, versionamento das transformações
  - execução programada: integração com orquestradores, Airflow ou Dagster, monitorar execução, integra com Airbyte
- **dbd Core vs Cloud**
  - cloud -> nuvem
  - core -> software open source

#### dbt Cloud

- IDE intagrado na web
- integração com diversas ferramentas de dados e pipelines
  - gestão da mudança
  - testes
  - documentação
- solução generalizada que reduz a complexidade operacional
- colaborativo -> controle de versão e rastreamento de mudanças
  - agendamento de tarefas
  - monitoramento
- consistência e qualidade
  - testes automatizados, alertas de falha
  - documentação
  - integridade de dados

#### dbt Core

- versão gratuira e open-source
- instalado e executado por linha de comando
- definir transformações, controle de versão
- solução que pode ser customizada ou estendida
- pipelines escaláveis e reutilizáveis
  - flexibilidade
  - integração com ferramentas de orquestração e infraestrutura
- criação de plugins personalizados, scripts auxiliares ou integrações específicas
- é possível realizar o desenvolvimentolocar com dbt cloud cli
- acesso ao repositório de dados -> adaptadores
  - 1. plataforma de dados
  - 2. transformações de dados com SQL
