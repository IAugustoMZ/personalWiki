# Formação Engenheiro de Dados

## Engenharia de Dados com Airbyte, DBT e SQL

### O que é um Cursor?

- acompanhamento de quais registros já foram adicionados
  - cursor é como se fosse um ponteiro para esse propósito
  - parte da consulta no sistema de origem para garantir que apenas registros mais recentes sejam movimentados
- limita a consulta apenas aos registros mais recentes que o último valor do cursor

#### Por que e Quando é Necessária uma Chave Primária?

- no caso de sincronização com histórico deduplicado
  - dados precisam ser deduplicados (mesmo no caso das tabelas de dados brutos e históricos possuírem várias versões)
- chave-primária usada para selecionar o registro mais recente

#### Quando usar Sincronização Incremental?

- campo do cursor adequado + chave primária
- operações de exclusão não são propagadas corretamente
  - CDC pode ser mais adequado
- registros atualizados ou incluídos devem atualizar o campo de destino
- registros modificados várias vezes terão apenas o seu estado do registro no momento da sincronização
- apenas onde dbt/SQL é suportada
