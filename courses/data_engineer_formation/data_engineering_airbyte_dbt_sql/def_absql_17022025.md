# Formação Engenheiro de Dados

## Engenharia de Dados com Airbyte, DBT e SQL

### Orquestração e Automação

- gerenciamento e execução de tarefas e processos de forma integrada e eficiente
- **orquestração**: coordenação de processos, ETL, para garantir que tarefas sejam executadas na ordem correta e da forma otimizada
  - Airflow, dbt -> gerenciar fluxos de trabalho
- **automação**: configuração de processos recorrentes e monitorar eventos dentro da plataforma
  - tasks (tarefas agendadas que executam consultas SQL ou scripts)
  - streams (rastreio de alterações nos dados)
  - procedures (blocos de código SQL para lógica complexa)
  - pipelines de dados automatizados

### Monitoramento e Alertas

- **query history**: monitorar desempenho e histórico de execução de consultas; identificação de gargalos e otimização
- **resource monitor**: acompanhar e gerenciar o uso de créditos e recursos computacionais
  - configurar limites e alertas para evitar custos excessivos
- **account usage views**: visualizações com dados detalhados sobre atividades no ambiente
  - consultas, armazenamento e alterações na estrutura
- **integration with external tools**: ferramentas de monitoramento externas, para alertas mais avançados e centralizados
  - Datadof / Splunk
- **alerts with Snowflake Tasks and Procedures**

- tarefas agendadas, streams e procedures
  - alertas customizadas baseados em condições específicas
  - falhas de processo ou anomalias dos dados
- operação contínua, eficiente, suportando práticas de governança e controle de custos
