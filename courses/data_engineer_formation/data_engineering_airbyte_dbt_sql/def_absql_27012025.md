# Formação Engenheiro de Dados

## Engenharia de Dados com Airbyte, DBT e SQL

### Conhecendo a plataforma Snowflake

- computação em nuvem voltada para o gerenciamento de dados e análise
  - integrar funcionalidades de data warehouse, data lake, processamento de dados em tempo real
- alta escalabilidade, alta performance, simplicidade operacional
  - sem manutenção complexa
  - sem administração de infraestrutura
- arquitetura separada em camadas
  - armazenamento
  - processamento
- acesso e análise por múltiplas equipes simultâneas, sem impacto no desempenho
  - grandes volumes de dados e cargas de trabalho variadas
- compatível com múltipls provedores de nuvem
- suporta diversos formatos de dados
  - JSON, Parquet, Avro
- precificação por uso dos recursos -> apenas demanda
