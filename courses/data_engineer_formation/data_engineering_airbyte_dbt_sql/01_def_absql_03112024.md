# Formação Engenheiro de Dados

## Engenharia de Dados com Airbyte, DBT e SQL

### Tarefas de Extração, Transformação e Carga em Engenharia de Dados - Parte 1

- ETL/ELT -> integração de dados brutos entre sistemas heterogêneos
- extração de dados
  - complexidades variadas determinadas por
    - bancos de dados
    - sistemas de arquivos
    - APIs
    - planilhas
    - registros de eventos
  - pode ser feito programaticamente ou sob demanda
- transformação
  - limpar, reformatar e reestruturar os dados extraídos
  - remoção de duplicatas
  - conversão de tipos
  - agregação de informações
  - normalização
  - aplicação de regras de negócios
- carga -> repositórios de destino
  - consistência com o esquema de registro
  - integridade ou qualidade de dados
- ETL -> é parte do processo de engenharia de dados
- ETL é mais usado em Data Warehouses
  - ELT para Data Lakes
  - qualquer um dos dois para Data Lakehouse


| Atributos | ETL | ELT |
| --- | --- | --- |
| Local da transformação | Staging Area | Servidor separado ou o servidor de destino |
| Desempenho e escalabilidade | Mais recursos de hardware | pode ser mais rápido para grandes volumes de dados
| Flexibilidade | Menos flexível | Maior flexibilidade |
| Complexidade | Mais Complexo | Menos complexo -> bases não estruturadas |

#### O que é Modern Data Stack?

- conjunto de ferramentas para coletar, processar e analisar dados
  - escalável
  - flexível
  - eficiente
  - adoção de soluções em nuvem
  - preparado para o Big Data
- Airbyte e dbt são normalmente associados

#### Desafios Comuns em Projetos de ETL

- complexidade de integração de dados
  - fontes muito heterogêneas
- qualidade e consistência de dados
  - dados inconsistentes
- performance e escalabilidade
  - otimização de desempenho
- transformação -> pode ser muito complexa
- manutenção e monitoramento -> mudanças nas fontes de dados, atualizações nos requisitos de negócio, ajustes de performance
- governança e conformação -> regulamentação e proteção de dados
- segurança de dados -> privacidade, confidencialidade
- gerenciamento das mudanças -> sistemas de origem, formatos de dados, requisitos de negócio
- documentação e conhecimento -> manter documentação e transferêcnia de conhecimento
- orçamento e recursos -> podem ser custosos em termos de tempo e recursos.
