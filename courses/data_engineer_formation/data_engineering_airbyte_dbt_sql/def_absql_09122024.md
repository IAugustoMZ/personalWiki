### SQL Avançado para Transformações de Dados

#### O que é Analytics Engineering?

- dados brutos em formatos úteis para análises, relatórios, e camadas de decisão
  - engenharia de dados + análise de dados

1. **modelagem de dados** -> dados acessíveis, compreensíveis e adequados para análise
2. **pipeline de dados** -> ETL, para tornar dados prontos em tempo real
3. **manutenção em data warehouses** -> governança, integridade e segurança de dados
4. **suporte a decisões baseadas em dados** -> dashboards, relatórios e ferramentas analíticas
5. **colaboração com stakeholders** -> cientista de dados, analista de negócios, equipes de TI

##### Ferramentas e Tecnologias

- linguagem de programação: SQL, Python e R
- plataformas de big data: Apache Spark, e Hadoop
- sistemas de data warehouse, Snowflake, Redshift, BigQuery
- ferramentas de BI e visualização de dados, Tableau, Looker, Power BI

##### O que são LLMs (Large Language Models)?

- modelos de inteligência artificial treinados em vastos conjuntos de dados textuais para entender a linguagem humana
  - treinar para geração
- *"Attention is all you Need (2017)*
- características
  - **arquiteturas dos transformadores** - processamento em paralelo + compreensão de contexto (mecanismo de atenção)
  - **treinamento de larga escala** - extensos conjuntos de dados, compreensão profunda de padrões linguísticos, gramática e semântica
  - **geração de texto**
  - **capacidades de compreensão** - responder perguntas, resumir textos, tradução
- aplicações
  - assistentes virtuais
  - tradução automática
  - geração de conteúdo
  - suporte ao cliente
- desafios e considerações éticas
  - viés e justiça
  - privacidade
  - impacto do emprego
  - autenticidade e desinformação
