### SQL Avançado para Transformações de Dados

#### Elementos do Plano de Execução

- adicionar índices pode não ser a resposta para melhorar
  - muitos inserts podem causar a fragmentação dos índices
- reescrever a query pode ajudar
- em subqueries correlacionaas, um subplano será criado para cada linha
  - aqui o índice pode ajudar
- *seq scans* são custosos se as tabelas escaneadas forem grandes
  - principalmente se forem muitos acessos redundantes
- **sugestão de otimização**
  - reduzir subplans -> evitar a execução para cada linha
  - índices -> operações de junção e filtragem
  - paralelização -> melhro desempenho em grandes conjuntos de dados
