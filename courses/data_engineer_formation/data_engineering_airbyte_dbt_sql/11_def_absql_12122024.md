#### Engenharia de Prompt para o LLM

- prática de criar, ajustar, e otimizar as instruções (prompts) fornecidas a LLMs para obter respostas precisas, úteis e relevantes
  - guiar o modelo de forma eficaz
- **contextualização:** compreensão melhor da tarefa
- **especifidade:** formular erguntas de maneira clara, para evitar ambiguidades
- **iteração:** refinar e ajustar prompts com base no feedback -> melhoria contínua
- **estruturação:** formatos estruturados, perguntas encadeadas, fornecer exemplos
