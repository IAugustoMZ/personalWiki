# Formação Engenheiro de Dados

## Engenharia de Dados com Airbyte, DBT e SQL

### Modelo com Materialização Incremental

- não pode ser aplicado a views (apenas tables)
- atualizar apenas dados adicionados ou modificados desde a última atualização
  - definir lógica de como detectar novos dados (coluna `updated_at`) ou campo de classe
  - inserções, atualizações ou exclusões
- quando fazemos deploy / re-deploy com `dbt run`, ele recria todos os modelos definidos
- proatividade sempre vai ser necessária para buscar soluções para os erros
- modelo não consegue atualizar modelos com consultas diferentes das que foram criadas para defini-lo
- detecção de todos os modelos e recriação de tudo
```bash
dbt run --full-refresh
```

#### Criando os Testes para os modelos de dados

- garantir dados corretos, complexos e em conformidade
  - qualidade de dados
- testes nativos de qualidade
- testes personalizados para verificação de regras específicas de negócio
- automação e continuidade: CI/CD para validação contínua
- detecção de problemas
- facilidade de implementação
- `dbt test`
  - definição no arquivo de schema yaml
