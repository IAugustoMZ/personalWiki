# Formação Engenheiro de Dados

## Engenharia de Dados com Airbyte, DBT e SQL

### Estratégias de Backup e Recuperação para Data Warehouse na Nuvem

1. **Backup Incremental e Total**
   1. incremental: apenas dados alterados desde o último backup
   2. total: backup completo
2. **Snapshots Automatizados**
   1. cloud providers -> intervalos regulares
   2. restauração fácil
3. **Retenção e Arquivamento**
   1. períodos diferentes: diários, semanais e mensais
   2. arquivamento de dados antigos -> armazenamento de baixo custo
4. **Replicação Geográfica**
   1. Multiregional -> proteção contra falhas localizadas
   2. Alta disponibilidade -> contra falhas de hardware ou interrupções em datacenters
5. **Logs de Transação e Deploys**
   1. Logs de transação ou de alteração (Change Data Structure) -> rastreio
   2. Usar logs para restaurar dados até o ponto da falha
6. **Testes Regulares de Recuperação**
   1. simular falhas -> eficiência dos processos de recuperação
   2. redução dos riscos -> garantir backups completos, utilizáveis e tempos de recuperação que atendem aos requisitos
7. **Estratégias de Versionamento**
   1. versionamento de dados -> proteger contra exclusões ou modificações acidentais
   2. tabelas temporais -> acessar versões anteriores dos dados
8. **Backups Multi-Cloud**
   1. Redundância multi-cloud -> reduzir dependência de um único provedor
   2. proteção adicional -> contra interrupções generalizadas de um único provedor
9. **Automação com Ferramentas de Backup**
   1.  Nativas dos provedores
   2.  Integrações com terceiros
10. **Planos de recuperação de desastres**
    1.  Procedimentos documentados -> para diversos cenários de falha
    2.  RTO (tempo máximo de recuperação) e RPO (perda de dados aceitável) definidos
11. **Proteção contra exclusões e corrupções**
    1.  backups imutáveis: sem modificações ou exclusões por um período definido
    2.  validação automática de backups: processos automatizados para verificar a integridade e consistência dos backups
12. **Monitoramento e Alertas**
    1.  monitoramento contínuo -> alertas para falhas nos processos de backup ou para alterações inesperadas
    2.  respostas proativas -> intervenção rápida para corrigir problemas
