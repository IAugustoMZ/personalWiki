# Formação Engenheiro de Dados

## Engenharia de Dados com Airbyte, DBT e SQL

### Estratégias de Backup e Recuperação para Data Warehouse na Nuvem

- para conectar o Airbyte (docker) a um banco de dados (docker)
  - `host.docker.internal`
- scan changes with user defined cursor
  - uma coluna definida para rastrear modificações
- host do Snowflake -> url acesso sem o `https://`
- no caso de um full overwrite refresh -> sobrescrita total
  - no caso de incrementais -> apenas as modificações (pode ser lento em caso de mudanças grandes e frequentes dos dados)

### Validação e Garantia da Qualidade de Dados

- **validação de dados**: conformidade dos dados com regras, padrões e formatos definidos
  - dados duplicados
  - valores ausentes
  - inconsistências entre fontes
  - erros de tipo ou violações de integridade referencial
  - diferentes estágios
- **garantia da qualidade de dados**: práticas e processos contínuos para manter e monitorar a qualidade dos dados ao longo do ciclo de vida
  - métricas de qualidade
  - automatizar auditorias
  - corrigir problemas identificados
  - rastrear origem (linhagem)
  - governança -> dados sempre úteis e confiáveis
