# Formação Engenheiro de Dados

## Engenharia de Dados com Airbyte, DBT e SQL

### Estratégias de Migrações de Dados da Área de Staging para DW

- etapa crítica na engenharia de dados -> integridade, eficiência e conformidade

1. **modelo incremental**
    - apenas dados novos ou atualizados
    - evita o processamento completo
    - útil para dados atualizados com frequência
2. **modelo de snapshot**
    - captura o estado em intervalos específicos, registrando mudanças ao longo do tempo
      - auditoria
      - acompanhamento de sistemas financeiros
3. **time based ETL**
    - dados migrados em lotes com base em períodos
    - coluna de timestamp para identificar novos ou registros modificados
4. **full-load and replace**
    - carga completa, substituindo a tabela de destino
    - volume gerenciável de dados ou sem lógica fácil de identificar incrementos
    - tabelas de referência ou de dimensão
      - menos eficiente em tabelas de grande volume
5. **data vault para armazenamento flexível**
    - tabelas hub, links e Sites
    - flexibilidade na carga e integração de múltiplas fontes
    - migração mais robusta e detalhada
    - sistemas que requerem rastreabilidade
6. **validação e testes de qualidade**
    - padrões de qualidade
    - testes + automação
    - alertas
7. **tratamento de tabelas de dimensão e fato**
    - tabelas dimensão -> slowly changing dimension
    - tabelas fato -> inserção incremental
8. **orquestraçã e monitoramento de workflow**
    - Airflow, Prefect ou dbt Cloud
    - automação dos fluxos de trabalho
      - consistência
      - horários agendados
      - detecção resolução de falhas
9. **limpeza e deduplicação de dados**
    - dados únicos e relevantes
    - elminação de redundância
10. **controle de versão**
    - rastreabilidade
    - reverter ou ajustar modelos

### Cenários para Integração entre Airbyte, dbt, SQL

- **ELT Moderno**
  - Airbyte -> extração dos dados
  - dbt -> transformações
  - SQL -> dentro do dbt
- **construção de Data Warehouses**
  - Airbyte -> carregar dados
  - dbt -> modelos analíticos
  - SQL -> consultas e análises do warehouses


| Ferramenta | Airbyte | dbt | SQL |
| --- | --- | --- | --- |
| Integração de Dados Multicamada | Unifica os dados num banco central | Padroniza, transforma os dados | Extração e criação de dashboards |
| Automação Pipelines de dados | Movimentação facilitada | Atualização dos módulos com base nos requisitos de negócio | Visualização e relatórios |
| Análise de Dados históricos | Importação dos dados históricos | Criação de modelos temporais | Cálculos de tendências |
| Monitoramento de Indicadores de negócios | Importar dados operacionais | Criar métricas calculadas | Alimentas ferramentas de BI |
| Compliance e auditoria de dados | Extração de sistemas | Pipelines de anonimização | Relatórios de auditoria |
| Prepação de dados para machine learning | Coleta de informações necessárias | Organização e padronização dos dados | Criar conjuntos de treinamento ou validação |
| Migração de dados | Extração do sistema analítico | transformações para atender o novo esquema | Verificação da integridade ou reconciliação dos dados migrados |
