# Formação Engenheiro de Dados

## Modelagem, Implementação e Governança de Data Warehouses

### Monitoramento e Logs com Cloud Watch

- serviço que permite monitorar e gerenciar recursos da AWS
- *monitoramento*: métricas, alarmes, ações automáticas
- *logs*: configurável, pesquisáveis e analisáveis

### Otimização de Queries e Performance no Amazon Redshift

- **distribuição dos dados**: entre os nós do cluster
    - `KEY`, `EVEN` e `ALL`
- **sort key**: organização física dos dados, alinhar com padrões de consultas
- **`VACCUM`e `ANALYSE`**: reordenar os dados e recuperar espaço em disoc, analisar estatísticas sobre os dados
    - planos de execução mais eficientes
- **uso de `MATERIALIZED VIEWS`**: acesso rápido a dados sem a necessidade de recalcular
- **compression**: reduzir espaço de armazenamento, minimizar I/O de disco (`COPY` e `ANALYZE COMPRESSION`)
- **partitioning**: emular com `UNION ALL`, criar chaves de distribuição e ordenação lógica
- **concurrency scaling**: escalonamento automático de consultas
- **workload management (WLM)**: controlar como as consultas são gerenciadas e priorizadas filas para cargas de trabalho, ajuste de parâmetros como tempo limite de consulta e memória alocada
