# Formação Engenheiro de Dados

## Modelagem, Implementação e Governança de Data Warehouses

### Definindo o Processo ETL vs ELT

- não recomendado realizar transformações no banco transacional
- o Airbyte usa SQL integrado para realizar as transformações
- futuro não é ELT ou ETL -> futuro está na integração dos dados
- lá no Airbyte, existem muitos conectores com fontes de dados
    - agendamento de ingestão (manual ou agendada)

#### Qual a importância da Staging Area em um ambiente de DW?

1. isolamento e separação dos dados - minimiza o impacto das operações pesadas no DW
2. limpeza e transformação de dados
3. consistência e conformidade - uniformidade antes do DW
4. performance e eficiência - processamento em lote (escalabilidade e gerenciamento)
5. auditoria e recuperação dos dados - ponto de verificação e auditoria
6. suporte para processamento incremental - adição apenas dos dados processados e modificados
7. flexibilidade e adaptação - adaptação a novas fontes ou modificações nas fontes existentes
    - teste de novas transformações antes da aplicação ao DW

- configuração de como buscar os dados
    - full -> pode ser interessante no caso de baixo volume de dados
    - incremental
