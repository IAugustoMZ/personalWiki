# Formação Engenheiro de Dados

## Modelagem, Implementação e Governança de Data Warehouses

### Particionamento de Dados em Data Warehouses

- otimização de desempenho, facilitar gerenciamento e escalar sistemas
    - dividir os dados em partes menores

- **Horizontal**: cada partição contém um subconjunto das linhas da tabela original, mas todas as colunas
    - distribuições de dados semelhantes

- **Vertical**: cada partição conté um subconunto de colunas da tabela original
    - consulta que acessam apenas um número limitado de colunas

- **Particionamento por Range**: baseado em intervalos de valores

- **Hash**: distribuição uniforme, balanceamento de carga e otimizar desempenho de leitura e escrita

- **Lista**: listas de valores para uma coluna distinta
    - categorizar dados com um número limitado de valores distintos
    - benefícios do particionamento
        - desempenho melhorado
        - gerenciamento simplificado
        - escalabilidade
        - disponibilidade e recuperação

- complexidade adicional na concepção e manutenção do esquema de particionamento
- monitoramento constante

### Gerenciamento da Qualidade dos Dados no DW

- precisão, complitude, confiabilidade, relevância das informações
- estratégias para o gerenciamento de qualidade
    - avaliação e monitoramento -> se possível em tempo real
    - governança de dados
        - políticas
        - padrões
        - responsabilidades
        - processos
        - diferentes stakeholders
    - processo de limpeza e enriquecimento
    - ferramentas e tecnologia
        - especializadas em qualidade (limpeza, validação e monitoramento de dados)
        - técnicas de AI / ML para detectar problemas de qualidade
    - treinamento e conscientização
        - todos os envolvidos (entradas de dados, analistas e gestores)
        - cultura organizacional voltada à qualidade de dados e melhoria contínua

#### Desafios

- volume e variedade de dados
- mudanças nos requisitos de negócio
- integração de dados de fontes diversas

- compromisso contínuo, recursos dedicados, abordagem holística
    - tecnologia, processos e pessoas
