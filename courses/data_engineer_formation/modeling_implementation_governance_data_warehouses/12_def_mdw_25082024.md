# Formação Engenheiro de Dados

## Modelagem, Implementação e Governança de Data Warehouses

### Fluxos de Trabalho e Orquestração

- gerenciar processos complexos de ETL / ELT, automação de tarefas, integridade e disponibilidade de dados

#### Conceitos

1. **fluxos de trabalho**: passos ou tarefas para realizar um processo completo
2. **dependência entre tarefas**: pode ser condicional
3. **agendamento e triggers**: tempo, eventos ou manualmente
4. **monitoramento dos logs**: monitorar o desempenho e registrar eventos
    - auditoria e depuração

#### Ferramentas de Orquestração

1. Apache Airflow
2. Luigi
3. Prefect
4. AWS Step Function
5. Azure Data Factory

#### Melhores Práticas

- modularidade -> reutilização e manutenção
- documentação e versionamento -> colaboração
- tratamento de erros -> resiliência e continuidade dos processos
- segurança -> práticas de segurança, gestão de acessos, criptografia

SGBD -> databases -> schemas -> tabelas
