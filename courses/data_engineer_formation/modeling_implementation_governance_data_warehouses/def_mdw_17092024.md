# Formação Engenheiro de Dados

## Modelagem, Implementação e Governança de Data Warehouses

### O que é Governança de Dados?

- conjunto de políticas, processos, práticas e padrões que garantem a qualidade, segurança, acessibilidade e uso adequado dos dados

- gerenciar dados de maneira consistente e confiável
    - regulamentações e normas

- definições de responsabilidades claras sobre direitos de acesso, modificação ou gerenciamento de dados

- regras de integridaddde e proteção

### O que é Qualidade de Dados?

- estado dos dados, que determina a adequação ao uso
    - **precisão**: descrição correta da realidade
    - **complitude**: todos os valores esperados estão presentes
    - **consistência**: uniformidade em diferentes sistemas
    - **confiabilidade**: dados podem ser usados com confiança
    - **atualidade**: dados estão atualizados?
    - **relevância**: os dados são adequados e relevantes ao objetivo do projeto?

#### O que é e Quando utilizamos a ferramenta Great Expectations?

- ferramenta de código aberto para validar, documentar e monitorar a qualidade dos dados
- "expectativas" ou regras que os dados devem seguir
    - monitoramento contínuo
    - relatórios automáticos

- quando usar
    - **validação dos dados**: garantir critérios de qualidade no pipeline
    - **documentação de dados**: automaticamente
    - **monitoramento contínuo**: tempo real, detecção de anomalias
    - **auditoria e confiabilidade**: demonstrar atendimento às regulamentações
