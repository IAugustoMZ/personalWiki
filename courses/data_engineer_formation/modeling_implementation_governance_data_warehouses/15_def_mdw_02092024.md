# Formação Engenheiro de Dados

## Modelagem, Implementação e Governança de Data Warehouses

### Principais Características, Vantagens e Desvantagens do Amazon Redshift

- data warehouse totalmente gerenciado na nuvem AWS
    - grandes volumes de dados
    - consultas analíticas rápidas

- características
    - armazenamento colunar
    - escalabilidade (horizontal e vertical)
    - processamento massivamente paralelo - divisão automática entre os nós do cluster
    - integração com AWS
    - consultas SQL padrão
    - redshift spectrum: combina dados direto do S3
    - gerenciamento automático

- bom equilíbrio custo / desempenho
- facilidade de uso
- alta disponibilidade e confiabilidade

- desvantagens
    - latência de ingestão (streaming)
    - custos de armazenamento
    - manutenção dos clusters
    - desempenho para workloads não analíticos (transacionais / tempo real)
    - dependência da AWS
