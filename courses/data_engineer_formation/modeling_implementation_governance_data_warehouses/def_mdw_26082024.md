# Formação Engenheiro de Dados

## Modelagem, Implementação e Governança de Data Warehouses

### Melhores Práticas em ETL / ELT

1. **Planejamento e Design Cuidadoso**

- análise de requisitos: definir fontes de dados, formatos, frequência de atualização, objetivos finais
- modelagem de dados: necessidades atuais e futuras, normalização

2. **Extração Eficientes**

- minimizar a carga nas fontes de dados
- incremental vs full load: economia de recursos e tempo

3. **Transformações Confiáveis**

- limpeza de dados: verificações de qualidade
- regras de negócio: dados prontos para análise no destino
- desempenho: otimização de consultas, indexação e particionamento

4. **Carga Eficiente**

- monitoramento
- tolerância de falhas

5. **Automatização e Orquestração**

- agendamento para evitar intervenção manual
- orquestração de fluxos de trabalho: gerenciar dependências, execução ordenada de múltiplos processos de ETL

6. **Segurança de Conformidade**

- medidas de segurança, controle de acesso
- conformidade: GDPR / LGPD

7. **Monitoração e Logging**

- auditoria e logs -> depuração
- monitoramento de desempenho: rápida identificação e resolução dos problemas

8. **Documentação**

- todo o processo: mapeamento dos dados, transformações aplicadas e dependências do sistema
