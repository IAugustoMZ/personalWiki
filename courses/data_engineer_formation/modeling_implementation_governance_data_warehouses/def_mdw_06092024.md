# Formação Engenheiro de Dados

## Modelagem, Implementação e Governança de Data Warehouses

### Manutenção, Backup e Snapshots no Amazon Redshift

- disponibilidade, integridade e segurança dos dados

- **manutenção**
    - `VACCUM` e `ANALYZE`
    - atualizações automáticas -> segurança, estabilidade e desempenho
    - monitoramento de performance (Cloud Watch)
- **backup**
    - snapshots automatizados -> 8h ou 5 GB
        - salvos no Amazon S3
    - snaphsots manuais -> a qualquer momento
- **snapshots**
    - cópias completas do estado de um cluster num determinado momento
        - esquema do banco
        - dados
        - configurações do cluster
    - restauração dos dados
    - clonagem do cluster
    - retenção e exclusão -> gerenciar para controlar armazenamentos e custos

### Opções de Segurança no Acesso aos Dados com Amazon Redshift

- autenticação de usuário
    - senha ou AWS IAM
- controle de acesso granular
    - permissão a nível de tabela, colunas e views (`GRANT` / `REVOKE`)
- criptografia de dados
    - trânsito (SSL / TLS)
    - repouso (AWS KMS ou chaves gerenciadas)
- redshift spectrum -> políticas de acesso
- auditoria e logs -> Amazon Cloud Trail
- VPC (Virtual Private Cloud) -> grupos de segurança, monitoramento do tráfego
- enhanced VPC routing -> direcionamento forçado do tráfego
