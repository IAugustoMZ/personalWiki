# Formação Engenheiro de Dados

## Modelagem, Implementação e Governança de Data Warehouses

### Carga de Dados ETL

- *full* ou incremental
- ambas impactadas pela modelagem do DW
    - casar a modelagem dimensional + processo ETL

- **carga full**
    - extrair todos os dados dos sistemas de origem e carregar nas tabelas do DW e da staging area
        - configuração inicial do DW
        - alteração significativas na estrutura dos dados de origem ou nos requisitos
        - atualizações gerais ou dados corrompidos

- **carga incremental**
    - extrair apenas os dados novos ou alterados dos sistemas de origem desde o último carregamento bem sucedido
    - geralmente mais eficiente e menor volume
    - fontes de dados mudam constantemente, porém com menor volume -> manter DW atualizado

### Otimização do Modelo Dimensional

- somente depois de implementar (experimentos e tempo de execução)

1. **escolha da granularidade adequada**
    - carga de dados trava as tabelas
    - impacta no ETL e na geração de relatórios

2. **indexação adequada**
3. **particionamento de tabelas** -> subconjunto menor com base em critérios (manutenção e consulta)
4. **sumarização de dados** -> pré-calcular e armazenar valores agregados em tabelas de sumário
5. **uso eficiente do índice bitmap** -> colunas de baixa cardinalidade, usadas frequentemente em operações de filtro
6. **compatação de dados** -> reduzir o tamanho do armazenamento
7. **denormalização seletiva** -> consultas que exigem junções de várias tabelas, mas pode criar redundâncias
8. **monitoramento e ajustes contínuos**
