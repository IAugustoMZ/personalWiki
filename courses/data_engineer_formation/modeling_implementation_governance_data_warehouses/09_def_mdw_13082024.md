# Formação Engenheiro de Dados

## Modelagem, Implementação e Governança de Data Warehouses

### Granularidade e Agregações

- nível de detalhe ou sumarização -> volume de dados vs detalhamento de análises
    - alta (muito detalhe x alto volume)
    - baixa (pouco detalhe x baixo volume)

### Agregações

- resumos pré-calculados dos dados para acelerar consultas computacionalmente intensivas
    - úteis em análises de BI
- **propósito**: melhorar o desempenho das consultas com base nos relatórios mais frequentes
- **tipos de agregações**: simples ou complexas
- **desafios**: requerem gerenciamento, atualização
    - balancear espaço de armazenamento x performance

### Designs de Tabelas e Indexação

1. **esquemas de tabelas**
    - modelo dimensional: fatos e dimensões
    - tabela fato -> medidas quantitativas e relacionamentos com tabelas dimensões
2. **normalização vs. desnormalização**
    - normalização -> minimizar a redundância dos dados e dependências funcional
    - desnormalização -> melhora a performance de leitura pois reduz `JOINS`
        - aumenta a redundância e o tamanho do banco (geralmente aceitável)

3. **indexação**
    - **índices B-tree**: padrão, eficien para ampla gama de operações
    - **bitmap**: atributos com número limitado de possibilidades. Eficientes para operações lógicas com múltiplos filtros
    - **clusterizados / não clusterizado**
        - clusterizados -> fisicamente armazenado na ordem do índice -> recuperação sequencial
        - não clusterizados -> apenas referências às linhas de dados -> consultas com poucas linhas

### Estratégias de Indexação

- índice sobre colunas frequentemente consultadas
- índice em tabelas fato podem causar *overhead* na carga
    - tabelas dimensão podem ser mais livremente indexadas

### Volumetria de Data Warehouses

- quantidade de dados armazenados, gerenciados e processados no ambiente 
    - planejamento
        - desempenho
        - escalabilidade
        - custos
        - manutenção
- fatores que influenciam a volumetria
    - crescimento de dados
    - granularidade dos dados
    - históricos de dados
    - frequência de atualização
- desafios
    - performance no ETL
    - custos de armazenamento
        - requisitos de compliance
    - gerenciamento e manutenção
        - backup e recuperação de dados

#### Estratégias para Gerenciar a Volumetria

- arquivamento e purga
- particionamento de dados
- compreensão de dados
- agregações pré-calculados

- eficiência operacional, desempenho nas consultas
