# Formação Engenheiro de Dados

## Modelagem, Implementação e Governança de Data Warehouses

### Qual a importância da Modelagem na Implementação de um Data Warehouse?

- **entendimento dos dados**: significado dos dados para os stakeholders
- **performance**: otimização para consultas
- **estrutura lógica e física**: consulta e recuperação
- **consistência e qualidade**: confiabilidade
- **flexibilidade para mudanças**: evolução natural dos negócios
- **integração de dados**: várias fontes de dados
- **dimensão e fato**: contextos x medidas
- **histórico e auditoria**: versionamento
- **governança de dados**: propriedade, responsabilidade e regras relacionadas aos dados
- **facilita a visualização e reporting**: ferramentas de BI e visualização

### Data Warehouse x Data Marts

| Data Warehouse         | Data Mart              |
|-----------------------|------------------------|
| base de dados centralizada para consolidar, armazenar e permitir análise de dados. Visão abrangente e integrada de dados         | subconjunto do DW, mais focado, projetado para uma área específica do departamento ou função          |
| mais complexo e maior em tamanho | mais simples e menor em tamanho |
| múltiplas fontes de dados | fontes relevantes para um departamento |
| maiores tempos de consultas | consultas mais simples |
| mais caro de implementar | mais barato de implementar |
| menos flexível | mais fácil de alterar ou expandir |
| frequência regular | geralmente mais rápido |

- **ETL reverso** - democratizar acesso aos dados, por meio da disponibilização dos mesmos em aplicações operacionais.
