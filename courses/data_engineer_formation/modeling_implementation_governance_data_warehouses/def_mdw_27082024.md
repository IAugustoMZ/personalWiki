# Formação Engenheiro de Dados

## Modelagem, Implementação e Governança de Data Warehouses

### Assistentes Baseados em IA

- sistemas de software que utilizam técnicas de IA para responder a perguntas, gerenciais informações pessoais
    - praticamente todos os dispositivos

- principais características e funcionalidades
    - processamento de linguagem natural: permite interação humana
    - reconhecimento de voz
    - aprendizado de máquina
    - integração com serviços e dispositivos (experiência mais abrangente)
    - automação de tarefas
    - assistência personalizada
- nem todos os assistentes possuem reconhecimento e resposta por voz
- no uso do ChatGPT -> fornecer contexto na pergunta ajuda bastante
