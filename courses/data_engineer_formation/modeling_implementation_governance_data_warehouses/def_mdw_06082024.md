### A Importância da Arquitetura na Governança de Dados

- gestão de dados -> planejamento, controle e entrega de ativos de dados e de informação
    - governança -> exercício de autoridade e controle sobre gerenciamento de ativos
- assegurar a origem, linhagem de dados, qualidade
    - definir as necessidades da gestão de dados
    - objetivos + escopo
- governança de dados é uma jornada
- arquitetura de dados -> conjunto integrado de artefatos de especificação
    - requisitos de dados
    - orientar integração e controle de ativos
    - alinhar estratégias de negócio
    - diagramas em diferentes tipos de abstração

### Conceitos Fundamentais de Modelagem Dimensional

- abordagem de design de banco de dados
- banco transacional não é adequado para relatórios
    - data warehouse
        - estrutura de dados simples e intuitivas para facilitar análise e geração de relatórios

#### Modelo Estrela (Star Schema)

- mais comum na modelagem dimensional
- tabela de fatos central centrada por tabelas dimensão
    - tabelas dimensão descrevem os atributos na tabela de fatos (chaves primárias)

#### Modelo Floco de Neve (Snowflake)

- extensão do modelo estrela
- tabelas dimensão são normalizadas em várias outras tabelas
    - reduz a redundância dos dados
    - modelo de dados mais complexo

- **tabelas fato**: métricas ou medidas que são quantificáveis ou analisáveis
    - chaves estrangeiras referentes às dimensões que descrevem os dados
    - pode existir mais de uma no modelo
        - múltiplos *Data Marts*
- **tabelas dimensão**: atributos descritivos pelos quais as informações são analisadas

- em algumas dimensões, os atributos podem formar hierarquias naturais

- granularidade refere-se ao nível de detalhe dos dados em uma tabela de fatos
    - nível mais baixos de informações ou a menor unidade de análise na tabela de dados
        - volume de dados x detalhes
- escolha de granularidade
    - capacidade de armazenamento
    - poder de processamento
    - natureza das consultas esperadas
    - tipos de análise necessária
- alta granularidade -> tabelas fatos muito grandes e detalhadas (recursos de armazenamento)

- **atributos descritivos**: que descrevem os dados e que são armazenados na tabelas de dimensão
    - filtrar, classificar, segmentar os dados
