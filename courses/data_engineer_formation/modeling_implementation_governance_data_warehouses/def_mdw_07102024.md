# Formação Engenheiro de Dados

## Modelagem, Implementação e Governança de Data Warehouses

### O que é e como implementar ETL reverso?

- extrair dados de sistemas de armazenamento ou ferramentas de análise, transformar conforme necessário e carregar de volta para sistemas transacionais ou de CRM, marketing, vendas ou outras plataformas

- **benefícios**
    - *ação baseada em insights* -> insights transferidos para ferramentas operacionais
    - *automação* -> personalização operacionável
    - *tomada de decisão acelerada* -> reduz a dependência de relatórios manuais

- popular em arquiteturas de dados modernas, onde as empresas buscam unificar operações e análises em ciclo contínuo
    1. definir os dados a serem sincronizados
    2. escolher a ferramenta de ETL reverso
    3. configuração de ferramentas e das fontes de dados
    4. extração e transformação de dados
    5. carregamento das informações nas ferramentas transacionais
        - mapeamento de dados
        - configuração de sincronização
    6. monitoramento e manutenção
