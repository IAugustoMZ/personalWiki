# Formação Engenheiro de Dados

## Modelagem, Implementação e Governança de Data Warehouses

### Estratégias de Migração

1. *lift-and-shift* (re-host) -> simple dump e restauração do DW
2. refatoração -> pequenos ajustes no DW
3. rearquitetura -> mudar a arquitetura do DW
4. híbrido -> parte do banco local e parte na nuvem
5. migração por etapas
6. migração incremental -> à medida que novos dados chegam
7. transformação e migração (rebuild) -> ajuste do modelo para corrigir e depois migração
8. migração de dados em massa (bulk-load)
9. migração de dados em tempo real
10. migração de fluxos de trabalho e aplicações conectadas

#### Planejamento e Estratégia de Migração

1. avaliação do ambiente atual
    - sistemas do banco de dados
    - sistemas de armazenamento
    - rede local (LAN)
    - ferramentas de ETL
    - ferramentas de backup e recuperação
    - ferramentas de BI e visualização de dados
    - monitoramento e gerenciamento
    - o que vai ser migrado?
        - banco
        - ferramentas ETL
        - aplicações de análises de dados
        - redes virtuais
        - como será o acesso?
        - como será o backup?
2. seleção do provedor de cloud computing
    - Azure
    - AWS
    - Google Cloud
3. ferramentas e serviços de migração
    - *schema migration* -> AWS Schema Migration Tool
    - *data migration* -> AWS Data Migration Tool
    - scripts
4. planejamento de scripts e ferramentas
    - sempre vai ser necessário realizar alguma modificação para realizar a migração
        - scripts customizados SQL
        - ajustar índices
        - corrigir ou ajudar triggers de funções
        - transformações dos dados
        - migrações de partições da tabela
        - limpeza ou verificação de dados pós migração
        - ajuste das permissões e papéis de usuário
        - recriação de views complexas
        - automação de backup e recuperação
    - exemplo: comando S3 + COPY
        - carregar grandes volumes de dados
        - escalabilidade e armazenamento econômico do S3 com a eficiência do comando COPY
5. conversão do esquema
6. transferência / carregamento dos dados
7. testes e validação após migração
    - validação de esquema
    - comparação dos dados
    - integridade referencial
    - performance
    - funções e triggers
    - consultas e relatórios
    - consistência e transações
    - testes de permissões e segurança
    - testes de backup e recuperação
8. consultas e performance -> capacidade da organização de analisar dados
    - latência
    - otimização de consultas
    - diferenças de infraestrutura
    - impacos de índices e partições
    - carga de trabalho e concorrência
    - ferramenta de monitoramento e tuning
    - escalabilidade e autoescalabilidade
    - balanceamento de carga e réplicas de leitura
    - manutenção de estatísticas e planejamento de consultas
    - performance pós-migração
9. revisão dos custos
    - custo de migração (CAPEX)
    - custo operacional (OPEX) -> infraestrutura como código
    - análise de custos dos serviços na nuvem
    - possíveis custos extras
    - otimização de custos -> recomendações
        - hardware superestimado
    - avaliação de instâncias sob demanda e uso de créditos
    - monitoramento e alertas de custos
        - calculadora da AWS
10. encerramento e desativação dos ambientes locais
