## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### IaC com Terraform para Deploy de Aplicação Web em Container Docker no Amazon ECS

- não podemos visualizar os arquivos que fizemos upload no bucket do S3
- precisamos criar usuários e roles para gerenciar grupos de acesso
    - criar um grupo de acesso a serviços AWS
- no momento de baixar os módulos do Terraform pode ser necessário baixar o git, pois muitos móduloes podem demandar o download do GitHub
- colocar o download do git no Dockerfile ou usar o `apt-get install git`
