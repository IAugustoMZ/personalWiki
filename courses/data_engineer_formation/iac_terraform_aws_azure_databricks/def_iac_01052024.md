# Formação Engenheiro de Dados

## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### Creation-Time e Destroy-Time

- usuário precisa consumir o modelo de ML, porém sem precisar interagir com o modelo
    - **conceito de API**
        - diversas formas de API
- provisioners são sempre definidos dentro de um bloco de recursos
- armazenamento de arquivos em S3 é sempre mais barato que armazenar em EC1
    - não conseguimos apagar o bucket se ele não estiver vazio
- `module path` -> busca o caminho atual
- `aws s3 sync` -> sincronizar arquivos do S3 no EC2 (+ barato)
