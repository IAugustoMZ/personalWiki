# Formação Engenheiro de Dados

## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### O que são módulos no Terraform?

- no caso de múltiplos módulos, cada módulo tem, de forma independente
    - `main.tf`
    - `variables.tf`
    - `outputs.tf`
- são referenciados no `main.tf` global
- dica é usar o ID da conta AWS no nome do bucket
    - o ID da conta é único

#### Arquivo `tf.state`

- armazena o gestão atual das recursos gerenciados
- usado quando executamos `apply` ou `destroy` para determinar qual ação deve ser realizada
    - *sensibilidade* -> pode conter informações sensíveis
    - *armazenamento remotor* -> permite que várias pessoas trabalhem no projeto sem conflito
        - proteção contra aplicação simultânea
    - *backup* -> ao escrever. Útil para recuperação de dados corrompidos
- não é recomendado colocar no sistema de controle de versão

### Estados do Terraform

- representação JSON dos recursos gerenciados
    - *mapeamento*: configuração Terraform para recursos reais no provedor
        - evitar duplicatas
    - *metadados*: ex.: dependências
    - *sincronização*: diferentes pessoas ou em diferentes sistemas -> colaboração
    - estados possíveis
        - local -> estado atual no arquivo `terraform.state`
            - experimentação e aprendizado
        - remoto -> produção
            - sistema de armazenamento remoto
            - compartilhado
            - bloqueado

### Terraform Functions

- transformar e combinar valores
- parecidas com outras linguagens de programação
- principais tipos de funções
    - numéricas
    - strings
    - coleção
    - condicionais
    - consulta -> busca de dados
    - encoding
    - timestamp -> datas

### Terraform Resource Graph

- representação visual ou estrutural de todas as dependências entre os recursos
    - entender ordens de criação, atualização e destruição
- utilidade
    - paralelismo
    - gerenciamento de dependências
    - visualização
    - ordem de execução
    - dependências implícitas e explícitas
        - explícitas (*depends on*)
        - implícitas (a entrada de um depende do outro)
- comando: `terraform graph` -> dot format

### Terraform State Remote Storage

- benefícios
    - colaboração
    - durabilidade
    - controle de versão (ou versionamento de estado)
    - bloqueio de estado
- exemplos de armazenamento
    - Amazon S3
    - Azure Blob Storage
    - Google Cloud Storage
    - Terraform Cloud / Enterprise
- definição do backend na configuração
