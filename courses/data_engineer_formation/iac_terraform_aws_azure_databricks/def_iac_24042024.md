# Formação Engenheiro de Dados

## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### Terraform Local Provisioners

- invocar um executável local depois da criação de um recurso
    - executado na máquina executando o Terraform
    - `remote-exec` para executar no recurso
- quando chamamos o provisioner, não temos como garantir que os recursos estão operáveis

#### Terraform File Provisioner

- automatizar a subida de arquivos diretamente para o recurso
- podemos pegar o conteúdo do arquivo de configuração e colocar direto no Terraform

#### Terraform Remote Provisioner

- executar comandos e scripts dentro do recurso criado na nuvem
- demanda a criação de uma *connection SSH*
    - usuário e senha
- `remote-exec` para executar o comando
    - privilégio de execução

### Creation-Time e Destroy-Time

#### Creation-Time

- executados no momento da criação de um recurso
    - inicializar configurações
    - executar scripts
    - configurar dependências
- se o recurso já existe, o provisioner não será executado

#### Destroy Time Provisioners

- executados no momento da destruição do recurso
    - ações de limpeza
    - gerenciar dependênicas externas que precisam ser removidas ou atualizadas
    - executados antes da destruição do recurso
    - se o recurso estiver corrompido, pode ser que o provisioner não consiga destruí-lo.
