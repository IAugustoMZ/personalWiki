# Formação Engenheiro de Dados

## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### Automatizando o Deploy de Infraestrutura com Databricks e Terraform

- para usar o Databricks, precisamos ter uma conta AWS, Azure ou GCP
    - não é gratuito o provedor
- quando iniciamos a conta no Databricks, eles criam uma pilha no Amazon Cloud Formation para, então, iniciar um *cluster* na AWS

#### Exemplos de Casos de Uso da Plataforma Databricks

- **análise de dados de log**: monitoramento de sistemas e detecção de anomalias
- **recomendações personalizadas**: baseado no comportamento
- **análise de dados financeiros**: risco, fraudes, conformidade regulatória
- **pesquisa científica**: dados experimentais e análises complexas

<br>

- *cluster* - conjunto de máquinas trabalham juntas para executar processos de computação distribuída
    - podem ser configuradas para *auto-scaling*
    - *job* - conjunto de tarefas automatizadas que são agendadas para serem executadas num cluster
        - scripts de notebooks
        - tarefas de ETL / ELT
        - pipelines de ML
        - principais passos
            1. definição e configuração
                - parâmetros: cluster, frequência, dependência entre tarefas
            2. agendamento: ativação por tempo, manualmente ou eventos
            3. dependências entre tarefas
                - garantia de orquestração
            4. monitoramento e logs: registrados na plataforma Databricks
            5. alertas e notificações: status, falhas e sucessos
            6. escalabilidade: dimensionamento automático
    - 1 master + n workers
        - master orquestra o job
        - workers executam o job
    - especificação do tamanho das máquinas e do ambiente de computação
    - clusters temporários ou permanentes
        - temporários são usados para jobs pontuais
        - permanentes são mais aplicados em cargas de trabalho contínuas

- *notebook* - ambiente interativo usado para analisar, desenvolver e testar algoritmos de ML ou pipelines de dados
    - execução interativa
    - múltiplas linguagens suportadas (R, Python, Scala, SQL)
    - visualização de dados
    - integração com clusters
    - colaboração em tempo real
    - controle de versão
