# Formação Engenheiro de Dados

## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### Creation-Time e Destroy-Time

- automatizando a criação do grupo de segurança
```
resource security group
```
- ingress -> regras de entrada
- egress -> regras de saída

- precisamos realizar o bind do grupo de segurança durante a configuração do `terraform.file`
    - criando dependências (`depends on`)
    - usando o id criado na criação do security group
    ```
    vpc-security-group-ids = [aws-security-group-sstk-allow-ssh.id]
    ```
    - desvantagem: se o primeiro recurso (security group) falhar, a EC2 falha junto

- podemos juntar todos os comandos a serem executados no terminal da EC2 num arquivo `.sh`

- **sem o uso de provisioners**
    - não precisamos abrir a porta de conexão SSH
    - variável `user-data` recebe os comandos a serem executados na instânica
        - limitação do tamanho dos comandos
    - segmentar a infraestrutura em várias pastas
        - vários arquivos `.tf`
