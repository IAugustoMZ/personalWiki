### O que é e Como Executar Servidor WSGH?

- *Web Server Gateway Interface*
    - especificação entre interface e universal entre servidores web e aplicações web Python
    - objetivo é facilitar a comunicação e portabilidade
        1. escolher framework
        2. desenvolver aplicação web (Flask, Django, ...)
        3. instalação e configuração do WSGI
        4. executar a aplicação
        5. configurações adicionais + otimização (workers, portas, logging, ...)
        6. integração com servidores web front-end
            - balanceamento de carga
            - arquivos estáticos
            - acesso seguro com SSL
- *nokup* -> aplicativo que pega comandos que digitamos e coloca o script rodando em segundo plano
    - arquivo de log para monitoramento da situação
