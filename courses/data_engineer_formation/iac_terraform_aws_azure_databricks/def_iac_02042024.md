# Formação Engenheiro de Dados

## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### Automatizando a Infraestrutura das Instâncias EC2 na nuvem AWS com Terraform

- **EC2** -> Elastic Cloud Computing (máquina virtual)

- alguns serviços podem não estar disponíveis em todos os datacenters
    - preços podem variar em função do datacenter escolhido
- AMI - Amazon Machine Image -> virtualização
- para comunicaçãom precisamos criar rede e par de chaves
- container contendo Terraform vai conectar a AWS por meio das chaves credenciais de segurança
    - acesso por meio de um par de chaves
- necessário utilizar AWS CLI para utilização e interação com AWS
    - `aws configure`
