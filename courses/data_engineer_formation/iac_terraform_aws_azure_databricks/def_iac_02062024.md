## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### Projeto 2. Deploy do Stack de Treinamento Distribuído de Machine Learning com PySpark no Amazon EMR

- cluster EMR não vem com todos os softwares que precisamos
    - instalação via *bootstrap actions* -> *script bash*
    - steps -> passos a serem executados com o cluster
- *hadoop jar step* -> arquivo Java que será executado quando executar um step do cluster
    - execução dos passos não é tarefa do Terraform
    - não é possível jogar diretamente os arquivos para as EC2
        - passos de processamento não podem ser executados durante o provisionamento do Terraform
- arquivo de log -> registro das ações e acontecimentos de um processo
