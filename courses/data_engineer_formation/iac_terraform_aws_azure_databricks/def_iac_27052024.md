# Formação Engenheiro de Dados

## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

#### IAM Instance Profile

- bom usar o `terraform plan` para executar uma varredura em erros de digitação, erros de sintaxe e evitar a criação de recursos antes de ocorrer algum erro
    - se falhar no último recurso, todos os outros recursos deverão ser apagados manualmente
- acessando o cluster via SSH, podemos automatizar o resto dos processos
    - job
- podemos conectar no cluster via navegador (mais lento)
- Flink manda o arquivo para o `yarn`
    - `yarn` é o gerenciador do cluster
- não lemos os arquivos no HDFS
    - puxamos para o sistema do master
- quando executamos etapas, o Hadoop usa um JAR para executar outro JAR
- usando o S3, podemos manter os arquivos de leitura / escrita
    - EMR não é armazenamento
- se salvarmos o plano de destroy num arquivo, basta executar o plano
    - `terraform apply terraform.tfplan`
