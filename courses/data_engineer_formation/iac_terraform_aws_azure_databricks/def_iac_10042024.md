# Formação Engenheiro de Dados

## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### Terraform Registry

- configuração de máquinas em diferentes servidores
    - alta disponibilidade
    - servidor de múltiplos serviços
        - zona demilitarizada
        - não expõe uma das subnets à internet pública
- no AWS -> VPO (virtual private cloud)
    - cada VPC pode ter várias subnets
- ao usar os nomes padrão dos arquivos, não precisamos especificá-los no momento das chamadas
- automação
    - arquivos de definição de variáveis (`variables.tf`)
    - arquivo `main.tf`
    - arquivos de valores de variáveis (`terraform.tfvars`)
- quando criamos uma VPC, automaticamente criam-se subnets
    - cada subnet possui um range de endereços IP que podem ser acessados
- no arquivo dos valores das variáveis, os ids devem ser obtidos na minha conta AWS
- no arquivo `main.tf`
    - especificamos para ele puxar os nomes das variáveis usando o `var.<variable_name>`
- quando criamos uma instância EC2, uma VPC padrão é criada automaticamente
    - se não especifico a VPC, as instâncias são colocadas na VPC padrão
    - especificamos os recursos por id, temos mais controle e gerenciamento
        - diminui a interoperabilidade
