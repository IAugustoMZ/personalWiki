# Formação Engenheiro de Dados

## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### AWS EC2 Profile Role

- função do IAM associada a instâncias EC2 no cluster EC2
    - usado pelas instâncias para interagir com outros serviços AWS
    - definido para cada instância EC2 -> determina as permissões
- *service roles* -> EMR para interagir com outros serviços
- *profile role*: usado pelas instâncias EC2 dentro do cluster EMR para acessar outros recursos da AWS
    - resolve o problema da necessidade de resolver problemas de acesso e privilégio para o nível de instância
    - quando o serviço está sendo criado, ele ainda existe para usar os perfis do nível do serviço

#### IAM Instance Profile

- artribuir uma função do IAM para uma instância EC2
    - passar as permissões da função para a instância EC2, permitindo acesso a outros recursos
    - credenciais da função são disponibilizadas automaticamente à instância e a qualquer aplicativo ou serviço rodando da instância
        - não precisamos armazenar credenciais diretamente na instância (segurança e facilidade de gerenciamento)
    - nos grupos de segurança, apenas nos comunicamos com o master
        - master se comunica com os workers
        - workers se comunicam entre si -> porta "0"
- zonas de disponibilidade -> áreas de rede diferentes dentro de cada datacenter
    - podemos configurar zonas de disponibilidade em regiões diferentes
        - mesmo país
        - mesmo continente
        - países / continentes diferentes
- par de chaves é necessários para conectar nas instâncias
