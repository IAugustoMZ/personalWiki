# Formação Engenheiro de Dados

## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### O que é Infraestrutura como Código?

- metodologia de gerenciamento e provisionamento da infraestrutura de TI através de código e automação
    - sem a necessidade de intervenções manuais
    - consistência, reprodutibilidade, escalabilidade
    - versionamento -> colaboração, CI/CD
    - arquivos de configuração descritiva
        - YAML ou JSON -> descrevem o estado desejado da infraestrutura
    - rapidez na entrega, eficiência operacional, redução de erros
        - desafios na gestão de configurações complexas

### O que é o Terraform?

- plataforma de gerenciamento de infraestrutura como código (IaC)
- código para descrever recursos -> provedores de nuvem
    - gerenciamento de forma abstrata, agnóstica ao provedor da nuvem
    - versionamento, controle de mudanças e rollback
- `https://terraform.io`

### Plataforma Databricks

- plataforma de engenharia de dados, aprendizado de máquina e análise
    - construída sobre o Apache Spark
    - computação distribuída e processamento de larga escala
- ingestão, limpeza, transformação e visualização de dados
- recursos colaborativos
    - controle de versão
    - espaço de trabalho
    - controle de acesso baseado na função
- integração com outras ferramentas de dados e análises
- gerenciamento de data lake, streaming em tempo real, ML
    - projetos de Big Data / IA
    - cargas de trabalho de BI
- `https://www.databricks.com`

### Amazon Web Services (AWS)

- plataforma de serviço e computação oferecida pela Amazon
    - armazenamento
    - rede
    - banco de dados
    - serviços de aplicativos
    - ferramentas de desenvolvedor
    - internet das coisas
    - dispositivos móveis
- acesso pelo console web, linhas de comando ou APIs
- serviços famosos
    - *Amazon Elastic Compute Cloud (EC2)*: máquinas virtuais
    - *Amazon Single Storage Service (S3)*: armazenamento de objetos
    - *Amazon Relational Database Service (RDS)*: banco de dados relacional
    - *Amazon Elastic Block Storage (EBS)*: armazenamento em nível de bloco para as EC2
    - *Amazon Cloud Front*: distribuição de conteúdo por pontos de presença
    - *AWS Lambda*: serverless computing

- pode ser a infraestrutura principal ou pode ser um complemento de infraestrutura
- `https://aws.amazon.com`
