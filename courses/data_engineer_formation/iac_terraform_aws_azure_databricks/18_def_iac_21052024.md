# Formação Engenheiro de Dados

## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### Amazon Elastic Map Reduce

- uso para processamento de grandes quantidades de dados
    - Apache Spark
    - Apache Hive
    - Apache Hadoop -> usa o HDFS para armazenamento dos arquivos
    - Apache Flink
        - processamento de dados -> batch / streaming
        - escrever fluxo em Java / Scala
        - processamento distribuído
        - trabalha em eventos em ambientes distrbuídos

#### Configuração do EMR

- configuração do primário -> master
- configuração dos núcleos -> workers
- configurações dos hardwares
- configurações de elasticidade
- configuração da rede
- etapas do processamento
    - JAR
    - Hive
    - Script Shell
- depois da criação do cluster
    - acessar via painel AWS
    - acessar via linha de comando usando o endereço DNS
        - sempre usar o DNS do master
- camadas de segurança
    - IAM -> segurança interna
        - comunicação entre diferentes serviços AWS
    - grupo de segurança (firewall) -> segurança externa, o cluster vai estar exposto à internet

#### AWS EMR Service Role

- função do serviço do IAM para realizar ações
- interação com outros serviços AWS
    - define permissões
        - Amazon S3
        - Cloud Watch
        - EC2
