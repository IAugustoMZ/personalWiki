# Formação Engenheiro de Dados

## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### O que são módulos no Terraform?

- estrutura da organização de múlti´plos recursos utilizados em conjunto
    - infraestrutura reutilizável, de fácil manutenção e escalável
- pasta `modules` no caminho raiz
- provider não é necessariamente obrigatório
    - Terraform já busca qual é o provide com base no recurso especificado
- no `main.tf` da root -> especificar a fonte dos módulos dentro da tag "module"
- caso não haja dependência entre os recursos na infra, a criação deles pode ser paralelizada
- usando `output` podemos concatenar a criação de recursos usando outputs sequenciais e capturados
    - o mesmo vale para a destruição dos módulos e infras
- S3 -> storage account
    - cada bucket representa uma organização lógica de arquivos
    - nome do bucket deve ser único na AWS global
