#### Por que usar Arquivos no Formato Parquet?

- **eficiência de armazenamento** -> formato colunar
    - compressão e codificação mais eficientes
- **desempenho de leitura otimizado** ->
    - leitura seletiva para consultas específicas
- **compatibilidade de Big Data**
    - amplametnte suportado Hadoop, Spark, Amazon Redshift
- **suporte para esquemas complexos**
    - aninhamento
    - tipos de dados primitidos / modernos
- **velocidade na execução de consultas**
    - ferramentas de Big Data usam nativamente 
    - útil para análise e Machine Learning
- `tail -f <filename>` -> ler o final do arquivo
