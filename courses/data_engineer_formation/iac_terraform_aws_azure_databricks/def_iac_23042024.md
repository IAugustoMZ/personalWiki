## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### Lab 3 - Terraform Fundamentos 3

- nem toda infraestrutura pode ser representada com IaC
    - provisioners

#### Terraform Provisioners

- último recurso para coisas que não podem ser representadas pelo modelo declarativo do Terraform
    - permite uma chamada a um módulo externo
    - adicionam complexidade e incerteza à execução
        - Terraform não consegue controlar as ações dos provisioners
- provisioner = poder sobre o SO
    - IaC + sistema operacional
