# Formação Engenheiro de Dados

## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### Automatizando a Infraestrutura das Instâncias EC2 na nuvem AWS com Terraform

- inicialização do Terraform
    - `terraform init`
    - apenas uma vez no diretório
    - precisa ter o arquivo `.tf`
- inicializar a automação
    - `terraform apply`
- para "derrubar" a infra
    - `terraform destroy`
- no arquivo `tf` -> HCL

#### Testes Unitários e Integrados

- qualidade, confiabilidade, desempenho
    - identificar e corrigir problemas
- **testes unitários**
    - partes isoladas do código (funções, métodos)
    - rápidos e leves -> execução frequente
    - simulação dos componentes externos
    - problemas em estágios iniciais
- **testes integrados**
    - integração entre várias partes do código
    - mais lentos e complexos -> configurar e gerenciar dependências
    - podem envolver equipes de QA
    - garantia de interface e comunicação

#### Como empregar mudanças em produção?
1. desenvolvimento e revisão do código
2. controle de versão -> rastreabilidade + colaboração
3. testes automatizados
4. integração contínua -> compilar, validar, testar
5. entrega contínua -> implantação automática
6. testes adicionais -> carga, desempenho, segurança, aceitação
7. implantação em produção
8. monitoramento e registro -> conformidade e auditoria
9. feedback e ajustes -> coletar e analisar dados de uso

### HashiCorp Configuration Language (HCL)

- linguagem de configuração
- **estrutura clara e legível**: expressiva e clara, suportando estruturas comuns como blocos e atributos
- **suporte a JSON**: facilita a integração
- **tipos primitivos**: strings, números e booleanos, além de compostos como listas e mapas
- **interpolação**: referências de valores em outras partes da configuração ou operações simples
- **reutilização e modularidade**: reutilização de configurações, IaC modular.
