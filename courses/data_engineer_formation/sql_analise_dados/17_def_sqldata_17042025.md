### O que são Valores Ausentes?

- situações onde dados esperados não estão presentes no conjunto de dados $\to$ afetam qualidade de análises e modelos
- principais causas de valores ausentes
  - dados não coletados
  - erros na coleta
  - dados removidos (intencionalmente ou não)
  - inaplicabilidade

### Tipos de Dados Ausentes

1. **completamente aleatórios** $\to$ MCAR (missing completely at random)
   1. probabilidade de estar ausente é a mesma para todas as observações, sem relação a outros dados
   2. **exemplo:** questionários perdidos por falha técnica do sistema em uma pesquisa de saúde — qualquer observação tinha a mesma chance de sumir, sem relação com o perfil ou respostas dos pacientes
2. **aleatórios** $\to$ MAR (missing at random)
   1. a probabilidade de dado ausente está relacionada a outras variáveis, mas não à variável ausente em si
   2. **exemplo:** em uma pesquisa de renda, pessoas mais jovens tendem a não informar o salário — a ausência está relacionada à variável *idade* (presente no dataset), mas não ao valor do salário em si
3. **não aleatórios** $\to$ MNAR (missing not at random)
   1. a probabilidade de um dado estar ausente está diretamente relacionada à variável que está ausente
   2. **exemplo:** pessoas que ganham muito (ou muito pouco) se recusam a informar o salário *por causa do valor do salário* — o mais problemático, pois pode introduzir viés nos modelos

#### Tratamento de Dados Ausentes

- **exclusão:** simples, mas pode levar à perda de dados.
  ```python
  df.dropna()                        # remove linhas com qualquer valor ausente
  df.dropna(subset=['salario'])      # remove apenas onde 'salario' é nulo
  ```
- **imputação simples**: usa uma estimativa, alguma estatística descritiva $\to$ pode causar um viés
  ```python
  df['salario'].fillna(df['salario'].mean())    # média
  df['salario'].fillna(df['salario'].median())  # mediana
  df['cargo'].fillna(df['cargo'].mode()[0])     # moda (categórico)
  ```
- **imputação baseada em modelo**: usar modelos estimar valores ausentes com base em outras variáveis $\to$ complexo, dependente do modelo
  ```python
  from sklearn.impute import KNNImputer

  imputer = KNNImputer(n_neighbors=5)
  df_imputed = imputer.fit_transform(df[['idade', 'salario']])
  ```

- importante avaliar como resultados analíticos variam com diferentes técnicas (sempre afeta o modelo)
- valores ausentes distorcem resultados

#### O que são Complete Cases?

- registros ou linhas onde todas as variáveis têm valores não ausentes
- análise em complete cases é livre de bias introduzido por dados ausentes
  - mais simples

#### Técnicas de Tratamento de Dados Ausentes

|| Descrição | Quando Usar | Limitações |
| --- | --- | --- | --- |
| **Exclusão ou Listwise Deletion** | - descartar qualquer observação com dados faltantes | - quando a perda de dados é pequena e aleatória MCAR | - perda significativa e viés caso não MCAR |
| **Imputação com Estatísticas Descritivas** | - usa estatísticas descritivas para estimar dados faltantes | - simples e útil para poucos dados faltantes | - modifica a variação e a distribuição dos dados |
| **Imputação HotDeck ou ColdDeck** | - usa casos semelhantes (hot deck) ou fontes externas (cold deck) | - útil no caso de padrões claros ou agrupamentos nos dados | - pode ser arbitrário e introduzir viés |
| **k-nearest neighbors** | - k registros mais semelhantes (baseado em outras variáveis) | - padrões completos e interdependências | - requer uma definição cuidadosa de semelhança; <br>- computacionalmente intensivo |
| **Regressão** | - modelos de previsão dos valores ausentes com base em outras variáveis | - bom para dados com relações lineares fortes | - pode ser enviesado caso as relações lineares não prevaleçam |
| **Métodos baseados em verossimilhança** | - útil para análises estatísticas complexas e conjuntos de dados grandes | - métodos baseados em probabilidade | - conhecimento profundo em estatística<br>- computacionalmente exigente |
| **Imputação Múltipla** | - várias versões completas do conjunto de dados, usando múltiplas técnicas, e depois combinando os resultados | - mais robusto, especialmente quando os dados não são MCAR | - complexo em termos de entendimento e implementação, e interpretação |
| **Baseadas em modelos de Machine Learning** | - usar modelos de machine learning para estimar os dados faltantes | - para padrões complexos e não lineares | - compreensão avançada de ML<br>- pode dar overfitting |

- essencial entender os dados e avalair os impactos
  - análise de sensibilidade
