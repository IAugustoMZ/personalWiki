# Formação Engenheiro de Dados

## SQL para Análise de Dados e Data Science

### O que são Enriquecimento e Inputação de dados?

- consulta para substituir valores ausentes pela moda

```sql
SELECT col1
FROM table_name
WHERE col1 NOT NULLL
GROUP BY col1
ORDER BY COUNT(*) DESC
LIMIT 1
```

- vai criar um viés na distribuição dos dados (toda decisão de imputação traz impactos)
- realiza substituições com `UPDATE`
- o mais seguro realmente é deletar os dados ausentes, mas perdemos dados
  - impactos de cada decisão
- consulta para preencher valores nulor com a média de uma coluna, segmentado por outra coluna

```sql
UPDATE table1 AS c
SET col1 = d.media
FROM (
    SELECT
        col2,
        AVG(col1) AS media
    FROM table1
    WHERE col1 IS NOT NULL
    GROUP BY col2
) AS d
WHERE c.col2 = d.col2
    AND c.col1 IS NULL
```
