# Formação Engenheiro de Dados

## SQL para Análise de Dados e Data Science

### O que são Enriquecimento e Inputação de dados?

- criar nova coluna

```sql
ALTER TABLE <table_name>
ADD COLUMN <col_name>
```

- label encoding

```sql
UPDATE <table_name>
SET col2 = (
    CASE col1
        WHEN .... THEN ...;
        ...
        ELSE NULL
    END
)
```

- às vezes, os próprios tratamentos realizados produzem valores nulos
- extrair ano de uma data
```sql
TO_CHAR(data_inicio, 'YYYY')
```
  - no ``WHERE``
    ```sql
    EXTRACT(YEAR FROM data)
    ```

- normalização MinMax
```sql
WITH stat AS (
    SELECT
        MIN(col1) AS min,
        MAX(col1) AS max
    FROM table1
)
SELECT
    ROUND(
        (col1 - min) / (max - min)
    )
FROM table1, stat
```
