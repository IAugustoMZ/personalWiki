# Formação Engenheiro de Dados

## SQL para Análise de Dados e Data Science

### O que são Enriquecimento e Inputação de dados?

1. qual o número total de vendas e média de quantidade vendida?

```sql
SELECT COUNT(*) FROM vendas;
SELECT ROUND(AVG(quantidade), 2) FROM vendas
```

2. qual o número total de vendas únicas?

```sql
SELECT COUNT(DISTINCT id) FROM vendas;
```

3. quantas vendas ocorreram por produto? Mostre o resultado em ordem decrescente

```sql
SELECT
    p.nome, 
    COUNT(id) AS total_num_vendas
FROM vendas v
    JOIN produtos p
        ON v.id = p.id
GROUP BY p.nome
ORDER BY total_num_vendas DESC
```

4. quais os 5 produtos com maior número de vendas?

```sql
SELECT
    p.nome,
    COUNT(*) AS total_vendas
FROM vendas v
    JOIN produtos p
        ON v.id = p.id
GROUP BY p.nome
ORDER BY total_vendas DESC
LIMIT 5
```

5. quais clientes fizeram 6 ou mais transações de compra?

```sql
SELECT
    c.nome,
    COUNT(v.id) AS total_compras
FROM vendas v
    JOIN clients c
        ON v.id = c.id
GROUP BY c.nome
HAVING COUNT(v.id) >= 6
ORDER BY total_compras DESC;
```
