## SQL para Análise de Dados e Data Science

### O que são outliers?

- observações num conjunto de dados que se desviam significativamente do restante das observações
  - maiores, menores, distintos de alguma forma

#### Técnicas de Detecção e Tratamento de Outliers

1. análise gráfica
   1. boxplot
   2. scatterplot
   3. histograma
2. estatísticas descritivas
   1. desvio padrão
   2. intervalos interquartis
3. métodos de distância
   1. Mahalanobis
   2. Euclidiana
4. métodos baseados em densidade
   1. DBSCAN $\to$ clustering (outliers = pontos que não pertencem a nenhum cluster)
5. Análise de influência
   1. alavancagem e resíduos nos modelos de regressão
      1. impacto no modelo estatístico

#### Técnicas de Tratamento de Outliers

- **exclusão** $\to$ apenas para medidas erradas ou irrelevantes
- **transformação** $\to$ matemáticas
- **imputação** $\to$ estatísticas ou baseadas em modelos
- **capping** $\to$ limitação de valores
- **modelos robustos** $\to$ modelos menos sensíveis a valores extremos
- **análise separada** $\to$ caracterização e impacto

- Considerações
  - **contexto dos dados** $\to$ outliers podem ser justamente o objeto de interesse
  - **natureza** $\to$ diferenciar de variações normais ou importantes
  - **impacto na análise** $\to$ entender impacto e influência

### O que são Normalização e Escala de Dados ?

- padronização da escala dos diferentes atributos a alguns algoritmos são sensíveis às escalas dos dados
- **normalização** $\to$ ajustar diferentes escalas para uma escala comum, entre 0 e 1 comumente.
  - sem distorcer as diferenças nos intervalos de valores ou perder informações
  - `min-max`:
    $$x_{norm}=\frac{x-x_{min}}{x_{max}-x_{min}}$$
  - útil quando parâmetros precisam estar na mesma escala positiva
    - algoritmo baseados em distâncias como KMeans, KNN
- **escalonamento** $\to$ transformação de dados para média zero e desvio padrão 1. Não vincula valores a um intervalo
    $$x{std}=\frac{x-\bar{x}}{s}$$
  - útil em algoritmos que assumem centralidade em 0 e mesma magnitude de variação
    - regressão linear / logística
    - algoritmos baseados em gradiente
- normalização preserva os outliers
- aplicação em todos os conjuntos (treino / teste / validação) para consistência
