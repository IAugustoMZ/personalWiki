13. qual a média móvel de quantidades de unidades vendidas ao longo do tempo? Considere uma janela de 7 dias.

```sql
SELECT
    data_venda,
    quantidade,
    ROUND(
        AVG(quantidade) OVER (
            ORDER BY data_venda
            ROWS BETWEEN 3 PRECEDING AND 3 FOLLOWING
        ), 2
    ) AS media_movel_7_dias
FROM vendas
ORDER BY data_venda
```

14. qual a média móvel e desvio padrão móvel de quantidade de unidades vendidas ao longo do tempo? COnsidere uma janela de 7 dias

```sql
SELECT
    data_venda,
    quantidade,
    ROUND(
        AVG(quantidade) OVER (
            ORDER BY data_venda
            ROWS BETWEEN 3 PRECEDING AND 3 FOLLOWING
        ), 2
    ) AS media_movel_7_dias,
    ROUND(
        STDDEV(quantidade) OVER (
            ORDER BY data_venda
            ROWS BETWEEN 3 PRECEDING AND 3 FOLLOWING
        ), 2
    ) AS desvio_padrao_7_dias
FROM vendas
ORDER BY data_venda
```

15. quais clientes estão cadastrados mas ainda não fizeram transações?

```sql
SELECT
    c.id_cliente,
    c.nome
FROM clientes c
    LEFT JOIN vendas v
        ON c.id_cliente = v.id_cliente
WHERE v.id_cliente IS NULL
```

### Como entregar o resultado do seu projeto de análise de dados?

- comunicação de forma eficaz e compreensível
  
1. entenda seu público
   1. ajustar linguagem
   2. nível de detalhe e forma de apresentação
2. resuma as principais descobertas
   1. resumo executivo ou introdução dos destaques
   2. visão clara e imediata
3. utilize visualização de dados
   1. gráficos, tabelas, infográficos para comunicações complexas
   2. visualizações claras e precisas
4. explique a metodologia
   1. explicar ferramentas e técnicas que foram utilizadas
5. apresente *insights* e recomendações
   1. além de mostrar, interpretar
   2. *insights* e recomendações
6. seja claro e conciso
   1. evitar jargões técnicos desnecessários
   2. focar nos pontos mais importantes
7. prepare-se para perguntas e *feedbacks*
   1. discutir implicações
   2. novas perspectivas de ideias
8. escolha o formato de entrega adequado
9. forneça documentação de suporte
   1.  relatórios técnicos detalhados
   2.  anexos de dados
10. faça um acompanhamento
    1.  perguntas adicionais e discutir próximos passos

- entrega = entendimento + geração de valor para tomada de decisão e ações futuras
