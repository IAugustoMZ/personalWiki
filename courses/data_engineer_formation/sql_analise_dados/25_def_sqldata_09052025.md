6. qual total de transações comerciais por mês do ano de 2024?

```sql
SELECT
    CASE
        WHEN EXTRACT(MONTH FROM data_venda) = 1 THEN 'Janeiro'
        ...
    END,
    COUNT(*) AS total_vendas
FROM vendas
WHERE EXTRACT(YEAR FROM data_venda) = 2024
GROUP BY EXTRACT(MONTH FROM data_venda)
ORDER BY EXTRACT(MONTH FROM data_venda)
```

7. quantas vendas de notebook ocorreram entre junho e julho de 2023?

```sql
SELECT
    COUNT(*) AS total_vendas_notebook
FROM vendas v
    JOIN produtos p
        ON v.id = p.id
WHERE p.nome = 'notebook'
    AND EXTRACT(YEAR FROM v.data_venda) = 2023
    AND EXTRACT(MONTH FROM v.data_venda) IN (6, 7)
```

8. qual o total de vendas por mês e por ano ao longo do tempo?

```sql
SELECT
    DATE_TRUNC('month', data_vendas) AS mes,
    COUNT(*) AS total_vendas
FROM vendas
GROUP BY mes
ORDER BY mes
```

9.  quais produtos tiveram menos de 100 transações de venda?

```sql
SELECT
    p.nome,
    COUNT(v.id) AS total_vendas
FROM vendas v
    JOIN produtos p
        ON v.id = p.id
GROUP BY p.nome
HAVING COUNT(v.id) < 100
ORDER BY total_vendas
```

10. quais clientes compraram smartphone e também compraram smartwatch ?

```sql
WITH compraram_smartphones AS (
    SELECT v.id_cliente
    FROM vendas v
        JOIN produtos p ON v.id = p.id
    WHERE p.nome = 'Smartphone'
    GROUP BY v.id_cliente
), 
compradores_smartwatch AS (
    SELECT v.id_cliente
    FROM vendas v
        JOIN produtos p ON v.id = p.id
    WHERE p.nome = 'Smartwatch'
    GROUP BY v.id_cliente
)
SELECT c.nome
FROM clientes c
WHERE c.id IN (
    SELECT id_cliente
    FROM compradores_smartphone

    INTERSECT

    SELECT id_cliente
    FROM compradores_smartwatch
)
ORDER BY c.nome;
```
