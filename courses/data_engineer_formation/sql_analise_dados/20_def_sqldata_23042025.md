# Formação Engenheiro de Dados

## SQL para Análise de Dados e Data Science

### O que é Mapeamento de Dados?

- correspondência entre campos de dados de uma fonte para campos de dados de um destino
  - garantir que os dados sejam transportados corretamente de um sistema para outro $\to$ integridade e significado
- **componentes-chave**
  - fontes de dados
  - destino de dados
  - campos de dados (unidades individuais)
  - regras de mapeamento $\to$ guias de transformações

identificação de campos relevantes $\to$ definição de correspondências - fontes $\times$ destinos $\to$ transformação (concatenação, divisão, fórmulas) $\to$ validação

- **usos comuns**
  - integração de sistemas
  - migração de dados
  - ETL
  - relatórios e análises de dados
- **desafios**
  - complexidade e erros
  - manutenção
  - qualidade de dados

### O que é Pivot Table?

- tabela dinâmica $\to$ resumir, analisar, explorar e apresentar grandes conjuntos de dados
- permitem ao usuário rearranjar ou "pivotar" os dados
- **características**
  - agrupamento de dados por diferentes dimensões
  - sumarização
    - médias, somas, contagens, mínimos e máximos
  - rearranjos e filtros
  - cálculos e fórmulas
  - visualização de dados $\to$ gráficos e dashboards interativos
- **uso de pivot tables**
  - análises de negócios
  - ciência de dados $\to$ exploração rápida, identificação de anomalias
  - relatórios e apresentações $\to$ concisos / informativos

### O que são Enriquecimento e Inputação de dados?

- melhorar a qualidade e utilidade dos conjuntos de dados

#### Enriquecimento de Dados

- aprimorar, refinar ou melhorar os dados brutos com informações adicionais
  - dados externos
  - combinação de diferentes conjuntos
- **usos e benefícios**
  - melhoria da anális $\to$ melhor contexto, mais profundidade
  - segmentação e personalização
  - aprimoramento de modelos de machine learning

#### Imputação de Dados

- substituir dados faltantes ou nulos em um conjunto de dados por valores substitutos
- **usos e benefícios**
  - redução de viés introduzidos por dados ausentes não elatórios
  - melhoria na qualidade de dados
