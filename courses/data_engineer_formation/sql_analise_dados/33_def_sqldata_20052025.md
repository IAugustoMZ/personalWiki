# Formação Engenheiro de Dados

## SQL para Análise de Dados e Data Science

### Consultoria na área de dados com Agentes de IA

#### Especificação Técnica e Funcional

- especificação técnica $\to$ detalha os componentes, tecnologias, infraestrutura necessária, arquitetura
  - ferramentas
  - linguagens de programação, bibliotecas, *frameworks*
  - infraestrutura
    - servidores
    - serviços de nuvem
    - integrações com APIs externas
    - tecnologias de inteligência artificial
- especificação funcional $\to$ define o comportamento esperado da perspectiva dos usuários e stakeholders
  - funcionalidades entregues
  - como cada recurso opera
  - fluxos de integração
  - requisitos operacionais
  - processos automatizados
  - critérios de desempenho / qualidade
  - regras de negócio
- técnica $\times$ complementares e fundamentais
  - compreensão técnica e dos usuários

#### Construção do Módulo de Analytics

- **analytics**: coletar, analisar e interpretar dados para extrair informações úteis
  - técnicas estatísticas
  - ferramentas computacionais
  - inteligência artificial
- **métricas**: engenharia de atributos
  - média móvel simples (SMA) $\to$ suavização e tendências
  - média móvel exponencial (EMA) $\to$ peso maior a dados mais recentes $\to$ útil para identificar alterações rápidas em tendências

#### Construção do Módulo de Agentes de IA

- agentes que percebem seu ambiente, tomam decisões e executam ações
  - pouca ou nenhuma intervenção humana
  - podem aprender e se adaptar
  - interação com outros sistemas
  - interação com modelos de LLM (processamento e execução em linguagem natural)
    - insights em volumes de dados textuais

#### Construção do Módulo de App Web

- aplicação web $\to$ software executado diretamente em navegadores, acessível por meio da internet
  - sem necessidade de instalação
- sempre importante gerar testes unitários para garantir a qualidade dos softwares
- documentação
- modularização da aplicação
- automação dos testes no pipeline CI/CD

#### Deploy do Projeto na AWS

- região da AWS também influencia no custo da aplicação
- criação da máquina EC2 $\to$ para servir a aplicação

#### Monetização do App - Venda, Implementação, Automação e Monetização

- **monetização**
  - assinatura, licenciamento ou venda direta
    - o cliente paga para utilizar funcionalidades específicas
  - marketplace especializado $\to$ exposição e alcance
- **implementação**: disponilização da aplicação no ambiente do cliente
  - cenários B2B $\to$ app adaptado e integrado ao contexto técnico e de negócios
- **automação**: infraestrutura como código $\to$ provisionamento automático de recursos e infraestrutura
  - Terraform
  - AWS Cloud Formation
  - Ansible
  - implantação, configuração e manutenção do app são padronizada e agilizados
    - reduz custos operacionais
    - acelera o processo de entrega
    - mais confiabilidade
