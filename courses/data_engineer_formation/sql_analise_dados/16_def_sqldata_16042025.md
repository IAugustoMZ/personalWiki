# Formação Engenheiro de Dados

## SQL para Análise de Dados e Data Science

### O que é exatamente Limpeza de Dados?

- preparação de conjuntos de dados para análise e modelagem
  - precisão, consistência, utilizabilidade

1. **identificação e remoção de erros e inconsistências**: valores fora do padrão
2. **tratamento de valores ausentes:** imputação ou exclusão
3. **normalização ou padronização:** correção em formatos comuns
4. **detecção e tratamento de outliers:** valores atípicos
5. **verificação de duplicatas**: distorções em análises
6. **transformações de dados:** funções matemáticas
7. **validações de dados**: dados corretos e válidos
   1. comparação com regras de negócio ou fontes externas

- dados de má qualidade levam à conclusões incorretas, afetam negativamente a precisão dos modelos -> decisões equivocadas
- limpeza dos dados $\to$ consome boa parte do tempo

#### Qual a diferença entre Limpeza e Transformações de dados?


| **Limpeza de Dados** | **Transformação de Dados** |
| --- | --- |
| - garantir a precisão, complitude, confiabilidade | - converter dados brutos para formato mais otimizado |
| - identifiar e corrigir erros | - normalização, padronização, agregação, condificação de variáveis categóricas, funções matemáticas |
| - essencial para validade dos resultados analíticos | - engenharia de atributos |
| | - tornar dados mais manejáveis para algoritmos específicos, revelar padrões, melhorar eficiência computacional |
