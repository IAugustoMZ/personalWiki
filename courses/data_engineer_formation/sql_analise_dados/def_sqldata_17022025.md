# Formação Engenheiro de Dados

## SQL para Análise de Dados e Data Science

- linguagem SQL -> linguagem programação padrão para gerenciar, manipular banco de dados
  - consulta a dados
  - manipulação de dados
  - criação e manipulação de estruturas
  - gerenciamento de acesso
  - funções de agregação
  - integridade dos dados
- padronização -> interoperabilidade

### Papel na Ciência de Dados

- extrair e manipular dados diretamente da fonte
- extração e limpeza dos dados
  - dados empresariais -> transacionais (bancos de dados relacionais)
- consultas e exploração de dados
- integração com ferramentas de ciência de dados
  - importação direta para o ambiente de análise
- agilidade na manipulação de grandes conjuntos de dados
- suporte para sistemas de BigData
  - Hadoop / Spark / HiveQL
- criação e manipulação de pipelines de dados
  - limpeza e processamento de forma regular
