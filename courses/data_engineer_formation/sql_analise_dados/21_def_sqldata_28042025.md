# Formação Engenheiro de Dados

## SQL para Análise de Dados e Data Science

### O que são Enriquecimento e Inputação de dados?

- consulta para identificar valores ausentes

```sql
SELECT
    COUNT(*) - COUNT(col1) AS col1_miss
    ...
FROM table_name
```

- identifica apenas valores ausentes que sejam representados como `NULL`
  - nem todos os valores ausentes são `NULL`
  - podem vir como caracteres especiais

```sql
SELECT *
FROM table_name
    WHERE col1 LIKE '%?%'
```

- '?' indica o valor ausente nesse exemplo
- consulta para verificar duplicatas (sem considerar o `id`)

```sql
SELECT 
    col1,
    col2,
    ...
FROM table_name
GROUP BY col1, col2, ..., col3
HAVING COUNT(*) > 1
```

- identificação de outliers ($\pm1.5$ desvio padrão)
  - usar um `CTE` para calcular as estatísticas

```sql
WITH stats_values AS (
    SELECT
        AVG(col1) AS avg,
        STD(col1) AS std
    FROM table_name
)
SELECT col1
FROM table_1, stats_values
WHERE
    col1 >= avg + 1.5 * std OR
    col1 <= avg - 1.5 * std
```
