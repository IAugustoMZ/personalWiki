# Formação Engenheiro de Dados

## SQL para Análise de Dados e Data Science

### Técnicas de Remoção de Dados Duplicados

- análises imprecisas + resultados enganosos

|| Descrição | Limitações / Aplicações |
| --- | --- | --- |
| Identificação Manual | - Revisão manual<br>- Apenas Conjuntos Pequenos | - Ineficiente<br>- Propenso a erros |
| Deduplicação baseada em regras | - Regras específicas<br>- Comparação de colunas | - Útil onde houver padrão de duplicação |
| Comparação de strings e técnicas de similaridade | - Algoritmos de similaridade de strings:<br>- dist. Jaccard<br>- dist. Levenshtein<br>- Similaridade de cossenos | - dados textuais onde duplicatas podem não ser exatas, erros de digitação ou formatação |
| Algoritmos Hashing | - conversão em código hash e comparação | - rápido e eficiente para grandes volumes<br>- risco de colisão de hash |
| Ferramentas de Software | - software e linguagens de programação | - Eficiente para conjuntos de dados de médio a grande porte<br>- Abordagem mais utilizada |
| Machine Learning | - técnicas de aprendizado de máquina para identificar padrões complexos de duplicações | - casos complexos, duplicações não triviais, interdependência |

- Considerações importantes:
  - **Definição de duplicatas** $\to$ precisa ser clara e documentada
  - **Preservação de dados** $\to$ pode ser importante manter registro, auditoria e análise posterior
  - **Qualidade dos dados** $\to$ evitar a eliminação individa de dados válidos
