# Formação Engenheiro de Dados

## Infraestrutura como Código com Terraform, AWS, Azure e Databricks

### Microsoft Azure

- plataforma de serviço e computação em nuvem da Microsoft
    - computação
    - armazenamento
    - rede
    - serviços de bancos de dados
    - análise e aprendizado de máquina
- integração de sistemas locais + nuvens
- dispositivos web, mobile, IoT, IA
- `https://azure.microsoft.com`

### Google Cloud Platform

- plataforma de serviço de computação em nuvem do Google
    - compute engine: máquinas virtuais
    - Kubernetes engine: apps em containers
    - cloud storage: armazenamento de objetos
    - Big Query: analisar grandes conjuntos de dados
    - cloud SQL: serviço gerenciado SQL
    - cloud ML engine: serviço para criar e implantar modelos ML
- suporte à ampla variedade de linguagens
- integração para gerenciamento e monitoramento de recursos
- `https://cloud.google.com`
