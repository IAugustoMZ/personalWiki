### Sistema Operacional Linux, Docker e Kubernetes

#### Lab 4 - Automatizando Tarefas no Linux com Bash Script

- `grep` -> filtra a saída de outro comando
- `|` -> pipe serve para concatenar comandos
- `awk` -> linguagem de programação dentro do bash
    - para manipular linhas de arquivos
- `cut` -> cortar (como se fosse um filtro), baseado num padrão
- `uname` -> retorna o SO
    - `-i` -> retorna arquitetura do hardware

- quando usamos o `grep`, ele busa padrões similares aos informados, e não somente a palavra informada

- `free` -> mostra quanto de memória está disponível
- `uptime` -> mostra o tempo uptime da máquina
- `ps` -> processos em execução
- `sleep` -> tempo que o script vai aguardar em segundos
- `find` -> função de busca
- `netstat` -> conexões ativas e portas abertas
- `history` -> comandas executados

#### Lab 5 - Deploy de Aplicação Python com Linux e Docker

- aplicação Python no Docker
    - facilita manutenção
    - segurança e isolamento da aplicação
    - regras de versionamento (CI/CD)
- *Dockerfile* -> para construir uma imagem personalizada
    - conjunto de comandos Linux e Docker
    - maiúsculas -> comandos Docker
    - `FROM` - imagem a ser utilizada (origem)
    - `WORKDIR` - cria e define o diretório de trabalho
    - `COPY` - copia arquivos de um diretório local para dentro do container
    - `RUN` - executa um comando no terminal do Linux
    - `EXPOSE` - expõe uma porta do container
    - `CMD` - executa um comando no terminal do Linux
- `RUN` -> comandos durante a criação da imagem (modificação do sistema de arquivos)
- `CMD` -> comandos executados na inicialização do container
    - se tiver mais de um `CMD`, apenas o último será executado
- `ENV` -> para definir variáveis de ambiente
