### MLOps Essentials: Para Portfolios de Projetos, Gestão de Código e Dados com Git e DVC

#### O que é MLOPs na prática?

- comportamento de um sistema é definido por 3 pilares independentes: código, dados e parâmetros
  - se os dados de entrada mudam (drift) ou se um hiperparâmetro for modificado sem registro, o modelo resultante será completamente diferente
- disciplina que une o desenvolvimento (Dev) e a operação (Ops) para gerenciar três variáveis automaticamente
  - prática que garantem o ciclo de vida do modelo (ingestão do dado ao deploy) seja automatizado, monitoranável e seguro
- construtor de sistemas sustentáveis
  - ML não é um artefato estático, mas um componente vivo que precisa ser versionado, testado e re-treinado continuamente

#### Gestão de Código e Dados com Git e DVC

##### DVC ou Data Version Control

- ferramenta complementar ao git, voltada especificamente para o versionamento de dados, modelos de Machine Learning e pipelines de experimentos
- projetado para lidar com volumes de dados e artefatos binários, mantendo apenas metadados no repositório Git e armazenandos os dados em backends externos
- reprodutibilidade de experimentos, rastreamento de resultados e alinhamento entre código, dados e modelos ao longo do ciclo de vida de projetos de ciência de dados e aprendizado de máquina
