### Sistema Operacional Linux, Docker e Kubernetes

#### Conhecendo o Docker e Docker Hub

- dentro da criação do containers vamos usar as interações do terminal
    - podemos configurar e separar uma parte dos recursos computacionais
    - as equipes dos softwares continuamente estão atualizando as imagens oficiais
    - não podemos usar imagens que estejam sendo utilizadas em pelo menos um container
        - podemos usar o "pull" para manter as imagens atualizadas
    - dentro das imagens podemos explorar quais são as coisas que compõem as imagens
        - procurar usar sempre as imagens oficiais
    - imagens são compostas de camadas
        - comandos Linux
- containers podem ser parados, executados ou deletados
    - tags de versão
    - mapeamento de portas
    - visualização de logs
    - podemos usar o terminal (comandos Linux)
    - estatísticas
- se o container apresentar problemas na inicialização, ele não vai ser criado

#### Docker via Linha de Comando

- todos os comandos são inicializados com `docker`
- `docker version` -> apresentar a versão
    - server -> motor de execução
    - cliente -> conexão
- `docker run` -> executar o container que não existe
    - `-d` -> *detached* (segundo plano)
    - `p` -> porta
- `docker run -d -p <image_name>` -> para executar a `<image_name>` em segundo plano na porta selecionada
- `docker ps` -> para visualizar se existem containers em execução
- `docker ps -a` -> mostra todos os containers criados, em execução ou parados
    - `-t` -> aloca com terminal
    - `--name` -> nome do container
- `docker run -dt --name lab1 ubuntu` -> execução em modo de segundo plano, com acesso ao terminal do container `lab1` com a imagem `ubuntu`
- `docker exec -it lab1 /bin/bash` -> entra no container do Linux e executa o comando `/bin/bash` para prover uma área de trabalho
- `exit` -> para sair do container
