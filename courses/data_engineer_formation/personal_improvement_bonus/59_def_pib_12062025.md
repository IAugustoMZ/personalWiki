### Administração do Sistema Operacional Linux com Docker e Kubernetes

#### Orquestração de Containers Docker para Escalabilidade de Web App e Banco de Dados

- **Redis**: banco de dados em memória (*in-memory*) open-source
  - cache, armazenamento rápido de dados
  - alta performance
  - baixa latência
  - processamento de operações simultâneas
- armazena dados no modelo chave-valor (*key-value*)
  - diversos tipos de estruturas armazeadas
- persistência dos dados via *snapshot* ou logs de alterações
- escalabilidade horizontal via *clustering*
- replicação integrada (alta disponibilidade)
- suporte para transações atômicas
- cache de consultas frequentes; gerenciamento de sessões, filas de mensagens, processamento de eventos em tempo real
  - respostas rápidas exigidas
