### Sistema Operacional Linux, Docker e Kubernetes

#### Lab 6 - Deploy de Containers com Docker Compose

- Deploy 2
    - container 1 -> Web App (HTML)
    - container 2 -> API (NodeJS)
    - container 3 -> banco de dados (PostgreSQL)

- NodeJS -> engine JavaScript do lado servidor
- no docker-compose, a ordem de configuração dos serviços não importa
- se eu especifico uma pasta que não existe, ela será criada
- posso especificar como o container será reiniciado como `restart`
- especificação do contexto para encontrar o Dockerfile com
```yaml
buid:
    context: .
    Dockerfile: <Dockerfile-name>
```
- estabelecer dependências com `depends-on`
