### Sistema Operacional Linux, Docker e Kubernetes

#### Lab1 - Linux e Docker

- `docker pull ubuntu` -> "puxa" a imagem do ubuntu -> podemos usar tags para especificar versões
- *shell* -> camada de software acima do Linux
- `hostname` -> nome da máquina Linux
- `pwd` -> verifica o caminho atual
- `ls -la` -> lista o conteúdo da pasta atual (somente `ls` faz o mesmo sem considerar os arquivos ocultos)

- cada usuário no Linux tem sua pasta `home`
- `cd ~` -> vai para o diretório home (também pode ser `cd /home/<user>`)
- `add <user-name>` -> cria um novo usuário
    - todo usuário Linux precisa fazer parte de um grupo
    - arquivos templates para novos usuários
- `su <user-name>` -> loga como outro usuário, funciona apenas para o usuário `root`
- `id` -> também pode ser usado para identificar o usuário logado
    - indica arquivos ocultos
- novos usuários não possuem privilégios de atividades administrativas mas o `root` pode conceder
- `docker start <name/id>` -> iniciar container parado
    - nas descrições dos arquivos, temos a descrição dos usuários e do grupo
        - mesmo nome do usuário e grupo se não for especificado o contrário
    - podemos dar privilégios para o grupo ao invés do usuário individual

- `addgroup <group-name>` -> cria um novo grupo
- `usermod -f <group-name> <user-name>` -> modifica o grupo primário do usuário
- `usermod -a -g <secondary-group> <user-name>` -> adiciona um grupo secundário
    - agrupamento permite a segmentação de responsabilidades e privilégios
