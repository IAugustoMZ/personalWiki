#### Lab. 11 - Configuração de Firewall, Regras de Acesso e SSH

- `docker run -dit --name lab11 -cap-add=NET_ADMIN ubuntu` -> permissão de uso da rede
- `apt-get install iptable, openssh-server vim sudo -y`
    - `adduser userdsa`
    - `adduser userdsa sudo` -> sudo é a permissão de admin
- `su -user1`
- `sudo iptables -l -r` -> lista as regras de firewall existentes
- `iptables -a input -p <protocol> --dport <porta> -j ACCEPT` -> regra para permitir tráfego para porta e protocolo especificados
    - `-s [IP_origem]` -> especifica o IP permitido
    - `DROP` -> regra para bloquear o acesso
- `iptables -save` -> salva as regras atuais
- `iptables -restore` -> restaura as regras salvas

- **Acesso e SSH**
    - `/etc/ssh/sshd-config`
    - Port -> porta padrão
    - PermitRootLogin -> define se o login como root é permitido
    - Password Authentication -> autenticação por senha
    - PermitEmptyPasswords -> senhas vazias permitidas
    - PubkeyAuthentication -> autenticação por chave pública
    - AllowUsers[User 1][User 2] -> lista de usuários permitidos para conexão SSH
    - DenyUsers[User 1][User 2] -> usuários negados
    - Allow/Deny Groups -> grupos permitidos / negados
