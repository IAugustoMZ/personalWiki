# Formação Engenheiro de Dados

## Cursos de Aperfeiçoamento Profissional - Bônus da Formação

###  E-Gov Analytics

- **O que é E-Government?** -> serviços governamentais
    - uso de TICs para melhorar a eficiência das agências governamentais
        - inovação em governança
    - melhorar o funcionamento interno do setor público
        - reduz custos financeiros / tempos de transação
        - integração de fluxos de trabalho
        - transparência e responsabilidade

#### Nomenclatura do E-Government

- **Governo para Governo (G2G)** -> trocas eletrônicas entre setores governamentais
    - nível nacional, provincial, local
- **Governo para Negócios (G2B)** -> específico e linhas de serviços para negócios
- **Governo para Consumidor/Cidadão (G2C)** -> facilitar a interação das pessoas com o governo
    - consumidores de serviços públicos
    - consulta, tomada de decisão

#### Projeto de E-Gov Analytics

- como o aumento do PIB e gastos do governo impactam os stores de saúde e educação
    1. em que ano o país teve um alto crescimento do PIB per capita?
    2. qual ano teve as maiores despesas com saúde?
    3. qual ano teve os maiores gastos com educação?
    4. como a receita do governo se correlaciona com a despesa do governo?
    5. como a educação e a saúde se correlacionam com o crescimento do PIB?
    6. como os gastos do governo com educação e saúde afetam o crescimento do PIB?
    7. com base nas análises, quais são as recomendações aos governantes e gestores?

- **fontes de dados** -> API do banco mundial
    - `https://api.worldbank.org/v2/en/country`
    - período 2003 a 2019
    - repositório de dados abertos
        - `https://data.worldbank.org/`
- **dicionário de dados** -> importante ter uma noção do significado de cada dado antes de iniciar o projeto de dados
    - padrão comum em dados governamentais
        - dados nulos e ausentes
    - processamento de dados -> decisões pessoais do analista
        - experiência em projetos
        - documentação das decisões + justificativa
        - análise crítica dos resultados, pois as decisões influenciam os dados.
