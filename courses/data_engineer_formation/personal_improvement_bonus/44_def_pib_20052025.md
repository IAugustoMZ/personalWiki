###  DuckDB e Firecrawl para Database e Web Scraping Analytics

#### O que é e quando usar o DuckDB?

- sistema de gerenciamento de banco de dados analítico (OLAP) embutido ou in-process
  - não precisa de servidor separado, executado dentro da aplicação
- **focado em análise (OLAP)**: otimizado para consltas analíticas complexas para grandes volumes
  - processamento vetorial e colunar
- **rico em recursos e SQL**: dialeto SQL moderno e rico, suportando:
  - funções analíticas (window functions)
  - tipos de dados complexos (estruturas, listas)
  - consulta diversos tipos de arquivos
- **rápido**: velocidade em cargas de trabalho analíticas
- **portátil e simples**: fácil de instalar, sem dependências externas e complexas. Banco de dados contido num único arquivo
- **extensível**: adicionar novas funcionalidades, formatos de arquivo, conectividade
- **quando usar?**
  - processamento analítico de dados
  - análise interativa
  - ETL leve de dados locais
  - consultar múltiplos formatos de arquivos
  - incorporar análise em aplicações (sem depender de um servidor)
  - alternativa rápida ao pandas para opera~çoes maiores
  - prototipagem rápida
  - trabalahr com dados maiores que memória RAM (out-of-core processing)
  - consultar dados de cloud storage $\to$ armazenados em serviços AWS S3 ou Google Cloud Storage
