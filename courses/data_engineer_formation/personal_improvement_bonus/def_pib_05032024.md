#### Governança de Dados e Big Data?

- Big Data -> metadados
    - volume
    - variabilidade
    - velocidade
    - veracidade

- Data Lake -> grande quantidade de dados estruturados e não estruturados em diferentes camadas
    - quais dados estão disponíveis?
    - como é consumido / preparado / transformado ?
    - quem usa? quem contribui?
- resposta para as perguntas acima -> manutenção de metadados e usabilidade do DataLake

- **metadados**
    - torna todos os dados mais acessíveis, ajuda a extrair valor do Big Data
    - importância dos dados
        - self-service BI
        - data-as-a-service
        - ML-as-a-service
        - provisionamento de dados
    - define a estrutura dos arquivos no RAW zone -> entidades no lado arquivo
        - evolução do esquema rastreável
        - relação entre várias entidades
    - camada de consumo
        - saber a fonte dos dados
        - relacionamento nos metadados -> ambiguidades e inconsistências nas associações
- **no ecossistema Hadoop**
    - Apache Atlas
    - conjunto escalonável de serviços de governança
    - Hortoworks
- **classificação de dados**
    - importar ou refinar taxonomia como anotações
    - definir, automatizar e anotar a captura de relacionamentos
    - explorar metadados para sistemas de terceiros

- **Pesquisa e Linhagem**
    - caminhos de navegação predefinidos (classificação e auditoria)
    - dados relevantes rapidamente localizados
    - visualização da linhagem dos dados
        - drill down
- **mecanismo de segurança e políticas**
    - racionaliza a política de conformidade em tempo de execução
        - base de dados
        - esquemas de classificação, atribuição e papeis
    - definição avançada de políticas
        - prevenção de dados
        - derivação baseada na classificação
    - mascaramento de nível de coluna e linha
