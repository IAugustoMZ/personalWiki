### Sistema Operacional Linux, Docker e Kubernetes

#### Orquestração de Containers com Kubernetes

- requisitos para o SO
    - Docker
    - kubectl
    - minicube

1. iniciar o cluster
    - `minikube start`
2. confirmar se o cluster está funcionando corretamente
    - `kubectl get nodes`
3. adicionar o arquivo app-deployment.yaml numa pasta
4. acessar a pasta com arquivo e executar o deploy
    - `kubectl apply -f app-deployment.yaml`
5. verificar se os pods estão em funcionamento
    - `kubectl get nodes`
6. verificar a criação dos serviços
    - `kubectl get services`
7. obter o endereço IP dos serviços
    - `minikube service app-service --url`
