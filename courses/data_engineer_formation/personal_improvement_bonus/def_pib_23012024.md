## Cursos de Aperfeiçoamento Profissional - Bônus da Formação

### Sistema Operacional Linux, Docker e Kubernetes

#### Linux

- *kernel* de código fonte aberto
- código-fonte -> conjunto de instruções baseado numa linguagem de programação, que forma um software
- *kernel* é o núcleo do sistema operacional
    - intermediação entre hardware e os programas executados pelo computador
        - *kernel* + software tornam o programa usável = sistema operacional
        - não é manipulável pelo usuário

#### Docker - O que é? Quando usar e por que usar?

- gerenciar e usar **containers**: componentes executáveis padronizados que combinam o código fonte de uma aplicação com as bibliotecas e dependências do SO
    - uma máquina virtual super leve com SO
- simplificação da entrega de aplicativos distribuídos
    - nuvem e ambientes muticloud
- arquitetura baseada em Linux
    - recursos de virtualização
    - compartilhamento de recursos de uma única instância do host
- vantagens de VM
    - isolamento de arquivos
    - escalabilidade de econômica
    - descartabilidade
- vantagens sobre a VM
    - mais leve: apenas processos e depedências do SO para executar o código
    - produtividade aprimorada: aplicativos executados em qualquer lugar. Fáceis de implantar, provisionar e reiniciar
        - pipelines de integração CI/CD
    - maior eficiência de recursos: mais cópias de um aplicativo no mesmo hardware
- Docker permite automação por API
    - portabilidade aprimorada
    - atualizações mais leves
    - criação automatizada de containers
    - controle de versão de container
    - reinicialização de containers -> imagens / modelos para criação de novos containers
    - bibliotecas de containers

#### O que é Orquestração de Containers?

- automatiza a implantação, o gerenciamento, o dimensionamento, e a rede de containers
    - microsserviços (maior controle sobre partes)
    - unidade de implantação ideal
    - ambiente de execução independente
    - fluxos de trabalho CI/CD
- Kubernetes, Docker Swarm, Apache Mesos
- automatizar e gerenciar tarefas
    - provisionamento e implantação
    - configuração e agendamento
    - alocação de recursos
    - disponibilidade do container
    - balanceamento de carga e roteamento de tráfego
    - dimensionamento ou remoção de containers com base no balanceamento de carga
    - monitoramento da integridade do container
    - configurações de aplicativos no container em que eles serão executados
    - manter as interações entre containers seguras

#### Kubernetes - O que é e quando usar?

- plataforma de orquestração de containers
    - implantação de containers
    - atualizações
    - descobertas de serviços
    - provisionamento de armazenamento
    - balanceamento de carga
    - monitoramento de integridade
- ecossistema de ferramentas
    - Istio e Kreative -> plataforma como serviço
- serviço e aplicações que abrangem vários containers (cluster)
- organização de grupos de hosts
    - gerenciamento do cluster
    - nuvens públicas, privadas ou híbridas
- portabilidade da carga de trabalho e no balanceamento de carga

#### Kubernetes vs Docker Swarm

- **Kubernetes** - composto de nós de trabalho gerenciados por um mestre (master) do cluster Kubernetes
- vantagens Kubernetes
    - variedade de funcionalidades
        - descoberta de serviços
        - entrada e balanceamento de carga
        - auto-recuperação
        - orquestração de armazenamento
        - escalabilidade horizontal
        - rollout / rollback automatizado
        - execução em lotes
    - conjunto unificado de APIs
    - comunidade de código aberto
    - maior adoção no mercado
    - testado por grandes players
    - nuvem ou uso local
- **Swarm** - nó gerenciado Swarm implantado pelo Docker e nós de trabalhadores
- vantagens Swarm
    - uso do Docker Engine
    - fácil de instalar e configurar
    - compatibilidade com Docker
    - API Swarm
    - integração às ferramentas Docker, Docker Compose e CLI
    - sistema de filtragem e agendamento para fornecer seleção inteligente de nós
        - escolher nós ideais
