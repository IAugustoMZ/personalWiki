#### Manipulando arquivos e pastas

- `mkdir <nome_pasta>` -> criar nova pasta
- `cp <filename> <foldername>` -> copia o arquivo para a pasta selecionada
- `mv <filename> <foldername>` -> move o arquivo para a pasta selecionada
- `rm <filename>` -> remover o arquivo
- `rmdir <folder>` -> remover diretório
    - não funciona se o diretório tiver conteúdos
- `ls -la <filename>` -> exibe os metadados do arquivo selecionado
    - se o arquivo não for oculto, não precisa do `-la`. Apenas o `-l` funciona
- `-rw-r--r--`
    - `-` = arquivo
    - `d` = diretório
    - `l` = link
    - privilégios
        - `(4) r` = leitura (read)
        - `(2) w` = escrita (write)
        - `(1) x` = execução (execution)
    - 1º grupo de 3 (`rw-`) -> privilégios do propritário
    - 2º grupo de 3 (`r--`) -> privilégios do grupo do proprietário
    - 3º grupo de 3 (`r--`) -> privilégios de qualquer outra pessoa no SO
- `chmod 770 <filename>` -> modifica privilégios do arquivo (7 é o privilégio máximo)
- `chown root: root <filename>` -> modifica o usuário: grupo do arquivo
    - mesmo sem poder escrever, posso deletar o arquivo
