#### Pesquisa Binária

- entrada: lista ordenada
- paradigma -> dividir para conquistar
- sucessivas divisões no espaço comparando o elemento buscado com o elemento do meio e foca a busca no elementos anteriors ou posteriores ao elemento do meio

$O(n) \sim log(n)$ - desde que o vetor esteja ordenado

- muito usado em Visão Computacional

```python
def binary_search(array: np.array, item: int) -> Union[int, None]:
    low = 0
    high = len(array) - 1

    while low <= high:
        middle = (low + high) // 2
        guess = array[middle]

        if guess == item:
            return middle
        if guess > item:
            high = middle - 1
        else:
            low = middle - 1

    return None
```

#### Ordenação

- design da solução tem impacto profundo na complexidade e velocidade dos algoritmos
- **bubble sort** -> percorre a lista e compara pares de elementos, trocando-os caso necessário
- complexidade $O(n^2)$

```python
def bubble_sort(array: np.array) -> None:
    n = len(array)
    for i in range(n):
        for j in range(0, n-i-1):
            if array[i] > array[j]:
                array[j], array[j+1] = array[j+1], array[j]
```

- **selection sort** - divide a lista em duas partes: sub lista ordenada e o restante
    - menor elemento do restante é colocado na lista ordenada
    - repetir até acabar a lista
    - complexidade $O(n^2)$

```python
def selection_sort(array: np.array) -> None:
    n = len(array)
    for i in range(n):
        lowest_idx = i
        for j in range(i+1, n):
            if array[j] < array[lowest_idx]:
                lowest_idx = j
        array[i], array[lowest_idx] = array[lowest_idx], array[i]
```

- **merge sort** -> dividir para conquistar
    1. dividir a lista N vezes, onde cada sublista possui um elemento não-ordenado
    2. mescla repetidamente as sub-listas, juntando-as 2 de cada vez para produzir novas sub-listas ordenadas
    3. repetir até ordenação total
    - complexidade $O(n log(n))$

```python
def merge_sort(array) -> None:
    if len(array) > 1:
        middle = len(array) // 2
        left = array[:middle]
        right = array[middle:]

        merge_sort(left)
        merge_sort(right)

        i = j = k = 0

        while i < len(left) and j < len(right):
            if left[i] < right[j]:
                array[k] = left[i]
                i += 1
            else:
                array[k] = right[j]
                j += 1
            k += 1

        while i < len(left):
            array[k] = left[i]
            i += 1
            k += 1

        while j < len(right):
            array[k] = right[j]
            j += 1
            k += 1
```

- **quick sort** -> dividir para conquistar
    1. selecionar o pivô
    2. se $k < pivô$ -> esquerda
    3. se $k > pivô$ -> esquerda
    4. aplicação recursiva das etapas acima nos subconjuntos menores que os pivôs
    - complexidade $O(n log(n))$

```python
def quick_sort(array) -> None:
    if len(array) <= 1:
        return array
    else:
        pivot = array[0]
        lower = [x for x in array[1:] if x <= pivot]
        bigger = [x for x in array[1:] if x > pivot]

        return quick_sort(lower) + [pivot] + quick_sort(bigger)
```

#### Tabelas *Hash*

- associa chaves de pesquisa (*hash*) a valores
- busca rápida para recuperação de valores
- indexação de grandes volumes de informação
- função *hash* $O(1)$ -> gera o índice a partir de uma chave
    - idealmente únicos, pode ocorrer colisão (duas entradas com a mesma saída)
    - podem ser associadas com outras estruturas de dados
- função *hash* -> mapeia strings a números
    - consistente -> mesmos resultados para mesmas entradas
    - diferentes *hash* para diferentes entradas
    - conhecimento do tamanho do array e sempre retorna valores válidos
- em Python -> dicionários são tabelas *hash*
