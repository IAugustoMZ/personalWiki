# Formação Engenheiro de Dados

## Cursos de Aperfeiçoamento Profissional - Bônus da Formação

### MLOps Essentials: Para Portfolios de Projetos, Gestão de Código e Dados com Git e DVC

#### Issues

- registros estruturados do trabalho, usados para documentar bugs, solicitações de melhorias, tarefas técnicas ou discussões de produto
  - unidades de acompanhamento
  - priorização, atribuição de responsáveis
  - categorização e rastreamento do progresso
- não altera o código diretamente, mas define o problema ou a necessidade que orienta futuras mudanças

#### Pull Requests

- mecanismo formal de proposta de alteração de código
  - desenvolvedor solicita que as mudanças feitas numa branch sejam revisadas e integradas a outra  
    - normalmente a principal
  - revisão de código, discussões técnicas, validação automática por testes, verificação de conformidade com padrões de projeto
- processo de integração via uma atividade explícita, rastreável e auditável, reduzindo riscos e melhorando a qualidade do software
- GitHub oferece automações como pipelines de integração e entrega contínua
  - testes, análises estáticas, e deploys automáticos a cada mudança relevante
  - conexão do versionamento de código a práticas modernas de engenharia
    - DevOps e MLOps
    - repositório é um ponto central de código e de processos
