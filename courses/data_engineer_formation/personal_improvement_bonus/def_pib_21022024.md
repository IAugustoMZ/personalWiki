### Sistema Operacional Linux, Docker e Kubernetes

#### Arquitetura do Kubernetes

- sistema de gerenciamento de containers
- automatizar tarefas de gerenciamento
- **arquitetura**
    - *Máquinas do cluster* -> conjunto de máquinas físicas ou virtuais
        - podem ser nó mestre ou nós de trabalho
    - *Nó Mestre* -> responsável por gerenciar o cluster
        - controlar os nós de trabalho
        - garantir funcinonamento de pods e containers
        - *kube-apiserver*: ponto de extremidade RESTful para interação com o cluster
        - *etcd*: banco de daodos distribuído que armazena os estados do cluster
        - *kube-scheduler*: seleciona qual nó de trabalho um pod deve ser executado
        - *kube-controller-manager*: gerencia os controladores, garantindo o atingimento do estado desejado
    - *Nós de Trabalho* -> execução dos pods e containers
        - *kube-kubelet*: gerencia os pods
        - *container runtime*: responsável por executar os containers
- **Pods**: unidade básica de execução do Kubernetes
    - um ou mais containers que compartilham um espaço de endereçamento de rede e um sistema de arquivos
    - containers de comunicação próxima
- **Serviços**: ponto de extremidade de rede
    - direciona o tráfego para um conjunto de pods
    - permite a conexão entre aplicativos e usuários finais
- **Deployments**: camada de abstração dos pods para lançamento do cluster
    - declaração das réplicas do pod que devem estar em execução
    - recuperação de pods
    - implantação de novos pods, quando necessário
- balanceamento de carga
- rollout e rollbacks de atualizações
- gerenciamento de storage
