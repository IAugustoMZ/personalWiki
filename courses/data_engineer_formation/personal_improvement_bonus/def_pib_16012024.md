### Introdução à Lógica de Programação

- **algoritmo** -> sequência de instruções lógicas feitas para resolver um problema
    - usa uma entrada para gerar uma saída
- sequências estruturadas em linguagem de programação
- é bom praticar a definição de problemas
- autoanálise e autorreflexão => humildade
    - sempre temos o que melhorar
    - plano de ação
- estruturas condicionais -> regras de lógica para decisões do computador
- estruturas de repetição -> operações repetitivas
- **recursividade** -> sub-rotina que pode inovar a si mesma
    - pelo menos uma chamada a si mesma de forma direta ou indireta
    - pelo menos uma condição de parada
        - instância simples do problema original
    - tendem a ser mais lentas pois usam alocação e desalocação de memória
    - podem ser mais compactas e legíveis
