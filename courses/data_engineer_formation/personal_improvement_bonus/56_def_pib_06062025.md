### Administração do Sistema Operacional Linux com Docker e Kubernetes

#### Navegando pelo terminal Linux 

- hostname: nome da máquina
- id: nome ou grupo(s) do usuário
- `pwd`: nome do diretório atual
  - `/` - diretório raiz
- `ls -la`: lista a estrutura do diretório atual
- `clear`: limpa a tela do terminal
- `cd`: navega para o diretório
- `rm -rf`: remover um arquivo
  - auto fill com tab
- `touch`: criar arquivo vazio
- `mkdir`: criação de pastas 
- `mv`: mover arquivos para pastas
  - se for usado para mesma pasta, mas com nome diferente, serve para renomear o arquivo
- `.`: diretório corrente
- `..`: diretório superior
