# Formação Engenheiro de Dados

## Cursos de Aperfeiçoamento Profissional - Bônus da Formação

### IA Generativa e Agentes de IA para Fluxos de Automação com Langflow e n8n

- **vibe coding** $\to$ usar a linguagem natural para que o modelo de linguagem possa construir a aplicação
  - bom se o profissional tiver o conhecimento na questão
  - precisamos conhecer os riscos de executar o código gerado pelo LLM / SLM
    - não há raciocínio na execução do modelo de linguagem
      - reprodução dos padrões aprendidados nos dados de treinamento
      - pode ser que saia código ruim ou inseguro

#### Langflow

- parte da família LangChain
- vem do LangGraph $\to$ baseado na teoria dos grafos
- ferramenta visual para criação de fluxos autônomos de IA
- profissional de dados não pode deixar de conhecer IA
- Langflow $\to$ ainda não há app para Windows (Desktop)
  - é um app bem novo
  - funciona no Docker
  - gratuito
  - pacote Python

#### n8n

- plataforma mais robusta
  - permite a instalação local e também na nuvem (14 dias)
- IA Generativa pode entrar no lugar de RPA
  - cuidado, muitas aplicações ainda podem ser resolvidas com ferramentas tradicionais
  - conhecimento da área de negócio continua a ser a parte mais importante
  - governança precisa atuar para o estabelecimento de regras de controle, conformidade
    - estabelecimento de processos
- uso da GroqAPI para acesso aos modelos de linguagem
  - agentes de IA = fluxos de automação + LLM + ferramentas
