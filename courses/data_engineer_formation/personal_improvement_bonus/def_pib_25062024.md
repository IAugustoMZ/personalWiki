# Formação Engenheiro de Dados

## Cursos de Aperfeiçoamento Profissional - Bônus da Formação

### Database Analytics com DuckDB

- banco de dados SQL OLAP (processamento analítico online)
- não requer processo de servidor separado
- *armazenamento colunar* -> otimizado para cargas de trabalho analíticas
    - compactação
    - consultas mais rápidas
- *suporte SQL*: funções window, CTEs, junções complexas
- *incorporável*: diretamento no aplicativo
- *compatibilidade entre plataformas*: escrito em C++
- *execução rápida de consultas*: execução vetorizada, otimização de consultas, processamento adaptativo
    - dados locais
    - fluxos de BI
    - baixa latência e facilidade de integração
    - não vai substituir o Apache Spark
        - Spark focado em volumes maiores ou aplicação de ML
