#### Manipulando arquivos e pastas

- estrutura geral da exibição do conteúdo de um diretório do Linux
- ```...... <user_name> <group> <size_bytes> <last_update> <name>```
    - `d` - indica que é um diretório (pasta)
    - `-` -> indica que é um arquivo
    - `.` -> diretório atual
    - `..` -> diretório anterior (nível supervioer da hierarquia)
- `touch <file_name>` -> cria um arquivo
- `vi` -> editor de textos que funciona no terminal
- se algum comando não foi encontrado, provável que SO não encontrou o arquivo de instalação do software
- instalação demanda privilégios de administrador
- `apt-get update` -> atualiza a lista de mirrors (pacotes)
    - apt é o gerenciador de pacotes do Linux
- `apt-get install <packages>` -> instalação dos pacotes
    - para editar o vim -> usar "I"
    - para sair do modo de edição do modo de inserção -> "ESC"
    - salvar o arquivo -> ":W"
    - sair do vim -> ":Q"
- `cat <filename>` -> lista o conteúdo do arquivo no terminal
- `cat <filename> <filename2>` -> copiar o arquivo para outro arquivo
