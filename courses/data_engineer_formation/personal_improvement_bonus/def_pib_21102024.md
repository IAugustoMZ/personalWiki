# Formação Engenheiro de Dados

## Cursos de Aperfeiçoamento Profissional - Bônus da Formação

### Web Scraping Analytics

- processo de extração automatizada de dados de websites. Extração automatizada de informações disponíveis na internet

#### Principais Elementos

1. coleta de dados -> requests
2. análise de dados -> extração de tags HTML
3. transformação de dados -> estruturação em tabelas
4. automação -> coleta contínua

- **Bibliotecas**
    - BeautifulSoup
    - Selenium
    - Scrapy

- respeito ao arquivo `robot.txt` -> páginas proibidas ou permitidas para extração de dados
- use atrasos entre as requisições -> evitar sobrecarregar o servidor, evitar bloqueios de IP
- imitar comportamento humano -> cabeçalhos HTTP comuns
- lidar com mudanças dinâmicas
    - monitorar mudanças no site -> monitoramento
- atenção com limite de requisições -> evitar banimento
- salvar dados de forma eficiente -> JSON ou CSV
- esteja ciente das implicações legais e éticas
