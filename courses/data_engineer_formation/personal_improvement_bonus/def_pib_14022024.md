#### Lab 4 - Automatizando Tarefas no Linux com Bash Script

- em bash script, podemos definir a variável usando a atribuição `=`
- para recuperar, usamos o `$`
- `bash <nome_script.sh>` -> executar o script
    - outra forma é mudar para binário - `chmod 655 <nome_do_sh>`
- `$HOME` -> pasta home da máquina
- `$HOSTNAME` -> nome da máquina
- `$TERM` -> tipo da sessão
- `$PATH` -> caminho real
- no Linux -> `env` => para mostrar as variáveis de ambiente
- no bash -> `read` => para ler variáveis do usuário (inputadas)
- `expr` -> para realizar expressões matemáticas
- *arrays* são declarados com parênteses, e os elementos não possuem nada para separá-los
    - para acessar os índices do array `ARRAY[0]`
    - indexação do bash começa em 0
- loop de repetição
    `for ...; do ...; done`
- condicionais
    `case ... in esac`
- no Linux -> `wget <link>` -> faz o download de um arquivo
