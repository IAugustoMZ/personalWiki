### Sistema Operacional Linux, Docker e Kubernetes

#### Lab. 7 - Orquestração de Containers com Docker Swarm

- aplicação do deploy 1 do Lab 6, porém escalada para ter alta disponibilidade

1. criar as imagens

`docker compose build` -> não inicia os containers

2. inicializar o Swarm

`docker swarm init`

3. criar a rede -> comunicação dos serviços (rede *overlay*)

`docker network create --driver overlay lab7`

4. criar um serviço para aplicação web

`docker service create --name dsa.webapp --network lab7 --replicas 3 -p 8000:5000 lab7-web: v1`

5. criar o serviço do banco de dados

`docker service create --name dsadb --network lab7 --replicas 3 lab7-redis`

6. escalar (aumentar o número de réplicas)

`docker service scale dsawebapp=5`

7. atualizar a imagem dos containers

`docker service update --image lab7-web:v2 dsawebapp`

8. no caso de um container ser excluído (máquina indisponível), o Docker Swarm vai se responsabilizar por subir novas réplicas até compor o cluster original

9. inspecionar o container
    - `docker service ls` -> lista os serviços em execução
    - `docker service inspect --pretty dsawebapp` -> inspeção dos serviços
        - sem o `pretty`, vem um JSON completo
    - `docker service ps dsadb` -> lista os serviços em execução

10. parar e remover os serviços

`docker service rm dsa-webapp`
