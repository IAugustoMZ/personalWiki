### Computação Quântica Aplicada para Profissionais de Dados

#### O que é Exatamente Computação Quântica?

- paradigma de computação baseado nos princípios da mecânica quântica
  - computação clássica: bits $\to$ 0 ou 1
  - computação quântica: *qubits* $\to$ 0, 1 ou superposição
- superposição $\to$ combinação probabilística de ambos os estados
- uso permite que um sistema quântico processe um grande número de possibilidades simultaneamente
- fenômeno fundamental $\to$ entrelaçamento quântico
  - o estado de um qubit passa a depender do estado de outros
    - mesmo que estejam fisicamente separados
  - correlações extremamente fortes e realizar operações computacionais que seriam inviáveis em computação clássica
    - algoritmos quânticos
      - fatoração de números muito grandes
      - busca em grandes bases de dados
      - simulações de sistemas moleculares
      - otimização combinatória
- computadores quânticos não substituem computadores clássicos
  - especializados em determinados tipos de problemas matemáticos e científicos

#### Por que Computação Quãntica Importa para Profissionais de Dados?

- crescimento exponencial do volume de dados $\to$ capacidade de processamento atingindo limites físicos
- computação quântica $\to$ paradigma diferente no processamento de informações
  - resolver problemas de otimização e modelagem

#### O Qubit: a unidade fundamental da informação quântica

- opera sob as leis da mecânica quântica
- estado do qubit

$$|\psi\gt=\alpha|0\gt+\beta|1\gt$$

- $\alpha, \beta\to$ são números complexos (amplitudes de probabilidades)
- a condição $|\alpha|^2 = |\beta|^2=1$ deve ser sempre verdadeira
- quando medimos o qubit, ele colapsa para $|0\gt$ com probabilidade $|\alpha|^2$ ou para $|1\gt$ com probabilidade $|\beta|^2$
- um qubit em superposição está nos estados 0 e 1 **ao mesmo tempo**
- um computador quãntico com N qubits pode processar $2^N$ estados simultaneamente
  - $n=50\to$ supera a capacidade de qualquer supercomputador clássico

#### Entrelaçamento Quântico: Correlações sem Precedentes

- ***entanglement***: fenômeno onde 2 ou mais qubits tornam-se correlacionados de forma que o estado de um afeta instantaneamento o estado do outro, independente da distância entre eles
  - medimos o 1º como $|0\gt$, sabemos que o segundo é $|0\gt$ ou $|1\gt$ (dependendo do tipo de entrelaçamento)
- equação de Bell $\to$ forma mais simples de entrelaçamento de um par:

$$|\Phi^{+}\gt=\Big(\frac{1}{\sqrt{2}}\Big)(|00\gt+|11\gt)$$

#### Interferência Quântica: Amplificando Respostas Corretas

- mecanismo que permite aos algoritmos quânticos encontrar respostas corretas de forma eficiente
  - amplitudes de qbits também interferem entre si, da mesma forma que ondas eletromagnéticas
- algoritmos quânticos são projetados pra que os caminhos computacionais que levam à resposta correta se reforcem, e caminhos incorretos se cancelem
- não ocorre de forma aleatória $\to$ cuidadosamente controladas, por meio de portas quânticas aplicadas
  - manipulam as fases das amplitudes dos qubits
    - permitindo simultaneamente a exploração de múltiplas probabilidades
    - amplificar probabilidades associadas às respostas corretas

#### Portas Quânticas: as Operações Fundamentais

- operações unitárias reversíveis que transformam os estados dos qubits
- organizadas em circuitos quânticos
  - diferentes portas aplicadas sequencialmente aos qubits para realizar algoritmos como busca, fatoração ou otimização
  - combinação de superposição, interferência, e entrelaçamento
- vocabulário operacional da computação quântica $\to$ manipular estados quânticos de forma controlada

#### Circuito Quântico: Programando em Computador Quântico

- sequência de portas quânticas aplicadas a qubits seguidas de medições
- forma fundamental de expressar algoritmos quânticos $\to$ análogo a um programa de computador clássico
- **estrutura**
  - **inicialização**: todos os qubits começam nos estado $|0\gt$ (estado quântico puro)
  - **transformações**: sequências de portas quânticas para manipular os qubits segundo o algoritmo
  - **medições**: colapso das superposições em valores clássicos (0 ou 1)
    - circuito executado milhares de vezes (*shots*) para se obter distribuições de probabilidades

#### A Era NISQ: onde estamos hoje

- NISQ $\to$ *Noisy Intermediate Scale Quantum*
  - descrever a geração atual de computadores quânticos
- entre 50 e 1000+ qubits, mas são ruidosos
  - suscetíveis a erros causados por decorrência e interferências ambientais
- Microsoft+ definiu 3 níveis de progresso quântico
  - **nível 1**: NISQ, máquinas ruidosas atuais
  - **nível 2**: máquinas pequenas com correções de erros
  - **nível 3**: sistemas de larga escala com correções de erros

#### Correções de Erros Quânticos

- principal desafio técnico atual
- processador Willow demonstrou supressão exponencial de erros conforme o tamanho das matrizes de qubits aumenta

#### Computação Quântica Aplicada a Data Science

- acelerar algoritmos de otimização, melhorar modelos de aprendizados de máquina, processar grandes volumes de dados
- **Machine Learning Quântico (QML)**:
  - traduzir algoritmos clássicos para sistemas quânticos
    - eficiência de parâmetros e *transfer learning*
- **otimização de portfolios**
  - simulação de mercados financeiros, detecção de fraudes e criptografia inquebrável
  - otimização das operações de câmbio
- **Kernel Quântico e SVM**
  - *Quantum Suppport Vector Machine (QSVM)*
  - kernels quânticos para mapear dados em espaços de Hilbert de alta dimensão
- **Simulação Molecular e Drug Discovery**
  - simulação quânticas para modelar interações moleculares potencialmente reduzindo tempo de desenvolvimento de medicamentos de anos para meses
  - bibliotecas Python $\to$ *Qiskit (IBM)* para propósito geral
    - Pennylove (Xanady) $\to$ ML quântico

#### Sistemas Híbridos Quântico-Clássicos

- abordagem mais viável na prático para profissionais de dados 
  - sub-rotinas quânticas são integradas a pipelines clássicos de processamento
- fluxo típico $\to$ combina o melhor dos dois mundos
  1. pré-processamento clássico dos dados
  2. codificação dos dados em um circuito quântico parametrizado
  3. execução do circuito no processador quântico
  4. medição dos resultados
  5. otimização clássica dos parâmetros do circuito

#### Algoritmos Variacionais (VQA)

- padrão para a era NISQ
- funcionam como circuitos quânticos cujos parâmetros são otimizados por um algoritmo clássico (como *gradient descent*)

#### Programação Diferenciável Quântica

- circuitos quânticos são diferenciáveis, permitindo calcular gradientes dos parâmetros de controle
- integração com frameworks de Deep Learning como PyTorch e Tensorflow

#### Segurança de Dados na Era Quântica

- algoritmos quânticos tem potencial de quebrar sistemas criptográficos amplamente utilizados
- abre espaço para novas abordagens de proteção
  - criptografia pós-quântica
  - distribuição quântica de chaves (QKD)
- avaliar riscos, algoritmos resistentes a ataques quânticos e acompanhamento da evolução das tecnologias
