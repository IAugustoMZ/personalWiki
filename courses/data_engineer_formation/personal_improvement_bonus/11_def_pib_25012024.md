# Formação Engenheiro de Dados

## Cursos de Aperfeiçoamento Profissional - Bônus da Formação

### Sistema Operacional Linux, Docker e Kubernetes

#### Principais Distribuições Linux

- existem milhares
- uma distribuição tem o *kernel* Linux, com softwares personalizáveis
    - Ubuntu será o utilizado (uma das mais usadas)

#### Conhecendo o Docker e Docker Hub

- containers e máquinas virtuais superleves
    - colocamos no container somente o que precisamos
- abordagem de microsserviços
    - intercâmbio de containers para manutenção
- compatilhamento de imagens = portabilidade
- execução do container criado pela imagem = compatibilidade de aplicativos

- **Docker Hub**
    - conjunto de imagens oficiais dos softwares necessários
    - ajuda na configuração da infraestrutura
    - *versões*
        - person = $ 0
        - pro = $ 5 / mês
        - team = $ 9 / usuário / mês
        - business = $ 24 / usuário / mês -> mínimo 5 licenças
- Docker funciona tanto na linha de comando como também na versão Desktop
    - desktop = motor de execução + UI
    - imagem = *"template"* do container, contém tudo que container precisa para ser executado
        - especificação
            - SO
            - diretório
            - privilégios
            - softwares
            - pacotes
    - podemos usar a imagem pronta ou criar a imagem por meio do Dockerfile
        - de uma imagem, posso criar um ou mais containers
    - volumes -> mapeamentos da máquina física para o container
    - extensões
        - *disk usage* -> consumo de espaço em disco
        - *logs explorer* -> visualização aprimorada de logs
