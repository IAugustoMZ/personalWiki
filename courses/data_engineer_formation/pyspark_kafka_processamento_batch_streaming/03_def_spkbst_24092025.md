# Formação Engenheiro de Dados

## PySpark e Apache Kafka para Processamento de Dados em Batch e Streaming

- para interagir com o cluster Spark sempre precisamos abrir uma sessão Spark e criar um job para estabelecer a conexão
- sempre precisamos de uma estrutura para os dados que estamos trabalhando
  - dar um schema aos dados
- sempre que fazemos mudanças nas transformações precisamos nos atentar às migrações necessárias no banco de dados
- função `filter` permite aplicar operadores relacionais e valores condicionais para filtrar os dados no nível de linha
- podemos usar o `regex_replace` em colunas específicas para realizar limpeza de colunas textuais
- para usar uma conexão do banco via JDBC, pede uma construção de uma string de conexão
  - string de conexão é específica para cada SGBD
  - necessários drivers para permitir a conexão
    - passar como um dicionário de propriedades

### O que é um Driver JDBC?

- *Java Database Connectivity* $\to$ padrão de API para conectar aplicações em bancos de dados

1. **interface padrão**: permitem interação com qualquer banco de dados com driver JDBC, sem a necessidade de escrever código específico para cada
2. **tipos de driver JDBC**
   1. tipo 1 $\to$ JDBC - ODBC bridge
   2. tipo 2 $\to$ API nativa
   3. tipo 3 $\to$ *middleware* de rede
   4. tipo 4 $\to$ drivers nativos de protocolo
3. **execução de consultas SQL**
   1. execução de consultas, atualizações e comandos de gerenciamento diretamente do código da aplicação
4. **portabilidade e flexibilidade**
   1. permite a portabilidade de código
   2. conectar a diferentes bancos apenas mudando o driver JDBC, sem precisar alterar o código fonte
5. **parte do Java SE**
   1. mantido e atualizado como parte do ecossistema Java
6. **suportes a fabricantes de bancos de dados**
   1. maioria dos fabricantes oferece drivers para permitir conexão

- no comando de submissão, precisamos passar o camanho do jar com o driver JDBC para o master do Spark
