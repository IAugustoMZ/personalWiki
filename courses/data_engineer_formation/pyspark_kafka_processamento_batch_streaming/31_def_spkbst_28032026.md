## PySpark e Apache Kafka para Processamento de Dados em Batch e Streaming

### Multi-Node Cluster Spark, HDFS e Kafka

#### Spark Streaming

- módulo do Apache Spark projetado para o processamento de dados em tempo real
- ingestão de fluxos contínuos de dados de fontes como o Kafka, sockets TP, filas de mensagens ou sistemas de arquivos, e os processa em micro-lotes
  - micro-lotes transformam os dados em tempo real em uma sequência de RDDs
  - RDDs permitem operação como filtragem, agregação e análise em alta escala
- cenários de monitoramento de logs, detectação de fraudes, processamento de logs de dados de IoT, e análise em tempo real
