### Multi-Node Cluster Spark, HDFS e Kafka

#### Balanceamento de Partições entre Nodes de Clusters Kafka

- distribuir uniformemente a carga de trabalho entre os brokers
  - otimizando o uso de recursos
  - processo automático ou manual
- o briooker que contém aa partição líder é responsável por gerenciar toda a leitura e escrita para essa partição
  - brokers com réplicas sincronizam dados a partir do líder para garantir alta disponibilidade
- implementa o balanceamento por meio do controlador
  - broker eleito para gerenciar metadados e coordenação do cluster
  - coordenador distribui as partições e réplicas
  - leva em consideração fatores
    - número de partições
    - volume de dados processado
    - configuração da replicação
  - redistribuição feita sem interrupção significativa do serviço
