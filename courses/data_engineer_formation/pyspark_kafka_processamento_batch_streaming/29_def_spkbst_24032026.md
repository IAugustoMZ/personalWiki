## PySpark e Apache Kafka para Processamento de Dados em Batch e Streaming

### Multi-Node Cluster Spark, HDFS e Kafka

#### Compreendendo o Conceito de Offsets no Kafka

- identificador único atribuído a cada mensagem dentro de uma partição
  - representa a posição da mensagem dentro da fila das partições
- os consumidores usam para rastrear mensagens que já foram processadas
  - registro do último offset consumido
  - retoma a partir do último offset em caso de falhas / reinicialização $\to$ continuidade sem perda ou replicação
- exclusivo da partição $\to$ diferentes partições podem ter offsets semelhantes ou idênticos, mas que são gerenciados de forma independente

#### Como Particionamento e Offset trabalham em um Multi-Node Kafka Cluster

- **paralelismo**: diferentes consumidores podem ler mensagens em paralelo de várias partições, maximizando o desempenho
- **balanceamento de carga**: distribuição automática das partições entre os brokers, otimizando a utilização de recursos
- **recuperação em caso de falhas:** se um broker falhas, o Kafka promove uma réplica da partição armazenada em outro broker para o status de líder
  - consumidores continuam lendo mensagens sem interrupção
- **escalabilidade:** quando é adicionado ao cluster, as partições podem ser redistribuídas para o novo nó
