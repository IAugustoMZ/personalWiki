##### Ações

- Apache Spark é uma ferramenta verbosa
  - precisamos ajustar o nível do log
  - ajustar usando o arquivo `.properties`
- não conseguimos usar SQL com um dataframe Spark
  - criar uma view temporária na memória do cluster
- o ideal é sempre usar as funções nativas do Spark, pois elas são otimizadas para ambientes distribuídos
- podemos criar colunas com elementos dentro de valores
  - acelera muito operações matriciais
  - podem ser explodida com a função `.explode`
- no Spark, os dicionários são chamados de `map`

##### Objeto Row

- objeto que representa uma linha do dataframe $\to$ similar a uma linha numa planilha
- cada Row possui um conjunto de atributos que representam as colunas do DataFrame
  - acesso via notação de ponto ou notação de dicionário
- atributos ordenados da mesma forma que as colunas do DataFrame
- uma vez criado, um Row não pode ser modificado
- utilidades e aplicações
  - iteração
  - filtragem
  - agregação
  - manipulação de dados, adição e remoção de colunas, remoção de linhas e modificação de valores

#### Conversão Map-Column-Map

- transformar um DataFrame aplicando funções a cada coluna individualmente

1. **Etapa 1: `map`**: aplicação uma função a cada linha do DataFrame de forma paralela, aproveitando a capacidade de processamento distribuído
2. **Etapa 2: Column**: função aplicada a cada coluna do DataFrame
   1. cálculo de estatísticas, agregar valores
   2. execução em paralelo
3. **Etapa 3: `map`**: etapa final aplicando outra função a cada linha do DataFrame
   1. pode ser usada para combinar os resultados das etapas anteriores ou realizar outras transformações de dados
   2. finalizar as modificações nos dados e retonar o DataFrame transformado

- **Vantanges da Conversão MCM**
  - **eficiência**: a execução em paralelo das funções em cada etapa garante um processamento rápido, especialmente em grandes conjuntos de dados
  - **escalabilidade**: pode ser facilmente dimensionada para lidar com conjuntos de dados cada vez maiiores
  - **flexibilidade**: grande variedade de operações de manipulação de dados através das funções mapeadas
