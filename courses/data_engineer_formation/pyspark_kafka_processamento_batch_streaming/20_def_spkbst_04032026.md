# Formação Engenheiro de Dados

## PySpark e Apache Kafka para Processamento de Dados em Batch e Streaming

### Multi-Node Cluster Spark, HDFS e Kafka

#### Configurações do Consumidor e Controle de Offset

- determinam como os consumidores lêem mensagens de tópicos e acompanham progresso de leitura
- **offset** - identificador numérico exclusivo que representa a posição de uma mensagem dentro de uma partição de um tópico
  - índice de localização de rastreio de mensagens
- **Parâmetros de configuração**
  - `group_id`: identificar o grupo de consumidores. Consumidores de um mesmo grupo dividem o trabalho de consumir mensagens de um tópico, garantindo que cada partição seja atribuída a apenas um grupo consumidor do grupo
  - `auto.offset.reset`: define o comportamento ao iniciar o consumo em um tópico
    - `earliest`: começa a distribuir do início (primeio offset disponível)
    - `latest`: começa a consumir apenas mensagens novas
    - `none`: gera erro se não houver um offset previamente salvo
  - `enable.auto.commit`: controla se o consumidor deve salvar automaticamente os offsets após processar as mensagens
    - `true`: o Kafka salva automaticamente o offset (padrão)
    - `false`: o consumidor gerencia manualmente
  - `fetch.min.bytes` e `fetch.max.wait.ms`: controlam o comportamento da busca de mensagens para equilibrar latência e eficiência

#### Construindo Kafka Spark Consumer

- componente da aplicação que lê mensagens de tópicos do Apache Kafka
  - processamento dos dados publicados por consumers
  - forma eficiente, controle sobre offset
- Kafka atua como um *middleware* assíncrono
