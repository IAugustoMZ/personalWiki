# Formação Engenheiro de Dados

## PySpark e Apache Kafka para Processamento de Dados em Batch e Streaming

### O que é Processamento Distribuído?

- components de software localizados em computadores interconectados comumente para alcançar um objetivo em comum
  - tarefas divididas em partes menores e distribuídas por diferentes máquinas
  - paralelização do trabalho, otimização de desemepenho e eficiência
- **escala**: permitem a manipulação de grandes volumes de dados, com distribuição de carga e tráfego
- **resiliência**: mesmo que uma máquina falhe, o sistema pode absorver essa demanda
- **otimização de recursos**: combinação de capacidade de processamento, memória, e armazenamento de várias máquinas
  - tarefas complexas podem ser realizadas mais rapidamente
- desafio de processamento distribuído
  - coordenação entre nós
  - garantia de consistência de dados
  - recuperação de falhas
  - segurança

#### Processamento Distribuído no contexto de Engenharia de Dados

- processar, analisar e transformar grandes conjuntos de dados de maneira eficiente e escalável
- dados divididos em partições ou fragmentos
  - cada partição designada para ser processada em um nó específico de um cluster de máquina
- sistema de gerenciamento de cluster $\to$ distribuir as tarefas de processamento para os diferentes nós
  - recursos utilizados de maneira otimizada
- sistema é projetado para lidar com falhas de processamento de nós
  - se um nó falha, a carga é redistribuída pelos nós restantes
  - evitar pontos únicos de falha
- após o processamento, resultados são consolidados e agregados para produzir o final
- Apache Hadoop e Apache Spark, Apache Kafka para streaming de dados em ambientes distribuídos
- HDFS é um sistema de armazenamento distribuído
  - garante proximidade ao sistema de processamento

### O que é e como usar pySpark?

- interface Python para o Apache Spark
- Apache Spark $\to$ processamento distribuído em clusters de computadores
  - capacidade de armazenar dados intermediários na memória
  - reduz I/O no disco
- pySpark aproveita a familiaridade de uso e facilidade do Python tornando a plataforma mais acessível
- uso do Spark $\to$ instalar, configurar, criar uma `SparkSession`
  - ler dados de várias fontes
  - aplicação das transformações, processamento de dados estruturados
  - aprendizado de máquina, streaming de dados e consultas a grafos
  - armazenar de volta em sistemas distribuídos
  - visualizações
- curva de aprendizado suave

### O que é e como usar Apacha Kafka?

- sistema distribuído de mensagens de alto rendimento e baixa latência
- lidar com fluxos massivos de dados em tempo real de maneira durável, rápida e confiável
  - escalabilidade horizontal
- arquitetura de consumidadores e produtores
  - produtores enviam as mensagens
  - consumidores lêem
- mensagens organizadas em tópicos
  - sequências ordenadas e imutáveis de mensagens que são continuamente produzidas e consumidas
  - pode ser dividido em partições $\to$ durabilidade e alta disponibilidade
  - partições podem ser replicadas em diferentes servidores
    - permite a recuperação em caso de falhas
- configurar e iniciar um cluster Kafka
  - um ou mais servidores (ou brokers)
  - criar tópicos oara armazenar mensagens
    - aplicativos podem produzir mensagens
    - outros aplicativos podem começar a consumir essas mensagens
- Kafka oferece uma capacidade de "retenção"
  - mensangens não são deletadas após serem consumidas
  - período configurável de tempo
    - outros consumidores podem ler as mesmas mensagens em momentos diferentes
- interação com Kafka $\to$ por meio das APIs que o Kafka fornece
  - disponíveis em várias linguagens, incluindo Python
- Kafka possui um ecossistema em expansão de ferramentas
  - *Kafka Streams* para processamento de fluxos de dados
  - *Kafka Connect* para facilitar a interação com fontes de dados
- para a criação do servidor Spark
  - `master`
  - `history-server` $\to$ armazenar o histórico das chamadas
  - `workers` com nome dinâmico
- `env-file` $\to$ armazenar valores de variáveis de ambiente e segredos usados para configurar o servidor
