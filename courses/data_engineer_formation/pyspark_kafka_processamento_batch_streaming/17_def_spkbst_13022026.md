# Formação Engenheiro de Dados

## PySpark e Apache Kafka para Processamento de Dados em Batch e Streaming

### Multi-Node Cluster Spark, HDFS e Kafka

- toda a configuração do Kafka é feita via arquivos de configuração
- cluster HDFS + Spark + Kafka $\to$ configurado via Docker Compose
  - *datanodes* devem ser criados apenas depois do `namenode` (criação de dependências)

#### Segurança e Autenticação no Kafka

- proteger dados, e garantir a integridade do cluster
  - evitar acessos não autorizados e ataques
- mecanismos de autenticação
  - SASL (*Simple Authentication and Security Layer*)
  - SSL/TSL (*Transport Security Layer*)
- criptografia de comunicação $\to$ cada cliente possui um certificado digital que valida a identidade
- autorização $\to$ controla quais ações um cliente autenticado pode realizar
  - gerenciado por ACL (*Access Control List*)
    - produção de mensagens
    - consumir mensagens
    - criar ou excluir tópicos
    - executar operações administrativas (configuração de brokers)
  - ACLs são configuradas via CLI $\to$ permissões por tópico, grupos de consumidores ou outro recurso
