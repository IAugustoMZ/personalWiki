### PySpark para Processamento Distribuído de Dados - Parte I

#### Estratégias de Particionamento de Tabelas

- particionamento para melhorar o desempenho e a eficiência de consultas

1. **por coluna (uma ou mais)** $\to$ organização das consultas para permitir uma leitura mais rápida ao filtrar pelas colunas selecionadas
2. **dinâmico** $\to$ dados são automaticamente particionados com base nos valores de uma coluna específica durante a inserção de novos dados
3. **bucketing** $\to$ dados distribuídos em buckets, com base no valor de uma coluna de chave
   - mais equilibrado que o particionamento convencional
   - útil para JOINs e agregações
4. **particionamento hierárquico** $\to$ camadas de partições
   - útil quando os dados seguem uma estrutura lógica com base em mais de um critério
5. **intervalos de valores** $\to$ com base em intervalos definidos
   - para dos distribuídos de forma desigual
6. **combinado** $\to$ duas ou mais colunas para definir as partições
   - data e região
   - consultas mais rápidas, onde se exigem múltiplos critérios de filtro

#### Engenharia de Atributos

- transformar dados brutos em características ou variáveis que podem ser usadas para melhorar o desempenho dos modelos de ML
- criação / modificação + seleção de atributos relevantes a partir dos dados originais
   - capturar informações mais importantes para o modelo
   - tornar os dados mais representativos
- no pySpark, a variável de saída precisa ser chamada `label`
   - entradas e saídas precisam estar em formatos de vetor

#### Ajustando o número de partições

- cada partição contém uma função dos dados e é processada de forma independente
- considerações
   - distribuição dos dados: paralelização de operações
   - controle de particionamento, poucas partições sobrecarregam os nós individuais
      - muitas partições adicionam sobrecarga de gerenciamento
   - operações baseadas em partições: Spark otimiza com base no particionamento
      - redução de movimentação de dados entre nós
   - resiliência: se um nó falha, apenas as partições que estavam sendo processadas por aquele nós precisam ser reprocessadas
