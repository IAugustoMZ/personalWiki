### Multi-Node Cluster Spark, HDFS e Kafka

- uma DAG é uma estrutura que representa um conjunto de tarefas organizadas que respeita uma dependência lógica
  - define como as tarefas se relacionam
- composição de uma DAG
  - tarefas: unidades de trabalho
  - dependências: relações entre as tarefas, determinando a ordem de execução
- características principais
  - direcionada: as tarefas seguem um fluxo unidirecional sem ciclos
  - acrônica: garantia de que nenhuma tarefa possa se refletir a si mesma diretamente ou indiretamente, evitando loops infinitos
- DAGs são criadas por meio de scripts Python
- no Cassandra, um keyspace é a estrutura de mais alto nível usada para organizar dados
  - container lógico para tabelas
  - defines atributos importantes
    - fator de replicação
    - estratégia de replicação
    - número de réplicas usadas para garantir a resiliência e a disponibilidade dos dados
