# Fundamentos de Engenharia de Dados

## Estudo de Caso 1

### IaC (Infraestrutura como Código) e CI/CD

- gerenciar criação, atualização e manutenção da infraestrutura
    - scripts para ligar / provisionar / desprovisionar recursos de computação
    - mudanças rápidas e implementando as boas práticas de CI/CD
- CI/CD -> DevOps -> software é um organismo vivo
    - automação de técnicas de publicação, teste e versionamento
- para dados -> Data Ops
- Iac -> Terraform

### Custo do Pipeline de Dados

- AWS Data Lake (dados processados ou transformados)
- implementação Apache Spark / Kafka (transformação)
- Amazon ECS / EKS / Fargate (servidor modelo ML)
- construção dos modelos ML
- automação com IaC e boas práticas CI/CD
- custo de monitoramento
- referências -> sites das nuvens (Amazon, Azure, Google GCP)
