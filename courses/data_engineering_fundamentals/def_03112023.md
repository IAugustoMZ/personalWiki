# Fundamentos da Engenharia de Dados

## Ciclo de Vida da Engenharia de Dados

- *Carga e Uso de Dados*
    - Armazenamento Futuro E/OU Uso Imediato
    - Pode carregar os dados em outras plataformas
    - Geralmente uma etapa simples

- *Armazenamento*
    - Pode estar presente em múltiplas etapas do pipeline
    - Datalake (dados brutos), data warehouse, Data lakehouse
    - Muitas vezes não podemos aplicar as transformações na origem
    - Também não conseguimos manter todos os dados em memória --> Armazenamento

- *Analytics, Machine Learning, AI, Dashboards e Relatórios*
    - Uso final para gerar valor para empresa
    - Todos podem usar a mesma fonte (date warehouse) ou porções diferentes

- *Arquitetura de Dados*
    - Desenho da Solução, Seleção de Tecnologias
    - Melhoria Contínua --> Novo Software, Novos requerimentos de Negócios

- *Gestão de Dados e Metadados*
    - Permissão para usar dados?
    - LGPD/ Dados Sensíveis (Anonimização de Dados)
    - Chaves de ligação das fontes diversas
    - Quem são os data owners? Quem garante confiabilidade?
    - Metadados --> Dados sobre os dados
        - Análise
        - Busca e Indexação (Catálogo de Dados)
        - Linhagem dos Dados (Ciclo de Vida do Dado)

- *Orquestração*
    - Gerenciamento dos Pipelines de Dados
    - Equipes Diferentes
    - Agendamento, Monitoramento, Organização
    - Gestão das Dependências de Atividades
    - Gestão dos Microserviços --> Contêiners

- *Segurança*
    - Gestão de Acesso e Privilégios
    - Cibersegurança e Rede Privadas
    - Quem mantém?
    - Configuração de Alta disponibilidade?
    - Criptografia de Dados Críticos
    - Recuperação de Desastre

- *CI/CD* --> Data Ops (Operação contínua da plataforma de Dados)
    - CI => Continous integration
    - CD => Continous Delivery
    - Progresso de build automatizado para detectar problemas de código
    - **CI** => Criação e Testes automatizados
        - Controle de Versão
        - Resolução de Conflitos e Versão
        - Repositório Principal Atualizado
            - Mesclagem de Alterações
    - **CD** => Implementação para lançamento de Código
        - Desenvolvimento incremental (ciclo curto)
        - Criação e Liberação de Software. A qualquer momento
        - Requer estrutura altamente repetível
    - *CI/CD* => Criação, teste e Implementação de Código em processo contínuo
        - Evita erros manuais, fonece feedback padronizador
    - Engenharia de Dados = Solução de Software

- *Data Ops*
    - Olha para todos os pontos do ciclo de vida da plataforma de dados
    - Operação de dados --> Manter tudo funcionamento com base em boas práticas da engenharia de software

- Engenharia de Dados --> Organismo vivo em evolução
    - Novos problemas de negócio
    - Mais maturidade
    - Novas tecnologias
    - Experiência dos Profissionais
