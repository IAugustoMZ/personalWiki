# Fundamentos de Engenharia de Dados

## Arquitetura dos Pipelines de Dados

- Arquitetura --> Trata do quadro geral na solução
- Pipeline de dados sempre inicia na compreensão dos *requisitos de negócio*
    - Conhecimentp técnico --> Perecível
    - Entender qual o uso desejado para os dados no *dia-a-dia*
- Pipeline de dados --> Arquitetura de Dados --> Plataforma de Dados
    - Requisitos de Negócio, menor custo possível, segurança, flexibilidade, mudança dos requisitos no tempo
- POC --> Laboratório, simulação de cenários, validação de requisitos, teste e previsãode custos
