 # Fundamentos da Engenharia de Dados

- Engenharia de Dados
    - Transformar os dados brutosem dados *utilizáveis*
- Múltiplas fontes de dados
- Formas de Armazenamento, processamento, catalogação, enriquecimento

1. Tarefa complexa de tornar os dados brutos utilizáveis para cientistas de dados e outros grupos dentro de uma org.
    - Raramento dados estarão prontos para uso na fonte
    - Extrair --> Processar
2. Ajuda a tornar os dados mais úteis e acessíveis para os consumidores de dados
3. Processo usado para coletar e validar dados de qualidade que possam ser usados por analistas e cientistas de dados
    - Problemas de qualidade são comuns
    - infraestrutura, mineração, processamento, aquisição, modelagem, gerenciamento
- Importância dentro da ciência de dados
    - Dados são importantes para dimensionar o negócio
    - Dados são ativos corporativos
        - Estratégia
        - Previsões
        - Anomalias
        - Tomada de Decisão
    - Estratégia de engenharia de dados -> Data Drivers
    - Qualidade dos processos = qualidade dos dados

- Prós e Contras de bancos nacionais/ não-nacionais
- Soluções Batch, streaming
- Operacionalizar modelos e soluções
- Computação distribuída
- Infraestrutura de armazenamento, processamento
- Datas Lakes
- Governança e Segurança de Dados
- Técnico, computação, Linux
