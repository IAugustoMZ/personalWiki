# Fundamentos de Engenharia de Dados

## O que é um sistema distribuído?

- computadores têm uma **quantidade limitada** de processamento e armazenamento
    - limitações físicas

- sistemas distribuídos -> capacidades de armazenamento / processamento de várias máquinas
    - redes de computadores que trabalham juntos como um único sistema
    - compartilhamento de recursos e cargas de trabalho para processar volumes maiores que as limitações físicas individuais

- aplicações
    - armazenamento de arquivos
    - gerenciamento de bancos de dados
    - computação distribuída
    - aplicações web
    - computação em nuvem
    - simulações científicas

- desafio -> gerenciar múltiplas tarefas em diversas máquinas
