# Fundamentos de Engenharia de Dados

## Armazenamento e Processamento Distribuído

- trabalho do engenheiro de dados começa e termina no armazenamento e em tipos de arquivos
    - armazenamento de dados fora dos bancos cada vez mais comum -> Big Data
- onde os dados residem?
    - arquivos no armazenamento no disco físico ou outra mídia de armazenamento
- repercussão é tão importante quanto o armazenamento
- decisões orientadas pelas necessidades dos dados e padrões de acesso
    - não escolher porque é "fácil"
- preço da unidade armazenadas caiu drasticamente
    - promove negligência com o armazenamento
    - algumas alternativas
        - Data Lake
        - Data Stores
        - bancos de dados relacionais

- padrão de acesso definem o tipo de armazenamento
1. quantos sistemas precisarão de acesso à camada de armazenamento?
2. com que frequência os sistemas acessarão o armazenamento de dados?
3. qual volume de dados que esses sistemas estarão lendo?
4. quanta lógica será aplicada por esses sistemas aos dados?
5. como o sistema acessa tecnicamente os dados?

- empresa deve estar pronta para flexibilizar infraestrutura a todo momento devido à evolução dos requisitos
