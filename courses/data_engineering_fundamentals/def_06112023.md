# Fundamentos de Engenharia de Dados

## Pipeline de Dados x Pipeline ETL x Pipeline Machine Learning

- Tudo começa nos usuários de negócios usando os sistemas que alimentam bancos de dados
    - Transacionais
        - CRM
        - ERP
        - Planilhas
- Extração de Dados --> Data Lake
    - Não podemos modificar/transformar os dados no banco transacional
- Limpeza e Transformação --> Padronizaçao
    - Pode haver um data lake intermediário
- Até aqui = ETL/ELT

- *Consulta AD-HOC com SQL* => Permitir a visualização dos dados limpos no data-lake
- Processamento de Dados
    - Pode ser necessário para execução modelos de machine learning
    - Criar-se um fluxo de dados
        - WEB
        - Mobile
        - API
    - Engenharia de ML --> Previsão em tempo real
- Até aqui e pipeline de Dados
- Tudo é o pipeline de machine learning
- Geralmente o pipeline de machine learning não é trabalho de uma única pessoa

### **Comece a arquitetura do pipeline de dados por estas perguntas**

1. Quais são os requisitos de negócios?
2. Quais resultados finais são necessários?
3. Os dados estão disponíveis? Quais são as fontes?
4. Quais tipos de formato(s) de dados estão disponíveis
5. Qual crescimento esperado do volume de dados
6. Quanto de armazenamento será necessário?
7. Quanto de capacidade computacional será necessário
8. Usaremos em batch, em streaming ou ambos
9. Já temos tecnologia que permite criar os pipelines
10. Quais tecnologias devem ser consideradas?
11. Quais sçao os acordos de nível de serviço (SLA's)
12. Qual o custo de implementar e manter os pipelines?
    - Custo total de propriedade
13. Qual será o destino do pipeline?
14. Como será o monitoramento
15. Usaremos diversos pipelines encadeados?
16. Vamos criar os pipelines locais, na nuvem ou ambos?
