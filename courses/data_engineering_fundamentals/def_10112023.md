### Volume de Dados e Armazenamento

- geração = 10 MB / h ~ 120 MB / dia
- aproximadamente 30 GB / ano (12 meses de 20 dias)
- segundo semestre, teremos mais 5 máquinas
    - + 10 GB
- precisamos armazenar dados extraídos da fonte e depois do processo de limpeza e transformação
    - ~ 100 GB / ano (considerando metadados)
- temos oportunidades de melhoria ? conseguimos otimizar o armazenamento?

### Repositório de Dados

- ambiente em nuvem
- supondo AWS -> já podemos pensar em custos
    - AWS Data Lake -> armazenamento
    - AWS Glue -> catálogo de dados
    - Amazon Cloud Watch -> monitoramento

### Extração e Processamento de Dados

- extração dos dados -> sistemas de mensagens do ambiente local para a nuvem
    - Apache Kafka -> elimina a necessidade de um armazenamento intermediário
    - Apache Spark -> para processamento
- processamento dos dados no momento da extração já aplicando as transformações
    - resultados -> Data Lake -> Machine Learning
        - sistema de estoque
