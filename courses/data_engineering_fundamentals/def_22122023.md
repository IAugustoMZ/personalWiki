# Fundamentos de Engenharia de Dados

## Data Warehouse, Data Lake, e Data Lakehouse

- como implementar um data warehouse
    1. **identificação dos requisitos** -> o que será incluído no DW?
    2. **projeto e arquitetura** -> armazenamento e gestão?
    3. **integração** -> várias fontes num único local (ferramentas ETL)
    4. **construir o DW** -> hardware / nuvem + software/nuvem + esquemas de tabelas
    5. **cargas de dados** -> dados limpos e processos validando os passos anteriores
    6. **agendar atualizações** -> frequência de atualizações de dados
        - frequência x volume
        - registro histórico
    7. **acesso e segurança** -> quem vai acessar os dados?
    8. **monitoramento** -> performance e realização de manutenções regulares
    9. **usar data marts**: DW departamentais, para resolver problemas de desempenho e segurança de acesso
    10. **manutenção no modelo de dados** -> revisitar periodicamente e ajustar para refletir o cenário de negócios
