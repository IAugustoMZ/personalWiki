## O que é um Pipeline de Dados? 27/10/2023

- Meio de Mover os dados de um local (a origem) para um destino
- - Dados transformados ao longo do caminho
- - Chegam no destino de forma adequada a ser utilizados
- Pipeline = Conjunto nas etapas
- - -> Automação
- - Tornar os dados disponíveis para procedimentos de análise/ciênciaa de dados/ modelagem
- Dados Brutos --> Tabela de Preparação --> Transform (destinos)
- --
- Pode ser implementado em diversas formas/linguagens/ferramentas
- Dados ingeridos no início do pipeline(múltiplas fontes, formatos)
- Cada etapa do pipeline fornece as entradas das próximas etapas
- Complexidade depende do problema
- - Etapas independentes podem ser paralelizadas 
- Engenheiro de Dados => Construir e manter pipelines de dados
- --
## Componentes dos Pipeline de Dados 30/10/2023
- Origem -> Onde os dados originalmente estão
- - -> Levar em consideração o impacto da extração na origem
- LGPG
- Múltiplas origens, múltiplos formatos
- Processamento --> + Complexas e extensa
- Múltiplos pipelines na companhia
- - -> Depende do objeto
- - -> Cada objeto demanda uma determinada sequênciade de etapas
- Destino --> Onde vamos colocar os dados?
- - -> Datalake, Datacuanehouse, Consumo em tempo real

## Pipeline de Dados x Pipeline ETL 31/10/2023

- ETL é um subprocesso de um pipeline de dados
- - -> Imádo na época onde o destinoera uma Data Wavehouse --> Processo menos complexo
- Hoje, processos mais complexos
- Múltiplas fontes --> Mult. processamento --> Mult. destino
- Pipeline de dados é um termo mais genérico e abrangente
- - Inclui enriquecimento, segurança, orquestração, integração/entrega contínua(CI/CD)
- - Pode ter vários ETL
- - Gestão de metadados, linhagem de dados
- - Dados em Batch, streamings ou ambos
- --
## Características dos Pipelines de Dados Modernos
- Criar novas oportunidades de mercado e negócio
- Processamento de dados contínuo e extensível
- Elasticidade e agilidade de nuvem
- Acesso demoratizado e gerenciamento de autoatendimento
- Alta disponibilidade  e recuperação de desastres
