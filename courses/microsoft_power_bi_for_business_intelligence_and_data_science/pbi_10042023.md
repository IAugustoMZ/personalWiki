# Microsoft Power BI para Business Intelligence e Data Science

## Introdução

- 4 a 6 horas por semana, preferencialmente, em pequenas doses diárias
- avaliação final: 65 questões / 120 minutos / mínimo 70 % para aprovação
- Bibliografia: Learning Power BI

### **BI** 
- Business Intelligence
- transformar dados em tomadas de decisão empresariais
- relatórios e visualização
- olhar para o passado

### **Big Data**

- grandes quantidades de dados
- variedade de fontes e formatos
- big data coleta e processa dados não estruturados
    - BI mostra

### **Data Science**

- matemática, estatística, computação
- mineração de dados
- machine learning
- Inteligência artificial
- aplicações
    - segmentação de clientes
    - previsões futuras
    - identificação de anomalias
    - classificação

### **Microsoft Power BI**

- plataforma de business intelligence
- visualização e análise de dados
- relatórios e dashboards / compartilhamento
- diversas fontes de dados
- importação, limpeza, transformação e modelagem

### **Power Platform**

- automação de negócios, desenvolvimento de aplicativos
- nuvem
- baseado no Microsoft Azure
- produtos
    - *Power Automate* - automatizar fluxos de trabalho
    - *Power Apps* - criar aplicativos personalizados para web e mobile
    - *Power BI* - análise e visualização de dados
    - *Power Virtual Agents* - chatbots

### **Família Power BI**

- powerbi.microsoft.com/pt-br
- *Power BI Desktop*
    - gratuito (criação de conta é opcional)
    - limitação de manter os dashboards na máquina local
    - usado para a criação dos dashboards
- *Power BI Pro*
    - compartilhamento e outras integrações
- *Power BI Premium*
    - unificar o BI com o self-service (aplicações móveis também)
- *Power BI Mobile*
    - acesso às análises por dispositivos móveis
- *Power BI Embedded*
    - dashboards dentro de aplicações web (incorporação)
- *Servidor de Relatórios*
    - gerenciamento dos relatórios produzidos (local ou nuvem)
<br><br>
- instalação via App Store = limitações (sem notificação das atualizações)

### **Interface do Power BI**

- página inicial
    - obtenção de dados
        - muitas fontes possíveis
        - Hub de dados
        - SQL Server
        - inserir manualmente
    - relatório
    - dados
    - modelagem
    - *Dataverse*
        - ponto único de integração de dados (repositório em várias fontes)
    - fontes recentes
    - transformar dados
        - Power Query
        - várias ferramentas de transformação
        - cálculos estatísticos
        - cálculos personalizados
- Visuais
    - área do lado direito
        - 80 % das necessidades da análise de dados
        - obter mais visuais
            - precisa de email corporativo ou de estudante
        - integração com R e Python
- Opções e Configuração
    - caminhos de arquivos
    - exibir notificações de atualizações
        - não tem histórico de versões -> o download é sempre o mais atual
    - configurações regionais -> casas decimais
    - detecção de tipos
    - relacionamentos
    - dados temporais
